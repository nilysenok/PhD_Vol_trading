## Объявлено до счёта
- Сетка дат — `har.eligible` (2272), общая со всеми строками этапов 1–2 и Б. Строки с недостающими парами (нет ES-блока 252 + эмбарго 1 + 100 обучающих) на сетке не пропускаются молча: число таких дат печатается и пишется в отчёт; при ненулевом числе — отступление «↺» (ES-блок сокращается до трети пар, но не меньше 30), не более чем на первые такие даты.
- Библиотека XGBoost (hist, nthread=1, seed 42, детерминизм побитно), потеря MSE в ln, монотонность выкл.; исключения: строка I1-base (монотонность Б-base: вкл.; рядом строка I1-free — выкл.), Д-а (старый код, Б-base с монотонностью).
- Ранняя остановка (И1): последние 252 пары окна, эмбарго 1 пара, терпение 100, потолок 3000; n* = best_iteration+1; финальная модель — на ВСЕХ парах окна (t+1 <= d) с n* деревьями. s² для (б) = средний квадрат остатка предварительной модели на блоке остановки (при весах — взвешенный).
- Неоднозначности, закрытые умолчанием (отступления от дословного текста — нет, это толкование): (1) гиперпараметры И2 выбираются ОДИН раз в год на конфигурации «уровень, базовые признаки, без весов» (`fix_i2_choice.csv`) и применяются ко всем последующим строкам (И3, И4, И5, Б-1, Б-2, И6) — «при гиперпараметрах года из И2»; (2) «И1+И2+И3+И4 без весов» совпадает с «И1+И2+И3» (все строки уже с ежедневным переобучением) — отдельно не считается, строка-дубль указывает на ту же серию; (3) LOYO И2/И6: обучение на всех парах с целями < 01.01.Y кроме целевого года y, проверка — QLIKE (б) на целях года y, без эмбарго у границ (только выбор, не оценка); (4) год Y отнесён к дате цели (как срезы метрик): гиперпараметры Y действуют на даты d, у которых target_date в Y; для них данные выбора — цели < 01.01.Y; (5) Б-2 в И3: ln-признаки рынка (прокси, среднее по бумагам) нормируются на ln RV_m SBER как остальные RV-признаки; (6) ничья по критерию LOYO — |Δ| <= 1e-12.
- Критерий «исправлен» (слова блока, механически): К1 «вся выборка заметно лучше честного»: QLIKE_full(б) <= 0,95 · QLIKE_work(б); К2 «честный не хуже HAR-J(б)»: QLIKE(б) на целях 2017–2021 <= HAR-J(б) и на целях 2023–2025 <= HAR-J(б) (каждый период отдельно, пулом по дням). Допуск 0.
- Тесты утечки на каждую строку: главный (побитно при порче/обрезке баров после 18:50 дня d — на SBER и на 16 бумагах); (i) oracle QLIKE <= 0,5·рабочего; (ii) full QLIKE <= рабочего + 1e-12; (iii) perm — около RV_m ±30 % (красный допустим, как этапы 1–2, не двигать). Варианты (i), (iii) считаются при ежемесячном переобучении (как этап 2/Б), (ii) — одной моделью на всей выборке.
- Мутации (обязаны делать тесты красными): M1 финальная модель без последних 252 пар; M2 пара с t+1 = d+1 в обучении; M3 n* берётся с блока, вошедшего в обучение предварительной модели; M4 LOYO включает целевой год в обучение; M5 выбор года Y видит цели >= 01.01.Y; M6 рыночный признак использует бумагу/бар дня d+1; M7 веса возрастают с возрастом; M8 цель-прирост без возврата уровня RV_d; M9 σ̂² без s²/2 в колонке (б); M10 I6 выбирает по QLIKE на целях года Y.
