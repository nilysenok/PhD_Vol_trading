# Тесты (канон v23)

Только действующие правила v22 и плана; новых нет.

1. Новый код шага — тест на синтетике + подложенная ошибка (мутация), которую тест обязан поймать. Без прошедшего теста PR не сливается. Источник: `docs/zadaniya/2026-10-27_razrabotka_strategiy_v3.md`, строка 185.
2. Проверяющий — отдельный от автора, с подложенными ошибками на новый код каждого шага; пишет их в отдельной копии (`orkestratsiya.md`, абзац 3). Источник: `docs/zadaniya/2026-10-27_razrabotka_strategiy_v3.md`, §0.8 (строка 61). Формулировка «только в памяти» в источниках не найдена — уточнить у владельца.
3. Аудит кода — тест на синтетике + подложенная ошибка, правки отдельными PR. Источник: `docs/zadaniya/2026-10-25_pereschet.md`, строка 412.
4. Тест проверки сдвига: допуск ε = 0,01 для плоских профилей; ряд с подложенной утечкой обязан блокироваться. Источник: `docs/zadaniya/2026-10-25_pereschet.md`, строка 217.
5. Код денег и критерия — тест, который падает до правки («попробуй сломать»: пустая лента, дыра, нулевой объём, перепутанный знак); честная половина — в тесте перебора. Источник: `.claude/agents/kodir.md`, пункт «Тесты».
6. Тест в сеть не ходит. Источник: `.claude/agents/kodir.md`, пункт «Код».
7. Автор реализации тесты не меняет (`orkestratsiya.md`, абзац 3); тест, падающий без правки, — в каждом PR на данные/кэш/умолчания (`pravki.md`, п. 12).

Указатель (Ж-020): обязательные мутации по темам и тесты-образцы — `mutations.md`; правило мутаций для каждого PR пайплайна — `proverka.md` п. 1.
