13. Главный файл канона — короткий (до 150 строк): роли, запреты, порядок работ, указатели. Подробные правила — отдельными файлами в .claude/rules/ по темам (полнота, оркестрация, данные, тесты, отчёты); задание агенту ссылается на нужные файлы, а не на весь канон.
14. Журнал решений владельца — отдельный файл только для записи (append), с номером и временем каждого блока; главная сессия подтверждает приём блока его номером. Блок без подтверждения считается не дошедшим.
