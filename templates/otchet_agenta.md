# Отчёт агента — шаблон (канон v23, `polnota.md` п. 11–13; `svyaz.md` п. 4)

Ответ главной сессии — не длиннее 500 слов (`orkestratsiya.md`); остальное — в файл отчёта, в ответе — путь. Результат — первой строкой. Свою ошибку — первой строкой. Числа перемерены в момент написания, источник у каждого.

```
# <Задача> — <агент>, <дата ЧЧ:ММ>

<Результат одной строкой: готово / передача. «Готово» запрещено при незакрытых, отложенных или ABANDON-гейтах.>
Реестр гейтов: закрыто N из M; ABANDON: k; pending: p

## Сделано
- <файл / PR — что>

## Не сделано и почему
- <ABANDON-гейты и причины; первой строкой, если есть>

## Проверено (команда → вывод)
- <CHECK-команда> → <фактический вывод>, код возврата 0

## Отступления
- <отступление от задания: сетка, выборка, число повторов, метод, пропущенный шаг; причина; до выводов>

## Требует решения владельца
- <вопрос · варианты · умолчание · срок>

## Канон
- гарантии: <что не ломается — имя_теста>

## Расход
токены агента: <число, до передачи>; время: <мин>
```

Без пересказа задания и общих слов. Для PR: тот же состав в теле PR (раздел «## Канон» читает писарь).
