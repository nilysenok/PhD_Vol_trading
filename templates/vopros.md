# Вопросы владельцу — шаблон (Ж-025, п. 1.3 [Ш]; Ж-026, ось 29)

Правила:
- В одном сообщении не больше трёх вопросов.
- У каждого вопроса: номер, класс, варианты, умолчание, срок («если нет ответа до T — делаю X»).
- Спрашивается только класс A (необратимое и предрегистрационное: открытие, эталон, гипотезы, комиссия, деньги, ключи, заявки бирж). Класс B — дирижёр решает сам и пишет в `docs/resheniya/tolkovaniya.md`; класс C — без записи.
- Вопросы класса A — пакетом, не чаще раза в 2 часа, кроме блокирующих. Блокирующий — без умолчания, помечается `❓!`. Вопросов владельцу за сутки не больше 5.
- Деньги, ключи, заявки и необратимое умолчанием не закрываются.
- Нет ответа до срока — в дело идёт умолчание, в канон блока пишется `↺ — что · откат: как (ДД.ММ)`, вопрос уходит в `arhiv.md` строкой «по умолчанию».
- Ответ владельца записывается в `docs/resheniya/resheniya.md` блоком с номером Ж-NNN и квитанцией.

## Шаблон сообщения

```
Вопросы владельцу (Ж-NNN), ДД.ММ ЧЧ:ММ — всего N (≤ 3)

В1 (класс A). <вопрос одной фразой, по существу, без жаргона>
   Варианты: а) … / б) …
   Умолчание: а) — <что делаю, если ответа нет>
   Срок: ДД.ММ ЧЧ:ММ (если нет ответа — делаю умолчание)
   Почему вам, а не мне: <необратимое / предрегистрация / деньги>

В2 (класс A). …
В3 (класс A). …
```

Строка в файле блока: `❓ ДД.ММ текст · варианты: a / b · умолчание: a · срок: ДД.ММ (кому)`.

## Пример

```
Вопросы владельцу (Ж-NNN), ДД.ММ ЧЧ:ММ — всего 1 (пример оформления, не действующий вопрос)

В1 (класс A). Открывать ли тест главы 4 после закрытия разработки?
   Варианты: а) открыть одним запуском / б) подождать FINAL v2
   Умолчание: нет (блокирующий, `❓!`) — без ответа не открываю
   Срок: ДД.ММ ЧЧ:ММ
   Почему вам, а не мне: открытие теста необратимо.
```
