## 3. Метрики

Ряд — дневная избыточная доходность портфеля над ставкой ЦБ: `excess = total − rf·cal`, ставка ЦБ за календарные дни [d, следующий торговый день) [аудит FA, Н2; `s9.Engine._finish`, `msp.cal_days`]. Годовая шкала √252, ddof = 1 [Д7].

**Основная метрика (одна, объявлена до взгляда):** итоговый mSR за 2020–2021 по дневному ряду после комиссии 0,04 % за сторону и платы за шорт 5 % годовых по Ж-089 [Ъ Ж-090 п. 1, Ж-088 п. 5, Ж-089]:
- mSR = mean(r)·252 / mVaR₉₅, mVaR₉₅ = −(mean + z_cf·sd)·√252, z_cf = z + (z²−1)S/6 + (z³−3z)K/24 − (2z³−5z)S²/36, z = −1,645, S — асимметрия, K — избыточный эксцесс [`semya_E.md` §6; толк. [Ж-025 §6]: mVaR в дневной шкале ·√252]; функция `metriki_e.msr`;
- mSR не определён (mVaR ≤ 0) — стратегия validation не проходит, подмены на Шарп нет [толк. [Ж-043] п. 1].

**Ворота-метрики:**
- **PSR** — P(SR > 0) по Бейли–Лопесу де Прадо: `sweep_drivers.psr(sr_d, 0, T, skew, kurt)`, SR в дневной шкале, T — число дневных наблюдений validation, kurt — обычный (K + 3) [Ъ Ж-044; толк. [Ж-025 §6]].
- **Δ по Ледуа–Вольфу** — Δ = разность табличных Шарпов (ddof = 1) [Д7, #279], p — студентизированный круговой блочный бутстрап, блок 5, 10 000 повторов, двусторонний (`s9_stats.lw_sharpe_diff`, v3 §0.3). База Δ:
  - Sk′ — против «A_strogaya только Sk» [Ъ Ж-086 п. 2];
  - A′ — против A_strogaya [Ъ Ж-086 п. 2];
  - C / D / E — против своей базы (A′ или A_strogaya) при тех же сигналах [Ъ Ж-088 п. 2].
- **к2** — p = доля сдвигов с Шарпом ≥ фактического, односторонний (v3 §0.3).

**Справочно (в отбор и ворота не входят):** Шарп, Сортино, Кальмар, MDD, Omega(0), FKO, оборот, доля исполненных лимиток, mSR по годам 2020 и 2021, Δ mSR, DSR(N) с N из реестра отбора [Ъ Ж-044 «DSR справочно»]; комиссия 0,035 %; плата за шорт 0 / 10 / 15 %; ставка T+1 для ФДР (если точка с `fdr`).

## 4. Комиссия и правила исполнения (одни для train, validation и test)

- Комиссия 0,04 % за сторону — основная; 0,035 % — вторая колонка, N не увеличивает [толк. [Ж-031, #304/#308]]. Лимитные и рыночные — одна ставка.
- **Плата за шорт** [Ъ Ж-088 п. 5, Ж-089]: только за перенос через ночь. Позиция открыта и закрыта в один торговый день — 0; иначе 5 % годовых × стоимость короткой позиции × календарные дни от даты входа до даты выхода (выходные и праздники включаются). Справочно — 0 / 10 / 15 %. Плата — не ось и не выбирается. Стоимость — вес позиции на 18:50 [умолч.; ❓ 7].
- Дивиденды: в PnL D × 0,87 (НДФЛ 13 %) на день гэпа; сигналы — на ряду с поправкой; стоп через отсечку сдвигается на D [Ъ Ж-059, Ж-060].
- **Основная строка — без цены закрытия, по которой решение принимается по сигналу того же дня** [Ъ Ж-086 п. 1; обязательно для C, D, E, контролей и бенчмарков главы 4 — Ъ Ж-088 п. 4]:
  - вход `rynok` — open d+1; лимитки `k_e` на d+1 — без изменений;
  - выход по сигналу — open x+1, 15:00 x+1, 17:00 x+1; выход по τ — по тому же `t_vyhod`, что у точки;
  - close x и `rynok` по close d — справочные строки; из них ничего не выбирается.
- **Время open** [Ъ Ж-086 п. 4; толк. [Ж-086 п. 4]]:
  - (а) «open d+1» и «open x+1» — open 5-мин бара, начинающегося в 10:00;
  - (б) «15:00 x+1» и «17:00 x+1» — open 5-мин бара, начинающегося в 15:00 / 17:00;
  - (в) лимитки `k_e` на d+1 — без изменений;
  - запасное правило: бара ровно в hhmm нет — open первого бара позже hhmm того же дня; таких нет — open бара 10:00 следующего торгового дня, а если нет и его — первого бара позже 10:00. Случаи считаются.
  - Правило одно для train, validation и test и после прохода 1 не меняется.
- Справка регламента (исследователь, #452, только документы биржи): непрерывные торги с 10:00, аукцион открытия 09:50–10:00, бар 10:00 есть во все годы; с 06.12.2021 у бумаг утренней сессии аукциона 09:50 нет — правило (а) не меняется.
- Внутри дня (Ж-047 п. 5, `semya_E` §2): лимит и тейк — при проходе на тик сквозь уровень, касание не исполняет; стоп — по цене стопа или хуже, при гэпе — по open; стоп и тейк в одном баре — первым стоп.
- Дневные позиции (A_strogaya, C, D): решение close t исполняется по open 10:00 t+1; ночь держит прежняя позиция, день — новая (контракт `strogoe` v1.0, план раздел 3).
- Конец окна validation (30.12.2021, цен 2022 нет): позиция оценивается по close 30.12.2021, комиссия выхода берётся, токен `konec_dannyh` [умолч.; ❓ 11].
- Ставка на свободный капитал, маржа (КС + 2 %) сверх 100 % — как в движке (`s9.Engine._finish`); при L = 1 маржи нет.

## 9. Открывается ли тест и в каком объёме

Решение — класс A, за владельцем [Ж-028]. Ниже — умолчание архитектора с основанием; без «да» владельца оно не действует.

- **Умолчание:** тест открывается одним открытием **при любом исходе** этапа 1 и validation [основание: Ж-088 п. 1 «любой из трёх исходов — результат главы»; прецедент 26.10 п. 13 — «для B — лучшая по С8, даже если не прошла, с пометкой»].

- **Альтернатива:** открывать тест только для объектов V-а и V-б (и баз), а при «все V-в» — не открывать, глава — отрицательный результат разработки (❓ 10).
