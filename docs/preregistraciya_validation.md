## 3. Метрики (две везде)

Ряд — **дневной PnL всего капитала, включая внутридневные сделки**; избыточная доходность над КС по календарным дням [d, следующий торговый день); дни без позиций входят с доходностью = ФДР, избыточная 0 [Ъ Ж-103 п. 1, 4; `s9.Engine._finish`, `msp.cal_days`]. Годовая шкала √252, ddof = 1 [Д7].

**Пороговая метрика (одна, объявлена до взгляда):** итоговый **mSR** за 2020–2021 после комиссии 0,04 % за сторону и платы за шорт 5 % годовых по Ж-089 [Ъ Ж-090 п. 1, Ж-102 п. 4]:
- mSR = mean(r)·252 / mVaR₉₅, mVaR₉₅ = −(mean + z_cf·sd)·√252, z_cf = z + (z²−1)S/6 + (z³−3z)K/24 − (2z³−5z)S²/36, z = −1,645, S — асимметрия, K — избыточный эксцесс [`semya_E.md` §6; толк. [Ж-025 §6]]; `metriki_e.msr`;
- mSR не определён (mVaR ≤ 0) — validation не пройдена, подмены на Шарп нет [толк. [Ж-043] п. 1].

**Интерпретируемая метрика — рядом, в каждой таблице** [Ъ Ж-102 п. 4, Ж-103 п. 1]: **Sharpe** = mean(r)/sd(r)·√252 по тому же ряду (тот же капитал, та же избыточная над КС, ddof = 1). Порогов по Sharpe нет. Рядом — разрыв mSR − Sharpe и его источник: skew и избыточный эксцесс дневных доходностей [Ъ Ж-102 п. 1].

**Справочно** [Ъ Ж-103 п. 1, 2, 4]:
- Sharpe по PnL только торговой компоненты (без ФДР);
- «Шарп в деле» — по дням с позицией;
- разложение дневной доходности на внутридневную (open→close) и ночную (close→open) части с долей дисперсии каждой — по категориям.

**Ворота-метрики:**
- **PSR** — P(SR > 0): `sweep_drivers.psr(sr_d, 0, T, skew, kurt)`, SR в дневной шкале, T — дневные наблюдения validation, kurt обычный (K + 3) [Ъ Ж-044].
- **Δ по Ледуа–Вольфу** — Δ = разность табличных Шарпов (ddof = 1) [Д7, #279]; p — студентизированный круговой блочный бутстрап, блок 5, 10 000 повторов, двусторонний (`s9_stats.lw_sharpe_diff`). База Δ: МСП и A′-базовая — против A_strogaya [Ъ Ж-086 п. 2]; C/D/E — против своей базы при тех же сигналах [Ъ Ж-088 п. 2].
- **к2** — p = доля повторов с Шарпом ≥ фактического, односторонний.

**Прочее справочно:** Сортино, Кальмар, MDD, Omega(0), FKO, оборот, доля исполненных лимиток, mSR и Sharpe по годам 2020 и 2021, по фазам (6 строк) [Ъ Ж-099 п. 6], вклад семейств в риск и доход, DSR(N) с N по МСП [Ъ Ж-099 п. 7]; комиссия 0,035 %; плата за шорт 0 / 10 / 15 %.

## 4. Комиссия и правила исполнения (одни для train, validation и test)

- Комиссия 0,04 % за сторону — основная; 0,035 % — вторая колонка, N не увеличивает [толк. [Ж-031, #304/#308]].
- **Плата за шорт** [Ъ Ж-088 п. 5, Ж-089]: только за перенос через ночь; вход и выход в один торговый день — 0; иначе 5 % годовых × стоимость короткой позиции × календарные дни от даты входа до даты выхода. Справочно 0 / 10 / 15 %. Не ось. Стоимость — вес на 18:50 [умолч.; ❓ 8]. Реализация — `fastbt/zaem_v2.py` (паспорт A_strogaya).
- Дивиденды: D × 0,87 на день гэпа; сигналы — на ряду с поправкой; стоп сдвигается на D [Ъ Ж-059, Ж-060].
- **Основная строка — без цены закрытия, по которой решение принимается по сигналу того же дня** [Ъ Ж-086 п. 1; для C, D, E, контролей и бенчмарков — Ъ Ж-088 п. 4]: вход `rynok` — open d+1; лимитки `k_e` на d+1 без изменений; выход по сигналу — open x+1 / 15:00 x+1 / 17:00 x+1; τ — по `t_vyhod` точки; close — справочно.
- **Время open** [Ъ Ж-086 п. 4; толк. [Ж-086 п. 4]]: (а) open 5-мин бара 10:00; (б) open 5-мин бара 15:00 / 17:00; (в) лимитки d+1 без изменений; запасное правило — первый бар позже hhmm того же дня, иначе бар 10:00 следующего торгового дня. Одно правило для train, validation, test.
- Ось «закрытие к 18:45 при отсутствии подтверждения» (Ж-103 п. 2), если включится: по какому бару и цене — ❓ 10.
- Внутри дня: лимит и тейк — проход на тик; стоп — по уровню или хуже, гэп — по open; стоп и тейк в одном баре — первым стоп [Ж-047 п. 5].
- Конец окна validation (30.12.2021, цен 2022 нет): оценка по close 30.12.2021, комиссия выхода берётся, токен `konec_dannyh` [умолч.; ❓ 12].
- ФДР по КС на свободный капитал; маржа КС + 2 % сверх 100 % — при плече ≤ 2 у МСП маржа есть [Ъ Ж-093 п. 3, Ж-099 п. 5].
