## 4. Метрики

**Ряд** — дневной PnL всего капитала, включая внутридневные сделки; избыточная доходность над КС по календарным дням; дни без позиций — с доходностью = ФДР, избыточная 0; √252, ddof = 1 [Ъ Ж-103 п. 1, 4; Д7].

**В каждой таблице — все четыре метрики** [Ъ Ж-111 п. 16]:
1. **Шарп дневной — основная метрика отчёта.**
2. Шарп по 3-дневным и недельным доходностям: суммы дневной избыточной доходности по неперекрывающимся блокам из 3 торговых дней и по календарным неделям; масштаб √(252/3) и √52, ddof = 1 [умолч.; ❓ П-3].
3. **mSR** (Корниш–Фишер): mSR = mean(r)·252 / mVaR₉₅; z = −1,645; mVaR ≤ 0 → «не определён», подмены на Шарп нет [толк. [Ж-043]; `metriki_e.msr`].
4. «Шарп в деле» — по дням с позицией [Ъ Ж-103 п. 4].

**Рядом** [Ъ Ж-102 п. 1]: разрыв mSR − Шарп, skew и избыточный эксцесс дневных доходностей. **Снят** «Шарп без ФДР» [Ъ Ж-106].

**Разрезы** — справочно, N не увеличивают:
- по годам, по 6 фазам (2015 — отдельной строкой; месяцы «без фазы» помечены) [Ъ Ж-113 п. 4];
- по категориям; лонг и шорт;
- овернайт-разложение: доли дисперсии и дохода [Ъ Ж-103 п. 2];
- вклад Sk в риск и доход; число ставок в год;
- Сортино, Кальмар, MDD, оборот, доля исполненных заявок.

**Какая метрика для чего — объявлено здесь, до hold-out** (`otbor_statistika.md` п. 8):

| для чего | метрика |

| пороги разработки | mSR [Ъ Ж-102 п. 4, Ж-111 п. 17] |

«A′» в H-3 и H-4 — A′-расширенная [умолч.; ❓ П-2].

- **Статистика:** Δ = разность табличных дневных Шарпов (ddof = 1) [Д7, #279]. p — студентизированный круговой блочный бутстрап Ледуа–Вольфа, блок 5, 10 000 повторов (`s9_stats.lw_sharpe_diff`); блок 21 — справочная колонка (↺ в начале).
- **Направление объявлено:** H₁: Δ > 0. p односторонний [умолч.; ❓ П-7].
- **Холм:** p₍₁₎ ≤ … ≤ p₍₅₎; гипотеза i отвергается, если p₍ⱼ₎ ≤ 0,05 / (5 − j + 1) для всех j ≤ i; уровень семьи — 0,05.

  - абсолютные Шарп и mSR каждого объекта;
  - все метрики раздела 4;
  - S1–S12 отдельно, E, лестница σ̂, контроли;
  - комиссия 0,035 %, плата за шорт 0 / 10 / 15 %.
- **Ничего не перевыбирается:** на hold-out выбора нет, точки — последнего окна walk-forward (2015–2024) [Ъ Ж-112 п. 5].
