- **N_k** — число различных `klyuch_n` семейства по всем ledger всех версий (zh047, v5, v6, v7) и периодов, роли `sobol`, `morris`, `faza2`, `faza3`, плюс пробы семейства из реестра отбора (`otbor_statistika.md` п. 4) и голых идей S8–S12. Роли `kontrol`, `spravka` — вне N (`ledger_v2.VNE_N`); точка на разных периодах — одна проба. Справочно — N только v7 и N по всем семействам.
- Прирост от v3 (оценка): s1 ≈ 0,86 млн + второй seed ≈ 0,14 млн + Моррис 0,045 млн ≈ **1,05 млн**.

### 4.2. PBO — для каждого семейства и для МСП
- Матрица семейства — точки с ledger на всей истории (s1, второй seed, Моррис v7, к3) × 36 кварталов (В-16). Точки zh047/v5/v6 на train4 — в N, не в матрице (нет кварталов 2020–2025).
- Правило выбора внутри CSCV — процедура §3 на IS-половине (Ж-080, мутация № 42), «годы» → блоки IS: доля блоков с Sharpe > 0 ≥ ⌈7/9·4⌉ = 4 из 4 [В-22 · умолчание дирижёра, класс B: доля 7/9 переносится на блоки, вверх], медиана > 0, режимы и сделки — на днях IS, плато — по знаку Sharpe IS. ω — ранг OOS-Sharpe выбранной точки среди канонических / (n + 1), λ = ln(ω/(1 − ω)), PBO = доля λ ≤ 0 среди непустых разбиений; непустых < 35 из 70 — «не определено». Справочно — PBO с argmax.
- МСП [В-23 · умолчание дирижёра, класс B]: матрица — варианты МСП (λ ∈ {0; 0,5; 1} × обе A′ = 6) × 8 блоков, правило — argmax Sharpe IS; при < 10 столбцах — пометка «мало столбцов, формально».
- PBO и DSR печатаются обязательно, воротами не являются (У-15 v2).

### 4.3. DSR для каждой устойчивой области
Для медианной точки каждой области из ≥ 5 точек: `metriki_e.dsr(r, n = N_k, v = V[SR])`, r — дневной ряд точки 2017–2025 (пересчёт с записью ряда), V[SR] — дисперсия итоговых Sharpe канонических точек матрицы §4.2 семейства. Мутация № 14 обязательна.

### 4.4. Таблица «ширина устойчивой области: сигнал против контролей»
По семейству (`"v": 1`, `okno` 2017–2025, `lag` d+1, `oos` net): строки — сигнал (префикс 2¹⁴ seed 1), второй seed (2¹⁵), к2 ×2, плацебо входа ×2, сигнал на всём s1 (справочно), фиксированная точка; столбцы — канонических, устойчивых % (ширина), точек в основной области, медианный Sharpe области. Описательное правило: устойчивость — не артефакт объёма сетки, если ширина сигнала больше максимума четырёх контролей; p не считается (4 повтора дают p ≥ 0,2). Рядом — строки «цена дивидендной ошибки» и «цена утечки окна» из #570 (`docs/tables/tabl_4_a_razlozhenie.csv`, У-38 v2).

## 5. МСП и гипотезы [Ж-155 п. 5]
- МСП v7 = медианные точки семейств с непустой основной областью → фазы (λ ∈ {0; 0,5; 1}) → обе A′. Прогнозные контроли HAR-J (б) и наивная √RV — справочные строки. λ = 1 против 0 и A′ против A_strogaya — справочно, вне m.
