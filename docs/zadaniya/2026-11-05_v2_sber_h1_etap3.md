## Умолчания дирижёра (класс B)
- Г0. Факт этапа 2 (дирижёр проверил): деревья не экстраполируют — в 2022 σ̂² бустинга ≤ 21 (%²) при RV до 3520, 10 дней 2022 дают 87–91 % годовой потери; лучшая строка этапа 2 по QLIKE (б) за весь период — `xgb_mse_nohar_mono_b` (0,3193). «Лучший бустинг» в Г1/Г3 — эта строка (выбор по оценочному периоду, так велит блок; пометка «выбор на оценочном периоде» в таблице).
- Г1 — ЗАМЕНЁН строкой Б-1 (Ж-198); абзац ниже не исполнять, оставлен для истории. Остаток: цель e_{t+1} = ln RV_{t+1} − ln HAR-J(а)_t, где HAR-J(а)_t — PIT-прогноз этапа 1 с дня t (OLS-остаток вне выборки, среднее ≈ 0). f — бустинг той же библиотеки, потери и замороженных гиперпараметров, что лучшая строка, признаки без HAR-признака; монотонность выключена (остаток не обязан быть монотонен по уровню; чувствительность — с монотонностью, одной строкой при c = 1). Расписание переобучения, ранняя остановка (252 пары, эмбарго 1) — как в этапе 2. σ̂² = HAR-J(б)_d · exp(c · f(x_d)), c ∈ {0,5; 0,75; 1} — три строки.
- Г2. Строки этапа 2 с HAR-признаком (б) — переносятся как есть; лучшая из 8 — строка «Г2».
- Г3. ln σ̂² = w_d · ln B_d + (1 − w_d) · ln H_d, B — лучший бустинг (б), H — HAR-J(б). w_d ∈ {0; 0,1; …; 1}, выбирается в день d по минимуму QLIKE на последних 252 закрытых прогнозах (цели ≤ d); до набора 252 — w = 0. Ряд w_d — в таблицу.
- Г4. Стресс-индикатор дня d: (RVI_d > медиана RVI по датам < d) ИЛИ (RV_w,d > 2/3-квантиль RV_w за 252 предыдущих годных дня, без d). RVI ≥ 2022 закрыт (❓ владельцу), поэтому после 2021 — только условие RV_w; в отчёте — доля стрессовых дней по годам. Спокойный эксперт — лучший из Г1–Г3 по QLIKE за весь период (выбор на оценочном периоде, пометка). Жёсткая смесь: стресс → HAR-J(б), иначе спокойный. Логистическая: ln σ̂² = π_d · ln H + (1 − π_d) · ln C, π_d = σ(a + b · z_d), z_d = ln RV_w,d − ln q67_d (одна переменная на весь период, чтобы 2017–2021 и 2022+ считались одинаково); a, b — минимум QLIKE на закрытых прогнозах (цели ≤ d), переоценка раз в месяц, до 252 закрытых — жёсткая смесь.
