1. Параметр периода в s9 (`YEARS`, `VAL_START`, окна) и в `ekviv_s9.WINDOWS`. **Умолчание — побайтно прежнее.** Эталоны `final3` зелёные — гейт.
2. Путь A не зависит от σ-прогнозов. На `train4` s9 должен строить A и «A только Sk» **без** загрузки `SOURCES` (σ_pred, HAR-J, наивная) — или загружать их лениво, только для B/C/D. Если B/C/D на `train4` невозможны — отказ с понятным текстом, а не тихий пропуск.
3. `etap1.anchor_s9_diff(..., period=)` — цикл по годам периода. **Не трогай `digest`**: это правка К-кл, PR #411.
4. Данные 2015–2016: бары, дивиденды 2015–2016 (#394), ставка 2013+ (#397), корп. события — уже есть. Проверь, что s9 читает их с 2015.
