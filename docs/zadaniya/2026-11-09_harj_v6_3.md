## Как считать (уточнения)
- **Шок дня** — бар k* с наименьшей r_j.
  - ρ1 = (n − k*)/n.
  - ρ2 = (P_n − P_{k*}) / (P_0 − min P), где P — нормированная кумулятивная доходность из подписи. Если знаменатель 0 (нет падения ниже открытия), ρ2 = 0; число таких дней — строкой отступления.
  - ρ3 = ln((RV после k*, на бар) / (RV до k*, на бар)), бар k* — в «до». Если «до» или «после» пусто (k* первый или последний бар), ρ3 = 0; число таких дней — строкой отступления.
  - ρ4 — доля объёма баров после k*.
  - ρ5 = ln(RS⁻ второй половины / RS⁻ первой половины). Пустую половину заменить малым ε = 1e-12·RV_d и записать отступлением.
  - ρ6 — число баров с |r| > 3·√(RV_d / n).
- **Слияние.** На закрытых парах 2015-07-07 … 2016-12-29 считается |корреляция Пирсона| каждого ρ с каждым из 12 признаков Σ. ρ с |корреляцией| > 0,8 исключается из R до счёта E1. Решение — автоматически, в `R_MERGE.csv`.
- **Обращение времени.** Траектория дня в обратном порядке баров, приращения с обратным знаком (стандартное обращение пути: X̃(t) = X(1−t) − X(1)). Признаки пересчитываются той же функцией. Это только диагностика.
- **E3** — по правилу плана: считается, если (E1 или E2 против A0) и (A1 или A2 против A0) несут новую информацию. Решение — автоматически по таблицам.
- **Обучатели, сетка λ, параметры GBM, clip, переоценка** — те же, без изменений.
