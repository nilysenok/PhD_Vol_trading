# HAR-J HYBRID V4 — АДРЕСНАЯ ДОРАБОТКА ПО ПРОМЕЖУТОЧНЫМ РЕЗУЛЬТАТАМ

## 1. Исходная ситуация

По текущему отчёту:

- C1 улучшает QLIKE относительно HAR-J на 3,6% по полной истории;
- C1 улучшает XGBoost на 0,5%, LightGBM на 0,15%;
- относительно LGBM-D2 выигрыш 0,7%;
- на периоде 2022–2025 C1 проигрывает самостоятельным бустингам;
- на SBER лучший C4 даёт QLIKE 0,2101;
- исторический ориентир SBER 0,2081 пока не достигнут;
- статистически подтверждённого преимущества после множественных проверок нет.

Главная исследовательская задача — установить, почему модель не обеспечивает устойчивого преимущества относительно самостоятельных XGBoost и LightGBM, и разработать механизм адаптации.

**Не закрывать программу после первого неудачного варианта. Но не искать положительный результат бесконечным перебором.**

## 2. Завершить текущие расчёты

Сначала завершить уже запущенный C-b:

- GAM;
- монотонный вес;
- малый QLIKE-бустинг;
- два мягких режима;
- три эксперта;
- индивидуальная чувствительность тикеров.

Не запускать эти варианты повторно.

После завершения выполнить анализ результата по годам и определить, насколько проигрыш 2017 года обусловлен стартовым весом 0,5.

Затем продолжить утверждённый этап E — калибровку смещения.

Все дополнительные исследования проводить внутри действующего общего лимита 60 конфигураций, с учётом уже использованных испытаний.

## 3. Cold Start Correction

Проверить гипотезу о недостаточной истории для выбора весов в 2017 году.

Рассчитать потери от:

- фиксированного стартового веса 0,5;
- лучшего допустимого априорного веса, сформированного на данных до 2017 года;
- панельного prior с shrinkage;
- постепенного увеличения веса индивидуальной информации по мере её накопления.

При наличии корректных PIT/OOF-прогнозов за 2016 год использовать их без изменения оценочной выборки.

Если таких прогнозов нет, не создавать псевдоисторию.

Обязательно показать результат 2017 года отдельно и проверить, не является ли улучшение по всей истории механическим устранением единственного неудачного года.

## 4. Negative Transfer Protection

Разработать механизм защиты гибрида от периодов, когда добавление HAR-J ухудшает прогноз относительно самостоятельного ML.

Использовать два конкурирующих прогноза:

- прогноз ML;
- прогноз гибрида HAR-J + ML.

Оценивать их условное преимущество исключительно по прошлым прогнозным ошибкам.

Разрешить:

- уменьшение веса HAR-J;
- возвращение веса при появлении новых признаков дополнительной информации;
- непрерывное изменение веса вместо жёсткого переключения;
- регуляризацию частоты и величины изменений.

Не навязывать положительный минимальный вес HAR-J, если это искусственно ухудшает QLIKE. При этом отдельно доказать, что HAR-J действительно добавляет информацию хотя бы в определённых рыночных состояниях.

Если её вклад систематически равен нулю, честно признать отсутствие дополнительной ценности гибрида.

## 5. Conditional Loss Differential

Сформировать исторический дифференциал:

`D_t = QLIKE(HARJ_t) - QLIKE(ML_t)`

Положительный D означает преимущество ML относительно HAR-J.

На прошлых наблюдениях оценить условное математическое ожидание D в зависимости от:

- величины и направления расхождения прогнозов;
- последних ошибок;
- уровня RV;
- динамики RV;
- внутридневной концентрации RV;
- рыночных сюрпризов HAR-J;
- времени после структурного изменения.

Проверить, возможно ли преобразовать прогноз условного дифференциала в устойчивые веса гибрида.

Прямое обучение весов по итоговому QLIKE обязательно оставить контрольной альтернативой.

Никаких меток будущего дня в признаках.

## 6. Robust QLIKE Calibration

Для фиксированного положительного прогноза f использовать аналитическую калибровку:

`a = mean(RV_actual / f)`

на разрешённой предыдущей обучающей истории.

Проверить:

- глобальную панельную калибровку;
- годовую калибровку;
- экспоненциальное забывание;
- иерархическую калибровку с частичным объединением;
- ограниченную адаптацию после рыночных скачков.

При расчёте коэффициента обязательно исключать будущие даты.

Не подменять простую корректировку систематического смещения чрезмерно сложной state-space моделью без дополнительного выигрыша.

## 7. Диагностика недостатка информации

По каждому году установить:

1. Когда HAR-J действительно лучше ML?
2. Когда ML уже полностью воспроизводит её информацию?
3. Когда обе модели одновременно недооценивают RV?
4. Когда обе одновременно переоценивают RV?
5. В каких случаях оптимальное выпуклое объединение вообще способно снизить ошибку?
6. Требует ли дальнейшее улучшение выхода за диапазон прогнозов?
7. Какие новые признаки помогают в этих случаях?

Особый приоритет — 2022–2025, но этот период использовать для диагностики, а не повторного подбора с последующим объявлением независимого OOS.
