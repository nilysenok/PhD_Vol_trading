## Как считать (уточнения)
- **Площади.** A_ij = ½ Σ_{k<l} (ΔX_i,k ΔX_j,l − ΔX_j,k ΔX_i,l) по барам основной сессии дня, X_0 = 0. Нормировка каналов — как в плане (на итоги своего дня). Если в дне RS⁻ = 0 или Vol = 0, канал N или Q этого дня равен 0, и это строка отступления с числом таких дней.
- **5-дневное среднее.** По 5 сессиям ≤ d.
- **Σ³.** Логарифм подписи 3-го порядка по (τ, P, V), координаты в базисе Линдона (8 слов длины 3 над 3 буквами). Реализация — своя, без внешних пакетов. Проверка — на синтетике через прямую подпись (G17).
- **Сводка S, обучатели, сетка λ, параметры GBM, clip, переоценка** — те же, что в листе 1a, без изменений.
- **«Новая информация»** — строго п. 2.2 плана, на целях 2017–2021. Решение по A3 — автоматически из `A_INFO.csv`, без ручного выбора.
- **DX-A** — диагностика задним числом: никакой её результат не используется для выбора признаков или параметров A1–A3. Это строка в отчёте.
