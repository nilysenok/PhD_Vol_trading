## Умолчания (класс B, дирижёр)
- О1. Основная сессия: бары с `begin` в [10:00, 18:40] (последний бар закрывается в 18:50). Утренняя и вечерняя сессии отбрасываются. День годен, если таких баров ≥ 30; иначе исключается (список: дата, число баров — в отчёт).
- О2. Внутридневные доходности: r_1 = ln(close_1/open_1), r_i = ln(close_i/close_{i−1}) для i ≥ 2 (ночной гэп не входит). RV_d = Σ r_i²; BV_d = (π/2) Σ_{i≥2} |r_i||r_{i−1}|; J_d = max(RV_d − BV_d, 0).
- О3. Ряд — только годные дни. RV_w, RV_m — среднее уровней RV за последние 5 и 22 годных дня, включая d. Остановка 28.02–24.03.2022 включительно — пропуск без склейки: окна RV_w/RV_m не пересекают разрыв (до набора 5/22 дней после разрыва — NaN); прогноз с последнего дня до разрыва на первый день после разрыва не делается. Даты без прогноза хотя бы у одной модели исключаются у всех (одна сетка дат). Цель для прогноза с дня d — RV следующего годного дня (за пределами разрыва).
- О4. PIT: прогноз с дня d (на d+1) использует только строки t ≤ d; обучающие пары (x_t, y_{t+1}) — только с t+1 ≤ d. Окно расширяется с первого дня, где определены все признаки (июль 2014). Первый прогноз — с дня d = 30.12.2016 на 03.01.2017 (оценка с целевой даты 03.01.2017).
- О5. HAR-J: OLS переоценка каждый день. (а) σ̂² = exp(f); (б) σ̂² = exp(f + s²/2), s² = SSR/(n − k) по остаткам того же окна (k — число коэффициентов).
- О6. Эталоны: RW σ̂² = RV_d; σ̂² = RV_w; σ̂² = RV_m; HAR без J — (а) и (б).
- О7. Режимы по дате цели: год (2017…2026; 2026 — январь–февраль, пометка «неполный»); RVI выше/ниже прошлой медианы (медиана RVI по датам < d, расширяющаяся с 03.01.2017; первые 20 дат без режима) — только 2017–2021, пока владелец не разрешит RVI ≥ 2022; март–июнь 2020 (цель 01.03–30.06.2020); 2022 (весь год цели).
- О8. Метрики на одной сетке дат: QLIKE = r − ln r − 1, r = RV/σ̂² (средний по всем датам и по каждому срезу); среднее r (смещение); RMSE и MAE ошибки e = ln RV − ln σ̂². Одно определение на проект (Д7) — в `models_v2/metrics.py`.
- О9. Сверка с arch: на 10 датах прогноза (равномерно по 2017–2026) коэффициенты и прогноз HAR-J из `arch.univariate` (HARX/ARX с теми же регрессорами в exog, константа) совпадают с собственной OLS с допуском < 1e-8.
- О10. Тесты утечки (на каждую модель, которая выходит в таблицу): (i) вариант с целью, сдвинутой назад (y_{d+1} доступен как признак), резко улучшает QLIKE — тест падает, если улучшения нет; (ii) вариант «обучение на всей выборке 2014–2026» даёт QLIKE не хуже рабочего; (iii) перемешанные признаки (перестановка строк X внутри окна) дают QLIKE около RV_m-эталона (объявить допуск до счёта в GATES). Плюс главный тест рабочей версии: прогноз на d не меняется при обрезке/порче всех данных после 18:50 дня d (побитно). Мутации: сдвиг признаков на +1 день и окно, включающее пару (x_d, y_{d+1}), — тест обрезки обязан падать.
- О11. Шапка каждой таблицы (`proverka.md` п. 4): «разработка; оценка 2017–02.2026 по Ж-197 (2022+ — просмотр контроля гл. 3 по SBER); код <commit/sha файлов>; sha входов».
- О12. Бустинг (п. 2) и гибрид (п. 3) — дословно по блоку; недоопределённое решает агент и пишет строкой «умолчание агента» в отчёт до выводов.
