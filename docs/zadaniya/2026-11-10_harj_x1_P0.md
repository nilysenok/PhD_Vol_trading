2. **G2 — масштаб RV при нормировке (числа по годам 2018–2025).**
   - Построитель M10 V7: связь суммы нормированного канала r² за день с RV_d — корреляция Пирсона и Спирмена, медиана отношения.

   - Функция агрегации `B(w) = Σ_k w_k·r²_k` для плана: при w ≡ 1 получается B = RV_d побитно на всех днях; при положительных нормированных весах (среднее w = 1) масштаб сохраняется — тест.
   - Вывод — в таблице `P0_SCALE.csv`.
3. **G3 — выход из нулевой инициализации.**
   - MoE V7 (конфигурация 6) на реальной первой переоценке 2018-01: градиент функции потерь по параметрам маршрутизатора и экспертов в точке инициализации — аналитический (автоградиент torch) и численный.
   - Если эксперты стартуют с нулевой поправки, градиент по логитам маршрутизатора ∝ g_k − Σπ_j g_j = 0. Проверь это числом.

   - Связь с равномерными π ≈ 1/3 из `LEAF2_REPORT.md` — числом.
   - Для планируемых в Ж-241 поправок (синтетика): при нулевой инициализации у каждого параметра ненулевой градиент, или явно указано, что он появится только после другого параметра.
   - Таблица `P0_INIT.csv`.
4. **G4 — оператор смешивания.** Для X1 (F = M^{1−π}·C^π), MoE V7 (G = Σπ_k g_k), X2 ((1 − p)·c_n + p·c_s), NTP2, K8 (√(K1·M)):
