# 3. Главное изменение подхода

Не ограничиваться линейным взвешиванием HAR и бустинга.

Исследовать три разных механизма:

**A. Forecast Combination**

HAR-J и бустинг дают два независимых прогноза, которые объединяются.

**B. Residual Boosting**

HAR-J прогнозирует основную структуру RV, а бустинг обучается корректировать ошибки HAR-J.

**C. Conditional Hybrid**

Гибрид определяет, когда HAR-J полезнее бустинга, на основе исключительно прошлой информации.

Для каждого механизма определить:

- экономический смысл;
- математическую спецификацию;
- необходимые признаки;
- правила обучения;
- источник дополнительной информации;
- степень сложности;
- риск переобучения.

Не смешивать эти конструкции в одну модель.

# 5. Этап II — прямой Residual Boosting

Приоритетное направление.

## R1. Мультипликативная коррекция

Использовать:

`RV_hybrid = RV_HAR × exp(g_ML(X_t))`

Где `g_ML` — XGBoost или LightGBM.

Преимущества конструкции:

- прогноз остаётся положительным;
- HAR сохраняет роль базового компонента;
- нелинейная модель корректирует систематические ошибки;
- возможно прямое обучение на функции QLIKE.

Проверить два варианта:

**R1-XGB:** HAR-J + residual XGBoost.

**R1-LGBM:** HAR-J + residual LightGBM.

Обучать корректор через согласованную с QLIKE функцию потерь с логарифмом HAR-прогноза как offset.

Проверить градиент, гессиан и корректность реализации.

## R2. Ограниченная коррекция

Исследовать ограничение величины поправки:

`RV_hybrid = RV_HAR × exp(clip(g_ML, -c, c))`

Параметр c выбирать только на прошлой внутренней валидации.

Цель — исключить чрезмерные поправки на редких экстремальных наблюдениях.

Не выбирать ограничение по будущим ошибкам.

## R3. Shrinkage коррекции

Проверить:

`RV_hybrid = RV_HAR × exp(λ × g_ML)`

Где λ находится в допустимом диапазоне от 0 до 1.

Нулевое значение должно точно воспроизводить HAR-J.

Проверить, помогает ли умеренная коррекция сохранить устойчивость HAR.

## R4. Коррекция разных компонент

Исследовать, объясняется ли дополнительная информация:

- jump-компонентой;
- асимметрией;
- рыночным фактором;
- volatility of volatility;
- изменением краткосрочной RV.

Не создавать отдельную модель для каждой компоненты, пока не подтверждена её дополнительная прогнозная ценность.

# 6. Критически важный протокол обучения

Residual Boosting должен получать исторические HAR-прогнозы, сформированные без знания соответствующей будущей RV.

Использовать nested walk-forward.

Последовательность:

1. В прошлом окне обучается HAR-J.
2. Формируются исторические out-of-fold прогнозы HAR.
3. По ним и фактической RV строится обучающая база корректора.
4. XGBoost или LightGBM обучается на этой базе.
5. На дату t рассчитывается доступный HAR-прогноз.
6. По признакам на t формируется корректировка.
7. Получается прогноз RV на t+1.
8. После наступления t+1 факт можно добавить в историю.

Обязательно обеспечить достаточный объём прошлых OOF-наблюдений.

Запрещено использовать fitted residuals HAR как замену реальных исторических ошибок прогнозирования.

Для любого признака фиксировать время его доступности.
