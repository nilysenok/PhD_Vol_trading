## Цель
`fastbt/progon_ustojch.py` — только из рядов, без пересчёта движка, кроме поправки:
- **LOYO.** 4 фолда: регион выбирается на 3 годах (12 кварталов), ряд региона смотрится на оставленном годе. Таблица: год, центр, совпал ли с полным выбором, медиана кварталов года.
- **LOTO.** Для каждого из 17 тикеров портфель всех точек пересобирается без тикера: nanmean по 16 тикерам, знаменатель — число оставшихся на дату. Выбор региона повторяется. Таблица: тикер, центр, совпадение, целевая.
- **Бутстрап по 16 кварталам.** 10 000 повторов с возвращением, seed 20261028. Ряд региона кандидата берётся блоками-кварталами. Выход — 5/50/95 % медианы квартальных Шарпов и доли + кварталов.
- **Тикерная поправка (справочно).**
  - Для кандидата досчитываются точки «кандидат × `vhod` (5) × `tau` (7)» через `evaluate_v2`; `istochnik = tiker`, эти строки входят в N.
  - По тикеру: лучший (`vhod`, `tau`) берётся, только если выигрыш Шарпа тикера ≥ 0,2 против кандидата и знак выигрыша тот же в ≥ 3 годах из 4.
  - Иначе — значение кандидата (усадка).
  - Таблица: тикер, выбор, выигрыш, годы.
  - В A′ и в кандидаты **не идёт** (§4 п. 3, ❓2).

Таблицы — `docs/tables/progon_e1/ustojch_*.csv`, шапка «разработка 2016–2019, потолок».

## Тесты и мутации
Синтетика:
- LOTO на тикере с NaN-днями;
- бутстрап воспроизводим по seed;
- поправка на синтетике, где выигрыш 0,25 в 2 из 4 лет → не берётся.

Мутации:
- LOTO не исключает тикер из знаменателя;
- бутстрап по дням, а не по кварталам;
- поправка без условия «≥ 3 из 4»;
- порог 0,2 сравнивается строго / нестрого не так, как в задании («≥»).
