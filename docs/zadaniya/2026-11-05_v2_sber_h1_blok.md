- Тесты утечки на каждую модель: цель, сдвинутая назад, резко улучшает QLIKE; обучение на всей выборке улучшает; перемешанные признаки → QLIKE около RV_m-эталона. Рабочие версии этих эффектов не содержат.

1. HAR-J (переоценка каждый день, OLS)
ln RV_{d+1} = b0 + b_d ln RV_d + b_w ln RV_w + b_m ln RV_m + b_j ln(1+J_d).
(а) exp(f); (б) exp(f + s²/2), s² по остаткам окна. Эталоны: RW (RV_d), RV_w, RV_m, HAR без J.
