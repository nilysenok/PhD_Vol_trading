## Диагностики (объявлены до счёта; после просмотра не добавляются и не меняются)
1. **Годы.** Δ_y = mean QLIKE(гибрид) − mean QLIKE(K3) по годам 2017…2026 и вклад года в общую Δ (вес = доля дат). Тождество: сумма вкладов = общей Δ. Знак по годам, смена знака 2021 → 2022.
2. **Крайние дни.** Доля общей Δ от 1 % и 5 % дней с наибольшим |l_гибрид − l_K3| (l — дневная QLIKE). Δ без этих дней. Тождество разложения.
3. **Режимы (PIT).** Терцили уровня прогноза K1 на дату d по порогам из прошлых дат ≤ d (расширяющееся окно, первые 250 дат — без группы и с пометкой). Δ и вклад по терцилям. Отдельно — дни, где RV(t⁺) > F_K1 и где RV(t⁺) ≤ F_K1 (группа по исходу, только описательно, помечается «по исходу»).
4. **Калибровка.** Mincer–Zarnowitz в логарифмах, log RV = a + b·log F, по окнам 2017–2021 и 2022–2025 для каждого ряда (a, b с HAC-ошибками, лаг 5). Средний сдвиг mean(log RV − log F) по годам.
5. **Сколько бустинговой поправки ловит гибрид.** x = log(K3/K1), y = log(F_гибрид/K1):
   - по окнам — наклон y на x, корреляция и доля дней с совпадающим знаком;
   - то же для K2.
6. **Устойчивость во времени.**
   - Скользящая Δ к K3 по окну 250 дат: доля окон с Δ < 0, минимум и максимум.
   - Разность средних Δ: 2017–2021 против 2022–2025 — с 90 % бутстрап-интервалом (блок 20, 2000, seed 0).
7. **Величина поправки.**
   - |g| = |log(F_гибрид/K1)| по годам: среднее и 95-й перцентиль;
   - доля дней на границе клипа |g| = 1;
   - то же |log(K3/K1)|.

Статистика — те же реализации, что в V6 FIN (импорт): бутстрап, DM, HAC. Δ владельцу — в % уровня K1, не bps.
