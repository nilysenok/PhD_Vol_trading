# ЭТАП 1. GRAPH-SCORE HYBRID

## 1.1. Новая математическая конструкция

Для каждой акции i и даты t:

`H(i,t) = HAR-J forecast formed before t`

`F(i,t) = H(i,t) * exp(u(i,t) + g_ML(Z(i,t)))`

где:

- H — замороженный прогноз HAR-J;
- u — скрытое состояние систематической ошибки;
- g_ML — регуляризованная нелинейная поправка.

После наблюдения фактической RV дня t рассчитать score:

`s(i,t) = RV_actual(i,t) / F(i,t) - 1`

Это отрицательный градиент QLIKE по логарифму прогноза.

Обновление скрытого состояния на следующий день:

`u(i,t+1) = rho*u(i,t) + alpha*s(i,t) + beta*sum_j W(i,j,t)*s(j,t)`

Здесь W — исторически оценённая матрица передачи информации между акциями.

Главное отличие от прежнего stacking: модель не подбирает, кому доверять, а обновляет условное состояние ошибок по QLIKE-score.

## 1.2. Ограничения

Матрицу W рассчитывать только на предыдущих наблюдениях.

Начать с простых моделей:

A. Только индивидуальный score.

B. Индивидуальный + общий рыночный score.

C. Индивидуальный + разреженная графовая передача score.

D. Низкоранговая передача score с сильной регуляризацией.

Не обучать свободную матрицу из сотен коэффициентов без регуляризации.

Допустить только ограниченный набор проверяемых параметров.

При LOTO исключать целевую акцию из обучающих данных других акций и правильно пересчитывать матрицу W.

Использование прошлой собственной истории исключённой акции для её индивидуального HAR-J допустимо, но участие её ошибок в обучении общей панельной поправки — нет.

## 1.3. Робастность score

Поскольку `RV/F - 1` может принимать большие положительные значения, проверить устойчивость обновления.

Разрешить предварительно утверждённую нормировку или ограничение влияния экстремальных score на динамику состояния.

При этом:

- не обрезать фактическую RV;
- не изменять QLIKE при оценке;
- не исключать кризисные дни;
- отдельно показать цену робастизации на экстремальных наблюдениях.

Проверить аналитический и численный градиент.

При нулевых корректировках модель должна точно воспроизводить HAR-J.

# ЭТАП 2. SPECTRAL ENERGY HYBRID

## 2.1. Главная гипотеза

Дневная RV — сумма квадратов внутридневных доходностей, но разные частотные компоненты могут иметь различную предсказуемость.

Обычная HAR-J использует агрегированную RV, не различая структуру её энергетического спектра.

Построить новую архитектуру, в которой ML корректирует спектральные составляющие.

## 2.2. Математическое разложение

Для вектора M10-доходностей r применить фиксированное ортонормальное преобразование W.

`c = W*r`

По тождеству Парсеваля:

`sum(r²) = sum(c²)`

Сгруппировать частотные коэффициенты:

- Low Frequency Energy;
- Mid Frequency Energy;
- High Frequency Energy.

Обязательно проверить точное равенство:

`RV = E_low + E_mid + E_high`

Использовать ту же RV, которая является исходной целью диссертации.

Если действующий расчёт RV содержит дополнительные элементы, проверить возможность точного разложения. Не подменять цель близким показателем.

## 2.3. Новый гибрид

`F = H * sum_b(pi_b * exp(g_b(Z)))`

где:

- H — исходная HAR-J;
- pi_b — исторически доступные положительные доли спектральных компонент;
- сумма pi_b равна 1;
- g_b — нелинейные поправки отдельных компонент.

Все g_b равны нулю → F равен HAR-J.

Обучать g_b с использованием только предыдущих исторических наблюдений.

Допускается общий регуляризованный ML-модуль с отдельными выходами для компонент.

Не обучать три независимых тяжёлых бустинга без доказанной необходимости.

## 2.4. Отдельные проверки

Проверить:

A. Простое разделение RV по фиксированным частотным группам.

B. Спектральную коррекцию с общей ML-регуляризацией.

C. Коррекцию с ограниченным межакционным общим спектральным фактором.

Учитывать изменения торговых сессий MOEX и количество M10-интервалов.

Не допускать появления будущих внутридневных данных в признаках прогноза.

Проверять, улучшает ли спектральная информация HAR-J сверх уже изученной intraday shape.

# ЭТАП 3. CONDITIONAL MOMENT HYBRID

## 3.1. Идея

Нужно добиться не только малого среднего QLIKE, но и отсутствия предсказуемого систематического смещения в различных состояниях рынка.

Для корректного условного среднего RV:

`E[RV_actual/F - 1 | information_at_forecast] = 0`

## 3.2. Архитектура

`F = H * exp(g_ML(Z))`

Обучать с регуляризованной функцией:

`Loss = mean(QLIKE) + lambda*sum_k(MomentError_k²) + mu*ComplexityPenalty`

Где:

`MomentError_k = mean((RV_actual/F - 1)*phi_k(Z))`

Функции phi_k должны быть заранее объявлены.

Кандидаты:

- высокий уровень прошлой RV;
- резкое увеличение RV;
- недавние скачки;
- высокий межакционный score;
- сильное расхождение HAR-J и ML;
- состояние высокой неопределённости.

Не использовать слишком много моментных ограничений.

## 3.3. Диагностика

Сравнить:

A. Обычный QLIKE-корректор.

B. Корректор с небольшой моментной регуляризацией.

C. Корректор с частичным объединением моментных ошибок между акциями.

Отдельно показать условную калибровку по режимам и изменение итогового QLIKE.

Не принимать модель только за уменьшение моментной ошибки, если итоговый прогноз становится хуже.

# ЭТАП 4. LATENT INNOVATION HYBRID

## 4.1. Главная гипотеза

Ошибка HAR-J может содержать три источника:

1. Общерыночное изменение волатильности.
2. Устойчивую специфическую особенность акции.
3. Краткосрочную нелинейную инновацию.

Исследовать декомпозицию:

`log(F/H) = a_i*f_market(t) + b_i*f_sector(t) + g_ML(Z_i,t)`

При необходимости индивидуальную компоненту ограничить одним медленно меняющимся состоянием.

## 4.2. Ограничения

Общерыночный фактор оценивать только на прошлом.

Секторный фактор — только при достаточном количестве акций в группе.

Нагрузки a_i и b_i сильно регуляризовать.

Число общих факторов — максимум 2, если дополнительные не обоснованы.

Не допускать переобучения индивидуальных нагрузок на коротких рядах.

Обязательно сравнить с уже проверенными простыми панельными факторами.

Принять новую конструкцию только при наличии конкретного улучшения от динамического скрытого состояния, а не от повторного добавления рыночных признаков.

# ЭТАП 5. JUMP DISTRIBUTION HYBRID

## 5.1. Новая гипотеза

Существенная часть общей ошибки HAR-J и ML возникает в редкие дни сильных скачков.

Проверить это количественно до построения модели.

Если гипотеза подтверждается, исследовать условную смесь распределений:

`P(Y|Z) = (1-p(Z))*P_normal(Y|Z) + p(Z)*P_jump(Y|Z)`

Итоговый прогноз RV должен быть условным средним:

`F = (1-p)*E[Y|normal,Z] + p*E[Y|jump,Z]`

Связать обе компоненты с замороженным HAR-J как базовым уровнем.

Разрешить отдельную регуляризованную ML-поправку к условным компонентам.

## 5.2. Проверки

- частота скачковых дней;
- качество вероятности скачка;
- условная величина RV;
- устойчивость при редких событиях;
- QLIKE;
- недооценка RV;
- панельная переносимость.

Не добавлять ожидаемую величину скачка второй раз, если она уже содержится в прогнозе HAR-J.

Не использовать тяжёлую смесь распределений при недостаточном числе скачковых событий.

Не повторять ранее завершённый jump-aware эксперимент, если математически новая конструкция не выделена и не подтверждена аудитом.
