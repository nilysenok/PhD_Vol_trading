## Как считать (уточнения)
- **Пул для прогноза дня d** — все закрытые пары s с t⁺_s ≤ d, s ≥ 2015-07-07. Пересчёт ежедневно (план, п. 6), не помесячно.
- **Нормировка Z_D** — z по среднему и СКО пула (те же закрытые пары), на каждый день d.
- **R_s = RV_{s⁺} / H_s**, где H_s — прогрев H или K1. Постоянный множитель, минимизирующий QLIKE на наборе пар, равен среднему R_s (тест на синтетике: численный минимум QLIKE = среднее).
- **D1.** M = среднее R по 50 ближайшим (евклидово расстояние в Z_D).
- **D2.** k = 100 ближайших, w = exp(−dist²/(2h²)), h = медиана расстояний до 50-го соседа по всему пулу дня d. Правило вычисления h — одно на все дни, без подбора. Если вычисление по всему пулу слишком дорого, допускается медиана по случайной подвыборке 500 точек пула (seed 0) — строкой отступления.
- **D3.** M = (n_eff·M_D2 + 50·M_glob)/(n_eff + 50), n_eff = (Σw)²/Σw².
- **Прогноз.** F = H·clip(M, e⁻¹, e). На 2016-12-30 — та же процедура (пул из прогрева).
- **K9.** F = H·M_glob, M_glob = среднее R по пулу дня d. Контроль, не кандидат: в `ALL_TRIALS` не пишется, в N не входит.
- **Правило «новая информация»** (п. 2.2) — D1, D2, D3 против K9.
- **D_REGIME.csv.** Δ D2 − K9 по терцилям H_t (пороги — по пулу дня d) и корреляция ln M_D2 с ln H_t. Если выигрыш только в одном терциле, это записывается выводом «эквивалент калибровки по уровню».
- **Сравнения.** Описательно — с A2, C2 и лучшими LIN-конфигурациями. Охват к K8 и K3.
