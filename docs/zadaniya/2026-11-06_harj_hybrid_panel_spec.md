## 1. Архитектура

```
 бумага i, день t (18:50)                                   панель (все i, только пары t'+1 ≤ t)
 ┌──────────────┐   ln Ĥ_{i,t+1}   ┌─────────────────────┐   ┌──────────────────────────────┐
 │ HAR-J(б)_i   │ ───────────────▶ │  ln σ̂² = ln Ĥ + λ·g │ ◀─│ g(X_{i,t}) — общий XGB  /     │
 │ (фикс., PIT) │                  │  σ̂² > 0 всегда       │   │ общий LGBM (раздельно)        │
 └──────────────┘                  └─────────────────────┘   └──────────────────────────────┘
        ▲ M10 бумаги i                       ▲                     ▲ X: группы G1–G6 (ниже)
```

- **База A0_i** — HAR-J(б) каждой бумаги отдельно, без изменений (`models_v2/har.py`: лог-HAR-J, ежедневная OLS на парах t+1 ≤ d, σ̂² = exp(f + s²/2)); для SBER побитно равна контролю.
- **Поправка g** — одна на панель (общие деревья), два независимых модуля: XGBoost и LightGBM; не объединяются.
- **Итог**: σ̂²_{i,t+1} = Ĥ_{i,t+1}·exp(λ·g(X_{i,t})), положителен по построению; λ = 0 ≡ HAR-J побитно.

## 2. Математическая спецификация

Цель поправки — лог-остаток прогноза HAR-J: e_{i,t+1} = ln RV_{i,t+1} − ln Ĥ_{i,t+1|t} (Ĥ — PIT-прогноз, не подогнанное значение).

Две функции потерь (объявляются заранее; выбор — внутренней валидацией, п. 4):
- **L2-лог** (как у утверждённого XGB): min Σ (e − g)²; σ̂² = Ĥ·exp(g + s²_g/2), s²_g — дисперсия остатка поправки по закрытым парам. Устойчив к хвосту.
- **QLIKE-offset**: L = ln f + RV/f, f = Ĥ·exp(g); grad = 1 − RV/f, hess = RV/f (проверка численно), с ограничением |g| ≤ c, c — по закрытым.

Признаки X_{i,t} — безразмерные (лог-отношения к собственным масштабам бумаги), чтобы общая g была осмысленна для разных бумаг:
- **G0 состояние HAR** (контроль): ln RV_d/RV_m, ln RV_w/RV_m, J/RV, ln Ĥ − ln RV_m, прошлые лог-ошибки HAR (закрытые, 1/5/22).
- **G1 внутридневная структура**: доли OPEN/MIDDLE/CLOSE в RV_d и их отклонение от собственной медианы; ln CLOSE/MIDDLE; доля первого бара.
- **G2 семиковариации с IMOEX**: асимметрия (cov⁺⁺ − cov⁻⁻)/(…), доля |cov_mix|, реализованная корреляция d и 22.
- **G3 рыночная и индивидуальная компоненты**: ln β²RV_m / RV_i, ln идиосинкратической части, их w-средние.
- **G4 качество измерения**: ln rv_rel (√(2RQ/n)/RV), RS⁻/RS⁺.
- **G5 поперечное состояние (только панель)**: ранг RV_d бумаги среди 28 в день t, разброс ln RV_d по панели, доля бумаг с RV_d/RV_w > 1, отклонение бумаги от панельной медианы — новое; сама панельная медиана близка к прокси 17 бумаг из F5 (Ж-200/201) и новой не считается.
- **G6 признаки утверждённого XGB (Б-2 + F4)** в безразмерной форме — только в абляции «сверх XGB».

Идентичность бумаги (номер, сектор, ликвидность) в основную спецификацию **не входит**; только в абляции P7.

## 3. Обучение (nested walk-forward)

- Пары (i, t): признаки — бары до 18:50 t; цель — RV_{i,t+1}; в обучение поправки на дату d — только пары с t+1 ≤ d по **всем** бумагам (данные других бумаг из будущего не попадают).
- Переобучение g — раз в месяц на расширяющемся окне (технический параметр, класс B: ежедневное обучение панели ≈ 110 × 21 раз дороже); HAR-J_i — ежедневно, как контроль.
- Гиперпараметры — малая фиксированная сетка (глубина {2, 4}, деревьев ≤ 600 с ранней остановкой на последнем году обучения, lr 0,03, min_child/min_data {200, 1000}, L2 {10, 30}); выбор — панельный LOYO по целям < 01.01.Y (критерий — средний по бумагам QLIKE, тот же `crit_wf`); λ ∈ {0; 0,25; 0,5; 0,75; 1} по закрытым прогнозам панели.
- Нормировка признаков — только по прошлому каждой бумаги (расширяющиеся медианы/квантили, ≥ 252 дня).
- Старт оценки — 2017 (как у SBER); 2014–2016 — прогрев HAR и первого обучения.

## 6. Статистика и уровни

- Метрики: QLIKE (основная), RMSE, MAE, R², bias — по бумагам, годам, периодам 2017–21 / 2022 / 2023–25 / 2026, без 24.02.2022, без 5 крупнейших дней.
- По бумаге: DM (Ньюи–Уэст, лаг 5), блочный бутстрап (блок 20, 5000, seed 42), MCS 90 %, Холм по полному реестру.
- Панель: DM на среднем по бумагам дневном дифференциале потерь (учитывает поперечную зависимость), бутстрап блоков **дат** с сохранением всех бумаг в дне; доля бумаг с Δ < 0 и знаковый тест с поправкой на зависимость; Холм по полному реестру.
- Уровни (как Ж-214 V14, панельная версия): 1 — лучше HAR-J на панели и в ≥ 2/3 периодов; 2 — лучше C1 **и** C2 (статистически, после Холма); 3 — устойчиво без 24.02.2022/топ-5 дней и в большинстве бумаг; 4 — то же на расширенных 11 при неизменной архитектуре. В отчёте раздельно: «снижение QLIKE» и «подтверждённое преимущество».
