## Этап 1. Доработка A без прогноза

По каждой стратегии отдельно, в порядке убывания вклада:

1. **Сетка по каждому параметру.** Сначала по одному параметру вокруг текущей точки (5–7 значений), потом малый факторный план по 2–3 главным. Выбор — центр плато, не пик.
2. **Сила сигнала.** Торговать только верхнюю часть сигналов по силе (квантиль по скользящей истории). Это измерение сетки.
3. **Выходы.** Стоп / тейк / время в единицах реализованной σ (без прогноза — скользящая √RV). Это задел под E.
4. **Издержки.** Оборот и комиссия при 0,035 / 0,04 — чтобы не выбрать стратегию, которая живёт только без комиссии.
5. **Сборка A.** Веса, конфликты, лимит одновременных позиций.

Инструменты диагностики: таблица «параметр → Шарп на train / на validation» (если расходятся — параметр нестабилен); вклад по годам; доля прибыли от топ-5 % сделок (если > 50 % — хрупко).

**Ворота этапа:** новый A (A′) лучше старого на train, подтверждён на validation (ЛВ p < 0,05, к2 на перемешанных сигналах), все параметры — фиксированные точки с плато; Шарп A′ на train/validation — записан как есть. Цель — выше 1; если честно не вышло — фиксируем лучшее и идём дальше, не подгоняем.

## Этап 2. Прогноз в C → E

1. **Как σ̂ входит сейчас.** Разобрать правило C дословно: ранг σ̂ в окне W, порог p, затвор на позиции A′. Показать: в каких днях затвор закрыт, какие стратегии он глушит, что даёт константная σ (без прогноза) в том же правиле.
2. **Доработка правила.** Порог по рангу → уровень σ̂ в единицах цены: лимит входа, тейк, стоп, временной стоп (семья E). Частичная экспозиция. Горизонт h=1 основной.
3. **Лестница σ в каждой точке:** константная → наивная √RV → HAR-J (б) → гибрид.
4. Контроли: к2 (сдвиг σ̂), к3 (A′ без того, что затвор глушит).

**Ворота этапа:** C/E на train лучше A′ и к3 и лучше константной σ; то же подтверждено на validation; лестница записана. Только после этого — этап 3.
