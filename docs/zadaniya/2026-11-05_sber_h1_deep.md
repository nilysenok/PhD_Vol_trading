### Поток B1 (агент 1): функции потерь, HAR + бустинг, режимы — `models_v2/s5/b1/`, `tests/test_v2_deep_b1_*.py`, таблицы `OBJECTIVE_EXPERIMENTS.csv`, `HAR_BOOSTING_RESULTS.csv`, `REGIME_MODEL_RESULTS.csv`, гейты `GATES_B1.md`.
- Функции потерь (≤ 17 trials первого прохода): L1 MSE по уровню RV (отрицательные прогнозы — запрет, фиксировать); L2 = текущий Б-2 (контроль, не trial); L3 Gamma log-link (XGBoost `reg:gamma`, LightGBM `gamma` — проверить поддержку версии); L4 прямой QLIKE (лог-параметризация F = ln σ̂²: потеря y·e^(−F) + F, grad 1 − y·e^(−F), hess y·e^(−F); тест на синтетике с известным минимумом и численная проверка градиента); L5 веса по прошлому (например, обратно к прошлой RV_w — только PIT). Для L1/L3/L4 — поправка s²/2 не применяется (прогноз в уровне), кроме L2.

- Режимы (≤ 25 trials): режимы только по прошлому (квинтили прошлой RV_w, стресс Г4, переход = смена квинтиля); R1 режимные признаки в Б-2; R2 отдельные модели (проверить число наблюдений в режиме); R3 смесь экспертов с вероятностями режима из логистической модели на прошлом; R4 переключатель HAR-J(б)/Б-2 (и HAR/H2) — правило по прошлому, обучение порога по LOYO.
