Владелец, 27.10.2026. Дополнение к постановке v3 (шаг 5). Разработка 2018–2021; тест не открывается. Пункты, помеченные ⚑, уточняются по таблице разведки (блок 15:30) до запуска счёта.

## 1. Зачем E и чем она отличается от C

В семье C прогноз σ работает переключателем по рангу: точность прогноза рангу безразлична, поэтому гибрид ≈ наивная (шаг 4). В семье E прогноз задаёт **цены**: лимит входа, тейк, стоп — в единицах σ̂. Завышенный σ̂ → заявка не исполняется, сделка упущена; заниженный → вход дорогой, стоп слишком близко. Здесь точность впервые монетизируется, и горизонт h=1, где гибрид сильнее всего (−14,8 % QLIKE), становится рабочим.

Для гипотез: H2a (прогноз против его отсутствия) и H2b (точность против грубого σ) проверяются на E той же лестницей, что на C. Ожидание до счёта: на E H2b может оказаться ненулевой — это и есть цель.

Цель владельца по уровню: на разработке 2018–2021 Шарп ≥ 1 у точки, идущей на тест. Это допустимо (разработочный набор открыт), но только вместе с защитой от выбора: контроль к2, плато соседей и DSR по числу точек сетки (§6). Точка с Шарпом ≥ 1, не прошедшая DSR, на тест не идёт.

## 2. Информационное множество и исполнение

- Решение о сделке на закрытии дня d по данным ≤ 18:50 дня d: сигнал A, его сила, σ̂₁ — прогноз дневной σ на d+1 (h=1, d0). Для многодневного удержания — σ̂₅/√5 как дневной эквивалент (вторая точка сетки).
- Заявки на день d+1 ставятся по ценам, известным на закрытии d. Проверка исполнения — только по барам дня d+1 и позже. Нарушение этого — ошибка, ловится тестом «сдвиг на −1 день» (§8).
- Исполнение внутри дня — по 5-минутным барам ⚑ (RV считается из них; разведка подтверждает полноту). Правила:
  - лимит на покупку L исполняется в первом баре, где low < L (строго; касание не считается); цена исполнения L; если открытие бара ниже L (гэп) — исполнение по открытию бара (лучше для нас, это честно, гэп вниз — реальность);
  - тейк T: первый бар, где high > T; цена T; гэп вверх через T — по открытию бара;
  - стоп S: первый бар, где low < S; цена S; гэп вниз через S — по открытию бара (хуже для нас);
  - тейк и стоп в одном баре — стоп первым (консервативно);
  - лимит входа и стоп в одном баре после входа — стоп срабатывает в том же баре, если low < S (консервативно);
  - временной стоп τ дней — выход по закрытию дня входа + τ.
- Комиссия 0,04 / 0,035 % за сторону, те же для лимитных и рыночных (без льготы мейкера — консервативно; льгота — в чувствительность).
- Освободившийся капитал — под ставку ЦБ с того же дня (как сейчас в движке: ставка начисляется на свободный капитал на конец дня). Внутридневная сделка, закрытая до конца дня, не теряет ставку за этот день.
- Пропуск в барах (нет торгов, остановка) — заявки не исполняются, позиция переносится; правило остановок — как в движке после аудита (test_08_halts).

## 3. Лестница σ (та же, что для C)

| Ступень | σ̂ для цен | Смысл |
|---|---|---|
| E-const | σ̄ — средняя √RV за прошлые 252 дня тикера | прогноза нет, масштаб есть |
| E-naive | √RV_w, w = 5 | грубый прогноз |

## 4. Семья: точки сетки

### E0 — база: сила сигнала без прогноза
A как есть, вход по закрытию d, но сделки только при силе сигнала выше квантиля q по его собственной истории (скользящее окно 252 дня, ex-ante).
- q ∈ {0 (все сигналы = A), 0,50, 0,67, 0,75} — 4 точки.
- Сила сигнала — определение из кода A ⚑ (z-оценка, расстояние до порога, или ранг); если у A несколько семей сигналов, сила нормируется внутри семьи.
- E0 при q = 0 должна побайтно совпадать с A (тест).

### E1 — лимит входа по σ̂
Для сигнала на закрытии d: лимит L = P_d·(1 − k·σ̂₁).
- k ∈ {0,25; 0,50; 0,75; 1,00} — 4.
- Не исполнилась за d+1: f ∈ {пропустить; войти по закрытию d+1; повторить лимит на d+2 по новой σ̂} — 3.
- Выход — как в A.
- Сетка E1 = q × k × f × 4 ступени σ = 4 × 4 × 3 × 4 = 192.

### E2 — выход по σ̂
Вход как в A (закрытие d). T = P_вх·(1 + a·σ̂), S = P_вх·(1 − b·σ̂), временной стоп τ.
- a ∈ {1,0; 1,5; 2,0}, b ∈ {1,0; 1,5; 2,0}, τ ∈ {1; 3; 5} дней.
- σ̂ для уровней: s ∈ {фиксирован на входе; пересчитывается каждый день по новой σ̂₁} — 2.
- Сетка E2 = q × a × b × τ × s × 4 ступени = 4 × 3 × 3 × 3 × 2 × 4 = 864. ⚑ Сократить до k-плана: q ∈ {0; 0,67}, a = b (симметрия) ∈ {1; 1,5; 2}, τ ∈ {1; 5}, s оба → 2 × 3 × 2 × 2 × 4 = 96 на первом круге; полная сетка — только вокруг прошедших.

### E3 — вход и выход по σ̂
Лучшие по С8 v2 точки E1 × E2 (не более 3 × 3 на каждую ступень σ), без нового перебора параметров.

### Подвыборка инструментов
u ∈ {все 17; топ-10 по обороту за предыдущий год} — ex-ante, пересматривается раз в год. Никаких отборов по результату.

Все сетки коммитятся до счёта; число точек N фиксируется — оно входит в DSR.

## 5. Контроли

- **к3 для E** — E0 в той же точке q (сила сигнала без прогноза): измеряет, что даёт σ̂ как цена сверх силы сигнала.
- **E-const** — тот же дизайн с безусловной σ̄: измеряет, что даёт прогноз сверх масштаба.
- **к2** — σ̂ выбранной точки, циклически сдвинутая по времени на случайный лаг по каждому тикеру (1 000 сдвигов, seed 20261027): сохраняет распределение σ̂, разрушает привязку к дню. p = доля сдвигов с Шарпом ≥ фактического.
- **Проверка на неблагоприятный отбор лимиток.** Лимит на покупку исполняется чаще в дни падения — это систематическое смещение против нас, и оно должно быть видно: доля исполнений, средняя доходность дня исполнения против дня неисполнения, результат ветки f = «войти по закрытию d+1» против «пропустить». Таблица обязательна.

## 6. Метрики (все таблицы E, затем — все таблицы главы 4)

Дневной ряд избыточной доходности портфеля r_t = R_t − rf_t, годовая шкала √252, ddof = 1.

| Метрика | Определение |
|---|---|
| SR | mean(r)/sd(r)·√252 |
| mSR (Фавр–Галеано) | mean(r)·252 / mVaR₉₅, mVaR₉₅ = −(mean + z_cf·sd)·√252, z_cf = z + (z²−1)S/6 + (z³−3z)K/24 − (2z³−5z)S²/36, z = −1,645, S — асимметрия, K — эксцесс (избыточный) |
| Сортино | mean(r)·252 / (sd отрицательных r · √252) |
| Кальмар | годовая доходность / MDD |
| Omega(0) | Σ r⁺ / Σ |r⁻| |
| MDD | максимальная просадка капитала (с учётом ФДР на свободный капитал) |
| FKO | доля дней, когда капитал выше (максимум − 10 %) |
| PSR | P(SR > 0) по Бейли–Лопесу де Прадо с поправкой на S и K: Φ[(SR − 0)·√(T−1) / √(1 − S·SR + (K−1)/4·SR²)] (SR в дневной шкале) |
| DSR(N) | PSR с SR* = E[max SR из N] = √V·((1−γ)Φ⁻¹(1−1/N) + γΦ⁻¹(1−1/(N·e))), V — дисперсия SR по точкам сетки, γ = 0,5772; N — число точек сетки семьи |
| Сделки | число, доля исполненных лимитов, средняя длительность (в барах и днях), доля закрытых внутри дня, доля по стопу / тейку / времени, оборот сторон/год |
| С учётом ФДР | полная доходность портфеля, волатильность, итоговый капитал на 1 руб., при 0,035 и 0,04 % |

Шарп и Δ — только избыточные. Таблица «с учётом ФДР» — описательная, без Шарпа по сырой доходности.

## 7. Отбор С8 v2 для E и пороги выхода на тест

Точка проходит С8 v2, если:
1. Δ к A > 0 в каждом из 4 лет;
2. SR > SR(к3 = E0 той же q) за период;
3. p к к2 < 0,05;
4. для ступеней naive/harj/hyb дополнительно: SR > SR(E-const той же точки) — иначе прогноз не нужен, достаточно масштаба.

Пороги выхода на тест (фиксируются **до** запуска E1–E3, после E0 и разведки; владелец утверждает) ⚑:
- SR ≥ 1,0 на 2018–2021 при 0,04 %;
- DSR(N) ≥ 0,95;
- mSR ≥ 0,8; MDD ≤ 15 %;
- плато: не менее 3 соседей (±1 шаг по k или a/b) проходят С8 v2;
- результат держится при 0,035 и 0,05 % (знак Δ, С8).

Если ни одна точка не проходит пороги — E на тест не идёт, в текст — как отрицательный результат разработки с полной таблицей. Пороги не пересматриваются после просмотра E1–E3.

Среди прошедших — максимум SR при 0,04 %, по ступеням σ отдельно (E_const*, E_naive*, E_harj*, E_hyb*), затем лестница между ними (шаг 4 для E).

## 8. Тесты и подложенные ошибки (проверяющий, до слияния каждого PR)

Обязательные мутации, каждая должна быть поймана:
1. σ̂ сдвинута на +1 день (использован прогноз, известный только завтра) — результат обязан измениться, детектор сдвига обязан сработать.
2. Исполнение лимита проверяется по барам дня d вместо d+1 — тест на синтетике с известным ответом.
3. Касание (low = L) засчитано как исполнение — тест: при low = L сделки нет.
4. Тейк и стоп в одном баре — порядок перевёрнут — Шарп обязан измениться на синтетике, где такие бары есть.
5. Гэп через стоп исполнен по уровню, а не по открытию — тест.
6. E0 при q = 0 ≠ A побайтно — тест.
7. Сила сигнала использует данные дня d+1 — тест на синтетике.
8. к2 со сдвигом 0 ≠ исходный ряд — тест.
9. Комиссия выхода не взята при закрытии по стопу внутри дня — тест.
10. Ставка не начислена на капитал, освободившийся внутри дня — тест.
11. Подвыборка топ-10 по обороту использует оборот текущего года — тест.
12. DSR: N подменён на 1 — тест (DSR обязан вырасти).

Сверка быстрый/медленный слой на 5 точках побайтно. Агенты E не читают данных 2022+ (проверка путей в логах).

## 10. Что идёт в текст, если E сработает и если нет

- Сработает (E_hyb* проходит пороги, лестница растёт к гибриду): §4.4 получает вторую семью, H2b переформулируется положительно — «точность прогноза монетизируется там, где прогноз задаёт цену, и не монетизируется там, где он задаёт переключатель». Это сильный и честный результат, связывающий главы 3 и 4.
- Не сработает (E-const ≈ E_hyb, или пороги не пройдены): E — отрицательный результат разработки, одна таблица и абзац; H2b остаётся нулевой на C. Глава 4 опирается на C и H2a/H3.
- В обоих случаях на тест идёт только то, что объявлено в FINAL v2, одно открытие.
