# Глава 4. Разработка стратегий v3 — полная постановка

Владелец, 27.10.2026. Заменяет 2026-10-26_razrabotka_strategiy_v2.md в части порядка работ и критериев. Дополняет Glava4_gipotezy_i_protokol.md (гипотезы, сценарии, чек-лист). Всё ниже — разработка 2018–2021. Тест 2022–2026 не открывается ни на одном шаге; скрипт открытия с замком не трогается.

Принцип: сначала стратегия без прогноза, затем каждая σ отдельно, сравнение прогнозов между собой — последним. Каждый шаг закрывается отчётом и решением владельца; следующий шаг не начинается до решения. Числа следующего шага агентам предыдущего не показываются.

## 0. Общие условия для всех шагов

### 0.1. Данные и информационное множество
- Бары 17 тикеров, 2018–2021 (разработка). Решение принимается на закрытии дня d по данным до 18:50 дня d включительно. Исполнение — по цене закрытия d; доходность позиции — d → d+1.
- σ-ряды: `data/regen/ch4_dev/` — гибрид, HAR-J (б), наивная √RV_w; h=1 и h=5; выровнены на d0. Перед каждым шагом — проверка сдвига (корреляция с RV при сдвигах −2…+1, максимум на последнем известном дне; для оконных — по приращениям). Результат проверки — первой строкой журнала шага.
- Ставка ЦБ: действует со дня вступления в силу; начисляется за календарные дни [d, d_next) на свободный капитал; та же ставка вычитается в избыточной доходности.
- RVI (`rvi_1850`) — для D, известен на закрытии d, берётся RVI_{d−1} (проверен, PR #245).
- Корпоративные события — `corporate_actions.csv`, хэш в ключе кэша (PR #249/#250).

### 0.2. Издержки и границы
- Комиссия 0,04 % за сторону, всё включено (тариф «Премиум» Т-Банка; ссылку в текст вставляет владелец). Чувствительность: 0,035 / 0,05 / 0,06 %.
- Проскальзывание не моделируется; оговорка в тексте.
- Позиции, открытые 30.12.2021, закрываются по цене 03.01.2022 с комиссией выхода (Н5). Окна отбора платят выход на своём конце. Плечо — по календарным дням (Н4).
- Правило закрытия биржи 28.02–23.03.2022 — только для теста, рядом с основной версией.

### 0.3. Метрики
- Основная: Шарп избыточной доходности над ставкой ЦБ, годовой, по дневному ряду равновзвешенного портфеля 17 тикеров.
- Дополнительные (считаются всегда, в отбор не входят): средняя доходность, волатильность, MDD, доля дней в рынке, средняя экспозиция, оборот (сторон/год), FKO (доля времени над порогом −10 % от максимума), CE при γ = 1 / 3 / 5.
- Значимость Δ Шарпа: бутстрап Ледуа–Вольфа, блок 5, 10 000 повторов, по дневным рядам обоих портфелей. По годам — знак Δ в каждом из 4 лет.
- Для к2: p по распределению сдвигов (1 000), односторонняя.

### 0.4. Контроли
- к2 — круговой сдвиг маски экспозиции точки по каждому тикеру на случайный лаг ∈ [21, T−21], независимо по тикерам, 1 000 повторов, фиксированный seed 20261027. Сохраняет оборот, длины серий, долю дней. Проверяется тестом на синтетике с подложенной ошибкой (сдвиг = 0 должен давать исходную маску).
- к3 — A без диапазонных сигналов S5/S6 (всё остальное как в A). Определение «диапазонный» — по коду семей S5/S6; список исключённого — в журнале шага 0.
- к1 — только для H4 (ΔCE): A, умноженная на среднюю экспозицию сравниваемой точки. В отбор не входит.

### 0.5. Правило отбора С8 v2 (для шагов 1–3, отдельно на каждой σ)
Точка проходит, если одновременно:
1. прежний С8 (все 4 года Δ к A > 0, и остальные условия С8 как записаны в handoff);
2. S(точка) > S(к3) на 2018–2021;
3. p к к2 < 0,05.
Среди прошедших — максимум Шарпа при 0,04 %. Справочно — выбор при 0,05 %; если другой, обе точки идут на тест, основная — по 0,04 (объявляется до открытия).
Дизайны с внутренним выбором (u02 и подобные) — не кандидаты.

### 0.6. Сетки
- C: семьи C1 (порог по рангу σ̂ в окне W), C2W (два порога, экспозиция 1 / 0,5 / 0), C* (ранг σ̂/√RV_w). W ∈ {126, 252, 504}; p ∈ {50, 60, 70, 80, 90}; h ∈ {1, 5}. Нижняя граница p50 — закрыта по экономическому основанию (порог ниже медианы — выход из рынка, не фильтр). Для W504 — растущее окно 252→504 в начале периода.
- D: семьи как в С9 (D1–D16), сигнал RVI_{d−1}.
- B: как в С9 (cap × band × h).
- Сетки коммитятся до счёта, число точек фиксируется в журнале.

- Сверка быстрый/медленный слой на 5 точках побайтно.
- Проверка, что агент шага не читал 2022+ (grep по логам путей).
