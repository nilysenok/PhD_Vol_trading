## Отбор: вложенная проверка leave-one-year-out (LOYO)

Обозначения:
- T = {2017, 2018, 2019, 2020, 2021} (val шагов 2–6, OOS);
- Q_y(D, s) — QLIKE дизайна D, seed s, в году y;
- 𝒟_h — пространство дизайнов h, в нём есть F_h.

**Процедура выбора Sel(S) на наборе лет S ⊆ T.** Она одна и та же для внутренних наборов и для полного T:

1. Для каждого D ∈ 𝒟_h:
   - Q̄_S(D) = (1/|S|)·Σ_{y∈S} Q_y(D, 42);
   - c1–c4 по годам S, функция `gibrid_designs.flags` (раздел «Критерии»), строки — только годы S; c4 — по парам соседних шагов, если оба шага входят в S.
2. **2σ по seed** (Д24.3, парно с F_h на тех же seed):
   - для s = 42…51: d_s = Q̄_S(D, s) − Q̄_S(F_h, s);
   - d̄ = (1/10)·Σ d_s; σ = √(Σ (d_s − d̄)² / 9);
   - порог пройден, если **d̄ < −2σ/√10**, то есть t по seed < −2.
   - У F_22 (HAR-J) seed нет: Q̄_S(F_22, s) одинаково для всех s.
   - У дизайна с ногой seeds10 d_s считается по его вариантам с одиночной ногой seed s. Точечная оценка при этом — по seeds10.
3. Допущенные E(S) — дизайны D ≠ F_h, у которых выполнены все c1–c4 на S и пройден 2σ на S. Порога 3% нет: Д26 не переносится.
4. Sel(S) = argmin_{D ∈ E(S)} Q̄_S(D).
   - Если E(S) пусто, Sel(S) = F_h.
   - Если |ΔQ̄| < 10⁻⁶, берётся дизайн с меньшим числом рычагов, затем — первый по порядку в `designs_h{h}.csv`.
   - Чтобы сэкономить счёт, 2σ можно проверять по списку, отсортированному по Q̄_S, до первого прошедшего. Результат тот же.

**Внешний цикл LOYO.** Для каждого Y ∈ T:
- D*_Y = Sel(T \ {Y}) — выбор по четырём остальным годам;
- r_Y = Q_Y(D*_Y, 42) / Q_Y(F_h, 42) − 1 — оценка на Y (минус — лучше финала);
- справочно та же величина по среднему 10 seed.

Итоги LOYO:
- r̄ = (1/5)·Σ_Y r_Y — среднее;
- r_max = max_Y r_Y — худший год;
- σ по годам: σ_год = √(Σ (r_Y − r̄)² / 4);
- число различных D*_Y — устойчивость выбора.

**Победитель h.** D**_h = Sel(T), выбор на всех пяти годах. В тест он идёт, только если выполнены все условия:
1. D**_h ≠ F_h, то есть на T выполнены c1–c4 и пройден 2σ (по построению Sel);
2. r̄ < 0 — процедура в среднем лучше финала на отложенных годах;
3. r_max ≤ +2% — ни в одном отложенном году не хуже финала больше чем на 2% (допуск как в c1/c2);
4. тестовые прогнозы D**_h для шагов 1–10 собраны к заморозке (раздел «Срок»).

Если хоть одно условие не выполнено, на этом h остаётся F_h. Таблицы раунда идут в приложение.

**Что подбирается внутри фолда:**
- дискретный выбор D из 𝒟_h, то есть выбор рычага, компонент, типа ноги, схемы, s², поправки a, усадки, смешивания;
- сетки рычагов, заданные их yaml (m, тикер или рынок, k в Д18 и так далее).

**Что фиксировано:**
- гиперпараметры бустинга (сохранённые точки);
- набор seed 42–51;
- пространство 𝒟_h (коммит `designs_h{h}.csv`);
- внутренняя адаптация по шагам < t;
- эталоны c1–c3;
- признаки v3.

**Справочно в отчёте:**
- e_y = Q_y(D**_h) − Q_y(F_h) по годам T: среднее, худший год, СКО по годам;
- t по seed на T;
- вариант 2σ из Д26 (d̄ < −2σ, без √10).

## Критерии c1–c4 (как в `gibrid_v17.py` → `gibrid_designs.flags`, без изменений)

- **c1**: Q_y(D) ≤ 1,02·Q_y(HAR-J с поправкой) в каждом году набора. Эталон — замороженный HAR-J с поправкой sm (`FD §1а`). Для V0_HAR c1 выполнен тривиально.
- **c2**: Q_y(D) ≤ 1,02·min одиночных компонент с той же s² в каждом году. Компоненты — HAR-J, XGB-слот, LGB-слот, а у дизайнов с бо́льшим числом ног — каждая одиночная компонента дизайна. V0 сам с собой не сравнивается. HEAVY и RG в обоих слотах — правило `GIBRID_SAME_SLOT` (`FD §3 п. 1`).
- **c3**: худший год (Q_y(D)/Q_y(HAR-J)) лучше худшего года ML-компонент. Если ML-эталона нет — худший год лучше HAR-J.
- **c4**: скачок весов между соседними шагами ≤ 0,3, для V1 — не больше 3 смен ML. У QLIKE-объединителя, mean и median скачок считается по их весам.

Эталон c1–c3 — замороженные ряды первого раунда. Поправки a и b к эталону не применяются: в тесте гибрид сравнивается с замороженным HAR-J. Вариант Д26 «поправка и к эталону» даётся справочно. Если рычаг дал эталону не меньший выигрыш, чем гибриду, в тексте он помечается как «эталонный, не гибридный».
