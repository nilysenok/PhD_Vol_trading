### 2.1. Складки и вложенный выбор

T = {2017, 2018, 2019, 2020, 2021}. Складка Y: обучающие годы T \ {Y}, отложенный год Y.

Единица отбора u — дизайн (yaml по схеме v1), у которого часть ключей задана списком: сетка λ, α, κ и другие. Это «гиперпараметры внутри складки».

В складке Y:
1. **Вложенный выбор.** Среди значений-списков берётся вариант с наименьшим средним QLIKE на T \ {Y} (равные веса лет) среди вариантов, у которых на T \ {Y} выполнен c3. Если c3 не выполнен ни у одного варианта, u в складке Y проваливает c3.
2. **Оценка на отложенном годе**: q_u(Y) = QLIKE года Y у выбранного варианта.
   - Прогноз — среднее по набору seed единицы (скрининг — 3 seed, финалисты — 10).
   - Если ключ `ens.agg = median` — медиана по seed × lib.
3. Отложенный год Y во вложенный выбор не входит никогда.

### 2.2. Условие входа

Единица проходит вход, если выполнено всё:
- (а) **лучше эталона** хотя бы в 3 складках из 5: q_u(Y) < q_E(Y) не меньше чем для трёх Y;
- (б) **c3 на всех складках**: худший год Q_y(u)/Q_y(E) на T \ {Y} лучше худшего года ML-компонент (`gibrid_designs.flags`); если ML-компонент нет — лучше E;
- (в) **c1, c2, c4 — как в R1** (❓ 1): считаются функцией `gibrid_designs.flags` без изменений на всех пяти годах T по варианту, выбранному на T. Должны быть выполнены все три, как в правиле M4 первого раунда (`FD §3 п. 6`):
  - c1 — не хуже E более чем на 2% ни в одном году;
  - c2 — не хуже лучшей одиночной компоненты с той же s² более чем на 2%;
  - c4 — скачок весов ≤ 0,3, у V1 не больше 3 смен ML. У калибровки кластера 3 скачок параметра больше 50% между шагами — отказ (аналог c4 из постановки);
- (г) **2σ** — только на финалистах (п. 2.5).

### 2.3. Средний ранг и выбор уровня

- rank_u(Y) — место q_u(Y) среди единиц уровня на этом h, прошедших вход (а)–(в), вместе с F_h(d0). 1 — лучший; при равенстве — средний ранг.
- R̄_u = (1/5)·Σ_Y rank_u(Y). Рядом в отчёте — средний q_u(Y), отношение к E и F_h(d0) по складкам, худшая складка и σ по годам (СКО по 5 складкам, ddof = 1).

### 2.4. Штраф за сложность

**Сложность** c(u) — число ключей дизайна, значение которых отличается от `default` в `schema_v1.yaml`. Группы признаков сверх G0 считаются по одной. Значения с `fixed: true` в счёт не идут.

Правило выбора на уровне:
1. u* — единица с наименьшим R̄.
2. Множество «неотличимых» — единицы с R̄_u − R̄_u* ≤ 1 или с mean_Y q_u(Y) ≤ 1,01·mean_Y q_u*(Y).
3. Из неотличимых выбирается единица с наименьшей c(u). При равенстве сложности — наименьший R̄, затем наименьший средний q.

### 2.5. Финалисты и 2σ (ворота E)

- **Финалисты h** — до трёх лучших единиц уровня 3 после штрафа за сложность. Плюс всегда два кандидата V0 — HAR-X+s² и RVI-anchor+s² (лучшие варианты), если они прошли вход.
- Финалисты пересчитываются на 10 seed (42–51). Вход (а)–(в) на 10 seed проверяется заново.
- **2σ — как в Д24.3**, парно с F_h(d0) на тех же seed, по среднему за T:
  - d_s = Q̄_T(u, s) − Q̄_T(F_h(d0), s);
  - d̄ — среднее по 10 seed; σ = √(Σ (d_s − d̄)² / 9);
  - проходит, если **d̄ < −2σ/√10**.
  - У детерминированных рядов (V0) значение одно на все seed. Если детерминированы оба ряда, σ = 0 и условие сводится к d̄ < 0.
- **Победитель h** — первый финалист в порядке п. 2.4, прошедший 2σ. Если победил V0, финал = эконометрическая компонента. Если не прошёл никто, строка гибрида на h — F_h(d0).

### 2.6. Проверка информационного множества (каждый ряд)

Для каждого ряда прогноза — ноги, роли, калибровки, итога — считается корреляция Спирмена ln ŷ_d с ln RV_{d+s}, s ∈ {−2, −1, 0, +1}. Только по val 2017–2021, по тикерам, затем медиана по тикерам. При h > 1 RV_{d+s} — дневная RV того же тикера.
- Требование: argmax_s приходится на s = 0, последний известный день.
- argmax = −1 или −2 — ряд отстаёт: информационное множество меньше d0. argmax = +1 — подозрение на заглядывание.
- В обоих случаях ряд **блокируется**: в ранги не входит, в `R2/O/blok_sdvig.csv` пишется ряд, корреляции и хэш yaml, дирижёру — доклад.
- Детектор утечек — как Д26: без утечки Δ = 0, подложенная утечка поймана. Обязателен для каждого модуля.

### 2.7. Число дизайнов и ожидаемое число ложных победителей

### 3.2. План 2^(14−8), разрешение IV, 64 прогона

- Базовые факторы A–F — полный план 2⁶ в стандартном порядке: в прогоне r (1…64) фактор номер b ∈ {0…5} равен +1, если бит b числа r−1 равен 1. A меняется быстрее всех.
- **Генераторы:**
  - G = BCDEF
  - H = CDE
  - J = ABCDF
  - K = BCE
  - L = ACF
  - M = ACD
  - N = ABCDE
  - O = DEF
- **Определяющие соотношения** (порождающие слова): I = BCDEFG = CDEH = ABCDFJ = BCEK = ACFL = ACDM = ABCDEN = DEFO. Подгруппа — 255 слов. Распределение длин слов: A₄ = 31, A₆ = 104, A₈ = 79, A₁₀ = 40, A₁₂ = 1, слов длины 3 нет.
- Все генераторы — нечётные подмножества базовых факторов. Значит, все слова чётной длины ≥ 4 (план-складка, foldover), и это **разрешение IV**:
  - главные эффекты не смешаны ни друг с другом, ни с двухфакторными взаимодействиями;
  - двухфакторные взаимодействия смешаны между собой — 93 пары.
- Проверено скриптом: столбцы сбалансированы (32/32), попарно ортогональны, Σ x_i·x_j·x_k = 0 для любого главного эффекта и любой пары.
- Генераторы найдены перебором: случайный поиск по нечётным подмножествам базовых факторов (seed 20261026) и локальное улучшение по минимуму A₄. Таблица однозначно восстанавливается по стандартному порядку и генераторам. O при старте B проверяет это и сверяет SHA-256 файла.
- **Таблица 64 × 14** — `models/designs/r2/factor_plan_v1.csv`: столбец `run`, затем `A_recency` … `O_median_agg`, значения ±1. Прогон 1 — все −1, прогон 64 — все +1.

### 3.3. Главные эффекты

Для h, прогона r и складки Y:
- z_r(Y) = ln q_r(Y), где q_r(Y) — QLIKE отложенного года Y. Прогноз — среднее (или медиана при O = +1) по 3 seed × lib. Сетки ноги — по п. 2.1.
- **Эффект фактора j в складке Y**: e_j(Y) = (1/32)·Σ_{r: x_rj = +1} z_r(Y) − (1/32)·Σ_{r: x_rj = −1} z_r(Y). Это приближённо относительное изменение QLIKE при включении фактора; минус — лучше.
- **Оценка**: ē_j = (1/5)·Σ_Y e_j(Y).
- **Доверительный интервал 95% по складкам**: ē_j ± t_{0,975; 4}·s_j/√5, где s_j — СКО e_j(Y) по 5 складкам (ddof = 1), t_{0,975; 4} = 2,776.
- Справочно: Lenth PSE по 14 эффектам средней складки и эффекты фиктивных факторов как эмпирический шум.

### 3.4. Порог выключения

Фактор остаётся включённым (+1) в фазах C–E на этом h, только если **ē_j ≤ −0,005** (улучшение не меньше 0,5%) **и верхняя граница интервала < 0**. Иначе фактор выключается: −1, то есть простое значение.

Фиктивный фактор выключается всегда. При нулевой гипотезе вероятность ложно оставить фактор ≤ 0,025: односторонний критерий, плюс порог 0,5%.

Выход — `R2/O/gate_B_h{h}.yaml` (включённые факторы, ē_j, интервал, хэш плана). Таблица эффектов — в `FINAL_DESIGN_round2.md`.

## 5. Схема yaml и кэш

- **Схема** — `models/designs/r2/schema_v1.yaml`: каждый переключатель кластеров 1–15 с исчерпывающим списком значений, `default` и кластером. Пример дизайна — в постановке владельца. Значение вне списка — ошибка валидации до счёта.
- **Кэш — по хэшу полного yaml**: дизайн дополняется значениями `default`, канонизируется (порядок записи — в шапке схемы), SHA-256 → `data/regen/R2/cache/<sha256[:16]>/`. Изменение схемы = `schema_v2.yaml` и новый префикс.
- Каждый переключатель — отдельный флаг конвейера. Модули агентов подключаются по ключу схемы, общий код при этом не правится.

> Второй раунд проведён после первого прогона теста по постановке владельца и протоколу, записанным до начала счёта.
