## Что сделать
1. **Инвентарь (G1).** По 28 бумагам: первая/последняя дата, число торговых дней, дыры, пары с разрывом > 5 календарных дней (`gap`, R2), медианный дневной оборот по годам, сектор (справочник задать вручную по общеизвестной отраслевой принадлежности, записать источник/основание в `P0_INVENTORY.csv`; сектор не признак). Календарь дата × бумаги `P0_CALENDAR.csv`. Явно: 25.02–23.03.2022, полные/неполные сессии, изменения расписания (как в Ж-214).
2. **Дневные M10-величины (G2).** Для 28 бумаг + IMOEX тем же кодом, что у SBER в Ж-214 (`hv2_m10.build` и `daily.py`; если `build` жёстко на SBER — обёртка в `s10/`, без правки `s9/`): RV, RS±, C, J, OPEN/MIDDLE/CLOSE по историческому расписанию, RQ, rv_rel, семиковариации с IMOEX, β, идиосинкратическая часть. SBER — побитно равно рядам Ж-214 и `components.rv` (`max_abs_diff = 0`, иначе — разбор до причины, не подгонка). Тождества — по каждой бумаге.
3. **Проверка сдвига (G3, Д1)** каждого входного ряда каждой бумаги — первой строкой `P0_REPORT.md`.
4. **HAR-J K1 (G4)** — R3, для 28 бумаг (и HAR-J IMOEX для C1 в будущем). SBER = `components.har` побитно. Тест обрезки будущего — через боевой путь (повреждение всех баров после d → прогноз на d неизменен). QLIKE K1 по бумагам и годам — `P0_K1.csv`.
5. **Синхронизация и признаки (G5).** R4: модуль, который для даты t собирает поперечные величины только из бумаг, у которых день t закончился к отсечке. Признаки X/M/C по R5 с нормировкой по прошлому бумаги; формулы — `P0_FEATURES.md` (формула, код, источник, минимальная история). Тесты с мутациями (каждая обязана падать на мутации и проходить на правке, через боевой путь, не тавтологии `assert … or True`):
   - «чужой день t+1» — признак бумаги i на t использует день t+1 бумаги j;
   - «ffill отсутствующей бумаги» в поперечных величинах;
   - «нормировка с днём t» или с будущим;
   - «цель на календарный t+1 вместо следующего собственного дня» при `gap`;
   - «HAR-J по полной выборке» (класс № 104).
   Переносимость K2/K3/K6 (`P0_PORTABILITY.csv`): для каждой бумаги — есть ли все входы замороженных спецификаций; чего нет — почему.
6. **Панель (G6).** `data/regen/harj_panel_hybrid/panel_base.parquet`: бумага, группа (M16/SBER/E11), сектор, дата t, t⁺, gap, RV_{t⁺}, K1 (σ̂²), QLIKE K1 дня, рыночная RV, J, части дня, корреляция с IMOEX, семиковариации, X/M/C. SHA-256 и число строк — в `P0_REPORT.md`. `CHECKPOINT.json` — продолжение `docs/otchety/harj_hybrid_v2/CHECKPOINT.json`: `N_registry_start` 585, `budget` 24 (10/10/4), `used` 0, `leaf` P0.
7. Запуск: `python3 -W ignore -m models_v2.s10.run_hp --stage inv|daily|shift|har|panel [--check]`; `--check` проверяет выход и печатает итог, код возврата 0/≠0.
