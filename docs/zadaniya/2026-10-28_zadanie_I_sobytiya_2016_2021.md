# Задание issledovatel — события 2016–2021 с датой объявления (Ж-070 п. 2)

## Цель
Собрать факты для будущего `data/events.csv` (Ж-070). Формат строки: тикер, тип, дата объявления, дата события, источник.

Типы событий — только те, у которых по инвентаризации `docs/issledovaniya/2026-10-28_inventarizaciya_sobytiy.md` (#385) есть **первичный источник с датой объявления**:
1. **Заседания ЦБ по ключевой ставке 2016–2021.**
   - Дата объявления — дата публикации календаря заседаний на год, если она известна; иначе дата пресс-релиза о решении (заседание известно заранее по календарю).
   - Дата события — дата заседания и решения.
   - Тикер — «*» (рынок целиком).
2. **Ребалансировки IMOEX 2016–2021 по 17 тикерам.**
   - Дата объявления — дата новости Мосбиржи об утверждении базы расчёта.
   - Дата события — дата вступления.
   - Только включения, исключения и изменения весов этих 17 тикеров. Если нет — строка «пересмотр без изменений по тикеру» не нужна; нужна строка самого пересмотра с тикером «*».
3. **Экспирации FORTS** (квартальные фьючерсы на индекс и акции 17 тикеров) 2016–2021.
   - Дата объявления — дата начала обращения контракта (спецификация задаёт дату экспирации).
   - Дата события — дата экспирации.
4. **Дивиденды** — не собирать заново. Они есть в `fastbt/dividendy.py` и `docs/issledovaniya/2026-10-28_dividendy_2015_2016.csv`: колонка `announce_date` и дата реестра. Только сослаться.

**Не собирать:**
- MSCI (архив дат объявлений не открылся);
- отчётность, SPO и байбэки (e-disclosure.ru недоступен).

Их — в список «не учитывались: нет данных» с причиной.

Тикеры: AFLT ALRS HYDR IRAO LKOH LSRG MGNT MOEX MTLR MTSS NVTK OGKB PHOR RTKM SBER TATN VTBR.

- `docs/issledovaniya/2026-10-28_sobytiya_2016_2021.md` — методика, полнота по типам, список «не учитывались: нет данных».

Ветка `issl-sobytiya-2016-2021` от `origin/kanon-v22-pereschet`. Закоммить, запушь, открой PR в `kanon-v22-pereschet`.

## Гейты
- **G1.** У каждой строки CSV есть ссылка, и дата объявления ≤ даты события. Строки, где это не так, — в `note` с объяснением.
- **G2.** Ни одной даты события и ни одной даты объявления ≥ 2022. Колонка `accessed` в эту проверку не входит.
- **G3.** Полнота по каждому типу: ожидаемое число событий в году (ЦБ ≈ 8, IMOEX — 4 пересмотра, экспирации — 4 квартала) и фактическое.
- **G4.** В `.md` — список «не учитывались: нет данных» с причиной по каждому типу.
