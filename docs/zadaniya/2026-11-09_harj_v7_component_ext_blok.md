# HAR-J HYBRID V7 — РАСШИРЕНИЕ АРХИТЕКТУРЫ И ОБУЧЕНИЯ
## Только SBER · M10 · h=1 · Совместная оптимизация компонентов гибрида

### 1. Принципиальное решение владельца

Уточняю исследовательский контракт.

**Мы разрабатываем единую гибридную модель, а не просто комбинируем три ранее рассчитанных прогноза.**

Разрешаю создавать, обучать и оптимизировать специализированные версии HAR-J, XGBoost и LightGBM, если они являются внутренними компонентами гибрида.

При этом ранее утверждённые самостоятельные HAR-J, XGBoost и LightGBM остаются полностью неизменными контрольными моделями.

Запрещается изменять их код, параметры, прогнозы, исторические результаты и контрольные артефакты.

### 2. Область исследования

- Единственный тикер — SBER.
- Данные — 10-минутные свечи за 2014–2026 годы.
- Горизонт прогноза — h=1 торговый день.
- Целевая RV остаётся неизменной.
- Основная функция потерь — QLIKE.
- Другие акции и горизонты не исследовать.
- Не запускать торговые стратегии.

Продолжить действующую V7, не создавая конфликтующих параллельных процессов.

### 3. Новая гибридная архитектура

Исследовать конструкцию из четырёх компонентов.

**A. Hybrid HAR-J**

Использовать HAR-J как эконометрический фундамент.

Разрешается исследовать внутри гибрида:

- адаптивную калибровку коэффициентов;
- регуляризованную коррекцию HAR-J;
- QLIKE-согласованное обучение поправки;
- ограниченную адаптацию параметров к рыночному состоянию.

Все изменения реализовывать в отдельных модулях гибрида.

Не заменять HAR-J самостоятельной новой эконометрической моделью.

**B. Hybrid-XGBoost**

Создать специализированный XGBoost, задача которого — не обязательно самостоятельно прогнозировать RV, а извлекать информацию, которую недостаточно учитывает HAR-J.

Возможные цели:

- мультипликативная поправка HAR-J;
- условная ошибка базового прогноза;
- влияние M10-последовательностей;
- асимметрия внутридневных шоков;
- дополнительная информация о будущей волатильности.

**C. Hybrid-LightGBM**

Разработать альтернативный корректирующий модуль LightGBM.

Проверить специализацию относительно Hybrid-XGBoost:

- различные источники остаточной информации;
- различные характеристики M10;
- различную чувствительность к скачкам;
- различную регуляризацию.

Не считать два почти идентичных бустинга независимыми источниками информации.

**D. M10 Encoder + Gating Network**

Использовать последовательности 10-минутных свечей.

Encoder извлекает скрытые признаки.

Gating Network определяет, какой корректирующий модуль полезнее при данном состоянии рынка.

Пропорции должны обучаться на предыдущих наблюдениях, а не назначаться вручную.

### 4. Математическая постановка

Начать с положительного гибридного прогноза:

`F_t = H_t * exp(g_t)`

где:

`g_t = w_X,t*g_X,t + w_L,t*g_L,t + g_M10,t`

Здесь:

- H — прогноз HAR-J или его разрешённой внутренней гибридной модификации;
- g_X — специализированная XGBoost-коррекция;
- g_L — специализированная LightGBM-коррекция;
- g_M10 — дополнительная поправка M10 Encoder;
- w_X и w_L — обучаемые условные веса.

Обязательно исследовать абляцию с нулевой поправкой, когда итог воспроизводит сохранённую HAR-J.

Сначала проверить отдельные компоненты, затем их комбинации.

Не допускать двойного учёта одной и той же информации.

### 5. Главное изменение обучения

**Разрешаю оптимизировать внутренние ML-компоненты гибрида под итоговую QLIKE.**

Не ограничиваться использованием замороженных готовых прогнозов самостоятельных бустингов.

Проверить:

1. Обучение специализированного XGBoost для коррекции HAR-J.
2. Обучение специализированного LightGBM для коррекции HAR-J.
3. Их совместную регуляризованную коррекцию.
4. Добавление M10 Encoder.
5. Обучаемые пропорции через Gating Network.
6. Ограниченную адаптацию самой HAR-J внутри гибрида, если она даёт дополнительную ценность.

В качестве основной функции использовать:

`QLIKE(F,Y) = log(F) + Y/F`

Для мультипликативной коррекции обеспечить положительность прогноза и корректные градиенты.

Если выбранная библиотека требует пользовательской функции потерь, проверить градиент и гессиан численно.

### 6. Отделить настоящий гибрид от самостоятельного ML

Обязательные сравнения:

- сохранённая HAR-J;
- сохранённый XGBoost;
- сохранённый LightGBM;
- лучший прежний гибрид;
- HAR-J + Hybrid-XGBoost;
- HAR-J + Hybrid-LightGBM;
- HAR-J + оба корректирующих модуля;
- HAR-J + M10 Encoder + корректоры;
- полная конструкция с Gating Network.

Ключевой вопрос:

**Действительно ли HAR-J добавляет информацию, или новая конструкция фактически превратилась в самостоятельный бустинг?**

Проверить её вклад через абляции.

Если вклад HAR-J отсутствует, честно зафиксировать этот результат.
