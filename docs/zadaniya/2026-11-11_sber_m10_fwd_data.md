# Задание: загрузка M10 SBER после 27.02.2026 (Ж-247 п. 3)

Ориентир: ~1 ч · 1 процесс сети. Токены — без порога (Ж-244).

## Цель
Получить 10-минутные свечи SBER (TQBR) с 2026-02-28 до последней **полностью завершённой** сессии и сохранить отдельно от архива, с источником и хэшами. Затем проверить:
- границу периодов;
- дубли и пропуски;
- расписание;
- единицы объёма;
- неизменность определения RV.

**Это только данные.** Никаких прогнозов, QLIKE, моделей, сравнений и сводных статистик RV нового периода (средних, квантилей, графиков). Ж-247: «Загрузка не означает разрешения использовать новый период для подбора модели».

## Факты об архиве (разведка дирижёра 11.11.2026)
- **Архив баров** — `data/iss_check/bars_10m_full/SBER.parquet`:
  - sha256 `b451cb48473ac15c246e5d2df0dae64704dff718039e7f34ca0a05ab47d76b9f`;
  - 206 591 строка, 2014-06-02 10:00 … 2026-02-27 23:40;
  - колонки `begin` (мск, без зоны), `open`, `high`, `low`, `close`, `volume` (штуки акций, не лоты), `value` (руб.);
  - все сессии: утренняя, основная, вечерняя, выходного дня.
- **Источник** — бесплатный публичный MOEX ISS, без ключа. Код загрузки — Rust `moex_iss/src/{download,fetch}.rs`.
  - URL: `https://iss.moex.com/iss/engines/stock/markets/shares/boards/TQBR/securities/SBER/candles.json?interval=10&from=…&till=…&start=N`, страницы по 500.
- **Определение цели RV** (`models_v2/daily.build_daily`, `models_v2/s10/hp_daily.py`): RV = 1e4·Σ r² по барам основной сессии с `begin` 10:00–18:40 включительно (53 слота). r₁ = ln(close/open) первого бара, далее close-to-close. Исключаются:
  - дни < 30 баров;
  - 2022-02-28…03-24;
  - с 2025-03-01 — выходные и дни без сессии IMOEX.

  Последняя цель в архиве — t⁺ 2026-02-27 (`data/regen/harj_panel_hybrid/har_SBER.parquet`, sha256 `4092d6080c98de9d…`).

Сверь эти факты с кодом сам и запиши расхождения.

## Что сделать
1. **Загрузчик** — новый модуль `scripts/dannye/fwd_sber_m10.py` (Python, только `urllib`/`requests` из уже установленных пакетов; ничего не устанавливать).

   - `scripts/dannye/dokachka_wf.py` не править.
2. **Загрузка.**
   - Период: `from=2026-02-20`, чтобы перекрыть последнюю неделю архива для сверки, `till=` последняя полностью завершённая сессия по `date` на Маке.
   - Сессия считается завершённой, если её день < сегодняшней даты и последний бар дня в ответе ISS есть. Сегодняшний день не берётся.
   - Пауза между запросами ≥ 0,3 с. Повтор при ошибке ≤ 3 раз.
   - Сырые страницы ответа JSON сохранить как есть в `data/fwd/sber_m10/raw/` (имя = from_till_start).
3. **Выходы** (каталог `data/fwd/sber_m10/`; новый, архив не трогать):
   - `SBER_m10_fwd.parquet` — те же колонки и типы, что у архива, все сессии, только бары > 2026-02-27 23:59;
   - `SBER_m10_overlap.parquet` — бары 2026-02-20…2026-02-27 из нового ответа;
   - `MANIFEST.json`:
     - источник (URL-шаблон, board TQBR, interval 10);
     - время запросов по `date`;
     - число страниц, sha256 каждого сырого файла и выходов;
     - первая и последняя метка;
     - число строк;
     - sha256 архива до и после работы (должен совпасть);
     - sha256 кода загрузчика;
     - git-коммит HEAD.
4. **Проверки** (скрипт `scripts/dannye/fwd_sber_m10_check.py`; таблица `data/fwd/sber_m10/CHECKS.csv` и `CHECKS.md`):

     - Расхождения — списком.
     - Новых баров ≤ 2026-02-27 23:59 в `fwd` нет.
   - **Дубли.** Повторы `begin` — 0.
   - **Пропуски.**
     - Торговые дни нового периода против календаря будних дней. Список будних дней без баров основной сессии — с пометкой; праздники проверить по `data/calendar/` при наличии.
     - Дни основной сессии с < 53 барами — список.
     - Пропуски внутри 10:00–18:40.
   - **Расписание.**
     - Число баров по сессиям (утро < 10:00, основная 10:00–18:40, вечер > 18:40, выходные) по месяцам — только счётчики.

   - **Корпоративные события.** Список событий SBER в новом периоде (дивидендная отсечка и т. п.) из уже имеющихся файлов `data/corporate_actions.csv` и `data/events.csv`, если покрывают. Не покрывают — записать «нет PIT-данных» без поиска в сети.
