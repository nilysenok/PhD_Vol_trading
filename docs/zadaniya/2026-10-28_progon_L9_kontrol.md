## Цель
`fastbt/progon_kontrol.py` — для ≤ 20 кандидатов на стратегию (центры регионов из Л-7):
- **Плацебо входа × 10** (seed 0…9). В каждом тикеро-годе дни начала сделок Sk заменяются случайными днями того же года. Число сделок, стороны и длительности те же. `p = (1 + #плацебо ≥ факт) / 11` — минимум 0,09, поэтому только в отчёт.
- **к1** — σ константой = безусловное среднее σ̂ тикера за прогрев 2015 (`sigma_mult` не годится: подмена ряда через `sig_fn` / свой ряд σ).
- **к2** — циклический сдвиг позиций Sk по тикеру на 20 лагов ≥ 63 дней (seed фиксирован); `p` по перестановкам.
- **к3** — база без компонента: та же точка, все новые оси = умолчания.
- **Лимит при σ = медиана года** (`sigma_lim_mediana`): медиана σ̂ календарного года — справочный контроль, в год есть заглядывание. Пометка в строке.
- **Возмущения:**
  - σ × 0,9 и × 1,1;
  - `bar_plus = 1`;
  - `stop_tik = 1`;
  - комиссия 0,04 % (база) и 0,05 %.

Все строки пишутся через `ledger_v2.Pisatel` в отдельный подкаталог `kontrol/` (`istochnik`, `kontrol`, `vozm`). Таблица — `docs/tables/progon_e1/kontrol_S{k}.csv` (шапка — статус «разработка 2016–2019, потолок»).
