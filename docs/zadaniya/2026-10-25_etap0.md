## Механика
1. Финальная версия каждого блока (HAR-J, бустинги, гибрид, DM, СВ-метрики, МСП, бутстрап, CE, K_min, счётчики наблюдений) — по `git log`, датам артефактов и совпадению с печатями.
2. Пересчёт печатей короткими скриптами в `scripts/analysis/etap0_*.py` (каждый ≤ 200 строк, читает сохранённые файлы, печатает число). Python — `python3` системы или venv проекта; нужен пакет — `❓`, не ставить.
3. Четыре факта (в шапку отчёта, с указанием файл:строка):
   - HAR-J оценивается пулом по 17 тикерам или по каждому тикеру отдельно;
   - сколько коэффициентов (константа, RV_d, RV_w, RV_m, J …), в логах или уровнях;
   - как считается валидационный QLIKE для выбора схемы гибрида (V1–V7): на каком году, пул или по тикерам, по h;
   - какой горизонт σ_pred подаётся в стратегии C/D (фиксирован или выбирается на валидации).
4. Форматы входных файлов, которые понадобятся `volcore` (путь, колонки, типы, число строк) — отдельная таблица.
