## Что сделать (объявлено в плане; не менять)
1. **Формы прогноза** (torch, float64). G = ln(F/H).
   - Residual MoE: F = H·exp(Σ_{k=1..K} π_k·g_k(z)), g₀ ≡ 0 в softmax на K + 1 выходов. Эксперт: g_k = c·tanh((a_k + b_kᵀz)/c), c = 1, d_z = 4.
   - Маршрутизатор: проекция входа в 4 (матрица без смещения) → линейный softmax на K + 1 выходов.
     - Вход A = Z (9), B = (Z, z) (13), C = z (4).
     - Параметров при K = 2: A 51, B 67, C 31.
   - Якорь: F = H·exp(w·ℓ + Σ π_k g_k), w — обучаемый скаляр, ℓ = ln(M/H), M = √(K2·K3).
   - Плоский корректор: g(z, Z) = c·tanh(MLP 13 → 5 → 1), 76 параметров.
   - Признаки Z (9, раздел 3 плана):
     - ln H, ℓ, ln(K2/K3);
     - EWMA₂₀ разности QLIKE(H) − QLIKE(M) по закрытым парам;
     - последние закрытые ln(RV/H) и ln(RV/M);
     - перцентиль ln RV_d по прошлому;
     - J/RV дня d;
     - CUSUM прошлых лог-ошибок H (определение V4 H6 — найти в `models_v2/s11/v4_h_*`, импорт).

     Стандартизация — по прошлому.
2. **Функция потерь:** L = mean(ln F + RV/F) + λ_g·mean(G²) + λ₂‖θ‖² + λ_LB·Σ_k(mean_t π_k − 1/(K+1))² + λ_s·mean‖π_t − π_{t−1}‖². Значения λ₂ и λ_s объявить в коде одной константой.
3. **Обучение.**
   - Adam (или L-BFGS), ранняя остановка по последним 126 закрытым парам внутри обучающего прошлого.
   - Решётка λ_g ∈ {0,1; 1} × λ_LB ∈ {0; 0,1} — выбор по той же внутренней валидации.
   - 5 seeds (0–4), прогноз — среднее ln F по seeds.
   - Детерминизм: `torch.use_deterministic_algorithms(True)`, 1 поток.
4. **Walk-forward.**

## Тесты (`tests/test_v2_v7_1m_*.py`; мутации ловятся)

- Состав входов маршрутизатора A / B / C: мутации «z в A», «Z в C» ловятся. Числа параметров равны объявленным.

  - внутренняя валидация с парами t⁺ > d;
  - EWMA и CUSUM с текущей парой.
