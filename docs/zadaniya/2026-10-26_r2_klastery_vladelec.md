## Кластер 1. Информационное множество, цель и обучающее окно

Зачем: Ф2, Ф8.

Переключатели:
- `info_set = d` — фиксировано. Все признаки и ноги по день d включительно; RV_d считается до 18:50. Оговорка про 18:40/18:50 — в ограничения главы 4.
- `embargo = h` — фиксировано. Последние h наблюдений перед годом валидации не входят в обучение.
- `train_halt = {keep, drop}` — что делать с окнами цели, пересекающими остановку торгов 28.02–23.03.2022, в обучении шагов 8–10. Только для сборки тестовых прогнозов победителей. Для оценки — две версии.
- `target = {ln_mean, mean_ln_jensen, ln_sum}`.
- `recency = {∞, 4y, 2y}` — экспоненциальные веса наблюдений: WLS для HAR, `sample_weight` для бустинга.
- `history_start = {2014, ISS_start}` — ISS_start = первые доступные 10-минутные бары (проверить 2011–2013, крейт). Годы валидации и теста не меняются.
- `winsor = {none, 1/99 by ticker}` — при обучении; оценка по сырой RV.
- `train_target_estimator = {RV10, RV5_subsampled}` — контроль, одна строка приложения.

Ожидание: `recency 4y` даёт 1–2 % на h = 5/22; `ISS_start` — 0–3 %. Цена: перегон признаков для ISS_start — 20–40 мин крейта. Риски: отчёт о числе наблюдений по шагам; 2y может «забыть» 2020.

Приоритет: А — info_set, embargo, recency, history_start; Б — target, winsor; В — train_target_estimator.

## Кластер 2. Эконометрическое ядро («честный HAR v2» как нога и как кандидат)

Зачем: Ф1, Ф3.

Переключатели — семейство ног; каждая нога — кандидат V0 и основа для ролей бустинга:
- `HAR-J` (d/w/m + J, OLS, расширяющееся окно);
- `HAR-X[S]`, где S1 = + RVI; S2 = S1 + RV_IMOEX; S3 = S2 + LHAR + PC1; S4 = S3 + HARQ (RV_d·√RQ_d) + RSV⁺/RSV⁻; S5 (только h=22) = S4 + RV66 + RV132. Эластичная сеть, λ ∈ {0,01; 0,1; 1}, α ∈ {0; 0,5; 1}, выбор вложенным LOYO внутри складки;
- `HAR-X-regime` — слагаемые × индикатор «RVI выше медианы окна 252»; три режима — В;
- `HAR-X-pooled[κ]` — β_i = (1−κ) β_pool + κ β_i, κ ∈ {0; 0,5; 1} по LOYO;
- `HEAVY` и `RealizedGARCH` — QMLE, итерация многошагового прогноза; если реализация занимает больше 2 ч агента — В;
- `MIDAS-RV` — бета-веса лагов 1…66, NLS, 2 параметра; h = 5, 22;
- `HAR-perlead` — прямой HAR на каждый день t+j, среднее (Д24.9);
- `RVI-anchor` — F = RVI_t² · k_i(t), k_i — медиана RV_i,h / RVI² по окну 252; для h=5 — пересчёт масштаба (Д25.1);
- `factor` — ln RV_i = β_i ln RV_mkt + u_i, систематическая часть — HAR-X на ряде рынка (Д25.2);
- окно оценивания расширяющееся; скользящее 3 года — одна строка приложения;
- `robust = {OLS, Huber}`.

Ожидание: h=5 — −2…−4 % к HAR-X R1; h=22 — −1…−4 %; h=1 — стабильность. Цена: минуты; HEAVY/RG — минуты на 128 ядрах. Риски: вложенный выбор λ, α, κ; несходимость HEAVY фиксировать и исключать с отчётом.

Приоритет: А — HAR-X[S1–S5] с сеткой, regime, pooled, RVI-anchor; Б — HEAVY/RG, MIDAS, perlead, factor; В — Huber, скользящее окно.

## Кластер 3. Поправка на смещение и калибровка под QLIKE

Зачем: Ф1. Отдельный слой `calib`, общий для всех моделей и применяемый симметрично. Параметры — только из OOS прошлых шагов.

Переключатели:
- `s2_est = {sm, smrob, sm_pooled, sm_by_ticker, sm_roll1y, sm_roll2y, sm_ewma(λ=0,97)}`;
- `kappa`: F = exp(ŷ + κ·s²), κ ∈ {0,5 (база); оценка по QLIKE на окне ∈ [0; 1,5]};
- `s2_state = {const, RVI, RVI+volvol, regime2}` — регрессия ln e² прошлых OOS-ошибок; не больше 3 параметров, окно не меньше 2 лет;
- `c_qlike = {off, roll_all, roll_2y}` — c = среднее(RV/F) по прошлым OOS;
- `mz = {off, on}` — a + b·ŷ в логах, по тикеру и в пуле;
- порядок фиксирован: s²(state, κ) → c_qlike → mz.

Ожидание: h=22 — −2…−6 % в шоковые годы; h=5 — −1…−3 %; h=1 — ~0. Эталон получает тот же слой. Цена: секунды. Риски: обязательна таблица «калибровка по шагам»; если параметр скачет между шагами больше чем на 50 %, вариант отклоняется (аналог c4).

Приоритет: А — s2_est, kappa, s2_state, c_qlike; Б — mz.

## Кластер 4. Присоединение бустинга и регуляризация остаточного ученика

Зачем: Ф4, Ф1, Ф7.

Переключатели:
- `role = {none (V0), feature (Д8.12), residual (V9), offset (Д17.1, gamma, init_score = ln ноги с поправкой), residual_std}`;
- `resid_source = {in_sample, cross_fit}` — **перекрёстно подогнанные остатки**: нога внутри окна оценивается K = 5 раз по временным блокам, с эмбарго между блоками;
- сетка остаточного ученика, отдельная от протокола B: LHS 60 точек, отсечение 60 → 30 → 15 → 8. Параметры: num_leaves {4, 8, 16}, max_depth {2, 3}, min_data_in_leaf {200, 500, 1000}, lr {0,01; 0,03}, lambda_l2 {1, 10, 100}, feature_fraction {0,3; 0,5}, bagging_fraction {0,5; 0,8}. Не больше 300 деревьев, ранняя остановка по QLIKE итогового прогноза (Д16.8), patience 30;
- `monotone = {off, on}` (для role = feature);
- `objective = {l2_log, gamma_level, huber_log}`;
- `clip = {off, ±c·σ_resid}`, c ∈ {2, 3};
- `shrink α ∈ {1; 0,75; 0,5}` — контроль Б;
- `lib = {lightgbm, xgboost, both_avg}`; `linear_tree = off`;
- сетка подбирается отдельно на каждом h и для каждой из двух лучших ног.

Ожидание: h=5 — −2…−4 % к HAR-X+s² или честный ноль; h=22 — −1…−3 %; h=1 — устойчивость. Цена: ~10 800 обучений, ~15 мин на 128 ядрах. Риски: эмбарго между блоками cross-fit; детектор утечек; ранняя остановка только на внутренней валидационной складке.

Приоритет: А — role (все четыре), cross_fit, сетка, ранняя остановка по QLIKE, monotone, clip; Б — residual_std, objective, shrink.

## Кластер 9. Протокол отбора и защита от переобучения (фиксируется до первого прогона R2)

- Отбор только на 2017–2021, LOYO по 5 складкам, выбор по **среднему рангу**.
- Вход:
  - лучше эталона (HAR-J+s², единое информационное множество) хотя бы в 3 складках из 5;
  - c3 на всех складках;
  - c1, c2, c4 — как в R1;
  - 2σ по 10 seed — на финалистах.
- **Скрининг дробным факторным планом**: ~14 бинарных факторов (recency, history_start, cross_fit, monotone, clip, s2_state, kappa_fit, c_qlike, G2+G3, G5+G6, G8+G9, persist, reconcile, median-agg). План разрешения IV — 64 прогона × 3 h × 10 шагов × 3 seed. Главные эффекты по h с доверительными интервалами по складкам. Факторы с эффектом < 0,5 % или неотличимым от нуля выключаются.
- Вложенный выбор гиперпараметров — внутри складки.
- Штраф за сложность: при разнице среднего ранга ≤ 1 или QLIKE ≤ 1 % выбирается более простой дизайн.
- Автоматическая проверка информационного множества для каждого ряда: корреляции со сдвигами −2…+1; ряд с максимумом не на последнем известном дне блокируется с докладом.
- В FINAL_DESIGN_round2 — число перебранных комбинаций по уровням и ожидаемое число ложных «победителей».
- HAR-X+s² и RVI-anchor+s² — кандидаты V0 на всех h; если побеждает V0, финал = эконометрическая компонента.
- Эталоны и справочные строки после исправления выравнивания заморожены. Гибрид — одно второе открытие по «да» владельца.
- Ничего ≥ 2022 не читается; сборка тестовых прогнозов победителей — по правилу 13:00.

## Кластер 10. Диагностика, объяснимость и связь с главой 4

- Лестница выигрыша: HAR-J → +s² → +HAR-X → +калибровка состояния → +бустинг → +согласование → финал; по h и годам.
- Абляция по кластерам.
- SHAP остаточного ученика по группам признаков и терцилям RVI.
- Стабильность ρ_h и параметров калибровки по шагам.
- Ошибка по режимам: терцили RVI и RV_m, годы, тикеры; доля тикеров; знаковый тест.
- Ранговые метрики для стратегий (вторичные): Спирмен σ_pred с RV, точность направления, устойчивость ранга, доля дней с разным режимом C по гибриду и HAR-J и QLIKE на этих днях.
- МЗ, охват, RMSE/MAE — в приложение.
- Правило «закрытие биржи» — версия рядом.

Приоритет: А — лестница, абляция, ранговые метрики, режимы; Б — SHAP, стабильность.

# Дополнение 15:45. Кластеры 11–15 (структурные), прогноз выигрыша и время счёта

## Кластер 11. Двухкомпонентная структура: медленный уровень × быстрая динамика

RV_{t+h} = τ_t · g_{t+h} (логика GARCH-MIDAS и Spline-GARCH):
- τ_t — месячный уровень: MIDAS по внешним данным, бустинг на месячных признаках (глубина ≤ 2, пул) или привязка к RVI;
- g — HAR на ln(RV/τ), поправка s² на g;
- прогноз — τ̂ · exp(ĝ_h + s²/2), τ продлевается константой или AR(1).

Вторая декомпозиция: RV = BV + J; непрерывная часть — HAR, скачки — классификатор вероятности × средний размер.

Переключатели: `struct = {single, tau_midas, tau_boost, tau_rvi} × {rv_whole, bv_plus_jump}`; окно τ — 22/44/66; продление — {const, AR1}.

Ожидание: h=22 — −2…−4 %; h=5 — −1…−2 %; скачки — −0,5…−1,5 % на h=1/5. Цена: ~2 000 обучений.

Приоритет: Б; А — tau_rvi и tau_midas.

## Кластер 12. Вероятностный гибрид: эконометрика для положения, ML для масштаба

ln RV_{t+h} = μ_t + σ_t·ε:
- μ — HAR-X;
- σ_t — бустинг или HAR второго уровня по |остатку| или ln e²;
- F — эмпирическое распределение стандартизованных остатков прошлых OOS или t;
- прогноз F_RV = exp(μ)·M_F(σ_t).

Побочно — квантильные прогнозы. Вариант quantile5 — квантильный бустинг на 5 квантилях, с монотонизацией.

Переключатели: `prob = {off, scale_boost, scale_har, quantile5}`; F = {empirical, student}; окно — 2 года или все прошлые.

Ожидание: поверх кластера 3 — −1…−2 % на h=22, −0,5…−1,5 % на h=5. Цена: ~5 000 обучений. Риски: cross-fit остатки обязательны; хвосты — усадка к t.

Приоритет: А — scale_boost; Б — quantile5.

## Кластер 13. Смесь экспертов: ML выбирает режим, эконометрика прогнозирует

- Метка режима — терциль или дихотомия средней RV за [t+1, t+h].
- Эксперты — HAR-X на подвыборках режимов, с усадкой к общему.
- Привратник — бустинг-классификатор P(режим | t) с изотонной калибровкой на прошлых OOS.
- Прогноз — мягкая смесь Σ P_k·F_k; жёсткий выбор при P > 0,7.

Переключатели: `moe = {off, k2, k3}`; привратник — {boost, logit}; калибровка — {isotonic, none}; порог — {off, 0,7}.

Ожидание: −1…−3 % на h=5/22; если AUC ≤ 0,6 — в приложение с числом AUC. Цена: ~3 000 обучений.

Приоритет: Б; А — если AUC на LOYO > 0,65.

## Кластер 14. Панельно-факторная архитектура и кросс-секционная усадка

- ln RV_i = α_i + β_i·ln RV_mkt + u_i, β по окну 252 с усадкой к 1.
- Рыночная компонента — HAR-X + RVI-anchor + калибровка.
- u_i — бустинг с пулом или HAR с частичным объединением.
- Усадка по сечению: F_i ← (1−w)F_i + w(α_i + β_i F_mkt), w ∈ {0,25; 0,5} или w = f(средней корреляции G5).
- Секторы — В.

Переключатели: `panel = {off, factor, factor+shrink[w], factor+shrink_state}`; окно β — 126/252; рыночный ряд — RV IMOEX или равновзвешенная RV 17 тикеров.

Ожидание: −1…−3 % на всех h, лучше c3. Цена: ~2 000 обучений.

Приоритет: А — factor+shrink; В — секторы.

## Кластер 15. Адаптивное обновление и оценивание под критерий

- Переоценка внутри шага: нога и калибровка — ежемесячно; бустинг — ежеквартально с тёплым стартом (`init_model`) или ежемесячно для финалистов. Год валидации — только для оценки.

Переключатели: `refit = {yearly, quarterly, monthly}` × `boost_refit = {yearly, quarterly_warm, monthly}`; `rls_lambda`; `estimator = {log_ols+calib, qmle_level}`; `calib_update = {step, daily}`.

# Дополнение 16:10. Кластеры 16–20: конструкция под значимость 80–90 % (текст владельца, без перевода чисел)

> **Пометка дирижёра.** Раздел опирается на числа первого прогона теста, который был сделан до исправления выравнивания. Решения по В1/В2/В3 и по исключению окон остановки ещё не приняты — это вопросы владельцу. До ответа владельца исполнителям R2 раздел не передаётся, в протокол он не входит.

**Почему 1–15 дают 55–60 %.** Панельный DM: t = среднее(d)/se(d), где se — Ньюи–Уэст по ~1 090 дням. Факты: (1) se(d) на h = 5 почти целиком создают 30–40 шоковых дней; (2) с правилом закрытия выигрыш h = 5 против HAR-J+s² исчезает. Значимость = устойчивое малое преимущество в спокойные дни ÷ нулевая разность в хаосе.

## Кластер 16. Селективная коррекция: гибрид воздерживается, когда не уверен
ŷ = нога + g_t·коррекция, где g_t ∈ [0, 1] известно в момент t. Варианты ворот:
- `conf_seed` — согласие 10 seed и двух библиотек;
- `regime` — P(спокойно) из кластера 13;
- `shock_fresh` — g = 0 в первые k ∈ {3, 5, 10} дней после скачка RV рынка выше q-квантиля;
- `halt` — g = 0 для окон через остановку торгов (правило модели);
- мягкая версия — uncert_shrink.

τ, k и q выбираются по LOYO, критерий — панельный t. Приоритет А.

## Кластер 17. Отбор по t-статистике, а не по среднему QLIKE
Главный критерий на LOYO — панельная t тем же кодом, что и в тесте (дневной ряд средней по тикерам, NW лаг h−1).

Вход:
- t ≥ 1,0 в ≥ 3 из 5 складок и средняя t ≥ 1,5;
- hit rate ≥ 55 % и ≥ 12 тикеров из 17;
- на 2 % худших дней приходится ≤ 40 % выигрыша.

Выбор среди прошедших: максимум средней t. При Δt ≤ 0,2 — больший средний выигрыш; если и выигрыш различается ≤ 1 % — более простой дизайн. c3 обязателен, средний QLIKE остаётся в таблицах. Приоритет А.
