# НАПРАВЛЕНИЕ A — CAUSAL PATH-SIGNATURE HYBRID

### 4. Главная гипотеза

Две торговые сессии могут иметь одинаковую дневную RV и одинаковые основные статистики, но совершенно различную последовательность событий.

Пример:

- резкое падение утром с последующим восстановлением;
- стабильная торговля утром с резким падением перед закрытием.

Обычная HAR-J использует агрегированные характеристики прошлого.

Даже спектральная энергия может не полностью отражать порядок изменения цены, волатильности и объёма.

**Нужно проверить, предсказывает ли хронологический порядок внутридневных событий ошибку HAR-J на следующий день.**

### 5. Path Signature Features

Для каждой завершённой торговой сессии SBER построить многомерную траекторию из:

- накопленной логарифмической доходности;
- накопленной реализованной дисперсии;
- накопленной отрицательной семивариации;
- накопленного объёма;
- нормированного времени сессии.

Все компоненты доступны только после завершения соответствующей сессии.

Исследовать усечённые path signatures порядка 2 и, только при необходимости, порядка 3.

Особенно интересны смешанные компоненты, описывающие порядок событий:

- цена → волатильность;
- волатильность → цена;
- объём → волатильность;
- волатильность → объём;
- отрицательная доходность → увеличение RV.

Отдельно проверить антисимметричные компоненты второго порядка, связанные с порядком прохождения траектории.

Начать с малого числа устойчивых признаков.

Не строить полноценную глубокую нейросеть.

### 6. Гибрид

`F_t = H_t * exp(g_signature(Z_t))`

где H — сохранённый HAR-J, а g_signature — небольшая регуляризованная ML-коррекция.

Обучать непосредственно под QLIKE либо использовать математически согласованную аппроксимацию с последующей обязательной оценкой QLIKE.

Проверить:

A1. Только хронологические признаки второго порядка.

A2. Хронологические признаки + простая регуляризованная ML-коррекция.

A3. Ограниченная комбинация второго и третьего порядка при доказанной полезности A1/A2.

Обязательная абляция:

- HAR-J;
- HAR-J + обычные intraday summary;
- HAR-J + ранее проверенные spectral features;
- HAR-J + новые path-signature features.

Если новые признаки не добавляют информации сверх обычной формы RV, направление закрыть.

# НАПРАВЛЕНИЕ B — TIME-REVERSAL ASYMMETRY HYBRID

### 7. Нетривиальная проверка

Создать диагностическую пару внутридневных траекторий:

1. Реальная последовательность завершённой торговой сессии.
2. Та же последовательность, развёрнутая во времени.

При развороте сохраняются некоторые агрегированные характеристики, но изменяется порядок событий.

Исследовать, присутствует ли в признаках асимметрия, которую обычные RV и HAR-J не объясняют.

Не применять развёрнутую траекторию как будто это реальная альтернативная история рынка.

Использовать преобразование только для проверки чувствительности признаков к последовательности событий.

Построить компактные показатели временной необратимости:

- ранняя против поздней концентрации отрицательных доходностей;
- изменение RV после экстремального движения;
- взаимодействие объёма и направления цены;
- асимметрия восстановления после скачка;
- различие между утренней и вечерней интенсивностью волатильности.

Проверить, сохраняется ли их дополнительная прогнозная ценность за пределами базовой HAR-J.

# НАПРАВЛЕНИЕ C — MEASUREMENT-UNCERTAINTY HYBRID

### 8. Главная гипотеза

Дневная RV является оценкой на основе дискретных M10-наблюдений.

В разные дни её надёжность и структура измерительной ошибки могут существенно различаться.

Обычная HAR-J и бустинги могут по-разному реагировать на дни с:

- большими разрывами между сделками;
- значительной долей нулевых доходностей;
- несколькими экстремальными свечами;
- низкой внутридневной активностью;
- высокой концентрацией объёма;
- необычным соотношением доходностей на разных временных масштабах.

Предлагаю исследовать **достоверность измерения RV как отдельный источник информации для коррекции HAR-J**.

### 9. Признаки качества измерения

По SBER рассчитать, где это корректно:

- RV из M10;
- сопоставимые оценки на более редких сетках;
- чувствительность RV к смещению сетки наблюдений;
- долю нулевых M10-доходностей;
- концентрацию квадратов доходностей;
- внутридневную неоднородность объёма;
- показатели доступности наблюдений;
- число торговых интервалов;
- прокси дискретизации цены;
- различие RV и допустимых noise-robust measures.

Не утверждать, что эти показатели точно измеряют микроструктурный шум без соответствующих данных.

**Основная целевая RV остаётся прежней.**

Альтернативные оценки используются только как исторические признаки качества наблюдений.

### 10. Noise-Aware Correction

`F_t = H_t * exp(g_ML(Z_t, Q_t))`

где Q_t — признаки качества измерения прошлой RV.

Проверить:

C1. Только дополнительные признаки качества измерения.

C2. Признаки качества + ограниченная нелинейная коррекция HAR-J.

C3. Регуляризация величины коррекции в зависимости от исторически оценённой надёжности признаков.

Не повторять обычную динамическую калибровку V4 без новой информации.

Главная проверка — становится ли прогноз точнее в дни после неустойчиво измеренной волатильности.

# НАПРАВЛЕНИЕ D — HISTORICAL ANALOG RESIDUAL HYBRID

### 11. Главная гипотеза

Некоторые состояния SBER могут исторически повторяться.

При этом глобальная ML-модель может усреднять разные состояния и терять локальную предсказуемость.

Предлагаю проверить корректировку HAR-J через поиск похожих прошлых рыночных состояний.

### 12. Математическая конструкция

Для дня t сформировать компактный вектор доступного состояния:

`Z_t = [RV_history, return_asymmetry, intraday_shape, volume_state, HARJ_state]`

Найти исторические дни, похожие на текущий, только среди наблюдений, чья фактическая RV следующего дня уже известна.

Вычислить локальную поправку на основе ошибок HAR-J в этих исторических аналогах:

`R_s = RV_actual_s / HARJ_forecast_s`

При необходимости сформировать регуляризованное локальное ожидание R.

Использовать:

`F_t = H_t * M_local(Z_t)`

где M_local положительна и оценивается только по прошлым аналогам.

Проверить:

- nearest-neighbor correction;
- distance-weighted analog correction;
- shrinkage локальной поправки к единице.

Не использовать аналогов из будущих дат.

Не использовать очень высокую размерность признаков.

Не выбирать задним числом наиболее удачное окно истории.

### 13. Критерий пользы

Historical Analog Hybrid имеет смысл только если локальная поправка снижает QLIKE относительно:

- HAR-J;
- самостоятельных бустингов;
- лучшего прежнего гибрида;
- простой глобальной QLIKE-калибровки.

Проверить, не сводится ли эффект к повторению существующего режима или калибровки.

# НАПРАВЛЕНИЕ E — ASYMMETRIC SHOCK-RECOVERY HYBRID

### 14. Главная гипотеза

Одинаковые значения RV могут сопровождаться разными механизмами её возникновения.

Особенно важно различать:

- отрицательный ценовой шок;
- положительный ценовой шок;
- быстрое восстановление;
- затяжное движение;
- кратковременный всплеск;
- последовательность нескольких всплесков.

Ранее signed semivariance и скачки уже изучались, поэтому сами по себе они не являются новизной.

**Новая гипотеза — зависимость ошибки HAR-J от последовательности шока и последующего восстановления.**

### 15. Новые признаки

Исследовать:

- время от крупнейшего отрицательного движения до закрытия;
- интенсивность последующего восстановления;
- накопленную RV до и после крупнейшего шока;
- долю объёма в фазе падения и восстановления;
- асимметрию поздних и ранних отрицательных движений;
- изменение структуры волатильности после шока;
- продолжительность восстановительной фазы.

Все признаки формировать из завершённой истории SBER.

Не допускать использования будущего дня.

Сопоставить с Path Signature: если признаки полностью дублируют друг друга, объединить гипотезы, а не тратить отдельный бюджет.

# НАПРАВЛЕНИЕ F — DISTRIBUTIONALLY ROBUST HYBRID

### 16. Проблема предыдущих исследований

Гибрид иногда снижает QLIKE на всей истории, но проигрывает в отдельных периодах.

После многочисленных испытаний обычная минимизация средней ошибки может выбирать конструкции, которые случайно подходят нескольким годам.

Предлагаю проверить принципиально иной критерий обучения **только новой поправки HAR-J**.

### 17. Робастная цель

Пусть g — корректирующий ML-модуль.

`F = H * exp(g(Z))`

Оценивать:

`L = mean(QLIKE) + lambda*InstabilityPenalty`

InstabilityPenalty должна измерять нестабильность коррекции между обучающими временными средами.

Исследовать:

- регуляризацию разброса потерь по доступным прошлым годам;
- ограниченный worst-environment risk;
- штраф на сильные изменения условной поправки;
- устойчивость к локальному изменению распределения признаков.

Не использовать будущие годы при формировании штрафов для прошлых прогнозов.

В частности, нельзя использовать 2022–2025 для настройки прогнозов 2017–2021.

Сравнить с обычной QLIKE-коррекцией на идентичном наборе признаков.

Главная цель — не обязательно минимальный исторический QLIKE, а устойчивое преимущество без зависимости от одного года.
