# НАПРАВЛЕНИЕ A — BESPOKE REALIZED VOLATILITY

## 4. Обучаемая мера исторической RV

Обычная RV:

`RV_t = sum_k r²_t,k`

Предлагаемая дополнительная характеристика:

`BRV_t = sum_k w_t,k * r²_t,k`

где веса определяются небольшой моделью на основании доступных характеристик свечей.

Возможные признаки:

- время внутри сессии;
- модуль доходности;
- направление доходности;
- объём;
- High–Low;
- положение относительно VWAP;
- концентрация RV;
- предшествующие изменения волатильности.

Веса должны быть неотрицательными и иметь заранее определённую нормировку.

**BRV не заменяет целевую RV и не изменяет HAR-J.**

Она используется исключительно как новый признак гибридной коррекции.

## 5. Особенность обучения

Сеть должна выбирать веса M10-интервалов с целью улучшить прогноз RV следующего торгового дня.

Использовать только прошлые данные при обучении весов.

Проверить несколько структур:

A1. Простые фиксированные веса по времени суток — контроль.

A2. Регуляризованные обучаемые веса.

A3. Веса, зависящие от направления и объёма движения.

A4. Компактный conditional weighting с ограниченной сложностью.

Не обучать свободный независимый вес для каждой исторической свечи.

Не создавать чрезмерную параметризацию.

## 6. Критерий новизны

Bespoke RV должна добавить информацию сверх:

- обычной RV;
- HAR-J;
- известных intraday shape;
- признаков V6;
- M10 Encoder V7;
- самостоятельных бустингов.

Проверить способность BRV прогнозировать ошибки самостоятельного XGBoost.

Если дополнительной информации нет, не продолжать усложнение.

# НАПРАВЛЕНИЕ B — MULTI-TASK INTRADAY FORECASTING

## 7. Основная идея

Обучать M10 Encoder не только на одном дневном значении RV.

Добавить вспомогательные задачи прогнозирования структуры следующей торговой сессии.

Основной прогноз:

`F_t+1 = HARJ_t+1 * exp(g_ML(Z_t))`

Вспомогательная структура:

`p_t+1 = softmax(q(Z_t))`

где p определяет ожидаемые доли будущей дневной RV.

Например:

- начало торгов;
- середина сессии;
- завершение торгов.

Сумма долей равна единице.

Прогноз компонент:

`RV_hat_part_j = F_t+1 * p_j`

Сумма прогнозов компонент должна точно совпадать с итоговым дневным прогнозом.

## 8. Вспомогательные задачи

Исследовать:

- доли RV по частям дня;
- вероятность выраженного внутридневного всплеска;
- ожидаемую отрицательную семивариацию;
- концентрацию RV;
- относительную интенсивность волатильности.

Не вводить слишком много задач одновременно.

Сначала проверить одну простую декомпозицию.

Затем добавить только те вспомогательные задачи, которые имеют дополнительную прогнозную ценность.

При обучении разрешено использовать фактическую структуру будущего дня как целевую метку.

При прогнозировании запрещено подавать её во вход модели.

## 9. Функция потерь

Основная функция — QLIKE итогового прогноза:

`L_main = log(F) + RV_actual/F`

Общий функционал:

`L = L_main + alpha*L_components + beta*Regularization`

Вес alpha выбирать исключительно на внутренней исторической валидации.

Использовать регуляризацию, чтобы вспомогательная задача не ухудшала основной прогноз.

Сравнить:

B1. Обычный Encoder с одной дневной целью.

B2. Encoder с прогнозом трёх внутридневных компонент.

B3. Encoder с компонентами и одной дополнительной задачей при подтверждённой полезности.

**Главный критерий — улучшение дневного QLIKE, а не точности вспомогательной задачи самой по себе.**

# НАПРАВЛЕНИЕ C — SELF-SUPERVISED M10 ENCODER

## 10. Главная гипотеза

Множество M10-наблюдений можно использовать для предварительного обучения представления рыночной динамики без необходимости иметь столько же независимых дневных целей.

Предлагается проверить компактное самоконтролируемое обучение.

## 11. Вспомогательные задачи

Возможные варианты:

- прогноз RV следующих нескольких M10-интервалов;
- восстановление скрытых участков прошлых последовательностей;
- восстановление внутридневной формы накопленной RV;
- прогноз затухания волатильности после завершённого ценового шока.

Выбрать не более двух различающихся задач.

Не использовать Transformer без отдельного обоснования.

Приоритет — компактная TCN или CNN.

## 12. Правильный временной протокол

Все параметры Encoder на дату t должны быть обучены исключительно на доступной истории до t.

При masked reconstruction нельзя обучать Encoder на будущих тестовых днях, даже если используются только входные данные без целевой RV.

После предварительного обучения Encoder либо замораживается, либо обновляется по заранее зафиксированному расписанию.

Признаки последующих дней не могут использоваться для пересчёта прошлого представления.

Проверить:

C1. Encoder без предварительного обучения.

C2. Encoder с прогнозированием будущих M10-интервалов.

C3. Encoder с другой вспомогательной задачей, только если она математически отличается от уже использованной в V7.

# НАПРАВЛЕНИЕ D — HAWKES SHOCK-INTENSITY HYBRID

## 13. Основная гипотеза

Скачки волатильности могут образовывать кластеры: один экстремальный M10-интервал увеличивает вероятность новых экстремальных интервалов.

Нужно исследовать динамику интенсивности таких событий.

## 14. Определение событий

Сначала определить событие скачка или экстремального движения по заранее установленному причинному правилу.

Не считать любой большой M10-доход истинным эконометрическим скачком.

Использовать корректное название события в зависимости от метода его выделения.

Проверить частоту событий, устойчивость порогов и исторические изменения торгового расписания.

## 15. Модель интенсивности

Начать с простой экспоненциально затухающей интенсивности.

`lambda_t = mu + sum_j alpha*exp(-beta*(t-t_j))`

Для дискретных M10-интервалов использовать корректную дискретную или интервально-цензурированную постановку.

Дополнительно рассмотреть раздельные интенсивности положительных и отрицательных экстремальных движений.

Не обучать высокоразмерный multivariate Hawkes.

## 16. Встраивание в гибрид

Использовать исторически доступную интенсивность скачков как признак коррекции:

`F_t = HARJ_t * exp(g_ML(lambda_t, Z_t))`

Обязательно проверить, даёт ли интенсивность дополнительную информацию к:

- предыдущей RV;
- jump-признакам HAR-J;
- признакам V5/V6;
- самостоятельным бустингам.

Не заменять HAR-J новой самостоятельной моделью.

# НАПРАВЛЕНИЕ E — CONDITIONAL DISTRIBUTION HYBRID

## 17. Модель распределения будущей RV

Исследовать, можно ли улучшить прогноз условного среднего RV, моделируя различия между спокойными и стрессовыми исходами.

`P(Y|Z) = (1-p(Z))*P_normal + p(Z)*P_stress`

Итоговый прогноз для QLIKE:

`F_t = E[Y_t | Z_t]`

Связать условное среднее с HAR-J.

Проверить:

- вероятность стрессового состояния;
- условную величину RV в стрессовом состоянии;
- размер возможной недооценки;
- устойчивость к редким событиям.

Не использовать условную медиану как основной прогноз QLIKE.

Не добавлять прогноз скачковой компоненты второй раз поверх уже учтённой HAR-J.

Если событий мало, ограничиться простой регуляризованной моделью.
