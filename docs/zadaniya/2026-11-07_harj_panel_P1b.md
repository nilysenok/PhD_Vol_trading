## Движок (контракт, им пользуются P2)
- Вход: панель, список признаков, offset-ряд (ln Ĥ или ln RV_m), функция потерь (`qlike` основная; `l2log` для A2), модуль (`xgb` | `lgbm`), исключаемые бумаги (для LOTO, R11), seed.
- Месячное переобучение (первый торговый день месяца) на расширяющемся окне; в обучение на дату d — пары (j, s) **всех** бумаг с s⁺ ≤ d (R4). Ранняя остановка — последние 126 дат окна, вне обучения (№ 99). HP по R8; глубина {2; 4} — два прохода walk-forward; c ∈ {0,5; 1; 2} и λ — при прогнозе (У-6, У-7); выбор на год Y — по закрытым прогнозам года Y−1 (t⁺ < 01.01.Y) по среднему по бумагам QLIKE; прогнозы с 2016, 2016 — умолчания R8.
- QLIKE: L = ln f + RV/f, f = exp(offset + g); grad = 1 − RV/f, hess = RV/f — **численная проверка** в тесте. Offset — `base_margin` (XGB) / `init_score` (LGBM).
- Выход на бумагу-дату: g (сырой), выбранные глубина/c/λ, итог σ̂², число пар обучения, время обучения.
- λ = 0 ⇒ σ̂² ≡ exp(offset) с поправкой масштаба K1 (то есть ≡ K1) **побитно на боевом пути**.

## Контроли
- **K4 / K5** — XGB / LGBM без HAR-J: признаки X+M+C из `P0_FEATURES.md` **без** величин, построенных из прогноза HAR (ln Ĥ − ln RV_m, ошибки HAR), offset ln RV_m, QLIKE, λ ≡ 1 (У-6), c по R8.
- **K6** — HAR-J + E8 на каждой бумаге (замороженная спецификация Ж-214, без новой подгонки параметров спецификации); SBER — побитно равен ряду E8 Ж-214 (`data/regen/harj_hybrid_v2/*_series.parquet`), иначе разбор до причины.
- **K7** — компонентная HAR (C1 при λ = 0, R7): f = β²_{i,t}·HAR-J(IMOEX) + HAR-J(u_i), β по прошлым 252 дням (≥ 0), u_i = max(RV_i − β² RV_IMOEX, ε·RV_i), ε = 0,01. Положительность — тест.

## Тесты (через боевой путь, каждая мутация падает на мутации и проходит на правке)
λ = 0 ≡ K1 побитно; блок ранней остановки в обучении (№ 99); пара с s⁺ > d в обучении; выбор года Y по прогнозам с t⁺ ≥ 01.01.Y (№ 102); чужой день t+1 (R4); исключённая бумага LOTO попадает в обучение; QLIKE grad/hess численно; K7 > 0; обрезка будущего всей панели после d не меняет прогноз на d.
