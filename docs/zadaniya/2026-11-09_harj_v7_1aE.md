## Что сделать (объявлено в плане; не менять)
1. **Энкодеры** (torch).
   - **TCN:** каналы 11 → 8, ядро 3, расширения 1, 2, 4, 8, причинные свёртки и остаточные связи; голова — прогноз ln(r²_{j+1}+ε) следующего бара. Не больше 1000 параметров.
   - **CNN:** 11 → 8 → 8, ядро 5, причинное дополнение. Не больше 1000 параметров.
   - Маска неполных дней и смены расписания — из листа 0.
   - Окна 1 и 5 дней. В окне 5 дней предыдущие дни идут перед днём d, причинность сохраняется.
2. **Предобучение (Stage A).**
   - Цель: ln(r²_{j+1} + ε) бара j + 1 по барам ≤ j; ε объявить, например 1e-6 от медианы r² по прошлому.
   - Энкодер года Y учится на барах сессий до 01.01.Y. Годы Y = 2018 … 2026; для 2018 обучение на барах 2015-07 … 2017.
   - Потери MSE на лог-метке, Adam, ранняя остановка по последним 10 % дней внутри обучающего прошлого.
   - 5 seeds (0–4); torch детерминированный, 1 поток.
   - Выход — функция `train_encoder(kind, window, year, seed, bars)`. Вызов на данных SBER — только из стадии 1b.
3. **Представление z_d.**
   - Конкатенация среднего и последнего скрытого состояния по окну.
   - Главные компоненты до d_z = 4 — по z дат < 01.01.Y (энкодер того же года); стандартизация — тоже по прошлому.
   - Функция `encode(model, X_d)` и `fit_pca_past(...)`.
4. **Гейт новизны E0.** Частный R² каждой компоненты z на (S, Σ, ln H, ℓ = ln(M/H)): PIT-регрессия по прошлому, расширяющееся окно, гребень.
   - Порог плана: R² ≥ 0,9 по всем компонентам на 2018–2021 ⇒ энкодер новой информации не несёт.
   - Функция `novelty_gate(z, X_ref, dates)`.
   - Тест на синтетике: z = линейная функция от S даёт R² ≈ 1, независимый z — ≈ 0.
