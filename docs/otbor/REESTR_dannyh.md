- **Файл:** `docs/issledovaniya/2026-10-28_dividendy_2015_2016.csv` (PR #385), читается `fastbt/dividendy.py` вместе с таблицей 2017–2021; файлы исследований не менялись. 46 выплат; AFLT, MTLR («выплат не было») пропускаются.

- **Не сделано:** `fastbt/sobytiya_e1.py::DIV_CSV` (ось событий `div`, выключена до сверки ❓5) по-прежнему читает только таблицу 2017–2021.
