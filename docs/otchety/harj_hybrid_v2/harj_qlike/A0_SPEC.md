## Формула

```
ln RV_{t+1} = b0 + b_d·ln RV_t + b_w·ln RV_w,t + b_m·ln RV_m,t + b_J·ln(1 + J_t) + ε_{t+1}
σ̂²_b(d)    = exp( f(d) + s²/2 ),   f(d) = b0 + b_d·ln RV_d + b_w·ln RV_w,d + b_m·ln RV_m,d + b_J·ln(1+J_d),   s² = SSR/(n − 5)
```

- **Контрольная колонка** `HAR` в `components.parquet` = σ̂²_b (вариант «б»). Вариант «а» = exp(f) (без s²/2) — QLIKE 0,249437, не контроль.
- **Единицы.** RV, BV, J — в %² (десятичные доли × 10⁴, `daily.SCALE`) до любых логарифмов.
- **RV_t** = Σ r_i² по барам основной сессии (begin от 10:00 до 18:40 включительно, 53 бара; до 24.04.2015 — 52 бара до 18:30). r_1 = ln(close_1/open_1) (ночной гэп и аукционы 09:50 / 19:00 не входят), r_i = ln(close_i/close_{i−1}).
- **BV_t** = (π/2)·Σ_{i≥2} |r_i||r_{i−1}| (без поправки n/(n−1)); **J_t = max(RV_t − BV_t, 0)**.
- **RV_w, RV_m** — средние УРОВНЕЙ RV за 5 / 22 годных дня сегмента, включая день t (`daily.W_WEEK`, `W_MONTH`; без склейки через разрыв).
- **Дни:** < 30 баров основной сессии — исключены; с 01.03.2025 день без сессии IMOEX и выходные — исключены; 28.02–24.03.2022 — разрыв (сегмент 0: 1952 строки, сегмент 1: 992); пара (t, t+1) не пересекает разрыв.
- **Выравнивание.** Прогноз на d (после 18:50 d) — на RV_{d+1}; сетка — 2271 дата d с 30.12.2016 по 26.02.2026 (цель с 03.01.2017 по 27.02.2026), `har.eligible`.

## Оценивание и окна

- OLS с константой (`har.ols`, lstsq), **расширяющееся окно, переоценка каждый день d**, обучающие пары (t, t+1) с t+1 ≤ d, один сегмент, признаки конечны (`har.pairs`). Первое окно (d = 30.12.2016): 629 пар (первая строка с RV_m — 22-й день, 02.06.2014 + 21); последнее (26.02.2026): 2899 пар.
- Прогноз и коэффициенты d не видят RV_{d+1} и далее (тест `test_v2_hv2_a0.py::test_pit_future_rows_do_not_change_fit_and_mutation_is_caught`).
