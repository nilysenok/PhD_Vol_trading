- **V6 (HARQ-J; 12; ступени Л2, Л3).** Реакция коэффициентов на качество измерения (Bollerslev–Patton–Quaedvlieg), **не RQ как признак бустинга** (RQ-признаки в бустинге уже есть: `f4_rq`, `f4_rq_rel`). q_t = z-оценка ln√RQ_t относительно среднего и σ по дням s < t (расширяющееся, причинно, ≥ 60 дней); q^rel_t — то же для ln(rv_rel) = ln(√(2 RQ/n)/RV). Лог-спецификация: ln RV_{t+1} = b0 + (b_d + b_dQ q_t) ln RV_d + b_w ln RV_w + b_m ln RV_m + b_J ln(1+J_d); коэффициенты — только прошлое. Конфигурации: **H1** `harq_ln_d` (реакция на d, q = ln√RQ, OLS); **H2** `harq_ln_dJ` (реакция на d и J); **H3** `harq_ln_dw` (d и w, q̄₅ — среднее q за 5 дней); **H4** `harq_rel_d` (q^rel, d); **H5** `harq_ln_d_wins` (H1 при винзоризации ln RV_d по расширяющимся 1/99 процентилям — устойчивость к экстремальной RV); **H6** `harq_ln_d_stress` (H1 + b_dQS·q·1[S_t], S_t — 5-дневная RV IMOEX выше расширяющегося 80-го процентиля — спокойный / стрессовый рынок); **H7** `qlike_harq_d` (H1 с QLIKE-подгонкой, `hs_qfit`; Л3); **H8** `qlike_harq_dJ` (H2, QLIKE; Л3); **H9** `harq_levels_bpq` (оригинал BPQ в уровнях: σ̂² = β0 + (β1 + β1Q√RQ_t) RV_d + β2 RV_w + β3 RV_m + β_J J, QLIKE-подгонка, реакция ≥ 0 на историческом диапазоне √RQ); **H10, H11** — соседи лучшей (винзоризация 0,5/99,5 и 2,5/97,5; порог стресса 70/90; стандартизация в окне 504) — плато; **H12** — резерв. **Минимальный набор: H1, H4, H7 (3).** Обязательный выход: `harq_j/HARQ_REACTION.csv` — β_d + b_dQ·q при q ∈ {−1; 0; +1} по годам и знак b_dQ (BPQ ожидают < 0). Контроли: A0 (для Л2), лучшая Q (для Л3).
- **V7 (декомпозиции RV; 16; ступени Л4, Л5; п. 8–11 блока).** Три **самостоятельные** схемы, компоненты разных схем не суммируются и не смешиваются; совместное использование — только после доказанной пользы каждой. Для схемы: прогноз каждой компоненты log-HAR (d, w, m своей компоненты, поправка s²/2), σ̂²_Σ = Σ_k σ̂²_k > 0; компонента с нулевым значением в X_d → `n_fallback`; контроль общего — прямой A0 (D1). Тождества (допуск 1·10⁻¹² относительный, `M10_IDENTITIES.csv`): rv_open + rv_mid + rv_close = RV; RS⁺ + RS⁻ = RV; **C + J = RV, где C := RV − J** (BV в сумму не входит: BV + J ≠ RV на 642 из 2944 дней, где BV > RV). **Расписание — по фактическим барам** (`SCHEDULE_BY_YEAR.csv`: до 24.04.2015 последний бар 18:30, 52 бара; далее 18:40, 53); OPEN — begin < 11:00, CLOSE — begin ≥ последний бар режима − 50 мин, MIDDLE — остальное; не номерами баров. Схема **S (знак):** **S1** `sign_own` (RS⁺, RS⁻, каждая по своим d, w, m + ln(1+J)); **S2** `sign_cross` (обе полусуммы в каждой регрессии); **S3** `sign_shar_direct` (D1: прямая ln RV на ln RS⁺_d, ln RS⁻_d, w, m, J — SHAR-аналог); **S4** `sign_qlike` (S1, QLIKE-подгонка). Схема **J (C + J):** **J1** `cj_own` (C — log-HAR по C; J — ln(1+J) по своим лагам, Ĵ = expm1(f + s²/2) ≥ 0); **J2** `c_only_scaled` (прогноз только C × PIT-коэффициент (RV/C) по закрытым — «скачки не прогнозируются»); **J3** `cj_logit` (вероятность J_{t+1} > 0 по прошлому, логистика с ridge, расширяющееся окно; AUC и Brier к базовой частоте — **прогноз будущих скачков отдельно от диагностики состоявшихся**); **J4** `cj_cross` (перекрёстные лаги C и J). Схема **T (время суток):** **T1** `tod_own`; **T2** `tod_cross` (d-лаги трёх частей в каждой); **T3** `tod_edges` (OPEN и MIDDLE получают CLOSE_t, CLOSE — OPEN_t: информация начала и завершения торгов); **T4** `tod_qlike` (T1, QLIKE). 12 конфигураций + 4 резерв (плато лучшей схемы). **Минимальный набор: S1, S3, J1, J3, T1, T3 (6).** Стабильность по годам и сумма прогнозов vs прямой — обязательные выходы.

- **V11 (согласование; 10; ступень Л9; п. 19).** Только для схем V7, прошедших V13. Правило отклонения: схема, не превосходящая простую сумму и прямой прогноз одновременно, отклоняется. 3 + 3 + 4 резерв. **Минимальный набор: R2S, R2J, R2T (3).** Реакция на нулевые и экстремальные значения компонент — тесты.
