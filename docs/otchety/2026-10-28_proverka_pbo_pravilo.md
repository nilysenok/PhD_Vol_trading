## 1. Эталон на синтетике (независимый счёт, чистый Python, своя реализация CSCV)
Сетка 3x2: c0=(0,0) c1=(0,1) c2=(1,0) c3=(1,1) c4=(2,0) c5=(2,1). T=8 строк, 8 блоков (блок = строка), 70 разбиений C(8,4).
M: константы c0..c4 = 0.8, 0.5, 0.6, 0.7, 0.9; c5 (шип) = +10 в строках 0..3, -10 в строках 4..7.
CSCV как в `sweep_drivers.pbo_cscv`: ранг = доля точек со средним на test строго ниже выбранной, делённая на N-1; logit<=0 (ранг<=0.5) = переобучение.

Выкладка. k = число train-блоков среди строк 0..3 (разбиений: k=0:1, 1:16, 2:36, 3:16, 4:1). Среднее шипа на train a=5(k-2) = -10,-5,0,5,10; на test 5(2-k).
- argmax: a<=0 (k<=2, 53 разбиения) -> c4 (0.9); на test шип 10/5/0, ранг c4 = 4/5, 4/5, 1 -> не переобучение. a>=5 (k=3,4, 17 разбиений) -> c5; на test шип -5/-10 худший, ранг 0 -> переобучение. **PBO_argmax = 17/70 = 0.242857**.
- центр плато (плато = среднее по соседям +-1 шаг по каждой оси включая себя; min_neighbors=3 — на 3x2 краёв нет; допуск ничьей 0.05; ничья -> меньшая sigma на train, затем меньший индекс). Плато: P0 (c0,c1) = mean(c0..c3) = 0.65; P1 (c2,c3) = (3.5+a)/6; P2 (c4,c5) = (2.2+a)/4. При a<=0 лучше P0 (при a=0: 0.65 против 0.583, разрыв 0.067 > 0.05) -> ничья c0/c1 -> c0 (0.8). При a>=5 лучше P2 (1.8; 3.05) -> ничья c4/c5 -> c4. Выбор: c0 в 53 разбиениях, c4 в 17. Ранги: c0 при k=0,1 — 4/5, при k=2 — 1; c4 при k=3,4 — 1. **PBO_центр = 0/70 = 0**.
- Мутация «argmax внутри центра плато» даёт 17/70 вместо 0/70: тест обязан это различать.
Без tie-break по sigma (первый индекс) результат тот же: 0/70, выборы {c0:53, c4:17}. Программа: argmax (17, 70, {c4:53, c5:17}); центр (0, 70, {c0:53, c4:17}).
Оговорка: на 3x2 окрестность по оси из двух значений охватывает всю ось, ничьи плато неизбежны — проверяется tie-break. В реальном коде sigma126 считается по excess_d, не по M: на синтетике нужна подмена или передача sigma в select_fn.
