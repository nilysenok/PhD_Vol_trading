## 5. Математические определения операторов

Обозначения: H = K1 (HAR-J PIT), K2 (XGBoost), K3 (LightGBM), D2 (LGBM-D2, контроль), M = √(K2·K3), ℓ = ln(M/H), RV — реализованная дисперсия дня t⁺ = d+1; QLIKE(RV, F) = RV/F − ln(RV/F) − 1. Параметры всех операторов оценены по ЗАКРЫТЫМ парам (цель t⁺ ≤ d), расширяющимся окном с 2017-01 на панели 17 бумаг, раз в месяц (если не указано иное); до первых 60 закрытых пар — приор; иерархия θ_i = θ_панель + δ_i со штрафом κ = 250 пар-эквивалентов (κ·s²/2·Σδ²). Базовые прогнозы не переобучались.

**B (5 из 6; B5 не считался).** B1 F = w·H + (1−w)·M; B2 F = H^w·M^(1−w); B3 1/F = w/H + (1−w)/M; B4 F = (w·H^p + (1−w)·M^p)^(1/p), p ∈ [−2; 2] общий; B5 F = H^w·M^(1−w)·e^b — только при правиле B5_RULE (c = 1,0140, t = 0,43 < 1,96: не выполнено, не считался); B6 F = H^a·K2^b·K3^c, a+b+c = 1, ≥ 0. Вес — оптимум среднего QLIKE.
**C (10).** F = H·exp(w(Z)·ℓ), w = σ(α_i + βᵀz); z стандартизован по прошлому; гребень на β. C1 z = (ℓ, |ℓ|); C2 + прошлое преимущество EWMA₂₀ QLIKE(H) − QLIKE(M) и лог-ошибки; C3 + рыночные (медиана ln RV, Δ ln RV, доля скачка); C4 + HAR-surprise и Intraday Shape (Херфиндаль 10-минутных квадратов, доля последнего часа). C5 GAM-гейт (кубический B-сплайн по ℓ, 5 ст. св.); C6 монотонный (γ ≥ 0 при EWMA-преимуществе); C7 QLIKE-бустинг гейта (200 деревьев глубины 2, раз в год); C8 мягкие режимы w = π·w_calm + (1−π)·w_crisis, π = σ(a + b·медиана ln RV); C9 три эксперта F = H^a·K2^b·K3^c с softmax-весами от z; C10 иерархические наклоны β_i = β + η_i.
**E (6).** F = F0·exp(b_t), F0 = H (E1) или G = H^w·M^(1−w) (B2-вес; E2–E6); b_t — причинная поправка смещения, обрезка ±0,5, ĉ = Σω·RV/F0/Σω. E1/E2 EWMA (полураспад 60) с иерархией; E3 общая панельная EWMA (20); E4 панель (20) × относительная бумажная часть (120); E5 фильтр Калмана «локальный уровень» b = m + s²/2; E6 совместные (b_t, w_t) по дисконтированному QLIKE (полураспад 250 пар) + дневная поправка.
**CS (2), холодный старт (база C8).** CS1 λ_prior(n) = 250·250/(250+n), n — закрытые пары панели; CS2 κ_i(n_i) = 250·250/(250+n_i), n_i — пары бумаги.

**I (3), согласованные компоненты.** RV = C + J (J = max(RV − BV, 0), C = RV − J; как в HAR-J K1). Ĉ — HAR на ln C (день, неделя, месяц), гребень, поправка e^{σ̂²/2}; Ĵ = p̂·m̂ (логит события J > 0, EWMA₆₀ величины скачка). ## 13. Причины выигрыша и проигрыша; почему гибрид не превосходит бустинги устойчиво

1. **Диапазон двух прогнозов слишком узок.** RV лежит вне [min(H, M); max(H, M)] в 92,3 % дней M16 (H_REPORT; DX_YEARS.csv: 91–93 % по годам) и эти дни несут 99,7 % потерь; поэтому выпуклая смесь H и M даже с идеальным постоянным весом (O1) снимает лишь 0,9 % QLIKE лучшей одиночной модели, с идеальным дневным весом внутри диапазона (O2) — 13,8 %, остаток 86 % требует информации вне прогнозов (таблица oracle выше; A_ORACLE.csv). Реальный условный выигрыш — малая часть O2.
2. **Ошибки почти совпадают.** Корреляция логарифмических ошибок на M16 (вся история): H–K2 0,966, H–K3 0,963, K2–K3 0,995 (A_REPORT, A_COMPLEMENT.csv): K2 и K3 — практически одна модель, поэтому смесь K2·K3 диверсификации не даёт, а к HAR-J добавляет выигрыш только там, где HAR-J информативен.
