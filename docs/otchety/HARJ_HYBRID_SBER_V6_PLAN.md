## 2. Общая конструкция

- **База.** H_t = K1, PIT-прогноз HAR-J SBER на t⁺, сохранённый, замороженный.
  - Для прогрева 2015-07-07 … 2016-12-29 H считается той же функцией `har.forecast_at` (лист 0: побитно = K1 на пересечении). Сохранённый K1 не меняется.
- **Прогноз.** F_t = H_t·exp(clip(g_t, −1, 1)). При g ≡ 0 F = H побитно.
- **Цель.** Остаток e_t = ln RV_{t⁺} − ln H_t.
- **Потеря.** QLIKE(RV, F) = RV/F − ln(RV/F) − 1 = exp(e − g) − (e − g) − 1. Она выпукла по g, поэтому линейная g оценивается прямо под QLIKE.
  - Градиент по g: 1 − exp(e − g); гессиан: exp(e − g).
- **Переоценка.** В первый торговый день каждого месяца, по закрытым парам (t⁺ ≤ d) с 2015-07-07. Окно расширяющееся.
  - Нормировка признаков — среднее и СКО по тем же закрытым парам.
  - Прогнозы дней месяца — по параметрам, оценённым на его первый день.
- **Обучатели** — объявлены сейчас, одинаковы во всех конфигурациях.
  - **LIN** — линейная g = θ₀ + θ'z: минимум mean QLIKE + λ‖θ‖² (Ньютон).
    - λ выбирается на каждой переоценке по закрытым парам: обучение — все, кроме последних 252, проверка — последние 252, сетка {1e-3, 1e-2, 1e-1, 1}.
    - Затем модель переоценивается на всех закрытых парах. Это вложенный PIT-выбор, не выбор по результату.
  - **GBM** — LightGBM с собственной целью QLIKE по g (начальное g = 0). Параметры: num_leaves 4, learning_rate 0,03, min_data_in_leaf 50, feature_fraction 0,8, без бэггинга, seed 0, ≤ 300 деревьев.
    - Число деревьев — ранняя остановка на последних 252 закрытых парах. Затем модель переобучается на всех закрытых парах с этим числом деревьев (мутации № 99, 100).
  - XGBoost в V6 как обучатель поправки не используется: один обучатель-бустинг даёт сравнимые абляции. Самостоятельный XGB (K2) — контроль.
- **Данные.** Только `data/iss_check/bars_10m_full/SBER.parquet` (M10: open, high, low, close, volume), основная сессия 10:00–18:40, и дневные ряды SBER проекта. Признаки дня d — только из баров сессий ≤ d.

### 2.1 Обычная сводка S (абляционная база, общая для всех направлений)

Признаки дня d; z — нормировка на закрытых парах:
- s1–s3: ln RV_d − ln H_t, ln RV_w − ln H_t, ln RV_m − ln H_t (неделя 5, месяц 22 дня);
- s4: RS⁻_d / RV_d;
- s5: r_d / √RV_d, где r_d = ln(close/open) сессии;
- s6: J_d / RV_d, где J = max(RV − BV, 0), BV — определение проекта (V2/V4);
- s7: ln(Vol_d / среднее Vol за 20 прошлых сессий, включая d);
- s8–s9: доля RV_d в первой и последней трети баров сессии.

Признаки s1–s7 не зависят от перестановки баров внутри дня. Признаки s8–s9 — обычная форма дня, уже проверенная.

### 2.2 Правило «новая информация» (Ж-229 п. 5; объявлено до счёта)

- (i) Δ = mean QLIKE(X) − mean QLIKE(Y) < 0;
- (ii) DM односторонний (НУ, лаг 5) p < 0,05 без поправки;

Окна 2022–2025 и 2026 показываются, но в правиле не участвуют. p с поправкой Холма (N = 722, N_wide = 3122) показывается рядом и не меняет вывода о направлении.

## 3. Направление A — Path Signature (4 конфигурации)

**Траектория дня d.** X_k = (τ, P, V, N, Q)_k, k = 0…n, X_0 = 0:
- τ = k/n;
- P = Σ_{j≤k} r_j / √RV_d;
- V = Σ_{j≤k} r_j² / RV_d;
- N = Σ_{j≤k} r_j²·1{r_j < 0} / RV_d;
- Q = Σ_{j≤k} vol_j / Vol_d.

Нормировка делает траекторию безразмерной: величина дня — в S, форма и порядок — в подписи.

**Подпись второго порядка.** Уровень 1 — приращения (1, P_n, 1, RS⁻/RV, 1): это уже признаки S. Симметричная часть уровня 2 — произведения уровня 1, новой информации не несёт. Новое — антисимметричная часть, площади Леви:

A_ij = ½ Σ_{k<l} (ΔX_i,k ΔX_j,l − ΔX_j,k ΔX_i,l).

- Площади с τ — это моменты «когда» и близки к форме дня s8–s9.
- Шесть площадей без τ — (P,V), (P,N), (P,Q), (V,N), (V,Q), (N,Q) — описывают порядок «цена → волатильность», «объём → волатильность», «отрицательная доходность → рост RV».
- **Обращение времени.** При обращении A_ij меняет знак, а S не меняется. Это и есть чувствительность к порядку событий (связь с направлением B).

**Признаки Σ.** Шесть площадей без τ за день d и их средние за 5 сессий ≤ d — 12 признаков.

**Признаки Σ³.** Логарифмическая подпись третьего порядка по каналам (τ, P, V), базис Линдона, 8 элементов, за день d.

**Конфигурации:**

| id | Признаки | Обучатель | Роль |
|---|---|---|---|
| A0 | S | LIN | абляционная база «обычная сводка»; база правила 2.2 для A, C, E |
| A1 | S + Σ | LIN | площади второго порядка; новая информация — A1 против A0 |
| A2 | S + Σ | GBM | то же с нелинейной поправкой; против A0 и против A1 |
| A3 | S + Σ + Σ³ | LIN | **только если** A1 или A2 несёт новую информацию против A0; иначе не считается и не расходуется |

**Абляция «+ спектр» (этап 6 блока)** — без бюджета:
- сравнение A1/A2 с сохранёнными V5 SP1–SP4 по SBER (контроли);
- диагностика DX-A задним числом, не выбор. На закрытых парах 2015-07 … 2021 QLIKE-регрессия e на S + доли энергий трёх полос DCT-II V5 SBER + Σ. Тест Вальда для Σ при наличии спектра. Модуль DX-A не импортируется путём прогноза.

Закрытие A: ни A1, ни A2 не несёт новой информации против A0 (п. 2.2).

## 4. Направление C — Measurement Uncertainty (4 конфигурации)

**Признаки качества измерения Q дня d** (только M10; тиков и спредов нет, поэтому утверждений о шуме микроструктуры не делается):
- q1–q2: ln(RV20_d / RV_d), ln(RV30_d / RV_d) — RV на сетках 20 и 30 минут, средние по 2 и 3 сдвигам сетки;
- q3: СКО RV30 по трём сдвигам / среднее — чувствительность к смещению сетки;
- q4: доля нулевых M10-доходностей;
- q5: Σr⁴ / (Σr²)² — концентрация квадратов доходностей (не RQ-поправка HARQ: в S и в g как отдельный признак, без взаимодействия с ln RV);
- q6: первая автокорреляция M10-доходностей дня;
- q7: индекс Херфиндаля объёма по барам;
- q8: n_d / мода n года — доля баров в наличии.

**Индекс неустойчивости измерения** u_d = среднее z(q3), z(|q6|), z(q1), z(q2) — нормировка на закрытых парах.

**Конфигурации:**

| id | Признаки | Обучатель | Роль |
|---|---|---|---|
| C1 | S + Q | LIN | только качество измерения; против A0 |
| C2 | S + Q | GBM | ограниченная нелинейная поправка; против A0 и C1 |
| C3 | S + Q + u·(s1, s2, s3) | LIN | вес отклонения прошлой RV от H зависит от надёжности её измерения; против C1. Не HARQ: u строится из сеток и автокорреляции, не из RQ |
| C4 | S + Q + u·(s1, s2, s3) | GBM | **только если** C1, C2 или C3 несёт новую информацию против A0 |

**Главная проверка C.** Дни d с u_d в верхнем квинтиле (порог квинтиля — по закрытым парам) против остальных. Показывается Δ QLIKE C* − A0 и C* − K3 в каждой группе.

Закрытие C: ни C1, ни C2, ни C3 не несёт новой информации против A0.

## 5. Направления B / E — Time-Reversal / Shock-Recovery (3 конфигурации)

**Диагностика обращения времени (B, без бюджета).** Каждый признак S, Σ, R пересчитывается на обращённой траектории дня. Показывается доля признаков, меняющихся при обращении: площади меняют знак, S не меняется. Обращённые признаки как вход прогноза не используются (п. 7 блока).

**Признаки шока и восстановления R дня d.** Шок — бар с наименьшей r_j:
- ρ1: время от шока до закрытия, (n − k*)/n;
- ρ2: восстановление (P_n − P_{k*}) / (P_0 − min P), в σ-единицах дня;
- ρ3: ln(RV после шока на бар / RV до шока на бар);
- ρ4: доля объёма после шока;
- ρ5: ln(RS⁻ второй половины / RS⁻ первой половины);
- ρ6: число баров с |r| > 3·√(RV_d/n) — серия всплесков.

**Конфигурации:**

| id | Признаки | Обучатель | Роль |
|---|---|---|---|
| E1 | S + R | LIN | шок и восстановление; против A0 |
| E2 | S + R | GBM | против A0 и E1 |
| E3 | S + R + Σ | LIN | **только если** E1 или E2 и A1 или A2 несут новую информацию. Пересечение с A: против A1 и против E1. Иначе не считается |

**Слияние с A.** Если |корреляция| признака R с признаком Σ на закрытых парах 2015–2016 больше 0,8, признак R исключается до счёта E1 как дубль. Запись — в отчёт листа.

## 6. Направление D — Historical Analog (3 конфигурации + контроль)

**Состояние Z_D дня d** — 6 измерений, z-нормировка на закрытых парах: s1, s2, s4, s5, s7, доля RV последней трети (s9).

**Пул аналогов** — закрытые пары s (t⁺_s ≤ d) с 2015-07-07, R_s = RV_{s⁺} / H_s. Минимум QLIKE по постоянному множителю на наборе пар — это среднее R_s. Поэтому локальная поправка — взвешенное среднее R по аналогам.

**Конфигурации** (евклидово расстояние в Z_D; пересчёт ежедневно по закрытым парам):

| id | Правило | Роль |
|---|---|---|
| D1 | M = среднее R по k = 50 ближайшим | ближайшие соседи |
| D2 | M = Σ w R / Σ w по k = 100 ближайшим, w = exp(−dist²/(2h²)), h = медиана расстояний до 50-го соседа | взвешенные по расстоянию |
| D3 | M = (n_eff·M_D2 + 50·M_glob) / (n_eff + 50), n_eff = (Σw)² / Σw² | сжатие к глобальной калибровке |

F = H·clip(M, e⁻¹, e). **Контроль K9** (без бюджета, не кандидат): глобальная QLIKE-калибровка F = H·M_glob, M_glob = среднее R по всем закрытым парам (этап 13 блока). Новая информация D считается против K9 (п. 2.2 с Y = K9).

**Проверка «не сводится к режиму».** Δ D2 − K9 по терцилям H_t (пороги — по закрытым парам) и корреляция log M_D2 с ln H_t. Если выигрыш только в одном терциле H, это записывается как «эквивалент калибровки по уровню».

Закрытие D: ни D1, ни D2, ни D3 не несёт новой информации против K9.
