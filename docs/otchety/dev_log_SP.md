## Находки п. 6 (проверка кода `fastbt.s9.Engine.port/_finish`, разработка 2018–2021; до аудита)

**Ставка.**
- Свободный капитал размещается под ту же ставку ЦБ, которая вычитается в избыточной доходности: `fdr = max(0, 1−exp)·rf·cal`, `excess = total − rf·cal`, где `rf = key_rate/365` из `msp.rate_cbr()`.
- Проверено по дням. Ставка размещения `fdr/((1−exp)·cal)·365` равна ставке вычитания `(total−excess)/cal·365` на всех 1 011 днях у A, опорных B/C/D, P1 и P2; |Δ| ≤ 6e-14 п.п. Ставка вычитания совпадает с файлом ЦБ: |Δ| ≤ 2e-14 п.п.
- Примеры по дням (портфель A):
  - 14.09.2018 — 7,25 / 7,25; 17.09.2018 — 7,50 / 7,50 (кал. дней 3);
  - 14.06.2019 — 7,75 / 7,75; 17.06.2019 — 7,50 / 7,50;
  - 24.04.2020 — 6,00 / 6,00; 27.04.2020 — 5,50 / 5,50;
  - 17.12.2021 — 7,50 / 7,50; 20.12.2021 — 8,50 / 8,50.
- Расхождение 1, для FA, не чинил: ставка даты d начисляется на все календарные дни интервала (d−1, d]. В понедельник смены выходные идут по новой ставке. Пример: 17.09.2018 — 7,50% за 3 дня, а по календарю вышло бы 7,33%. Размещение и вычитание сдвинуты одинаково, поэтому знак не меняется: в excess остаётся только член −exp·rf·cal, эффект ~1e-6 в день.
- Расхождение 2, для FA: в `key_rate_cbr.parquet` ставка 7,50% стоит с пятницы 09.02.2018. Все остальные 25 смен 2017–2021 приходятся на понедельник или вторник. По памяти, решение ЦБ от 09.02.2018 действует с 12.02.2018. Сверить с cbr.ru я не мог: сеть закрыта. Эффект — 1 день по 7,50% вместо 7,75%.
