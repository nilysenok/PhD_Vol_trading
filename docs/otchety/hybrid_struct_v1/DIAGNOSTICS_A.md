## Короткий вывод
**Условной QLIKE-информации HAR сверх XGBoost/LightGBM не обнаружено** (вопрос 8): коэффициент при HAR-прогнозе в σ̂² = XJ·exp(a + γδ) γ = −0,026 (t = −0,09), при LGBM +0,020 (t = 0,08); OOS по прошлому Δ = +0,0060 (XJ, DM p 0,25) и +0,0057 (LF, p 0,27) — поправка ухудшает. Обратное направление есть: бустинг добавляет информацию к HAR (γ = 1,026, t = 3,59; OOS Δ = −0,0166, p 0,13; ex 24.02 Δ = −0,0070, p 0,045, Холм 0,81). Среди 83 признаков PIT нет ни одного, предсказывающего знак/размер dq после Холма (минимальный p Холма = 1,0). Информация в δ есть для ln-ошибки (МНК-коэффициент 0,357, t = 3,6), но не для QLIKE (QLIKE при β = 0,357: 0,2141 против 0,2113 при β = 0). Единственные ненулевые сигналы по компонентам — асимметрия RS−/RS+ (γ = 0,066, t = 2,1), краткая RV_d (t = 1,85), скачок J (t = 1,65); в OOS они не дают выигрыша. Выигрыш HAR+бустинг сосредоточен в 2018 (единственный год с Δ < 0 при γ_δ: −0,0194).

## Источники дополнительной информации (итог этапа A)
1. **Условный источник сверх бустинга не найден** (QLIKE, SBER h=1): HAR-прогноз, RV_d/w/m, J — нет; ни одного устойчивого предиктора dq из 83.
2. Кандидаты только для проверки в D (с пометкой «не подтверждено»): асимметрия RS−/RS+, краткая компонента RV_d, скачок J (in-sample t 1,65–3,3, OOS без выигрыша).
3. Расхождение δ информативно для ln-ошибки (b ≈ 0,36), но не для QLIKE — гибриды, оптимизирующие QLIKE, этой информации не используют; ожидание для B/C: нулевое.
4. Преимущество комбинаций сосредоточено в 2018 (и частично 2017), как в Ж-211.
5. Обратное направление: бустинг несёт информацию сверх HAR — HAR-J остаётся контролем, а не источником.
**Решение по плану (класс B, умолчание):** выполнить B минимально, C4 обязательно, D0 (абляция), E1, F-тест третьего эксперта + F1/F2; остальное — по правилу «продолжать» (`GATES_HS.md`).
