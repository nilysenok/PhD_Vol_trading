Все HP фиксированы заранее (не годовой выбор): глубина 1 (аддитивная g, без взаимодействий), 150 деревьев, lr 0,03, subsample 0,8, colsample 0,8, min_child_weight/min_data_in_leaf 50, lambda_l2 10. Конфигурации на модель и **архитектурное отличие**:
  - **Ca** — признаки Б-2 + F4 (33), глубина 1. Отличие от `Ж-206:xgb_lgbm_ensemble:fec343a84fe5` (B1q, XGB) и `…:6378404826d8` (B2q, LGBM): аддитивная g без взаимодействий и фиксированные HP вместо годового выбора И2 (глубина 2–5, до 3000 деревьев).

Остальные 8 (Cb, Cd, Ce, Cs ×2) — по правилу продолжения HS11.
- **HS7 (D: Component Hybrid; 12).** Компоненты φ: d = ln RV_d, w = ln RV_w, m = ln RV_m, J = ln(1+J_d), a = асимметрия ln(RS−/RS+). **D0 — линейная QLIKE-согласованная абляция (6 trials):** D0-full: ln σ̂² = b0 + Σ b_k φ_k, коэффициенты — минимум QLIKE по закрытым парам, ежедневная переподгонка (`hs_qfit.fit`); D0-drop-k, k ∈ {d, w, m, J, a} (5). Компонент «информативен», если `crit_wf`(drop-k) − `crit_wf`(D0-full) ≥ +0,0005. **Dn_k (≤ 3 trials):** для трёх самых информативных (по убыванию разности) линейный член b_kφ_k заменяется 1-мерной формой s_k(φ_k) — бустинг пней (глубина 1, 100 деревьев, lr 0,05, объектив QLIKE-gamma, offset = линейная часть D0-full без k + c0); σ̂² = exp(·) > 0 по построению, форма s_k сохраняется в `D_SHAPES.csv` (интерпретируемость). **Dx_k (≤ 3):** Dn_k с взаимодействием g_k(φ_k, X_t), X_t = (терциль RV_w, ln(RV_w/RV_m), терциль рынка, стресс Ж-210), глубина 2 — только если Dn_k лучше D0-full на ≤ −0,0005 `crit_wf`. 6 + 3 + 3 = 12. **Минимальный набор: D0 (6).** Цель: найти компонент, на котором нелинейная форма лучше линейной спецификации (контроль — D0-full и HAR-J); если ни один не проходит — «компонентной нелинейности нет».
- **HS8 (E: Conditional Correction; 8).** σ̂² = HAR·exp(a_t·g), g — поправка лучшей C (по HS6, на модель победителя; контроль — самостоятельный S*), a_t ∈ [0, 1] только по прошлому. **E1** (постоянная a) = строка Cs из HS6 — ссылка, не новый trial. **E2 (4 trials):** a_t = logistic(a0 + a1·z_t), (a0, a1) — QLIKE-подгонка по закрытым строкам (ridge 0,01 на a1, расширяющееся окно, ≥ 252 закрытых, до этого a = 0), z_t стандартизован по закрытым; показатели: Z1 = e_HAR среднее 22 закрытых, Z2 = ln(RV_d/RV_m), Z3 = ln рыночной RV_w IMOEX (отклонение от расширяющейся медианы), Z4 = среднее dq за 22 закрытых (расхождение HAR−ML). **E3 (2 trials, только если E2 устойчив):** лучшая пара показателей из E2, на g победителя C и на g второй модели. «Устойчив» = для лучшего E2: Δ`crit_wf` к E1 ≤ −0,0005, знак ΔQLIKE < 0 минимум в 2 из 3 периодов {2019–21, 2022, 2023–25} и без 24.02.2022. **Проверка плато E2 (2 trials, только если E2 устойчив):** сила ridge ×10 и ×0,1 для лучшего E2. 4 + 2 + 2 = 8. **Минимальный набор: E1 (ссылка, 0 trials) + E2 ×4 при выполненном правиле HS11 для C; иначе направление E не запускается** (запись «нет g для коррекции»).
- **HS9 (F: Mixture of Experts; 6).** Эксперты HAR, XJ, LF. Сначала **тест условной информации третьего эксперта (не trial):** QLIKE-Вальд HAC (`hs_enc.wald`) для γ в σ̂² = GEO(HAR, XJ)·exp(γ(ln LF − ln XJ)) и OOS по прошлому; если p Холма ≥ 0,10 или OOS Δ ≥ 0 — остаётся двухкомпонентная конструкция (F5, F6 не запускаются). Конфигурации: **F1** геометрическая смесь HAR^(1−w)·XJ^w, w ∈ {0; 0,1; …; 1} по закрытым (≥ 252, ничья — ближе к 0,5); **F2** то же HAR + LF; **F3** Hedge(HAR, XJ): w_i ∝ exp(−η·L̄_i/L̄), L̄_i — средний QLIKE последних 252 закрытых, η ∈ {0,5; 2; 8} по закрытым; **F4** Hedge(HAR, LF); **F5** геометрическая смесь трёх (симплекс, шаг 0,1) — только при условной информации; **F6** Hedge из трёх — только если F5 запускалась. Отличие от Ж-210 A1–A4 (арифметические средние, `ensemble`) и Ж-211 `dyn_weights` (EMA/ограничение скорости арифметических весов): геометрическая смесь и экспоненциальные веса. Условный (gated) MoE не планируется. **Минимальный набор: F1, F2 (2 trials) + тест.**
- **HS10 (G/H: проверка, nested walk-forward).** Единые даты (2271) и RV цели для 10 моделей блока п. 9: HAR-J, XGB, LGBM, B-XGB, B-LGBM (лучшие по HS5), C-XGB, C-LGBM (по HS6), D (лучший), E (лучший), F (лучший). Метрики: QLIKE, RMSE (уровни и ln), MAE, R² (Минцер–Заркович), bias (ln и mean RV/σ̂²), QLIKE по годам, по режимам (терцили RV_w SBER и IMOEX, RVI, стресс), 10 крупнейших ошибок, корреляция ошибок, чувствительность к параметрам (соседние точки сеток, плато |Δ`crit_wf`| ≤ 0,0005), время счёта. - **HS11 (правило «продолжать направление» и критерии уровней; объявлены до счёта).** *Продолжать* (потратить остаток бюджета направления) — тогда и только тогда, когда лучшая конфигурация уже исполненного минимального набора направления по внутренней временной валидации (`crit_wf`, причинный) лучше контроля направления на **Δ`crit_wf` ≤ −0,0005** (контроль: B — соответствующий самостоятельный бустинг; C — лучшая B и HAR-J; D — D0-full; E — E1; F — лучший двухэкспертный F1/F2) **и** годовой QLIKE лучше контроля минимум в 6 из 10 лет; иначе — стоп направления с записью причины и числа неизрасходованных trials. Направления идут в порядке B → C → D → E → F; F — только после B–E. *Уровни* (модель M, опора H = HAR-J, S* = XJ): **Уровень 1** (лучше HAR-J) = (а) QLIKE(M) < QLIKE(H) на всей истории и `crit_wf`(M) < `crit_wf`(H); (б) знак Δ(M−H) < 0 минимум в 2 из 3 периодов {2019–21, 2022, 2023–25} и Δ < 0 без 24.02.2022; (в) сырой DM-p теста A < 0,05 и ДИ бутстрапа для Δ целиком < 0; (г) p Холма < 0,10 (иначе «L1 только сырой», не засчитывается). **Уровень 2** (лучше лучшего самостоятельного бустинга) = (а) уровень 1; (б) `crit_wf`(M) < `crit_wf`(S*) − 0,0005 и Δ(M−S*) < 0 на всей истории; (в) сырой DM-p теста B < 0,05, ДИ Δ(M−S*) < 0, **p Холма (N = 521 + новые) < 0,10**; (г) Δ(M−LF) < 0 (тест C). **Уровень 3** (устойчивость) = (а) уровень 2; (б) знак Δ(M−S*) < 0 минимум в 2 из 3 периодов {2019–21, 2022, 2023–25}; (в) без 24.02.2022 Δ(M−S*) < 0 и сырой p < 0,10 (вывод не меняется); (г) без 5 крупнейших по вкладу дней Δ(M−S*) < 0; (д) не сосредоточено в 2017–2018: Δ < 0 на «позднем» 2019–2026. **Уровень 4** (другие акции при зафиксированной архитектуре) — **«не проверялся»** до решения владельца о составе выборки (п. 13 блока); масштабирование на MOEX не начинается.
