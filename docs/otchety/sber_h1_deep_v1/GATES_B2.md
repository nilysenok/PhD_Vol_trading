## 1. Определения признаков (строка d; только бары ≤ 18:40 основной сессии дня d и раньше; r_i — 10-мин доходности `daily.intraday_returns`; ×100 → %)

**F2 скачки (8):** J=expm1(ln1p_j) (%²), флаг скачка — Хуанг–Таучен z>Φ⁻¹(0,99) (`mkt.paper`): `f2_jshare`=J/RV; `f2_jshare_m`=среднее f2_jshare за 22 дня; `f2_jfreq22`, `f2_jfreq5` = доля флагов за 22/5 дней (≥ половины конечных); `f2_jint_chg`=jfreq5−jfreq22; `f2_since`=дней с последнего флага (потолок 63; флагов не было в сегменте — 63); `f2_last_size`=ln(1+J_last/S) дня последнего флага (NaN, если не было); `f2_last_share`=jshare того дня.

## 4. Правило CUSUM (причинный сдвиг HAR; один способ, параметры не подбираются)
e_s = ln RV_{s+1} − lb_s, lb — PIT ln σ̂²_HAR-J(б) строки s (`resid.harj_ab`); e_s известна на строке s+1. На строке u (=s+1): z_u = (e_s − m)/sd, m и sd — среднее и std(ddof=1) e по 252 предыдущим закрытым ошибкам (≥126). S⁺_u = max(0, S⁺_{u−1} + z_u − k), S⁻_u = max(0, S⁻_{u−1} − z_u − k), k=0,5; срабатывание, если max(S⁺,S⁻) > h (h=5 или 8), затем S⁺=S⁻=0. NaN ошибки (граница сегмента) состояние не меняют. Перезапуск: строка срабатывания r(d)=последняя ≤ d; обучающие пары — t ≥ r(d), но не меньше 252 последних пар (окно = max(с момента срабатывания; 252 пар)), далее растёт до следующего срабатывания; до первого срабатывания — expanding.

## 5. Внутренний критерий и правило «перспективно» (объявлено до счёта)
- `crit_loyo`: для каждого Y∈2017…2026: среднее по y∈[2015, Y−1] QLIKE(б) на целях года y модели, обученной на парах с t+1 ≤ cut(01.01.Y) без года y, HP года Y (как `s4.select.run_loyo`); критерий = среднее по Y годовых средних. Признаки/абляции: обучение на всех таких парах. Rolling N / веса: из этих пар берутся N ближайших по времени к проверяемому году пар (расстояние до границ блока, обе стороны) / вес 0,5^(расстояние/H) (↺ к определению окна: в LOYO нет «конца окна»). Частота и CUSUM: LOYO не определён → `crit_loyo` = NaN.
- `crit_wf`: среднее годовых средних QLIKE(б) по полным годам цели 2017–2025 (описание, а не независимый критерий) — справочно для всех строк и вместо `crit_loyo` для w_weekly/monthly/cusum.
- Перспективно ⇔ (`crit` строки < `crit` Б-2 того же вида) И (QLIKE строки − QLIKE HAR-J(б) на 2270 датах без цели 24.02.2022 ≤ 0). Для w_weekly/w_monthly дополнительно `cheap_ok` = (QLIKE(все) − QLIKE Б-2 ≤ 0,0010) — экономия, не «перспективно». Кандидаты в волну C — только перспективные. Цифры без честной половины — потолок.
- Таблицы строк: колонки весь, 2017–2021, 2022, 2023–2025, 2026, без 24.02.2022, без 2022 (QLIKE); RV/σ̂²; RMSE ln; MSE обучение/блок остановки и отношение (по переобучениям); число деревьев, число признаков, время обучения; разность потерь к HAR-J(б) и к Б-2 (среднее, DM p лаг 5); доля лет 2017–2026 (≥ 30 дат) с выигрышем у HAR-J(б); crit_loyo, crit_wf, perspective, trial_id.
- SHAP (`pred_contribs` XGBoost) и gain — только диагностика (модель, обученная на первой дате сетки каждого года, средний |вклад| по обучающим парам), для Б-2 и протестированных групп.
