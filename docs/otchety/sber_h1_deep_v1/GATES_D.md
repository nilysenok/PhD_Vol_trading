## 1. Конфигурации D1 (ансамбли E1–E7), число trials = 16 (лимит 25)
Члены: H = HAR-J(б) (`ctrl.s2_harj`); X = `b2_f4` (XGB, Б-2+F4, I2 по годам; кэш C); L = `d_lgbm_f4` (LightGBM L2 на тех же признаках/цели/ES/s²: depth→max_depth и num_leaves = 2^depth, min_child→min_data_in_leaf, l2→lambda_l2, lr, subsample→bagging_fraction + bagging_freq 1, colsample→feature_fraction, max_trees; seed 42, `deterministic`); Xr = XGB F4, окно rolling 1008 пар; Xh = XGB F4, веса 2 года (half-life 504, `fit.weights`).
Компоненты (новые прогоны, trials): **t01 `d_lgbm_f4`**, **t02 `d_xgb_f4_r1008`**, **t03 `d_xgb_f4_hl504`**.
Правила весов (сумма 1, неотрицательные, сетка симплекса с шагом 0,1; ничья ≤ 1e-12 — первый вектор в лексикографическом порядке сетки, т.е. меньший вес первого члена; для K = 2 совпадает с правилом H3 «меньший w» волны C); до 252 закрытых прогнозов — равные веса:
- **roll** — минимум суммы QLIKE смеси по последним 252 закрытым; **exp** — по всем закрытым.
- **inv** — w_i ∝ 1/Q_i, Q_i — средний QLIKE члена i по последним 252 закрытым (E7).
- **regime** — как roll/exp-«reg» волны B1/C, но группа = стресс на d (Г4 `stress_p3` или стресс_RV), веса по закрытым прогнозам той же группы (≥ 60 в группе, иначе exp), E6.
Trials: **E1** (X+L): t04 `e1_roll`, t05 `e1_exp`. **E3** (H+L): t06 `e3_roll`, t07 `e3_exp`. **E4** (H+X+L): t08 `e4_roll`, t09 `e4_exp`. **E5** (X+Xr+Xh): t10 `e5_roll`, t11 `e5_exp`. **E6** (H+X+L, режимно-взвешенный): t12 `e6_g4`, t13 `e6_rv`. **E7** (inv): t14 `e7_hx`, t15 `e7_hxl`, t16 `e7_xl`. **E2** (H+X) — не новые trials: это `c2_h3_roll_f4` / `c2_h3_exp_f4` из C (те же правила H3; равенство весов кода D с `rules.h3_weights` ≤ 1e-15 и σ̂² ≤ 1e-12 — тест); строки E2 берутся из C_ALL со ссылкой, в бюджет не входят.
Обязательные контроли (простое среднее, без параметров, не trials): для наборов {X,L}, {H,X}, {H,L}, {H,X,L}, {X,Xr,Xh} — среднее в уровнях `mean_lvl_*` и среднее в логарифмах (геометрическое) `mean_log_*`: 10 контролей.

## 3. Статистика D2 (параметры фиксированы)
- DM (`s3/dm.py`, Ньюи–Уэст лаг 5, Бартлетт, двусторонний p) к HAR-J(б) и к Б-2 на: весь период, 2017–2021, 2022, 2023–2025, «без 24.02.2022». Знак: минус у `d_*` = строка лучше базы.
- MCS (Hansen–Lunde–Nason), статистика T_max, α = 0,10 (доверие 90 %), M0 = 6 финалистов + HAR-J(б) + Б-2 (8 моделей); бутстрап — круговой блочный, блок 20, 5000 повторов, `numpy.random.default_rng(42)`, одни и те же индексы для всех моделей и для всех тестов; дисперсия d̄_i· — по бутстрапу; исключение — модель с наибольшей t_i·; p-значение модели — бегущий максимум p шагов. Справочно (не критерий) тот же MCS на 2017–2021 и на 2022–2026.
- Блочный бутстрап Δ QLIKE (финалист − база) к HAR-J(б) и к Б-2: блок 20, 5000, seed 42; среднее Δ, 95 % перцентильный интервал, P* = (k+1)/(B+1), k = число повторов со средним Δ* ≥ 0 (односторонний).
- Холм: N = **106** = 90 (B1+B2+C) + 16 (D) — все уникальные trials программы; справочно N = 116 (+10 контролей). Семейства: DM весь период и DM «без 24.02» отдельно для двух баз, P* бутстрапа для двух баз; недостающие до N — p = 1 (консервативно). Подпериодные p — сырые, диагностика.
- Seeds 42–46: бустеры финалиста пересчитываются с seed 43–46, правило — тем же кодом; seed-ok: ≥ 4 из 5 seeds с `qlike_all` < QLIKE Б-2 И Δ к HAR-J(б) без 24.02 ≤ 0 (как в C). Для C-финалистов — `C_SEEDS.csv` (ссылка), `b2_f4` и `c3_f3calm_*` и лучший ансамбль — считаются в D (для `c3_f3calm_*` добавляются seeds `b2_top2`; для ансамбля — seeds XGB- и LGBM-членов).
- Соседи: бустеры — `C_PLATEAU.csv` (f4, opt); для `b2_top2` — ±1 шаг по осям пространства C (внутренний критерий LOYO, 55 фолдов), plateau-ok: доля соседей лучше Б-2 (0,1644) ≥ 0,75. Для ансамбля — соседи правила: окно roll/inv {126, 504} против 252 (для exp и режимных — только шаг), шаг сетки весов 0,05 против 0,1 (`Q_wf` каждого соседа лучше Б-2 в доле ≥ 0,75) И plateau-ok XGB-членов по `C_PLATEAU.csv`. Соседи HP LGBM не считаются (↺ до счёта: LGBM наследует HP XGB-И2; случайность охвачена seeds).
- Чувствительность к окну (диагностика, не trials): те же правила на бустерах Xr (rolling 1008) вместо expanding: `b2_f4`↔Xr, `c2_h3_roll_f4` на Xr, `c1_opt` на XGB-opt rolling 1008, ансамбль на rolling-версиях членов, `b2_top2` rolling 1008 для `c3_f3calm_rv`.
- Топ-20 вкладов: 20 дней с наибольшей |Δ потерь| к HAR-J(б) для каждого финалиста, их доля в Σ Δ и в Σ|Δ|, Σ Δ без них.
- Leave-one-year-out описания: QLIKE и Δ к HAR-J(б) и Б-2 при исключении каждого из 10 лет; знак Δ сохраняется? (доля лет).
- Нижний дециль по прошлому: дни, где RV_w(d) ≤ квантиль 0,1 по 252 предыдущим (`pit.q_prior_nan`, без текущего дня): n, QLIKE, mean(RV/σ̂²), Δ к базам.

## 5. Мутации волны D (тест падает на мутанте; № — `mutations.md`)
MD1: вес ансамбля с незакрытым прогнозом (`td = d` / `extra_closed = 1`) — вес меняется. MD2: MCS/бутстрап на перемешанных датах — блоки не смежны, дисперсия автокоррелированных потерь занижена; тест проверяет смежность блоков и что перемешанный ряд ломает свойство. MD3: Холм с N = 1 (поправка не растёт с N). MD4: состояние режима на d+1 в E6. MD5: окно inv-весов включает пару d (m+1). MD6: среднее в логарифмах подменено арифметическим (должно быть ≤ арифметического). MD7 (№ 1, 15, 22): главный тест обрезки — LGBM, rolling-1008, веса 2 года, ансамбли на синтетике; мутант «признаки +1 день». MD8: MCS не исключает заведомо худшую модель / исключает идентичные. MD9: бюджет D > 25 или дубль id пропускается. MD10: окно 1008 захватывает пары вне окна; веса 2 года не 504. MD11: лучший ансамбль выбирается по описанию вместо `Q_wf`. MD12: тройка включает строку с выбором на оценочном периоде или не требует MCS. MD13: порог нижнего дециля зависит от RV_w текущего дня (№ 22): тест проверяет независимость порога от x[d] и что мутант зависит (само отнесение дня к децилю при «≤» от включения текущего дня не меняется — поэтому проверяется порог, не маска). MD14: leave-one-year-out не исключает год. MD15: `exp`/`roll` на K = 2 расходится с `rules.h3_weights` (E2 ≢ C).
