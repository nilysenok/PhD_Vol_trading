## 2. C1. Optuna по Б-2+F4 (границы объявлены до счёта; блок п. 19, 21: неглубокие деревья, регуляризация, ≤ 300 деревьев)
- Матрица: Б-2 (28 столбцов) + принятые F4 из `accepted.json` B2 (5 столбцов: `f4_rq_rel`, `f4_park`, `f4_range`, `f4_vov`, `f4_hhi`; число сверяется с `INFO_CHECK_B2.csv`, иное — стоп). Признаки/нормировка/пары/ES — как в B2 (`engine.make_dz`, `runner.pairs_upto`, И1: ES 252, эмбарго 1, терпение 100).
- Модель: XGBoost `reg:squarederror`, цель ln RV_{t+1} − ln RV_m (форма Б-2), σ̂² = exp(off + f + s²_es/2). Обёртка `fitx.fit_i1x` = копия `fit.fit_i1` с двумя добавленными осями (gamma, reg_alpha) и параметром seed; при gamma = alpha = 0 и seed 42 побитно равна `fit.fit_i1` (гейт G2).
- Пространство TPE (все оси ограничены; шаг для соседей — в скобках):
  `depth ∈ {1,2,3}` (±1); `min_child ∈ [10, 200]` лог (×2 / ÷2); `l2 ∈ [0,5; 100]` лог (×3 / ÷3); `lr ∈ [0,02; 0,10]` лог (×1,5 / ÷1,5); `subsample ∈ [0,5; 1,0]` (±0,1); `colsample ∈ [0,3; 1,0]` (±0,1); `gamma ∈ [0; 0,05]` (±0,01, не ниже 0); `reg_alpha ∈ [0; 5]` (±1, не ниже 0). `max_trees = 300` фиксировано (ранняя остановка И1 внутри). Выход соседа за границу — сосед не строится (пишется «нет»).
- Сэмплер: `optuna.samplers.TPESampler(seed=42, n_startup_trials=8)`, минимизация, 22 trials последовательно (n_jobs = 1; фолды внутри trial — пул ≤ 4). Без `enqueue`, без пересмотра границ после старта.
- Целевая функция Optuna J(θ) = среднее по Y ∈ {2017,…,2021} годовых средних QLIKE(б) LOYO-фолдов (`loyo.fold`: обучение — пары с t+1 ≤ cut(01.01.Y) без года y, проверка — цели года y, y ∈ [2015, Y−1]; θ постоянен по Y). Следствие: поиск не видит ни одной цели ≥ 01.01.2021 (честная половина по генерации кандидатов: годы 2022–2026 чисты от подбора границ и TPE; для 2017–2021 кандидаты направлялись целями < 01.01.Y, но сам критерий усреднён по этим годам — потолок).
- Для каждого trial считаются ВСЕ score_Y(θ), Y ∈ 2017…2026 (55 фолдов; в TPE уходит только J — проверка тестом G3).
- Выбор раз в год (как И2): HP_Y = argmin по score_Y из {22 θ} ∪ {I2-HP года Y на Б-2+F4}; score_Y использует только цели < 01.01.Y; ничья |Δ| ≤ 1e-12 — `select.order_key`. Строка `c1_opt`: ежедневное переобучение, HP = HP_Y года цели прогноза… (года даты d, как в B: `rows.year_of`), crit_loyo(c1_opt) = среднее по Y из score_Y(HP_Y). Оптимизм выбора (минимум по 23 кандидатам) сопоставим с I2 (минимум по 132) — записывается в README_C как оговорка; потолок.
- Описание на 2271 датах (дневной прогон) для каждого из 22 TPE-trials НЕ считается (стоимость); для них в реестре — внутренние метрики (J, score_Y) и «описание: не считалось»; описание считается для `c1_opt`, `c1_f4_range`, `c1_f4_park`, `c1_f4_f1` и для 3 лучших TPE-trials по J при постоянном θ (отступление от колонки «метрики описания» реестра — объявлено).
- `c1_f4_range`, `c1_f4_park`: Б-2 + ровно один столбец (`f4_range` / `f4_park`); `c1_f4_f1`: Б-2 + принятые F4 + принятые F1 (9 столбцов, без F3). HP — I2 года (как в B2), seed 42; crit_loyo — как в B2 (`loyo.fold` на HP_Y).
- Правило «перспективно» (то же, что в B, объявлено): внутренний критерий строки строго < Б-2 того же вида (`crit_loyo` Б-2 = 0,1644 для LOYO-строк; `Q_wf` Б-2 = 0,19198 для wf-строк) И QLIKE строки − QLIKE HAR-J(б) на 2270 датах без 24.02.2022 ≤ 0. Доп. флаг `better_than_f4` (crit строки < crit `b2_f4`, 0,1546) — только для утверждений «улучшает F4».

## 3. C2. HAR + бустинг (≤ 15, план 9)
- Смеси H3: σ̂² = w·HAR-J(б) + (1 − w)·σ̂²_boost, w — `s5.b1.rules.h3_weights` (kind w05 / exp / roll / reg; MIN_EXP 252, ROLL 252, MIN_GROUP 60, W-сетка `post.W_GRID`, закрытые: target_date ≤ d, ничья — меньший w); boost ∈ {`b2_f4` (I2-HP, эталон B), `c1_opt`}: 4 × 2 = 8 trials `c2_h3_{w05,exp,roll,reg}_{f4,opt}`. Группа режима для reg — `qw ≥ 4` (как B1).
- H2-L4: `c2_h2l4_f4_c05` — потеря QLIKE (L4, `s5.b1.fitobj`), цель RV_{t+1}/HAR-J(б)_t (форма `har_h2_l4m`), признаки Б-2 + принятые F4, σ̂² = exp(lb + 0,5·f); HP — I2 года; crit_loyo = LOYO по `jobs.fold_job` (c = 0,5).
- Внутренний критерий: смеси — `Q_wf` (`s5.b1.evalrows.q_wf`, walk-forward: score_Y по годам < Y; Б-2 = 0,19198, HAR-J(б) = 0,19180); H2-L4 — LOYO. Правило «перспективно» — то же. Для смесей дополнительно печатается Δ к `b2_f4` и к `har_h3_roll252`.
