Для log-link потерь σ̂² > 0 по построению. Число срабатываний границы и число σ̂²_сырой ≤ 0 — в таблицах (`n_nonpos`, `n_floor`); отрицательный прогноз «запрещён» = всегда заменяется границей и всегда считается.

## Конфигурации первого прохода (28 trials)
Objectives (`objectives_target`, 8): L2 = Б-2 контроль (не trial).
- `obj_l1n` L1 MSE по уровню y_ratio = RV/RV_m, X = `m_mkx`, σ̂² = RV_m·f, граница ε. 
- `obj_l1raw` L1 MSE по уровню RV (%²) без нормировки, X = `level_mkx` (те же 28 столбцов, ln-уровни), граница ε.
- `obj_l3x` L3 XGBoost `reg:gamma` (log-link), y_ratio, X = `m_mkx`, ES по gamma-nloglik (= y/μ + ln μ).
- `obj_l3l` L3 LightGBM `objective=gamma`, то же; отображение HP: max_depth, num_leaves = 2^depth, min_data_in_leaf = min_child, lambda_l2, learning_rate, bagging_fraction = subsample, bagging_freq 1, feature_fraction = colsample; ES метрика `gamma`.
- `obj_l4` L4 прямой QLIKE (F = ln(σ̂²/RV_m); потеря y·e^(−F) + F; grad 1 − y·e^(−F); hess y·e^(−F)), начальная F0 = ln взвешенного среднего y, ES по той же потере.
- `obj_l5a`, `obj_l5b` L5: потеря Б-2 (MSE ln, s²/2), веса пары t ∝ RV_w,t^(−γ), γ = 0,5 и 1,0, нормировка на среднее по окну обучения.
- `obj_l5c` L5 на L4: γ = 0,5.
HAR + бустинг (`har_boosting`, 11): H = HAR-J(б) пилота (`lb`, PIT, без in-sample).
- `har_h2_l2_c075`, `har_h2_l2_c05` H2 с L2: σ̂² = exp(lb + c·f + s²/2), f — остаток ln RV − lb, X = `resid_mkx`, c = 0,75 / 0,5 (c = 1 — контроль Б-1 пилота, пересчитывается и сверяется с parquet, не trial).
- `har_h2_l4_c1`, `har_h2_l4_c05` H2 с L4: y = RV_{t+1}/HAR_b,t, F = ln(σ̂²/HAR_b), σ̂² = HAR_b·exp(c·F̂), X = `resid_mkx`, c = 1 / 0,5.
- `har_h2_l4m_c1` то же, X = `m_mkx` (нормированные признаки Б-2), c = 1.
- `har_h1_s` H1: g — MSE на y = RV_{t+1}/HAR_b − 1, σ̂² = max(HAR_b·(1 + ĝ), ε) (↺ нормировка остатка на HAR: сырой остаток доминируется единичными экстремумами; сырой вариант — следующая строка); X = `resid_mkx`.
- `har_h1_raw` H1 сырой: y = RV_{t+1} − HAR_b (%²), σ̂² = max(HAR_b + ĝ, ε), X = `resid_mkx`.
- H3 (Boost = Б-2, HAR = HAR-J(б), смесь в уровнях σ̂² = w·HAR + (1−w)·Б-2, w ∈ {0; 0,1; …; 1}, ничья — меньший w): `har_h3_w05` w = 0,5 постоянно; `har_h3_exp` w_d = argmin QLIKE по всем закрытым прогнозам (расширяющееся окно, не менее 252 закрытых, до этого w = 0,5); `har_h3_roll252` то же по последним 252 закрытым; `har_h3_reg` w_d по режиму d: группа {q0–q3} / {q4} (квинтиль прошлой RV_w), w каждой группы — argmin по закрытым прогнозам этой группы (не менее 60, иначе общий w_exp).
Режимы (`regime_aware`, 9): режим строки t — квинтиль RV_w,t по 252 предыдущим значениям (`pit.past_bucket`, без текущего); стресс_RV = RV_w > прошлый q67 (`pit.q_prior_nan`; ↺ без части RVI Г4: RVI нет вне 2017–2021 и вне сетки); переход = q_t − q_{t−1}.
- `reg_r1a` R1: Б-2 + признак q_w; `reg_r1b` Б-2 + q_w, стресс_RV, переход; `reg_r1c` R1b на форме остатка (`resid_mkx` + 3 режимных столбца, L2, c = 1).
- `reg_r2a` R2: 2 режима {q0–q2}/{q3–q4}; `reg_r2b` 3 режима {q0–q1}/{q2–q3}/{q4}; эксперт режима обучается на парах окна с режимом строки t, L2, форма `m_mkx`; если пар режима < 300 (N_MIN) — прогноз Б-2 (резерв), доля резерва и число пар — в таблице.
- `reg_r3` R3: смесь экспертов R2a в уровнях σ̂² = (1−p)·σ̂²_низ + p·σ̂²_выс; p_d — логистическая регрессия (ridge λ = 1, IRLS ≤ 25 шагов) вероятности «группа d+1 = выс» по z_d = (q_w/4, ln RV_d − ln RV_m, ln RV_w − ln RV_m), обучена на парах t+1 ≤ d.
- `reg_r4a` R4: HAR-J(б) при q_w,d < θ_Y, Б-2 при q_w,d ≥ θ_Y; θ_Y ∈ {1,2,3,4,5 (= никогда)} по максимуму прошлого: среднее годовых QLIKE правила по годам [2017, Y−1], ничья — больший θ, 2017: θ = 5; `reg_r4b` то же с лучшей H2-строкой (по Q_loyo среди H2-L2/L4 включая контроль c = 1); `reg_r4c` стресс Г4 (`stress_p3.parquet`) → Б-2, иначе HAR-J(б) (параметров нет).
