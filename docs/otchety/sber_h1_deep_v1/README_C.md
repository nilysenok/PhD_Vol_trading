Выбор годовой: TPE-кандидаты вошли в 5 лет из 10 (2017–19, 2021, 2025), в остальные — I2.
2. **Все 19 строк C «перспективны» по объявленному правилу — правило слабое** (для смесей и переключателей Q_wf Б-2 ≈ HAR-J(б), «лучше Б-2» достигается почти механически; для H2-L4 `d_b2` = +0,0009). Содержательный отбор — Δ к `b2_f4` по частям и Холм.

## Отступления (до выводов)
1. Холм: N = 90 (все trials программы), а не 40 (↺ дирижёра); N = 40 — справочно (`p_holm_*_ref40`). Реально посчитано 19 строк; недостающие до N — p = 1.
2. Описание на 2271 датах для 19 TPE-trials не считалось (только 3 лучших по J, `C_TPE_DESC.csv`) — объявлено в GATES.
3. Описание соседей на 2271 датах (оси depth, min_child, lr, ≤ 6 прогонов) **не сделано**: depth и lr недопустимы у обоих бустеров (HP I2 вне границ TPE — в `i2` есть глубина 5 и max_trees 3000), min_child +1 допустим только у `f4`/`opt`; только внутренний критерий.
4. Границы TPE (глубина ≤ 3, ≤ 300 деревьев) не распространяются на I2-HP, которые тоже входят в годовой выбор (в 5 годах выбран I2 с max_trees 3000); соседи ≤ 300 деревьев не гарантированы.
5. Seed H2-L4 (`c2_h2l4_f4_c05`) в `b1.fitobj` зашит как 42: seeds для него не определены (в лучшие 3 не вошёл).
6. Реестр: trial-строки TPE содержат «описание: не считалось»; `c1_opt` — строка-процедура, не trial (25 trials C1).
7. Критерий «лучшие 3» (GATES §5) выбрал строки с mean(Δ) почти равным по смыслу (две на H3-roll); отбор не менялся.
