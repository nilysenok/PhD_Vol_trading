## Как считалось

1. **Матрица PBO.** Строки — 506 дней (254 в 2018 + 252 в 2019), столбцы — все уникальные ключи проб стратегии в реестре (`sweep_e1v2`, доводка `sweep_e1v2_dostroyka`, Ж-042, Ж-043) с боевым эталоном (`prichina_net` = None). Ряды — дневная избыточная после 0,04 % из оценщика (`Sweep.evaluate`), 2019 досчитан для всех. Пересчёт тех же точек: N проб не растёт. `pbo_cscv(M, 8)`, 70 разбиений. Отброшено без эталона: S1 238, S2 273, S3 362, S4 313, S5 327, S6 407. Ключ → точка → ключ совпал у всех (отброшено «ключ не круглый» 0), nan в рядах нет.
2. **Сверка рядов:** Шарп 2018 и 2019 из столбца матрицы совпал с `S{k}_dovodka.csv` (Ж-043) с точностью 1e-9 для всех кандидатов (assert в скрипте).
3. **Кандидаты и выбор точки.** Топ-10 пула Ж-043 (плато уже посчитано). Точка — лучшая по `obj` = min(mSR) среди прошедших ворота (`pick_best`, ничья ≤ 0,05 — меньшее σ126). Прошедших нет → показана лучшая по `obj` среди прошедших ворота кроме PBO (S1–S4), иначе лучшая по `obj` (S5, S6). Точка совпадает с итоговой Ж-043 у S2, S4, S6; у S1, S3, S5 — другая (Ж-043 выбирала по плато).
4. **PBO одинаково проваливает всё:** PBO — свойство стратегии (матрицы), не точки; пока PBO ≥ 0,2, ни одна точка не пройдёт при любом выборе.
5. **T.** В PSR/DSR здесь T = 506 (число дней), проверено в таблице (`T_psr_dsr`). В конвейере Ж-043 `dsr_n` получал `T` оценщика = 254 (дни 2018), а не сделки — число дневных наблюдений, правило соблюдено.
