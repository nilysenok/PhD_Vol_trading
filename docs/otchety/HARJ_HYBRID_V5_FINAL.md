## 4. Полные формулы

Обозначения: H = K1 (HAR-J), K2 (XGBoost), K3 (LightGBM), M = √(K2·K3), K8 = √(H·M), D2 (LGBM-D2); QLIKE(RV, F) = RV/F − ln(RV/F) − 1; s = RV/F − 1 — отрицательный градиент QLIKE по ln F (известен после закрытия дня).

**Общая конструкция V5.** ln F(i,t) = ln H + g₀ + u + Σ g_m, где g₀ = ½·ln(M/H) (при u = g_m = 0 получается K8; при g₀ = 0 — H; оба тождества проверены побитно).

**Graph-Score (GS1–GS5).** F = K8·exp(u); u(i,t⁺) = ρ·u(i,t) + α·s̃(i,t) + β·T(i,t), u = 0 в первый день; s̃ — сырой s (GS1) или min(s, 3) (GS2, форма записана в CHECKPOINT до GS3–GS5); T: GS1, GS2 — 0; GS3 — среднее s̃(j,t) по j ≠ i; GS4 — Σ_j W(i,j)·s̃(j,t) по трём соседям с наибольшей прошлой положительной корреляцией s̃ (веса ∝ корреляции, сумма 1); GS5 — (λ̃_i/λ̄)·Σ_{j≠i} λ̃_j s̃(j,t)/Σ_{j≠i} λ̃_j, λ — первый собственный вектор прошлой корреляции s̃, λ̃ = ½λ + ½λ̄. θ = (ρ, α, β) общие для панели, ρ ∈ [0; 0,99], α ∈ [0; 0,3], β ∈ [0; 0,3], переоценка ежемесячно по закрытым парам: средний QLIKE + штраф V4 (κ = 250 пар-эквивалентов) к θ₀ = (0,9; 0; 0); меньше 60 закрытых дней — θ₀ (F = K8). LOTO: исключённая бумага не входит ни в θ, ни в W, ни в λ.

**Spectral Energy (SP1–SP4).** E_b(i,d) = Σ_{k∈b} c_k², c = DCT-II·r (ортонормальное, r — дневной вектор M10-доходностей длины n); полосы low при 3k < n, mid при n ≤ 3k < 2n, high при 3k ≥ 2n; Σ_b E_b = RV (точно). π_b — расширяющееся среднее доли полосы по закрытым дням (первые 60 дней — равные доли). SP1: F = K8·clip(R, 2/3, 3/2), R = Σ_b Ê_b/Ê_tot, Ê — HAR в уровнях (МНК по бумаге, ежемесячно, не менее 250 закрытых пар, иначе R = 1). SP2: F = K8·Σ_b π_b·exp(θ_bᵀ z_b), z_b = (ln q_b дня d, средней q_b за 5 и за 22 дня, каждая минус ln π_b), θ общий для панели, QLIKE + штраф V4. SP3: SP2 + межбумажный спектральный фактор. SP4: SP2 + признаки формы дня H3 V4 (lasth, herf, firsth).

**Критерий выбора.** crit_panel = среднее по бумагам M16 величины crit_wf: для Y = 2018…2021 pen_Y = среднее годовых QLIKE лет < Y + 0,25·(max − mean), crit = среднее pen_Y. **«go»**: три условия одновременно (crit_panel, он же без целей 2017, он же без 1 % дат с наибольшей разностью QLIKE), каждое ≤ min(контроли, включая K8) − 0,0005.

## 5. Математическое отличие от V3/V4

V4 искала, кому доверять: веса, гейты и режимы между готовыми прогнозами H и M. V5 строит прогноз как замороженную основу HAR-J плюс аддитивные поправки в логарифме с объявленным механизмом каждой (при нулевой поправке — K8, лучший контроль V4). Вопрос каждого направления: что даёт механизм сверх K8.
- **Graph-Score против E1–E5 (V4):** score берётся к окончательному F, содержащему u (обратная связь, динамика score-driven), межбумажная передача — через оценённую по прошлому матрицу W, а не одно панельное среднее.
- **Spectral против Ж-214 и Intraday Shape:** энергия делится по частоте (DCT-II), а не по времени (части дня, Херфиндаль, последний час).
- **Moments, Latent** (закрыты без счёта конфигураций): регуляризованные условные моменты вместо B/E/RQC; скрытые факторы, оценённые по прошлому, вместо признаков текущего дня.

## 15. Особый вопрос: есть ли в новых архитектурах информация, которой нет в бустингах

**Вопрос блока владельца:** действительно ли новые архитектуры извлекают информацию, которой нет в самостоятельных бустингах, или только заново воспроизводят уже известную RV?

**Ответ.** Устойчивая информация сверх K8 (в ней уже есть HAR-J и бустинги) не показана ни у одной из девяти конфигураций; прогнозы новых архитектур практически повторяют K8 и бустинги. Показано следующее.

1. **Охват** (QLIKE-оптимальный ex post вес w в K8^(1−w)·F^w; 90 % интервал блоковым бутстрапом дат). В подтверждающем окне 2022–2025 у GS4 w = +0,90 [−0,08; +1,72], у SP1 w = −0,22 [−0,71; +0,12] — оба интервала включают 0, веса сверх K8 нет. У SP1 интервал веса к K8 включает 0 во всех окнах (2017–2021, 2022–2025, вся история: +0,01 [−0,77; +0,94], −0,22 [−0,71; +0,12], −0,18 [−0,58; +0,15]); к M он не включает 0 в 2017–2021 (+0,81 [+0,30; +1,48]) и включает в 2022–2025 (−0,16 [−0,81; +0,35]) и на всей истории (+0,19 [−0,31; +0,65]). У GS4 в окне выбора 2017–2021 w = +1,04 [+0,30; +1,61] и за всю историю w = +0,90 [+0,06; +1,61] — интервалы не включают 0, но это окно выбора и история, в которой выигрыш к K8 держится на 2022 (в 2023–2025 GS4 хуже K8), значимых различий QLIKE нет (раздел 10). Относительно M = √(K2·K3) у GS4 в 2022–2025 w = +0,63 [+0,05; +1,21] (интервал не включает 0), но M не содержит HAR-J, а K8 = √(H·M) его содержит: это согласуется с тем, что GS4 несёт долю HAR-J (известную из V4), и не доказывает новой информации. Остальные окна и интервалы — таблица в разделе 15.
2. **Совместные ошибки.** Корреляция ln(RV/F) GS4 с K8 — 0,990, SP1 с K8 — 0,993 (вся история); ошибка одного знака с K8 в 0,968 и 0,976 долей дней. 3. **Абляция спектра.** SP4 − SP2: Δ QLIKE (вся история) +0,00018, p DM = 0,762 (форма дня сверх спектра ничего не добавляет); SP2 хуже H3 (форма дня без спектра): Δ +0,00140, p 0,003. Спектр сверх формы дня информации не несёт.

**Не показано.** Отсутствие значимости не доказывает отсутствия информации: интервалы охвата широки (ширина w в 2022–2025: 1,80 у GS4 и 0,83 у SP1), ошибки бумаг коррелированы (средняя межбумажная корреляция ошибок 0,309 у K8), поэтому эффективная выборка меньше числа строк; результат — один исторический проход по одним данным (честной второй половины нет), мощность малых эффектов невелика; не проверены другие механизмы, чем GS1–GS5 и SP1–SP4 (направления 3–7 закрыты без счёта конфигураций по объявленным правилам).
