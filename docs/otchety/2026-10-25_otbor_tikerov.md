# Отбор тикеров 28 → 20 → 17 (раздел 2.1.1)

Решение владельца 25.10: вариант (в). Воспроизведение: `python3 scripts/analysis/otbor_metriki.py` → `data/out/otbor_metriki_20.csv`. Источники шага 28 → 20: `moex_discovery/reports/TICKER_SELECTION.md`; шага 20 → 17: `moex_discovery/reports/FINAL_V3_REPORT.md:55–61`.

## Факты
- Числового критерия шага 20 → 17 в коде нет (`moex_discovery/src/` не упоминает TGKA, MSNG, TRMK; `merge_borders.py:45–48` пишет список без фильтра). В отчёте 23.02.2026 — формулировка «много пропусков».
- «first_date позже» у TGKA не подтверждается: первый бар очищенных 10-минутных данных — 09.06.2014 у всех 20.
- Хронология: `quality_tickers_17.csv`, отчёты отбора и результаты стратегий попали в git одним начальным коммитом `c22a4b3` (23.02.2026), даты файлов — тот же день. Git не подтверждает, что отбор сделан до расчётов → слова «проведённой до расчётов» из формулировки убраны (условие владельца).
- Ни одна естественная метрика качества не отделяет ровно {TGKA, MSNG, TRMK}: LSRG по доле пропусков, числу дней RV и карантину хуже MSNG и TRMK. Поэтому в Приложении В — устойчивость к составу (16 без LSRG; 20 с исключёнными).

## Готовый абзац для 2.1.1
«Из 28 ликвидных акций с 10-минутной историей с июня 2014 г. по критериям длины ряда (не менее 2 000 торговых дней), доли карантинных баров (менее 5%) и среднего уровня RV (менее 50%) отобрано 20 (табл. 2.X). Покрытие 10-минутных интервалов основной сессии у отобранных бумаг составляет от 88,9% до 99,8%, у 14 из 17 — не ниже 98,8%. Устойчивость результатов к составу выборки (16 бумаг без LSRG и 20 бумаг с включением исключённых) приведена в Приложении В».
