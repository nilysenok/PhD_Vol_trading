## Сила сигнала в ансамбле итерации 2 (проверка ожидания)

Ожидание подтверждено с уточнением. Вес сделки в ансамбле = `w · mag` (`fastbt/etap1_ansambl_eval.py:55`), `mag = |m|` (`fastbt/etap1_ansambl.py:73`), но `m` — **среднее позиций точек ансамбля** `P ∈ [−1; 1]` (`fastbt/etap1_ansambl.py:67-73`), то есть согласие точек, а не сила сигнала. Сила действует лишь внутри каждой точки через `q_sily` (вход да/нет). Режим `golos` даёт вес 1 (`:74-77`). В итерации 1 размер равный: `w = np.ones` (`fastbt/etap1_eval.py:111`). Отдельно: `ball_sily = |сила|/σ` (`fastbt/e1_portfel.py:15`) используется только для ранжирования в ветке `plus` (`fastbt/etap1_plus_eval.py:73`), не в итерации 1.

## Итоговая таблица диагноза

«Тикеров на 80 %» — из 17. «Доля PnL топ-3» — топ-3 по чистому PnL / чистая сумма PnL; в скобках две величины: «те же топ-3 / Σ|PnL|» и «топ-3 по |PnL| тикера / Σ|PnL|» (набор тикеров второй может отличаться). «Доля порогов в абсолютах» — все оси / в точке. Для сравнения: при равномерном распределении топ-3 из 17 тикеров дают 17,6 % сделок.

Оговорки к диагнозу (честная половина):
- Сделки не сосредоточены ни у одной стратегии: 80 % сделок дают 11–13 тикеров из 17, топ-3 по сделкам — 22–28 %. Концентрация есть только в PnL, и она измерима лишь как доля чистой суммы, которая мала на фоне Σ|PnL| (значения 100–224 % — следствие взаимного погашения плюсовых и минусовых тикеров). К Σ|PnL| топ-3 не доходят до 50 % ни у одной стратегии: те же топ-3 по чистому PnL — 19,5–42,6 %; топ-3 по |PnL| тикера — 32,5–47,4 %.
- Доля порогов в абсолютах зависит от определения класса: фиксированные числа на безразмерных индикаторах (ADX 20, vol_regime 1,2) отнесены к А по формулировке Ж-062; если считать их нормированными по тикеру, доли падают, и диагноз у S2–S4 снимается. Значения «в точке» держатся на 3–4 порогах из 6–9, граница 50 % сдвигается одним порогом.
- Сделок на тикер 1–28; на тикер с 2–5 сделками PnL — шум. Потолок, не вывод: статистической проверки концентрации (перестановка тикеров) здесь не делалось.
- Без дивидендов (находка #362): PnL пересчитается после правки.

## Диагноз Ж-062 (для владельца)

Условие Ж-062 — «пороги в абсолютах И сделки сосредоточены в 2–3 тикерах». По сделкам оно **не выполнено ни у одной S**: топ-3 тикера дают 22–28 % сделок, 80 % сделок требуют 11–13 тикеров из 17. По чистому PnL оно выполняется формально у S2, S3, S4 (пороги в абсолютах 50 % в точке; топ-3 = 224 / 144 / 105 % чистой суммы), но это эффект малой чистой суммы на фоне Σ|PnL|: к Σ|PnL| те же топ-3 дают 36,9 / 42,6 / 32,7 %. Слово «диагноз» относится к S2–S4 только с этой оговоркой и зависит от отнесения ADX 20 и vol_regime 1,2 к абсолютам.
