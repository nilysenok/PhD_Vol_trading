## 1. Ряды, узлы продления и переобучения

### 1.1 Формулы рядов

- K1 = HAR-J; K2 = XGBoost `x2_best_j`; K3 = LightGBM `C0_inh_F4`; M = √(K2·K3).
- X1 = M^(1−π)·C^π, C = cfg8.
- ZB = X1·exp(e_d·(b + a·s_d)).
- W5-G = X1·exp(gap^PIT_d·β_m) (`W5_SPEC` разд. 1, 11).
- W8-G = X1·exp(gap^PIT_d·β_{m,G(d)}), G — PIT-терциль ln RV^IMOEX дня d. Если группа не включена, F = W5-G (`W8_SPEC` разд. 2).
- PH-R: ln F = ln M + π_d·(κ_H,m·D_H + κ_G,m·D_G). Здесь D_H = −(1 − w)·ℓ, D_G = G − w·ℓ; (κ_H, κ_G) — argmin QLIKE по последним 252 закрытым парам, помесячно (`x1_w9_diag_ph.walk(x, "R", True)`). PH-R0 — то же с общим κ.

### 2.1 Семейство: 7 односторонних гипотез «A лучше B»

| № | Гипотеза | Смысл | Почему в семействе |
|---|---|---|---|
| H1 | W5-G < X1 | поправка после перерыва над гибридом | W5-G — вторая контрольная версия (Ж-253). На окне M −0,44 %, У1, У3 и У5 не пройдены: решить может только новый период |
| H2 | W8-G < W5-G | групповой β по терцилю IMOEX | W8-G не прошёл только У6 (p сдвигов 0,15). Вопрос «удача отбора или признак» решают новые данные |
| H3 | W5-G < K2 | гибрид против XGBoost | главная цель владельца — гибрид против бустингов |
| H4 | W5-G < K3 | гибрид против LightGBM | то же |
| H5 | X1 < K2 | повтор H1 FWD1 | в FWD1 не подтверждено (+0,58 %). Второй независимый период для той же гипотезы |
| H6 | X1 < K3 | повтор H2 FWD1 | в FWD1 не подтверждено (−1,70 %) |
| H7 | W5-G **хуже** X1 в парах gap спокойных месяцев | механизм W6, часть «премия» (2.2) | рекомендация W6 и W9: проверять механизм, а не победу. Это единственная гипотеза с ожидаемым эффектом +5…+10 % на своей области (2.2) |

**Почему не больше и не другие:**
- **X1 < K1, ZB < K1** — подтверждены в FWD1 (p Холма 0,011 и 0,032). Бенчмарк остаётся в таблице как описание, место в Холме ему не нужно;
- **ZB < X1, ZB < K2/K3** — ZB отличается от X1 только в днях e = 1 (16 из 180 в FWD1). Мощность H5 FWD1 по архиву была ≤ 0,002, в FWD1 ZB хуже X1 на 0,60 %. Сравнения ZB даются описанием, без вывода;
- **W8-G < X1, W8-G < K2/K3** — W8-G = W5-G вне дней gap с включённой группой. Эти сравнения следуют из H2 и H1, H3, H4 и даются описанием;
- **PH-R** — диагностический ряд по W9 разд. 7: «не называть кандидатом». Описание — 2.3.

**Поправка — Холм по m = 7, α = 0,05.** Она контролирует FWER при любой зависимости гипотез, а здесь они зависимы сильно и положительно: W5-G = X1 вне дней gap, а W8-G = W5-G вне включённых групп. Холм по N программы (827) не применяется: новый период — отдельный раунд с одним открытием, как в FWD1, разд. 5.1.

**Статистика — та же, что в FWD1, разд. 5.2 (Д7):**
- QLIKE `models_v2/metrics.qlike`, среднее по общим парам;
- Δ_AB = 100·(Q_A − Q_B)/Q_B;
- основной p — `s13/v6_1_eval.dm_one`: НУ, лаг 5, односторонний. Для H7 направление обратное: «A хуже»;
- интервал — блочный бутстрап `stats_d.block_idx`/`boot_means`: 90 %, блок 10, 2000 повторов, seed 0;
- Холм — `s3/dm.holm` по 7 p в порядке H1…H7.

**Правило вывода** — как в FWD1, разд. 5.3:
- «подтверждено на новом периоде» — только при p Холма < 0,05;
- иначе — «не подтверждено (n = …)» с Δ, интервалом и строкой мощности для фактического n;
- таблица всегда из 7 строк; фраза «лучший гибрид на новом периоде» запрещена.

### 2.2 Гипотеза механизма (H7 и часть «страховка»)

**Утверждение W6 (разд. 2 и 7):** поправка уровня после перерыва — страховка. В спокойные месяцы она в среднем ухудшает QLIKE (платит премию), в месяцы шока — улучшает.

**PIT-правило «месяц шока»** (версия 2, до новых данных):
1. z_j = ln RV^IMOEX дня j — замороженный `x1_w8_gap_z.z_series`: бары основной сессии 10:00…18:30.
2. G(j) — замороженный `x1_w8_gap_z.labels`: PIT-терциль, пороги по z дней строго до j, не меньше 60 прошлых.
3. Календарный месяц m (по d пары) — **месяц шока**, если доля дней G = T3 среди дней месяца с G ≠ na больше 1/2. Иначе месяц **спокойный**. Месяц без дней G ≠ na не определён и не входит.
4. Метка известна на закрытии последней сессии месяца m. Используются только бары IMOEX сессий ≤ конца m и пороги из прошлого. Целевая RV SBER, прогнозы и потери не входят.
5. На момент d метка неизвестна — это намеренно. Механизм W6 говорит о реализованном шоке, а не о предсказуемом состоянии: метка, известная на d, проверяла бы другое утверждение.

**Подмножества нового периода:**
- C = {gap^PIT = 1, β W5-G включён, месяц спокойный};
- S = {то же, месяц шока}.

**Что считается подтверждением:**
- **H7 (премия):** среднее (l_W5G − l_X1) на C > 0. DM односторонний «W5-G хуже» на упорядоченной подпоследовательности C (НУ, лаг 5); входит в Холм семейства.
- **Страховка:** Δ(W5-G к X1) на S < 0 — только знак, без p; при |S| < 10 — «не определено».
- **«Механизм подтверждён на новом периоде»** = H7 подтверждена (p Холма < 0,05) **и** Δ_S < 0 при |S| ≥ 10.
- «Премия подтверждена, страховка не наблюдалась» — если выполнено только первое.
- Иначе — «механизм не подтверждён (n_C = …, n_S = …)».
- Те же разбиения для ZB к X1 и W8-G к W5-G — описание.

### 3.2 Вывод

**Нужен срок намного больше года.**
- При эффектах −0,3 и −0,5 % проверка за разумный срок невозможна ни в одной гипотезе: даже при мощности 0,5 без поправки нужно не меньше 19,5 года при −0,5 % и 54 лет при −0,3 % (обе цифры — у H2).
- При −1 % самая мощная гипотеза — H2 (W8-G против W5-G: малая дисперсия разности на днях gap). Ей нужно не меньше **1 233 пар (≈ 4,9 года)** при мощности 0,5 и одном уровне 0,05. С Холмом — 2 736 (≈ 10,8 года); при мощности 0,8 — 2 818 и 4 938.

### 3.3 Предлагаемое правило открытия (проект; вопрос 1)

- **n\* = 1 233** — наименьшее n, при котором хотя бы одна гипотеза семейства с эффектом из поручения (−1 %) достигает мощности 0,5 без поправки. Раньше этого ни одна из них не имеет даже такой мощности. Это нижняя граница, а не обещание: с Холмом мощность H2 при n\* — 0,21, H7 при +10 % — 0,60.
- **Счёт пар:** новые общие пары всех рядов семейства, t⁺ > 2026-11-10, по календарю правила IMOEX, построенному **только по `begin`** новых файлов (как FWD1 разд. 3).
- **T\*** — t⁺ пары номер n\*. Окно — ровно пары с t⁺ ∈ (2026-11-10; T\*]. Пары позже T\* не используются: это резерв следующего периода. Так дата открытия не влияет на окно.
- Если после замка полное правило календаря (rv > 0) выбросит k дней, n = n\* − k. Это строка ↺ в отчёте; окно не продлевается.
- **Не раньше:** до T\* — ни открытия, ни промежуточных взглядов на прогнозы, потери, RV нового периода.
- **Одно открытие.** Сбой после замка — открытие израсходовано, повтор — только по решению владельца (как Ж-249).
- Ожидаемая дата T\* — **≈ сентябрь–октябрь 2031** (1 233 / 253 ≈ 4,87 года от 2026-11-11). Это оценка, а не календарь: фактическая T\* — по числу пар.
