# HAR-J Hybrid SBER — Deep Structural Extension: план и смета (Ж-239; тема Ж-238), SBER, h = 1

DEVELOPMENT / HISTORICAL WALK-FORWARD, не независимый OOS; первая цифра — потолок. Составил дирижёр 09.11.2026 по итогам V7 (PR #948) и листа DE0 (`docs/otchety/harj_deep/DE0_REPORT.md`). **Проект предрегистрации: ни одной конфигурации не посчитано; счёт — только после утверждения бюджета владельцем (раздел 8).**

## 0. Итог в четырёх строках

1. **Причина проигрыша 2022–2025 измерена.**
   - Разрыв HAR-J к XGBoost вырос с +0,0026 до +0,0497 QLIKE.
   - Гибриды-поправки к HAR-J закрывают его лишь частично: конфигурация 8 V7 — на 84 %, A2 — на 38 %.
   - Почти весь остаток — дни сразу после **экстремального M10-бара** дня d (16 % дат, n = 156): там QLIKE HAR-J 0,773, XGBoost 0,512, cfg8 0,570 (+11,3 % к XGBoost).
   - На остальных 84 % дат cfg8 лучше XGBoost (Δ −0,0015).
   - В 2018–2021 в те же дни гибриды были лучше XGBoost (cfg8 −0,0133, A2 −0,0304). Знак сменился именно в этом состоянии.
2. **Дубли вычеркнуты** (раздел 2):
   - A1 и A2 блока — одна задача, и обе ≡ V6 A0g/A2;
   - Hybrid-XGBoost против Hybrid-LightGBM — класс V6 и Ж-211 H7;
   - Bespoke RV — в бюджете V7+;
   - ортогональная связка «бустинг + энкодер» — V4 H + V7 (z без сигнала, DX).
3. **Новых механизмов четыре:**
   - доверие к бустингу, зависящее от состояния, с онлайн-обновлением (D1);
   - смесь поправок «норма / стресс» с отдельной меткой стресса (D2);
   - устойчивая + адаптивная поправка (B1);
   - поправка с затвором по неопределённости (C1).
   
   Плюс одна условная комбинация. Смета — **5 конфигураций** (≤ 8).
4. **Самая перспективная — D1.** Она прямо нацелена на измеренную причину: в состоянии «после экстремального бара» доверие к бустингу обновляется по свежим потерям этого же состояния. Механизм NTP2 (лучший PIT-ряд всей истории, QLIKE 0,2097) — безусловный, D1 — нет.

## 1. Что измерено (DE0, сохранённые прогнозы; описательно, не отбор)

Источник — `DE0_*.csv`; общие даты V7 (2018-01-03 … 2026-02-26); u = ln(RV/F); adv = QLIKE(K2) − QLIKE(гибрид).

| Ряд | adv 2018–2021 | adv 2022–2025 | Доля разрыва HAR-J к K2, закрытая гибридом: 2018–2021 → 2022–2025 |
|---|---|---|---|
| V7 cfg8 | +0,0049 | −0,0080 | 291 % → 84 % |
| V4 NTP2 | +0,0056 | −0,0029 | 320 % → 94 % |
| V6 A2 | +0,0085 | −0,0307 | 434 % → 38 % |
| V7 cfg4 | +0,0034 | −0,0350 | 232 % → 30 % |

- **Хвосты.** 1 % крайних дат дают 89 % Δ cfg8 к K2 в 2022–2025 (cfg4 — 97 %).
- **Состояние «экстремальный M10-бар дня d»** (max |r| бара > 99-го перцентиля прошлых баров, PIT):

  | Окно | n | QLIKE H | Δ cfg8 к K2 | Δ A2 к K2 |
  |---|---|---|---|---|
  | 2018–2021 | 179 | 0,219 | −0,0133 | −0,0304 |
  | 2022–2025 | 156 | 0,773 | +0,0578 | +0,1310 |

  Без экстремального бара в 2022–2025: Δ cfg8 −0,0015.
- **Смещение.** HAR-J в среднем переоценивает в логарифме (u < 0) во всех 22 клетках. Это ожидаемо для прогноза условного среднего (Йенсен) и само по себе не дефект.
- **Предсказуемость.**
  - Дифференциал потерь гибрид − K2 по прошлым M10-признакам не предсказывается: PIT R² вне выборки −0,010.
  - Автокорреляция дифференциала на лаге 1 — +0,27 в 2018–2021 и +0,07 в 2022–2025: ошибки чуть повторяются.
- **Вывод:** выигрыш даёт не новый признак, а **правильное доверие в редком состоянии**, которое можно наблюдать. Перекос этого доверия после 2021 года — причина проигрыша.

## 2. Новизна: сопоставление с V1–V7 (G6)

H — HAR-J; ℓ = ln(M/H), M = √(K2·K3); Z — признаки режима V7; e_d — индикатор экстремального M10-бара дня d (PIT-порог).

| Механизм блока | Ближайшее завершённое | Математическое соотношение | Решение |
|---|---|---|---|
| A1 Direct QLIKE offset boosting, F = H·e^{g(Z)} | V6 A0g / A2 / C2 / E2 (LightGBM, QLIKE, F = H·exp(clip g)) | Та же функция потерь и форма. Отличие только в библиотеке (XGBoost / LightGBM). | **Вычеркнуто.** Контроль — V6 A0g / A2 |
| A2 Conditional multiplicative calibration c(Z) = E[Y/H \| Z] | A1; V4 E, RQC (c — константа или EWMA) | **A1 ≡ A2.** Для F = H·c: ∂/∂c E[ln(Hc) + Y/(Hc) \| Z] = 1/c − E[Y/H \| Z]/c² = 0 ⇒ c* = E[Y/H \| Z]. QLIKE-оптимальная мультипликативная поправка и есть условное среднее Y/H; разница — только в оценивателе. | **Вычеркнуто** |
| Hybrid-XGBoost против Hybrid-LightGBM (Ж-238 B, C) | Ж-211 H7 против H1: второй бустинг не добавляет (Δ +0,0007, p 0,509); V6 | Два бустинга на одних признаках — один источник информации. | **Вычеркнуто** |
| Адаптивная HAR-J (Ж-238 A) | V4 E1–E6, Калман E5, RQC1–3 | Скалярная калибровка уровня по прошлому — то же самое. | **Вычеркнуто** |
| E Bespoke RV | V7+ (Ж-237, направление A) | Тот же механизм. | В V7+, не здесь |
| F Orthogonal sequential / alternating «бустинг + энкодер» | V4 H (F = K8·exp(θᵀz̃), ортогонализованные признаки); V7 1–10 | DX V7: частный R² z сверх Z = 0,0002; z не предсказывает ошибку XGBoost. Последовательная остаточная схема = V4 H с z. | **Вычеркнуто** (нет сигнала, информационный дубль) |
| **D1 Доверие по состоянию с онлайн-обновлением:** F = M^{1−π_t}·C^{π_t}, π_t = π^{(s_t)}_t, s_t ∈ {норма, экстрем} по e_d; π^{(s)} обновляется экспоненциальными весами только на закрытых парах своего состояния | V4 NTP1–4 (π общий для всех дней; NTP2 — fixed share, α = 0,02); V4 C8 (мягкие режимы весов, статичные по обучению) | NTP — частный случай D1 при π^{(норма)} ≡ π^{(экстрем)}. C8 — веса обучены один раз, без онлайн-обновления по потерям. **Новое: два независимых процесса доверия, каждый учится только на днях своего состояния; состояние — наблюдаемый PIT-индикатор экстремального бара.** | **Конфигурация** |
| **D2 Хвостовая смесь поправок:** F = H·[(1 − p_t)·c_n(Z) + p_t·c_s(Z)], p_t = σ(·) обучен на метке «RV(t⁺) > PIT-перцентиль 90» (логистическая потеря), c_n и c_s — по QLIKE | V4 C8; V4 I (вероятность скачка); Ж-231 E | Как класс c(Z) вложена в A1. Новое — **обучение с отдельной меткой стресса** (вспомогательная цель с наблюдаемым будущим событием в обучении, не во входе) и согласованное среднее. | **Конфигурация** |
| **B1 Устойчивая + адаптивная поправка:** F = H·exp(g_s(Z) + a_t·g_a(Z)); g_s — QLIKE-GBM на расширяющемся окне (= A0g); g_a — QLIKE-гребень на последних 250 закрытых парах по остатку g_s; a_t ∈ [0; 1] — по CUSUM разности прошлых QLIKE «g_s» и «g_s + g_a» | V4 E (скалярная локальная поправка), Калман, RQC; V7 (поправки на расширяющемся окне) | В V4 адаптация была скалярной (смещение уровня). **Новое: адаптивная поправка зависит от признаков, обучается на коротком окне по остатку устойчивой, включение — причинный детектор.** | **Конфигурация** |
| **C1 Затвор по неопределённости:** F = H·exp(α_t·ḡ(Z)), ḡ — среднее R = 5 поправок QLIKE-GBM, обученных на разных прошлых окнах; α_t = exp(−κ·sd_r(g_r)/s̄), κ — по внутренней валидации | V7 маршрутизатор (признаки режима); V4 NTP (доверие по потерям) | **Новое информационное множество — разброс оценок поправки (эпистемическая неопределённость)**, в V1–V7 не использовался. Контроль «без затвора» (α ≡ 1) — ḡ того же ансамбля. | **Конфигурация** |

## 4. Протокол (как V7; объявлено до счёта)
- **Даты.** Одинаковые 2018-01-03 … 2026-02-26. Окно разработки 2018–2021; 2017 — только обучение; 2022–2025 — историческая проверка (не OOS); 2026 — отдельно.
- **PIT.**
  - e_d — порог 99-го перцентиля |r| по барам сессий < d;
  - метка стресса D2 — порог по закрытым парам t⁺ ≤ d; в обучении метка — будущее событие пары (разрешено Ж-232 п. 8), во входе — нет;
  - π^{(s)}, CUSUM, a_t — только закрытые пары;
  - GBM ансамбля X4 переобучаются помесячно по t⁺ ≤ d (как V6).
- **Внутренняя валидация** — последние 126 закрытых пар; seeds 0–4.
- **Проверки:**
  - F > 0;
  - при c_n = c_s = 1 (D2), g = 0 (B1, C1) и π ≡ 0 (D1, F = M) — побитно равенство базе;
  - градиент и гессиан QLIKE по g численно: ∂L/∂g = 1 − Y/F, ∂²L/∂g² = Y/F.
- **Правила — те же, что в V7:**
  - «go» 6.1 — шесть условий, включая «2022–2025 не хуже лучшего бустинга» и «не больше 50 % выигрыша от одного года»;
  - «новая информация» 6.2 — Δ < 0, DM p < 0,05, ≥ 3 из 4 лет 2018–2021;
  - Холм N = 733 + 5 = 738, N_wide = 3166 + 5·3;
  - MCS 90 %; бутстрап 20 · 2000 · seed 0;
  - стресс: без 2018, без 1 % крайних;
  - по годам и после 2021 — Ж-239 п. 10.
- **Абляции:**
  - D1 против NTP2 — польза состояния;
  - D2 против A0g и cfg4;
  - B1 против A0g — польза адаптивной части;
  - C1 против ансамбля без затвора и A0g — польза неопределённости;
  - X5 против X1.
