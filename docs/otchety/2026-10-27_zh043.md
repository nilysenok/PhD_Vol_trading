2. **Целевая** — mSR по годам `metriki_e.msr` из ряда оценщика; nan -> точка недопустима. Торнадо взято из mSR-колонок `sweep_e1v2/S{k}_oat_0.04.csv` (пробы не пересчитывались), остальные — оценщик.
3. **Ничья**: оценка ранжирования — плато (среднее цели точки и соседей), ничья в пределах 0,05 -> меньшее σ скользящего Шарпа 126 дней (train 2018+2019, шаг 1, √252, ddof=1). Среди кандидатов, прошедших все ворота, выбирается лучший; если таких нет — лучший по плато с указанием непройденных ворот.

Разница ряда целиком в одном дне (2018-12-29, 2019-12-30; |Δ| < 1e-5), остальные дни совпадают побайтно. S1 2018: окно −0,4919, полный −0,4942 (= `bazy_sverka`).
