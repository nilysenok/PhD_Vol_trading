## Выводы волны E (текст автора; числа сверены с `xgb_lgbm_ensemble/*.csv`, 06.11.2026)

Первая цифра — потолок: все числа — историческая прогонка 2271 дата (2017–02.2026), уже просмотренная при выборе; выбор правил — по внутреннему критерию `crit_wf`, p — сырые и Холм с N = 182 (уникальные trials Ж-206 на момент сравнения) **после** выбора на тех же данных.

### ACCEPT/REJECT (R8, раздельно)
- XGBoost `x2_best_j`: **ACCEPT (потолок)** — кандидат видел 2017–2021; на 2022–2026 лучше Б-2 на 0,0089 QLIKE; DM к Б-2 подтверждён (Холм, N=182). `ctrl_f4` (чистая): **ACCEPT**, DM не подтверждён.
- LightGBM `C0_inh_F4`: **ACCEPT**, DM к LGBM-аналогу Б-2 подтверждён (Холм); на 2022–2026 лучше на 0,0087.
- XGBoost против LightGBM: Δ = −0,0004 (XGB лучше), DM p = 0,77 — различие статистически неотличимо; корреляция дневных потерь 0,998, ln-ошибок 0,993 (ориентир «0,998» относился к потерям; EX0).
- Гибриды: A1…A4 проходят R8 (1)–(4) (лучший собственный компонент — XGB `x2_best_j` или LGBM), **но ни один не допущен**: критерий C (ΔQLIKE < 0 и DM p < 0,10 к лучшему компоненту без 24.02.2022) не выполнен: A1_roll_126 Δ = −0,0032, p = 0,30; A4 −0,0025, p = 0,32; A2 −0,0022, p = 0,40; A3 −0,0003, p = 0,59. На 2022–2026 A1, A2, A4 хуже своего лучшего компонента на 0,0009…0,0014 (A3 — на 0,00005). Residual B1q, B2q и адаптивный C6 — **REJECT**.

### Информационная дополнительность (EX1)
- HAR/XGB: корреляция ln-ошибок 0,951, потерь 0,918 — расхождения есть; XGB/LGBM: 0,993 / 0,998 — модели дублируют друг друга. Знак разности потерь предсказывается слабо (AUC 0,44–0,62 по годам, логит и дерево глубины 2), то есть «когда одна модель права» по прошлым признакам не определить.
- **Вопрос 1 (есть ли предсказуемая ошибка HAR):** да, но малая. Ridge на F1–F6 (годовой LOYO): R² к среднему остатка 0,034, QLIKE HAR·exp(ĝ+s²/2) − HAR = −0,0031 (−1,3 % от 0,2493 на 2018–2026); по группам F3 (−0,0060), F5 (−0,0035), F4 (−0,0014) полезны, F1, F2, F6 вредны; Б-2+F4 линейно (33 признака) переобучается (+0,018).
- **Вопрос 2:** residual-бустинг не воспроизводит HAR (корреляция g с ln HAR 0,07; доля |g| < 0,05 около 50 %), в спокойном режиме HAR не разрушает (ΔQLIKE +0,0002 / +0,0007), в стрессе Г4 улучшает на 0,023 / 0,026. Но итог хуже самостоятельных моделей: B1q 0,2234, B2q 0,2222 против XGB 0,2113 и LGBM 0,2117; log-MSE B1m 0,2254, B2m 0,2242; аддитивный B1a 1,38 (в 2022 12,1; положительность через ε_PIT не спасает) — отрицательный результат.
- **Вопрос 3:** нет. Взвешенное среднее (A1 0,2081, A2 0,2095, A4 0,2088) лучше residual-коррекции. Residual-модели уступают ансамблю — остаётся простое.

### Три лучших по `crit_wf` среди недопущенных — справочно; R9 допустил 0 (потолки)
(Название исправлено после проверки: прежнее «Три лучших архитектуры» читалось как допуск; ни одна гибридная архитектура не допущена, статус A1–A4 — «R8 пройдено; не допущен (R9, критерий C)».)
1. A1_roll_126 (HAR + XGB, roll 126): QLIKE 0,2081, `crit_wf` 0,2147 — к HAR DM p без 24.02.2022 = 0,0005, к XGB p = 0,30.
2. A4_roll_252 (HAR + XGB + LGBM): 0,2088, `crit_wf` 0,2162.
3. A2_roll_252 (HAR + LGBM): 0,2095, `crit_wf` 0,2173.
Факт проверяющего (сверен с `HYBRID_BREAKDOWN.csv`): выигрыш A1 над XJ приходится в основном на 2017–2018 (QLIKE 2017: 0,1057 против 0,1103; 2018: 0,2555 против 0,2836); с 2020 года A1 не лучше XJ (2020: 0,1526 против 0,1517; 2021: 0,1164 против 0,1162; 2022: 0,4668 против 0,4653). В 2017 году веса равные по правилу R3 (`MIN_CLOSED = 252`: закрытых прогнозов меньше, чем нужно окну), т. е. выигрыш 2017 — это эффект равного среднего с HAR, а не обученного правила.
Каждая — результат трёх последовательных выборов на тех же данных (комбинация, правило, окно): потолок. Для XGB+LGBM (A3) простое равное среднее не хуже сложной модели (разность `crit_wf` ≤ 0,0005, DM p > 0,10) — остаётся простое; выигрыш A3 над лучшим компонентом (Δ = −0,0003) — на уровне шума, объясняется разницей ошибок, а не новой информацией (корреляция 0,993).
