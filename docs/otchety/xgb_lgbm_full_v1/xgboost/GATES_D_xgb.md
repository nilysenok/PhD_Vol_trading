## Правила, объявленные до счёта
- **Базы.** `x2_best_j` (HP: годовой выбор И2 + сдвиг X2 из `X2_DECISION.json`; колонки 2017–2021 — «потолок: кандидаты видели 2017–2021») и `ctrl_f4` (Б-2+F4, годовой И2, чистая). Обе в каждой развёртке. Опоры расширяющегося окна читаются из кэша C; пересчёт расширяющегося в D — только контроль (D1) и построчные потери фолдов (нужны для составных строк).
- **Q1 (критерий).** `crit_pen` как в B/C: фолды LOYO (Y, y), y < Y, цели < 01.01.Y, HP года Y; `pen_Y = mean + 0,25·(max − mean)`. Для окна/весов фолд обучается на ближайших к проверяемому году парах (как B2: `loyo.nearest`, расстояние до блока; веса — по тому же расстоянию), чтобы окно действовало и в LOYO. Δcrit_pen = точка − своя база (минус — лучше).
- **Q2 (D1, окна; 12 trials).** rolling 504 / 756 / 1008 / 1260 пар; экспоненциальные веса, полураспад 756 строк (3 года) и 1260 (5 лет) — при 252 строках в году; окно/веса относительно даты T обучения; для каждой из двух баз. Expanding — контроль (не trial). Недоступность окна (пар меньше N) — окно = все пары, число таких дат по годам публикуется (`WINDOW_AVAILABILITY_D.csv`).
- **Q3 (D1, выбор окна по прошлому; процедура, не trial).** Для каждого года Y окно из {expanding + 6 строк D1} с минимальным pen_Y; ничья |Δ| ≤ 1e-12 — expanding. Год даты d — год цели (`rows.year_of`). Строка `*_annual_window`. Предупреждение: её crit_pen занижен (минимум по тем же фолдам, что и критерий) — потолок, как x2_annual.
- **Q4 (D2, частота; ≤ 4 trials).** Лучшее окно базы — argmin crit_pen среди expanding и шести строк D1 (фиксированные, не annual). На нём: еженедельно (блок = ISO-неделя сетки) и ежемесячно (блок = календарный месяц сетки), модель обучается на первой дате блока и прогнозирует весь блок (`engine.blocks`). Если лучшее окно — expanding, это расширяющееся окно с реже обучаемой моделью. LOYO частоту не видит (один фит на фолд), поэтому критерий частоты — **crit_wf**: ряд потерь самой строки, `ann_y` = средний QLIKE по году цели, `pen_Y = mean_{y<Y} ann_y + 0,25·(max − mean)`, `crit_wf = mean_{Y=2018…2026} pen_Y` (причинный, 2017 без прошлого). Порог **до счёта**, цепочка от самого редкого: еженедельное заменяет ежемесячное, только если `crit_wf(w) ≤ crit_wf(m) − 0,0005`; ежедневное заменяет выбранное, только если `crit_wf(d) ≤ crit_wf(выбранного) − 0,0005` (иначе дешёвое предпочтительно); функция `d_comp.freq_choice`. Время обучения — сумма секунд блоков.
- **Q5 (D3-R1, режимные признаки; 4 trials).** `designs.regime_cols(F)`: q_w (квинтиль RV_w по 252 предыдущим, без текущего), stress_RV (RV_w > q67 по 252 предыдущим), переход q_t − q_{t−1}. Строки: `r1_qw` (только q_w), `r1_all` (q_w, stress_RV, переход) на expanding, ежедневно, обе базы. ↺ Стресс Г4 (`stress_p3`) задан только на сетке 2016-12-30…, а обучающие пары идут с 2014: в признаки идёт stress_RV (как B1 Ж-204); стресс Г4 — в срезах описания.
- **Q6 (D3-R4, переключение; 4 trials, обе базы).** Состояние на строке t — stress_RV(t) (PIT). `r4_s1008`: стресс → rolling 1008, спокойно (и NaN) → expanding. `r4_s504`: стресс → rolling 504, спокойно → expanding. Новых обучений нет (составной ряд из строк D1/опоры; trial считается — новый ряд прогнозов). LOYO-потери составной строки — по строке t проверяемых пар (состояние на t известно в t). Показываются: число переключений состояния на сетке, задержка реакции (медиана строк от «шока» — дневной RV > 3 × медиана предыдущих 252 — до первого флага stress_RV на/после шока; n шоков), QLIKE на дате переключения и в 5 днях после, спокойно/стресс Г4. R2 (отдельные модели) и MoE не повторяются (Ж-204 B1: хуже).
- **Q7 (бюджет).** temporal_regime ≤ 30: план D1 12 + D2 ≤ 4 + R1 4 + R4 4 = ≤ 24, резерв 6 не планируется. Реестр `OPTUNA_TRIALS.csv`: wave `D-xgb`, trial_id = хэш конфигурации (база, окно, веса, частота, признаки, HP-источник, seed 42); дубль прежних запусков (Ж-197…Ж-204, C) — ссылка, не trial. Составные строки считаются trial. Annual-выбор окна — процедура (не trial). Счётчик — `CHECKPOINT.json: used.temporal_regime`.
- **Q8 (описание строки).** Через `rowsx.row_of`: QLIKE весь, 2017–21, 2022, 2023–25, 2026, без 24.02.2022, без 2022, RV/σ̂², RMSE-подобные из ряда, DM (лаг 5) к HAR-J(б), к `ctrl_f4` и к своей базе (весь и без 24.02.2022), crit_pen, crit_wf, unstable, статус; QLIKE в спокойном/стрессе Г4 (`stress_p3`, состояние на d). «Перспективно» = crit_pen лучше своей базы (> 1e-12) И разность к HAR-J(б) без 24.02.2022 ≤ 0 И не unstable.
- **Q9 (seed).** 42 везде; seed-контроли и ±1 шаг в D не делаются (отступление: окна/частота не имеют соседей по шагу, а seed был в C).
- Процессов ≤ 4 (spawn-пул), стадии по одной через run_in_background. `test_locked/`, `*_test.*`, `.env` не читаются; данные — только разрешённые.
