## 1. Текст для FINAL (дописыванием): уровни 0–4

**Уровень 0. Единица решения.** Решение принимается по тикеру на день d по данным, известным к 18:50 d (Ж-029). Исполняется в d+1 заявками, рассчитанными вечером d (Ж-086, Ж-091), по 5-минутным барам.
- лимит-заявка исполняется проходом на тик по цене min/max(open, уровень);
- стоп-заявка исполняется касанием по худшей цене из (open, уровень);
- если в одном баре сработали стоп и тейк, первым считается стоп;
- выход по времени исполняется по open бара 10:00 x+1.

Все признаки point-in-time (Д3). Ранги и окна кончаются в d−1 (Н1), если ниже не сказано, что окно включает d.

**Уровень 1. Сигнал — оценка s ∈ [−1; 1].**
1.1. Сырой скор по семействам (знак задаёт сторону):

| семья | Sk | s_raw |
|---|---|---|
| контртренд | S1, S2 | z = (c_d − SMA_w)/STD_w; s_raw = −sign(z)·clip((\|z\| − z0)/(3 − z0), 0, 1), z0 = 2,0 |
| тренд | S3, S4 | в день пробоя (S3: c_d вне max(high)/min(low) за d−w…d−1; S4: смена стороны линии ST): s_raw = sign(пробой)·ER₁₀,d, где ER = \|c_d − c_{d−10}\| / Σ\|Δc\| за 10 дней |
| диапазон | S5, S6 | x = (c_d − M)/(c_d·σ_d), M = P недели (S5) или VWAP_20 (S6); s_raw = −sign(x)·min(\|x\|, 3)/3; у S5 только при S2 < c_d < R2, у S6 — при dir_bias ON |
| кросс-секция | S7–S9 | s = ±(2·pct − 1), pct — перцентиль ранга в сечении 17 тикеров на d |

1.2. Нормировка внутри Sk (S1–S6). Скор переводится в ранг: s_norm = sign(s_raw)·F̂(|s_raw|). Здесь F̂ — эмпирическая функция распределения ненулевых |s_raw| этой Sk по всем тикерам за окно d−252…d−1. Если наблюдений меньше 20, то s_norm = 0 и входа нет. У S7–S9 скор уже ранговый, поэтому п. 1.2 к ним не применяется.

1.3. Контекст. Итоговый скор s_итог = s_norm · g, где g — произведение трёх индикаторов из {0; 1}, без обучения:
- **не-новость:** |r_d| < 2,5·σ̂_rv22,d−1 и vol_d < 2·mean(vol_{d−20…d−1});
- **согласие с рынком по семейству:**
  - контртренд — относительный z (тот же z, посчитанный по ряду log(P_i/IMOEX)) того же знака, и |z_rel| ≥ z0;
  - тренд — для лонга IMOEX_d > MA50 (d−49…d), для шорта — ниже MA50;
  - диапазон и кросс-секция — 1;
- **ликвидность:** w_max·K ≤ 5 % медианного дневного оборота тикера за d−19…d (бары ≤ 18:50 d). Здесь w_max — размер при |s| = 1, K — капитал (❓ Д-1).

1.4. Вход разрешён при |s_итог| ≥ порог; ось `porog` ∈ {0,3; 0,5; 0,7}.

**Уровень 2. Сделка.**

2.1. Вход. Заявка живёт 1 день:

| семья | заявка |
|---|---|
| контртренд | лимит c_d·(1 − sd·k_e·σ_d), k_e = 0,5 |
| тренд, ось `vhod_tip` | `stop_zayavka`: buy-stop на уровне пробоя (S3 — max(high, w), S4 — линия ST); `otkat`: лимит на уровень пробоя ± 0,5·ATR14, перевыставляется до 3 дней |
| диапазон | лимит на S1/R1 текущей недели (S5) или на VWAP ∓ dev_mult·dev (S6) |
| кросс-секция | по open 10:00 d+1 |

2.2. Размер: w = ρ/(k_s·σ_d)·|s_итог|, не больше 1 на позицию (L = 1, Ж-065). Ось `rho` ∈ {0,2; 0,3; 0,5} % капитала.

2.3. Выход по причине входа:
- **контртренд** — `tejk_signal` ∈ {k_srednemu, pol_puti, rodnoy_uroven} (без `net`) и τ ∈ {3; 5}. Выхода по сигналу нет (Ж-092 S1.4).
- **тренд:**
  - трейлинг-стоп на 2·ATR14 от экстремума после входа, пересчёт каждый вечер;
  - ½ позиции фиксируется лимитом на +1R, где R = k_s·σ_d·P_вх;
  - выход по обратному сигналу — стоп-заявкой на противоположной границе канала или на линии ST (Ж-091 п. 1.2);
  - выхода по τ нет.
- **диапазон** — ось `vyhod_diap` ∈ {protivopolozhnyy, k_srednemu}:
  - `protivopolozhnyy` — противоположный уровень: R1/S1 у S5, VWAP ± dev_mult·dev у S6;
  - `k_srednemu` — P или VWAP, зафиксированные на d.

  Плюс τ ∈ {5; 10}.
- **кросс-секция** — держание τ (S7 — 5 дней, S8/S9 — 21 день) траншами.

2.4. Стоп и пауза:
- стоп есть у всех: k_s ∈ {1,5; 2; 3}·σ_d от цены входа;
- через отсечку стоп сдвигается на дивиденд (мутация № 32);
- после двух стопов подряд по тикеру внутри книги Sk — 5 торговых дней без новых заявок.

**Уровень 3. Книга Sk.**

3.1. Ограничения книги:
- **сектор:** не больше 3 ставок одной книги в секторе. Открытые позиции занимают места первыми, новые заявки ранжируются по |s_итог|. Секторов 9, источник — `docs/issledovaniya/2026-10-27_sektory.csv`.
- **нетто:** |лонг − шорт| ≤ 30 % валовой экспозиции книги. При превышении доминирующая сторона пропорционально уменьшается. Хедж беты делает только уровень 4.

3.2. Таргет книги: m = min(m_max, 0,08 / σ̂_книги). σ̂_книги считается по немасштабированным дневным доходностям книги за d−W…d−1, W — ось `okno_knigi` ∈ {21; 63}. m_max задаёт валовую экспозицию книги ≤ 1 (❓ Д-6).

3.3. Горизонты по семействам фиксированы: контртренд 3–5, диапазон 5–10, тренд — трейлинг без τ (10–30 — ожидаемое держание), моментум 21.

**Уровень 4. Портфель A′-v3 — одно правило, без осей (N слоя = 1).**

4.1. Веса книг — паритет риска. Ковариация по 252 дням до d−1, корреляции усажены к нулю по Ledoit–Wolf: цель — диагональ, интенсивность по формуле LW. Книги-дубли с ρ > 0,7 получают один вес (Ж-066 п. 4). Контрольная строка — равный риск, вес ∝ 1/σ̂_книги.

4.2. Нейтрализация:
- β_d портфеля к IMOEX считается по дням d−63…d−1;
- хедж — продажа MIX на β·NAV, решение в 18:50 d, исполнение по open MIX 10:00 d+1;
- ролл — за 2 торговых дня до `LSTDELDATE`;
- комиссия MIX — ❓ Д-3;
- секторный нетто после сложения книг — |Σ_сектор w| ≤ 20 % NAV; при превышении пропорционально режется доминирующая сторона сектора;
- в отчёт — доля дисперсии портфеля, объяснённая IMOEX, до и после хеджа (цель < 10 %).

4.3. Таргет и выключатель:
- таргет портфеля — 10 % годовых, σ̂ по 21 дню до d−1;
- валовое плечо ≤ 2; маржа на часть сверх 100 % — по ставке КС + 2 % (`s9.py`, `mg`);
- выключатель: если вола портфеля за 10 дней (d−10…d−1) больше 2 × 10 % или просадка от пика больше 5 %, валовая экспозиция умножается на 0,5;
- выключатель снимается, когда на d−1 оба условия ложны.

4.4. Свободный капитал получает ФДР по КС, как в движке.

**Защищённая строка — A′-базовая (Ж-090 п. 2), считается всегда рядом:**
- исходные ряды — A_strogaya по Sk;
- веса — 1/σ по окну 63;
- таргет — 10 % по окну 63; L = 1; без тормоза.

Код — слитый Л-20 (#454), сверка с ним ≤ 1e-12. Справочные строки слоя по сетке Ж-093 (окно 21/63 × плечо 1/2 × паритет/равный = 8, из них одна основная) в выбор не идут, как и 1 295 конфигураций уровней 2–3.
