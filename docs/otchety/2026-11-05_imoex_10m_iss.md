## Сверка close (последний бар → дневной close), только чтение
`docs/tables/imoex_10m/close_vs_dnevnoj.csv`, сводка — вывод скрипта.
- По заданию, «последний бар основной сессии» (begin 18:30, конец 18:40): **не совпадает** с дневным close — медианная |отн. разница| 0,061 % (index_d 2022+, 1037 дней) и 0,105 % (iss_mix 2014–2019, 1409 дней); точно совпало 6 и 3 дня; макс. 1,74 %.
- Последний бар до 19:00 (18:40/18:50, аукцион закрытия): совпадает точно (|разн| < 1e-6) в 1032 из 1037 и 1402 из 1409 дней; отклонения > 0,01 % — 5 (2022-03-24, 2022-09-16, 2025-07-24, 2025-09-01, 2025-10-17) и 7 (2014-07-30, 2014-10-06/07, 2015-07-17, 2015-07-24, 2016-11-08, 2017-11-29), макс. 0,15 %. Вывод: дневной close индекса — после аукциона, поэтому его берут из бара 18:40–18:50, а не из 18:30.

## Отступления и оговорки
- Python без pandas/pyarrow: parquet читает Rust (подкоманда `index-days` → csv), скрипт сверки на стандартной библиотеке.
- `index10.rs` — 225 строк (из них ~55 тестов), `cargo test` целого крейта не собирается из-за старых ошибок в `src/bin/*` (до моих правок); проверено `cargo test --bin moex_iss`: 35 из 35. `cargo clippy -D warnings` падает на старых файлах (`rv1850.rs`), в новых замечаний нет; `cargo fmt --check` показывает старые расхождения.
- Мутация «путь shares/TQBR вместо index» ловится: `index10::tests::url_is_index_not_shares`; граница периода: `clip_drops_outside_period`.
