# R2, агент P — кластер 14, панельно-факторная архитектура (26.10, по Маку)

1. **Где.**
   - Код — `scripts/analysis/r2_panel.py`.
   - yaml — `models/designs/r2/r2_P_panel.yaml`, определения записаны до счёта.
   - Ядро — `r2_core.py` агента S: validate, variants, design_hash, cache_dir, write_series, load_d0, perturb_frame / plant_frame, shift_check, leak_check, run_phase.
   - Код первого раунда и модули соседей только импортируются (`harx.fit_en`, `d25_1.rvi_leg`).
2. **Разложение по день d.** ln RV_i,t = α_i + β_i·ln m_t + u_i,t на окне W ∈ {126, 252} строк тикера (`leg.panel_beta_window`).
   - β̂ усаживается к 1 по Васичеку: c = se²/(se² + τ²_d), где τ²_d — дисперсия β̂ по 17 тикерам дня.
   - Рынок m (`leg.panel_market`): RV_IMOEX (rv_IMOEX²/252) или RV_eq17 — геометрическое среднее RV 17 тикеров дня (↺, см. журнал).
3. **Рыночная компонента F_mkt** — прогноз ln m̄ на d+1..d+h, ряд по датам. Выбор по `leg.type`:
   - HARJ — HAR рынка;
   - HARX — HAR-X рынка: `harx.fit_en`, сетка λ × α (`leg.enet`, внутри складки), Z по `leg.regressors`: S1 = ln RVI², S2+ = вторая мера рынка, ln m за 66 и 132 дня;
   - RVI_anchor — `d25_1.rvi_leg` на рынке, калибровка — сдвиг в логах по датам обучения;
   - factor — среднее HAR-X и якоря в логах.
4. **Идиосинкразия F_u.**
   - HAR на ũ_d, ũ_w, ũ_m с частичным объединением: F_u = (1 − κ)·пул + κ·тикер, κ = `leg.pooled_kappa` (список — внутри складки).
   - Либо плюс пулированный LightGBM на остатке HAR-u (`boost.role = residual`, num_threads = 1, deterministic).
5. **Прогноз и усадка.** ln ŷ = α̃ + β̃·F_mkt + F_u. Варианты `leg.panel`:
   - `factor_shrink_025` / `_05`: ln ŷ ← (1 − w)·ln ŷ + w·(α̃^(h) + β̃·F_mkt), w = 0,25 / 0,5;
   - `factor_shrink_state`: w = 0,25 + 0,25·Ê_train(ρ̄_d), где ρ̄ — `g5_corr_m` (F, features_r2_v2), Ê — эмпирическая функция распределения по датам обучения шага;
   - `off`: та же HAR без разложения (абляция).
6. **Выход.**
   - Ряды: `R2/cache/<hash>/P_h{h}_s{seed}_val.parquet` (варианты сетки — `P__<тег>`), сырые, без s².
   - Параметры по шагам: `params.csv` (`design_sha, h, step, param, value`) — коэффициенты рынка, λ/α, a якоря, k якоря, распределение β̃ и c, ū^h, коэффициенты HAR-u, κ, число деревьев, w.
   - Пишутся только val шагов 1–6 (≤ 2021). Матрица — `load_d0`, G5 — фильтр date ≤ 2021-12-31 и сверка SHA.

   - Полный детектор: 17 тикеров, шаги 1–6, 6 срезов ядра — OK.
   - `run_phase` на временном каталоге: запись, сдвиг, params, DONE и повтор — OK; неприменимый дизайн отсеян.
