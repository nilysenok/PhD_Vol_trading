- **Б0.1 — один вариант, без выбора.** F = exp(s²/2). s² — дисперсия OOS-остатков ln RV − ln прогноза года оценки шага t−1 (объединение тикеров, эмбарго). На тесте шага t — s² шага t; F шага t−1 тоже сохранён.
- **GARCH/GJR.**
  - Спецификация `garch_sv.py`: доходности close×100, Constant, normal; параметры по годам < vy; фильтр через vy и ty.
  - Калибровка масштаба — OLS по логарифмам с единичным наклоном, по тикеру: ln a_{t,тикер} = среднее (ln RV − ln σ²_GARCH) на годе оценки шага t−1 (эмбарго).
  - Б0.1 — F = exp(s²/2), s² — внутритикерная дисперсия тех же остатков после вычета ln a. Прогноз шага t: σ²·a·F.
  - Почему не медиана: OLS по логарифмам с s² из тех же остатков даёт оценку среднего логнормального закона и согласуется с Б0.1 у остальных моделей. Медиана дала бы только медианную несмещённость, и Б0.1 пришлось бы оценивать отдельно.
  - Справкой — тот же масштаб без F и некалиброванный прогноз. Выбора по метрике нет.

  - LSTM и GRU — по 1 основному (ансамбль трёх seed с Б0.1); справкой — отдельные seed и прогноз без поправки;
  - GARCH и GJR — по 1 основному (a·F); справкой — a без F и без калибровки.
  - Выбора между вариантами по метрике нет.
