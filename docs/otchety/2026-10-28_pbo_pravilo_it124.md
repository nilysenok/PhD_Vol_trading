## Правило центра плато на половине CSCV (объявлено до счёта)

1. **mSR по годам на половине** — из тех дней года, что попали в половину (блоки CSCV с годами не совпадают). Год, в котором в половине < 21 дня, в min не входит; целевая точки = min mSR по оставшимся годам, nan хотя бы в одном — nan (как `V.obj`). mSR — `metriki_e.msr` (проверено тестом).
2. Плато: среднее целевой по соседям ±1 шаг по осям плана (включая себя, конечные), ≥ 3 конечных соседа, иначе край — не кандидат, кроме «нет» на оси из `OSI` (Ж-048); топ-20 по плато; ничья ≤ 0,05 по плато -> меньшая sigma126 (`pick_center`, `pick_best`).
3. Куб — оси плана из последней строки `docs/tables/zh047/S{k}_itog_v2.csv`, остальные оси — на значениях центра той же строки (= база факторного прогона). В матрице остаются все точки (Моррис, куб, пробы, ансамбли, элементы итераций 3–4): они считаются в ранге, но кандидатами центра плато бывают только точки куба.
4. Допустимость (`dopustima`: сделок ≥ 30 в год, сторон ≥ 0,5 × якорь, не вырождена) — по всему train: структурный фильтр активности, не доходность.
