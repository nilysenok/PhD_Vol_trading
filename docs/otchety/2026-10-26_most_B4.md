## 2. Режим фильтра C u02 (h=1) при старом и новом σ_pred

**Что такое режим.** Это булева маска C, которую `fastbt.approach_cd.run_c` выбрала по валидации для пары (тикер, стратегия S1–S6) и года: позиция C до фильтра оборота равна `A · маска`. Если ни одна маска не прошла ограничения, `run_c` возвращает позицию A, и такой пар-год считается «всё открыто» (65 пар-лет у final2, 61 у final3). Своего порога нет:
- выбранные параметры взяты из кэшей официальных прогонов С9 (`Cmeta`: final2 — `data/fastbt/s9/cache_6e3170610b.pkl`, final3 — `cache_89c0dd6160.pkl`);
- маска построена функцией `fastbt.masks.c_masks` на σ, поданной так же, как в `fastbt.s9._job`.

**Сверка.** Для всех 408 пар-лет на каждом σ заново прогнаны `ApproachA` → `run_c` → `turnover.apply`. Расхождений нет: `run_c` = A × сохранённая маска, позиция после фильтра оборота = кэш С9.
