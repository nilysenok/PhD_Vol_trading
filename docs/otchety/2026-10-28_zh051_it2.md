## 0. Отступления (до выводов)
1. Определение ансамбля — умолчание дирижёра (блок владельца 01:05 до дирижёра не дошёл): центр = последняя строка `S{k}_itog_v2.csv`; соседи по осям набора, радиус 1, без углов; наборы top2 / top3 (по μ* Морриса) / все оси; режимы `srednee`, `golos`; 6 конфигураций на стратегию.
2. Вес |m| (принято дирижёром): движок торгует сделками, дробную позицию не принимает. `srednee`: направление sign(среднего позиций), вес сделки × |среднее| на день входа. `golos`: строгое большинство точек (> n/2), вес 1.
3. Точки, различающиеся только осями исполнения (k_s, R, τ, σ, вход, размер, проверка выходов), дают тот же сигнал и схлопываются; выходы и размер всегда центральной точки. Поэтому у top2/top3 число сигнальных точек (`n_signal`) часто меньше 2k+1: у S2 и S6 top2/top3 = центральная точка (ансамбль вырожден). Так как набор осей Морриса у них почти целиком — оси исполнения.
4. Плато ансамбля — одностороннее правило Ж-048 по соседним конфигурациям (другой режим того же набора, соседние наборы того же режима; 2–3 соседа, «≥ 3» невыполнимо): все соседи > 0 и не хуже лучшей более чем на 0,1 mSR. G4 (плато k_s, R, τ) — для центральной точки из ledger итерации 1 (выходы те же).
5. N итерации 1: в `itog_v2` N посчитан по свежему Ledger без точек Морриса, проба плато, совпавшая с точкой Морриса, посчитана дважды. Воспроизведение (Моррис с тем же seed + строки faktor + пробы) совпало с `N_do_dosheta` и с N `itog_v2` по правилу `itog_v2`; честное число уникальных на 20–40 меньше (колонка `N_it1_unikalnykh`). N и PBO общей матрицы — по честным уникальным + 6 конфигураций (`N_obshchee`). Это не расхождение результатов, а двойной счёт 20–40 проб в итерации 1 (в сторону консервативности).
6. Комиссия только 0,04 % (0,035 % не считалась). В реестр дописаны 36 строк (`istochnik=zh051_it2`), колонки tune/ctrl = mSR 2018 / 2019.

## 2. Что проверено
- Golden: ансамбль из одной точки побайтно равен этой точке, оба режима (`tests/test_etap1_ansambl_dannye.py::test_golden_ansambl_iz_odnoy_tochki`); без данных — `test_golden_odna_tochka_pobaytno`.
- Сверка с s9 по компонентам: каждая сигнальная точка ансамбля сравнена с `ekviv_s9.boevoy_pos` (Unit + ApproachA + exec_layer + tfilter) по всем тикерам 2018–2019: расхождений 0; точки с q_sily ≠ 0 или значениями, которых боевой Unit не принимает, — «нет эталона» (столбец `sverka_s9`). Усреднение позиций — до движка, к s9 не сводится (боевого аналога нет).
- Мутации: «среднее с будущих точек» и «golos вместо srednee» — `tests/test_etap1_ansambl.py`; на данных — `test_ansambl_iz_dvukh_tochek_otlichaetsya_i_mutatsiya_golos`.
- Общая матрица: Ledger итерации 1 и 2 в `docs/tables/zh051/_ledger/S{k}/ledger_it{1,2}.pkl` (pickle кэша Ledger; на диске в рабочей копии, в git не включён по размеру ~6–40 МБ). Итерации 3–10 загружают `ledger_it2.pkl` и дописывают.
