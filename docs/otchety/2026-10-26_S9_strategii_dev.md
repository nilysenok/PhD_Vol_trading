# С9: доводка стратегий на разработке 2018–2021 — 26.10.2026

**Ни один дизайн С9 не даёт положительного избыточного Шарпа за 2018–2021.** Всё ниже предварительно: пересчёт будет на финальном σ_pred. По С8 лучшим остаётся C основного дизайна (u02): −0,47 против −0,93 у A, ΔШарп +0,45 (p = 0,014). Из новых вариантов D, B и портфелей ни один его не обгоняет. Ни один D и ни один B (таргетирование) С8 не проходит.

Ветка `s9-strat` (база `kanon-v22-pereschet`). Тест 2022–2026 закрыт: считалось только `--scope dev`, все σ-источники обрезаны по 31.12.2021, файла `FINAL_DESIGN_strategies.md` нет. Сетки объявлены в журнале до запуска (`docs/otchety/dev_log_strategies.md`, строка «С9 … сетки объявлены до запуска», коммит `f0af947`), прогоны — строки 60–64. Счёт шёл на 2 воркерах: кэш A и C — 23 с, все надстройки — 18 с. Таблицы — `docs/tables/strat_dev/s9_*.csv` (разделитель «;», десятичная запятая).

## Как считалось
- **База.** Взят дизайн `fastbt/designs/final/main.yaml`: A 2017–2021 с фильтром оборота, валидация с 2017, маска [0], комиссия 0,05%. Надстройки С9 (D, B, C1, C2) умножают позицию A основного дизайна того же года, уже после фильтра оборота. Эталоны — A и C (u02) основного дизайна на том же σ и горизонте.
- **Сверка движка.** Движок МСП `fastbt/s9.py` совпадает с `fastbt.msp.portfolio` на позициях пробного прогона основного дизайна: A −0,9262 / −0,9262, C −0,4714 / −0,4714, max|Δexcess| 4·10⁻¹⁰.
- **Прошлые данные.** Ранг, перцентиль и медиана считаются по окну [t−W, t−1], без текущего бара. Минимум max(50, W/5) баров. Если истории нет, затвор открыт.
- **Отсев D1–D6.** Точка исключается до оценки, если средняя доля закрытых баров калибровочного окна (2017…Y−1) меньше 10% или больше 50%. Семейный выбор — по Шарпу на валидации среди точек, попавших в полосу в своём окне.
- **Метрики.** Шарп избыточный, сравнения — парный бутстрап 1 000 (p = доля Δ* ≤ 0). C3 дополнительно проверен по Ледуа–Вольфу (2008): HAC-с.о., студентизированный круговой блочный бутстрап, блок 5, 1 000 реплик (в финале 10 000). Маржа: капитал в позиции = 20% номинала.
- **Кальмар** при отрицательном excess вырожден: MDD почти равна всей потере, и Кальмар ≈ −1/4 года у всех вариантов. Он есть в CSV, но выводов по нему нет.
- **12 вариантов D ночи** (`2026-10-26_ch4_d_night.md`) не повторялись. Их база другая: D пайплайна на сыром ансамбле A, без фильтра оборота, A = −0,89. Поэтому цифры С9 с ними напрямую не сравниваются.

## Итоги
1. **По С8 лучший — C u02** (−0,47, Δ к A +0,45, p = 0,014). Положительного периода нет ни у одного из более чем 200 вариантов, H3 формулируется по прежнему правилу.
2. **D не проходит С8 ни в одной семье.** Лучший непрошедший — D6 (σ_pred / RVI): единственный D, который обгоняет A за период (+0,17, незначимо).
3. **B-таргетирование и мультистратегийные смеси хуже A и C.**
4. **H2 на разработке:** гибрид против HAR-J — по знаку в пользу гибрида (+0,23…+0,33), незначимо. Против наивной — разницы нет.
5. **Основной дизайн не меняется** (ночное умолчание). Кандидаты, которые можно добавить в тест дополнительными строками (решает владелец): D6 и C1-семья.

## Ночные умолчания
- Надстройки D/B/C1/C2 умножают позицию A основного дизайна после фильтра оборота. У D и C пайплайна порядок другой: маска до фильтра.
- C1/C2: «порог p» = закрыт неблагоприятный хвост 1 − p маски режимов кода, по категориям. Пропуск ранга (нет истории) — открыто, в отличие от кода, где закрыто.
- «B (таргетирование)» в С9 — это масштаб позиции σ_target/σ_pred, а не B кода (стопы на σ_pred). В P2 вошёл B С9.
- Наивная σ = sqrt(rv_w) строки PIT дня t: среднее RV дней t−5…t−1, то есть «вчерашняя», без лишнего сдвига.
- RVI — close_RVI (срез 18:50) строки дня t, лаг 0; лаг 1 посчитан как D6lag1. В выбор по С8 вошёл D6 с лагом 1 — он строже и лучше.
- Seed-σ: rank 1 вместо top-5 (top-5 есть только для seed 42); масштаб F года взят из `sigma_pred_h1_final2_steps.csv`. Для C (ранги) масштаб не важен, для D6/B — важен.
- Отсев по доле закрытых дней в семейном выборе: нет точек в полосе — берётся ближайшая к полосе. На C отсев не применялся (не требовался заданием).
- Проскальзывание — 0,05% на сторону; тиков нет (нет шага цены по тикерам).
- Бутстрап 1 000; Ледуа–Вольф: HAC Ньюи–Уэста, блок 5. В финале — 10 000.
