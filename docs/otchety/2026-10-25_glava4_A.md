## 3. Бенчмарки и H3
**H3** (текст диссертации, введение и §4.4, табл. 4.9): «мультистратегийные портфели … значимо превосходят классические портфельные подходы различных пропорций акций и облигаций». Проверка: для каждого бенчмарка H0: Шарп(МСП-A) ≤ Шарп(бенчмарка); парный бутстрап по общим дням (1 000 реплик, seed 42), p = доля Δ* ≤ 0; H3 по бенчмарку принимается при Δ > 0 и p < 0,05. Индексы — MCFTR и RGBITR (`data/mcftr_iss.csv`, `data/rgbitr_iss.csv`; совпадают с `data/iss_check/index_d/*.parquet` до 0), данные с 03.01.2022, поэтому H3 считается только на окнах 2022–2025 и 2022–2026. Расхождение с текстом: в тексте акции — IMOEX, в коде — MCFTR (полной доходности); оставлен MCFTR (С5, записать в текст).
