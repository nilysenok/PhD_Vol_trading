## Решения и допущения
- **Набор для MCS.** Финальная, HAR-J (а), HAR-J (б), лучшая одиночная бустинга. Лучшая одиночная зафиксирована заранее по разработочному набору (`2026-10-25_final_assembly.md`, таблица QLIKE: на всех h лучшая — LightGBM с поправкой): столбец `lgb_corr`. Оговорка: в файле это LightGBM-слот ноги финального дизайна (h=1 — top5, h=5 — обёртка, h=22 — seeds3), а не строго single; при h=1 совпадает с «top5/V0_LGB». Подмена — константа `BEST` в `ftp_tables.py`.
- **MCS.** Ряд — дневная средняя по 17 тикерам потерь QLIKE. Бутстрап скользящими блоками (циклически), длина блока max(10, h), B = 10 000, seed 0. Считаются обе статистики, T_R и T_max; в таблице p_MCS (с накоплением максимума по шагам) и признак членства при α = 0,10 и 0,25.
- **Охват.** Ошибки A и B; d = e_A(e_A − e_B), дневная средняя по тикерам, NW лаг h−1, поправка HLN, t(n−1). H0: A охватывает B; H1 односторонняя (B добавляет информацию). Обе стороны финальная ↔ HAR-J (б), в уровнях RV и в ln RV. λ — вес второго прогноза в оптимальной линейной комбинации.
- **Минцер–Зарновиц.** y = α + βp, МНК на пуле (дата, тикер); HAC типа Дрисколла–Крея: скоры суммируются по тикерам внутри дня, NW лаг h−1 по дням. Wald α = 0, β = 1 (χ², 2 ст. св.). Шкалы RV и ln RV, четыре модели.
- **Тикеры.** QLIKE финальной и HAR-J (б) по тикеру, DM на тикер (ряд по датам, NW лаг h−1, одностороннее p), «значимо лучше/хуже» при 5%. Итоговая строка «ДОЛЯ из 17».
- **Подпериоды.** 2017-2019, 2020-2021, 2022, 2023-2025: QLIKE четырёх моделей и основной DM против HAR-J (а) и (б).
- **Терцили.** Пороги на дату t — квантили 1/3 и 2/3 RV_m по всем наблюдениям матрицы (17 тикеров, пул) с датой ≤ t; расширяющееся окно, будущее не используется (проверено на синтетике: правка RV_m после t не меняет терцили на датах ≤ t). Основной DM в терциле — по дневному ряду из тикеров, попавших в терциль, дни без наблюдений пропускаются (ряд не строго непрерывен, NW приближённый).
- **Формат CSV.** Как в существующих таблицах (разделитель-запятая, значения с запятой квотируются, p < 0,001 строкой «<0,001»), но с десятичной запятой по поручению владельца. Прежние таблицы 3.x в `final_test.py` остаются с точкой, как были.

## Что проверяет selftest
- равные прогнозы: DM = 0; независимые, равные по качеству: |t| < 3,5;
- MCS (обе статистики): равные по качеству остаются в наборе (p ≥ 0,10), заведомо худшая вылетает (p < 0,01), одинаковые прогнозы — обе в наборе с p = 1;
- MZ: несмещённый прогноз — β ≈ 1, Wald не отвергает; прогноз ×2 — β ≈ 0,5, Wald отвергает;
- охват: B = A + шум — A охватывает B (p > 0,05, λ ≈ 0), B не охватывает A (p < 0,001);
- терцили без заглядывания, доля низкого терциля ≈ 1/3;
- полный прогон `run` на синтетике: размеры всех шести таблиц, чтение CSV с `decimal=','`, знаки DM в подпериодах и терцилях, доля тикеров = 1, финальная в MCS, HAR-J (б) вне MCS.
