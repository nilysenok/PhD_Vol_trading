## 4. Статистический аудит (Ж-254 п. 13; `S_STAT_AUDIT.md`)
- **N = 846** — счётчик конфигураций программы, не число гипотез одного семейства. Холм с N — граница «лучший из N». Прежние поправки не менялись. Для этапа добавлены семейство «кандидаты × базы» (m = 8–12) и studentized SPA/StepM.
- **DM/HAC** реализован верно, лаг NW-8 для этапа. Бутстрап стационарный, B = 10 000. MCS — низкая мощность, а не эквивалентность.
- **«≈ 3 000 дней»** верно только как n для мощности 0,8 при эффекте −1 % (W5-G − X1, окно без 2022). При эффектах −0,2…−0,4 % нужно 10–40 тыс. пар.
  - Это ограничение мощности, а не доказательство невозможности улучшения.
  - Для S-RCK к W5-G (σ_LR и n — в `S_R_POWER.csv`) подтверждение с поправкой на поиск недостижимо на истории.

## 7. История условия концентрации У6 (Ж-255)

1. **W8 (15:15).** У6 = p по 19 сдвигам ряда IMOEX ≤ 0,10 — условие W8-G. Не менялось. W8-G его не прошёл (p 0,15).
2. **Поручение дирижёра S-R (18:35).** Пример условия: «доля выигрыша от 1 % лучших пар ≤ 0,5». Число взято из рекомендации S-C-WHY, не зарегистрировано.
3. **Архитектор S-R (18:35–18:49).** Откалибровал условие на сохранённых рядах **всей истории проекта**: K2/K1, B_mix/K1, X1/K2, X1/K3, X1/B_mix, W5-G/X1, W8-G/W5-G, S-A2, S-CK — `S_R_SPEC.md` разд. 4.3, `s_r_calib/conc.csv`.
   - Доля ≥ 1,0 у всех улучшений проекта, поэтому «≤ 0,5» отвергло бы любого кандидата.
   - Заменено на **У6-R**: Δ_trim < 0, где Δ_trim — Δ после удаления 22 дат с наименьшей и 22 дат с наибольшей разностью дневных потерь d_t = ℓ(кандидат) − ℓ(база).
   - Форма выбрана, когда было видно, что она пропускает широкие улучшения (K2/K1, X1/бустинги) и отвергает концентрированные (W5-G/X1, W8-G, S-A2).
4. **Дирижёр (18:50)** принял замену до регистрации S-R (19:00:24) и до любого прогноза R.

**Итог.** У6-R — условие, выбранное до счёта S-R, но **после просмотра истории проекта**; его нельзя считать предрегистрированным в строгом смысле. Даты, исключаемые срезом, выбираются **по исходу**, то есть по реализованной разности потерь кандидата и базы. Поэтому срез — диагностика устойчивости, а не основная оценка.
