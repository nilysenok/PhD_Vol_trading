### 1.2 Дневной ряд (`models_v2/daily.py::build_daily`)
- **Бары:** основная сессия, начало бара 10:00…18:40 (`main_session`).
- **Доходности** (`intraday_returns`): r₁ = ln(close₁/open₁), r_j = ln(close_j/close_{j−1}). Ночной гэп не входит.
- **RV_s** = Σ_j r²_{s,j} · 10⁴ (%²). BV_s = (π/2)·Σ_j |r_j||r_{j−1}| · 10⁴ (внутри дня). J_s = max(RV_s − BV_s, 0).
- **Исключаются дни:**
  - баров < 30;
  - с 01.03.2025 — дни без сессии IMOEX и выходные;
  - остановка 28.02–24.03.2022;
  - RV ≤ 0.
- **Сегменты:** seg = 0 до 24.03.2022, 1 после. Окна через разрыв не склеиваются.
- **Окна** (`add_windows`):
  - RV_w = среднее **уровней** RV за 5 последних годных дней сегмента, **включая d**;
  - RV_m — то же за 22 дня.
  - Окна **перекрывающиеся** (вложенные: 1 ⊂ 5 ⊂ 22), по строкам ряда, а не по календарным дням.

### 1.3 Модель (`models_v2/har.py`, `hp_har.py`)
- **Регрессия:** ln RV_{t⁺} = b0 + b_d·ln RV_d + b_w·ln RV_w + b_m·ln RV_m + b_J·ln(1 + J_d). **Логарифмы окон уровней**, а не средние логарифмов.
- **Оценка:** МНК с константой, s² = SSR/(n − k).
- **Прогноз:** σ̂² = exp(f + s²/2) (колонка `sigma2`; `sigma2_a` = exp(f)).
- **Обучающие пары:** (t, t+1) внутри одного сегмента, t+1 ≤ d, все признаки конечны (`har.pairs`). Окно расширяющееся от начала ряда (2014-06-02). **Переоценка каждый день.**
- **t⁺** — следующая строка собственного ряда.
- **Сетка прогнозов** (`hp_har.grid`): цель ≥ 2017-01-03, пар ≥ 252. Включает строку через разрыв 2022: пара (последний день seg 0, первый день seg 1) прогнозируется, в обучение не входит.

## 2. Параметризация

### 2.1 Лаговая память a[k,l] — смесь прямоугольника HAR и гладкого ядра

a[k,·] = (1 − ω_k)·R_k + ω_k·G_k(·; ψ_k), где k ∈ {s, m, l}:
- R_s = δ₀; R_m = 1/5 на l = 0…4; R_l = 1/22 на l = 0…21 — прямоугольники K1;
- G_k(l) = exp(ψ_k1·x_l + ψ_k2·x_l²) / Σ_{l'} exp(ψ_k1·x_{l'} + ψ_k2·x_{l'}²), x_l = l/(L_k − 1), l = 0…L_k − 1;
- носители: L_s = 5, L_m = 22, L_l = 66.

Это дискретное «экспоненциальное ядро Альмона» (MIDAS).

**Свойства:**
- a ≥ 0 и Σ_l a = 1 при любых параметрах — выпуклая комбинация двух точек симплекса;
- ω = 0 ⇒ a = HAR **точно**;
- ω_k ∈ [0, 1] (границы L-BFGS-B), ψ ∈ [−8, 8].

**Усечение.** Если в сегменте до t доступно L′ < L_k строк, G_k нормируется по l < L′. Для R_k на датах D_M и на обучающих парах K1 усечения нет: K1 определён только при ≥ 22 строках.

**Параметры a:** 3 × (ω + ψ₁ + ψ₂) = **9**.

### 2.2 Внутридневная функция b[k,j] — гладкая функция доли времени сессии
- **Координата бара** — календарная, не номер бара: τ_j = (минута начала бара − 600)/520 ∈ [0, 1]; 10:00 → 0, 18:40 → 1. Так смена расписания (52 бара до 2015, пропуски) не переносит вес на другое время (S-LIT разд. 2).
- **Форма:** h_k(τ) = Σ_{m=1}^{4} c_km·N_m(τ).
  - N_1…N_4 — натуральный кубический сплайн с узлами τ ∈ {0; 0,25; 0,5; 0,75; 1} (≈ 10:00, 12:10, 14:20, 16:30, 18:40), без константы (5 функций базиса минус константа).
  - Базис центрирован по сетке 53 слотов (`np.arange(53)/52`) — фиксированная константа кода, не данные.
- **Нормировка по фактическим барам сессии:** b_k(s, j) = exp(h_k(τ_j)) / mean_{j′ ∈ present(s)} exp(h_k(τ_j′)).
  - b > 0; mean_j b = 1 по присутствующим барам каждой сессии s.
  - Пропущенный бар выпадает из суммы и из нормировки.
  - Сессия из 41–52 баров нормируется по своим барам.
  - Статистик по выборке нет — нормировка PIT по построению.
- **Агрегат:** RV_b[k](s) = 10⁴·Σ_{j ∈ present(s)} b_k(s, j)·r²_{s,j}.
  - c = 0 ⇒ b ≡ 1 ⇒ RV_b = RV побитно (умножение на 1.0).
  - Первый бар (r = ln(c/o)) и бар 18:40 входят как есть. Отдельных точечных эффектов концов сессии нет: это не гладкая часть. Если понадобится — отдельная абляция.
- **Параметры b:** 3 × 4 = **12**.

### 2.3 Память
- S[k,t] = Σ_l a[k,l]·RV_b[k](t − l), по строкам дневного ряда внутри сегмента t (как K1).
- J_t — архивный: без весов b, ln(1 + J_t). Компонента скачка не меняется.

### 2.4 Число параметров

| блок | A0 | A1 | A2 |
|---|---|---|---|
| δ HAR-части (разд. 3.1) | 5 | 5 | 5 |
| a (ω, ψ) | 0 | 9 | 9 |
| b (c) | 0 | 0 | 12 |
| g_internal (δw, δκ) | 2 | 2 | 2 |
| **всего обучаемых** | **7** | **16** | **28** |

Гиперпараметр λ — выбор из 3 значений помесячно (разд. 5). Слой доверия (α из 3 по состоянию) и β перерыва — как в X1 и W5-G, новых параметров не добавляют.

Обучающих пар на первой переоценке — ≈ 250 (2017), на последней — ≈ 2700.

## 3. H_internal и g_internal

### 3.1 H_internal — HAR-J на новой памяти, вложенный в K1
Для даты d (и для каждой обучающей пары j по её дате d_j):

ln H_A,d = ln K1_d + δ₀ + Σ_k (β^{K1}_{k,d} + δ_k)·ln S_k,d(a, b) − Σ_k β^{K1}_{k,d}·ln S_k,d(HAR, 1) + δ_J·ln(1 + J_d)

- β^{K1}_{k,d} = (b_d, b_w, b_m) строки d сохранённого K1 — PIT: МНК по парам t⁺ ≤ d.
- K1 переоценивается ежедневно, A — помесячно. Поэтому H_A задан как отклонение от K1 дня d, а не как свой МНК. Иначе стартовая точка не совпала бы с K1 внутри месяца.
- **Вложение:** δ = 0, a = HAR, b = 1 ⇒ H_A ≡ K1 на каждой дате, до 1e-12.
- **Стягивание к HAR** — штраф λ·‖δ‖².

### 3.2 g_internal — корректор (выбор: дифференцируемый, со стягиванием к нулю)
C_A,d = H_A,d · exp((w⁸_d + δw)·ℓ_A,d + (1 + δκ)·m_d), ℓ_A,d = ln(B_mix,d / H_A,d):
- w⁸_d — колонка `w` сохранённого cfg8 (помесячная PIT-оценка V7);
- m_d = G_d − w⁸_d·ℓ_d — MoE-часть cfg8. Проверено: F = H·e^G точно, H ≡ K1, ℓ = ln(B_mix/H) точно (`s_a/cfg8_decomp.py`). То же определение, что D_G в W9 (`W9_EXHAUSTION.md`, Д-1);
- **вложение:** δw = δκ = 0 при H_A = K1 ⇒ C_A ≡ cfg8 побитно по формуле, до 1e-12.

**Почему так.**
1. Сохраняется существующий корректор X1: якорь на B_mix и MoE по z энкодера. W9: вне 2018 полезна именно MoE-часть, в 2018 — HAR-часть.
2. m_j каждой обучающей пары — сохранённый **вневыборочный** выход cfg8 на дату d_j: месячная модель обучена на парах t⁺ ≤ начала месяца. Метауровень не учится на внутривыборочных прогнозах нижнего уровня (Ж-254 п. 6).
3. Корректор дифференцируем: совместная оптимизация с a, b, δ по одной QLIKE допустима (Ж-254 п. 6).
4. MoE не переобучается — не повтор «старого MoE» и не residual boosting.

**Пары без cfg8** (t⁺ 2017-01-03…2018-01-03; cfg8 начинается с d = 2018-01-03):
- корректор не определён, g := 0 по определению;
- в функцию потерь такие пары входят как QLIKE(RV, H_A) — тот же объектив при g = 0.

**Ограничения:** w⁸ + δw ∈ [0, 1], δκ ∈ [−1, 1].

**Включение корректора:** δw, δκ обучаются, только если в закрытом пуле ≥ 120 пар с cfg8 (ожидаемо с 2018-07-02, как Y и ZB). Иначе δw = δκ = 0.

### 3.3 Функция потерь и инициализация
L(θ) = (1/|P|)·Σ_{j∈P} ℓ(RV_j, F_j) + λ·(‖δ‖² + Σ_k ω_k² + Σ_k ‖c_k‖² + δw² + δκ²) + 10⁻⁴·Σ_k ‖ψ_k‖²
- ℓ(RV, F) = RV/F − ln(RV/F) − 1;
- F_j = C_A,j для пар с cfg8, иначе H_A,j.

**Нулевая инициализация** = контроль: δ = 0, ω = 0, ψ = 0, c = 0, δw = δκ = 0.
- Градиенты по δ, ω, c, δw, δκ в этой точке в общем случае ненулевые. Ограничение ω ≥ 0 — граница, а не насыщение: L-BFGS-B выходит внутрь, если ∂L/∂ω < 0.
- Градиент по ψ при ω = 0 равен нулю. ψ получает градиент, как только ω > 0. Это записано: блокируются не все градиенты (Ж-254 п. 6).

**Оптимизатор:** scipy L-BFGS-B, градиенты — torch autograd float64, maxiter 500, ftol 1e-10. Новых библиотек нет (torch и scipy есть в среде V7).

**Seeds 0–4:**
- seed 0 — точная нулевая инициализация;
- seeds 1–4 — она же плюс N(0; 0,05²) на ω (затем clip в [0, 1]), ψ, c;
- итог — F = exp(среднее по seeds ln F_s), как Y3 и cfg8.

**Синтетический тест «выход из начального состояния» (Ж-254 п. 6), обязателен в S-A-IMPL:**
- **(а) Известный сигнал.** 1500 сессий × 53 бара. r² = σ²_s·u_j·ε², u_j — U-профиль. Истинная модель: ln RV_{t+1} = c + 0,4·ln S_s(a*, b*) + 0,3·ln S_m + 0,2·ln S_l + шум; b*_s ∝ exp(1,5·τ²) (поздняя сессия), ω*_l = 0,6, ψ*_l = (−3, 0).
  - **Ожидание** из нулевой инициализации: ω_l > 0,2; ψ_l1 < 0; c_s даёт возрастающую b_s(τ) на [0,5; 1]; QLIKE обучающих пар ниже стартовой.
- **(б) Нулевой сигнал.** Данные порождены HAR с b* ≡ 1, a* = HAR. Ожидание: max ω < 0,05, max|c| < 0,1, |ΔQLIKE| к старту < 1e-3.
- Базу K1 для синтетики строит `models_v2/har.py` (МНК по синтетическому ряду, ежедневно).

### 3.4 Связь с X1 и W5-G — что сохраняется
- **Гибрид A:**
  - X1_A = слой доверия X1 над (B_mix, C_A): `models_v2/s15/de_e1_state.py::run(rv, B_mix, C_A, s, d, t⁺)`, импорт без правок. s = e_d — колонка `s` x1.parquet. α по состоянию помесячно из {0,01; 0,02; 0,05}, fixed share по закрытым парам.
  - F_A = слой перерыва W5-G над X1_A: `models_v2/s16/x1_w5_gap.py::walk(d, t⁺, rv, base=X1_A, gap^PIT)`, оценщик `beta_gap`, без правок.
- **Вложение всего гибрида.** При нулевых параметрах C_A ≡ cfg8 ⇒ X1_A ≡ X1 ⇒ F_A ≡ W5-G (до 1e-12 на 2198 датах). Это технический гейт; строкой реестра он не является.
- **Что заменяется.** Только HAR-сторона внутри компоненты C (K1 → H_A) и два отклонения корректора. Архивный K1 не меняется и остаётся бенчмарком. H_A стянут к K1 дня d и сам по себе в таблицу сравнения как «модель» не входит, только диагностической строкой «внутренний компонент». Поэтому это не «новый самостоятельный HAR для подмены бенчмарка» (Ж-254 п. 5).
- **Выигрыш 2018.** Канал C в 2018 — HAR-направление (W3, W9). Он сохраняется: H_A стартует из K1, а штраф держит его рядом. У3-S (разд. 6.2) охраняет 2018 явно.
- **Слой доверия** не меняется по правилу, а пересчитывается над новым C_A. Новый C, которому доверяют больше или меньше, — часть эффекта; это и проверяется.
- **W8-G** — справочно: экспериментальная версия, база сравнения не она.

## 4. Варианты

| id | что обучается | a | b | роль |
|---|---|---|---|---|
| **S-A0** | δ (5), δw, δκ | HAR | 1 | стандартная память + существующий корректор, переоценённые под QLIKE тем же протоколом. Контроль (в) для a и b |
| **S-A1** | + ω, ψ | обучаемая | 1 | обучаемая междневная память |
| **S-A2** | + c | обучаемая | обучаемая, своя на k | совместная междневная и внутридневная структура — основная гипотеза |
| **S-A2p** | как A2 | обучаемая | τ_j заменено на τ_{π(j)}, π — фиксированная перестановка 53 слотов (`np.random.default_rng(0).permutation(53)`), одна на все дни | контроль (б): распределение весов сохраняется, привязка ко времени дня разрушена |

**Одинаковая информация:**
- у всех вариантов одни входы: бары M10 SBER (float64), J, K1 строки d, B_mix, cfg8 (w⁸, m), e_d, gap^PIT;
- одни пары, одни даты переоценки, один λ-выбор, одни seeds.

**Сложность:** число параметров (разд. 2.4); штраф и PIT-выбор λ. В отчёте — QLIKE и эффективное число параметров ‖θ‖₀.

**Не входят в пилот** (регистрируются со статусом «не запускается в пилоте», в N не считаются, пока не посчитаны):
- **S-A3** — условная по состоянию память: ω_k = ω_k⁰·σ(γᵀz_t), z_t = (ln RV_d − PIT-медиана, e_d) (Ж-254 п. 5: отдельная абляция);
- **S-A2s** — b одна на три памяти (класс V2 Z): отличает «глубино-зависимую» b от «одной TOD-нормировки»;
- **S-A2g** — бустинг-корректор с временным cross-fitting (Д-2).

Запуск любого из них — после S-A-EVAL, отдельной регистрацией.

**Порядок проверки (фиксирован до счёта):** A2 — основной кандидат. A1 рассматривается как кандидат «новой контрольной версии», только если A2 не прошёл правило разд. 6.4. A0 и A2p кандидатами не являются.

## 5. Временной протокол
- **Окно обучения — расширяющееся.** Пары j с K1 и закрытой целью: t⁺_j ≤ D. Первая пара — t⁺ 2017-01-03 (первая строка K1), как у cfg8 (`v7_1m_wf.FIRST_REFIT` 2017-01-01).

- **Почему помесячно, а не ежегодно.**
  - Даты те же, что у компоненты C и слоёв над ней. Тогда A0 против cfg8 различаются только параметрами, а не расписанием.
  - Вычислительно это доступно (разд. 9): 107 переоценок.
  - Ежегодная переоценка сократила бы расчёт в 12 раз, но смешала бы эффект памяти с эффектом расписания.
- **Включение:** θ_H (δ, a, b) — при ≥ 250 закрытых парах (с первой переоценки 2018-01-03); иначе стартовая точка. Корректор — разд. 3.2.
- **Валидация — только закрытые пары.** На каждой D:
  - валидация — последние 126 закрытых пар (t⁺ ≤ D), обучение — остальные закрытые;
  - λ ∈ {10⁻⁴; 10⁻³; 10⁻²} выбирается по QLIKE валидации, при равенстве — больший λ;
  - затем переобучение на всех закрытых парах с выбранным λ.
  - Ни одна пара с t⁺ > D не входит ни в обучение, ни в валидацию, ни в выбор λ.
- **PIT входов:**
  - S дня d — только бары сессий ≤ d с началом ≤ 18:40 (`Src.bars(·, cut)`);
  - b нормируется внутри сессии;
  - K1, cfg8, B_mix строки d — сохранённые PIT-ряды;
  - e_d и gap^PIT — сохранённые колонки X1 и W5.
- **Новый период** (t⁺ 2026-03-02…2026-11-10):
  - бары читаются через `models_v2/s17/fwd_src.Src` — замок открытия существует, ❓ его содержимое не читалось;
  - K1, cfg8, B_mix, x1 — из `data/fwd/models/new/`.

- **Год как переключатель не используется.** Параметры одни на месяц для всех дней.

Справочно (критериев не дают): против W8-G (экспериментальная версия), K2, K3, B_mix, K1, ZB.

### 6.3 Статистика — показывается, условием «новой контрольной версии» не является (по `S_STAT_AUDIT.md`)
- **DM.** Ньюи–Уэст, односторонний.
  - Основной лаг — правило NW-94: L = ⌈4·(n/100)^{2/9}⌉ = 8 при n = 2198; для подпериодов — по их n.
  - Лаг 5 — справочно, для сопоставимости с W1–W8.
- **Бутстрап.** Стационарный (Politis–Romano), средний блок 20, B = 10 000, seed 0: 90 % интервал Δ и p.
- **Холм с N программы.** N = 827 + 4 = **831**, N_wide = **3367** (разд. 7). Как в W5/W8: исправляются p этапа, остальные до N — единицы. Прежние опубликованные поправки не меняются.
- **Явное семейство этапа:** кандидаты {S-A0, S-A1, S-A2} × базы {X1, W5-G, K2, K3} = 12 гипотез; Холм с m = 12. Против X1 сравнивается X1_A, против остальных — F_A.
- **«Лучший из многих»** — основной вывод о совокупности кандидатов:
  - studentized SPA (Hansen 2005), бенчмарк W5-G для F_A и X1 для X1_A; кандидаты {A0, A1, A2};
  - StepM (Romano–Wolf 2005) — перечень превосходящих;
  - стационарный бутстрап, блок 20, B = 10 000, seed 0.
- **MCS 90 %** (T_max, реализация W1, с фильтром конечных и положительных) по {F_A0, F_A1, F_A2, W5-G, X1, W8-G, K2, K3, B_mix}.
- **«Подтверждено»** — только при p Холма (N программы) < 0,05 **и** p SPA < 0,05. Численное улучшение при больших p не называется превосходством. Отсутствие значимости не называется отсутствием выигрыша.
- **Мощность** — для каждого основного сравнения (М1, М2 по A2 и A1):
  - σ_LR разности потерь (NW-8);
  - наблюдаемый эффект;
  - n для мощности 0,5 и 0,8 при α = 0,05 одностороннем: n = ((z_α + z_β)·σ_LR/|Δ_абс|)²;
  - то же без 2022.
  - Недостаточная мощность не превращается в довод «улучшение невозможно».
- **До S-STAT** взято бы: DM NW-5, блочный бутстрап B 2000, MCS W1, Холм N программы. После аудита применяются пункты выше, прежние — справочно.

### 6.4 Концентрация — диагностика, не условие (кроме У5-S)
Для каждого кандидата против X1 (М1) и W5-G (М2):
- вклады лет c_y = Σ(l_X − l_base)/(n·Q_base), Σ c_y = Δ (1e-12);
- доля выигрыша от лучшего года и от двух лучших;
- Δ без каждого периода;
- Δ без t⁺ = 2022-02-24;
- Δ без самого влиятельного дня — max |l_X − l_base|;
- Δ без самого влиятельного года;
- доля дисперсии разности от крупнейшего дня: (d_(1) − d̄)²/Σ(d_t − d̄)².

Срезы — диагностика, не новая выборка. Основная оценка — по всем 2198 датам.

### 6.5 Правило «новая контрольная версия»
Кандидат (A2, затем A1 по порядку разд. 4) становится **новой контрольной версией**, если выполнены (М1), (М2) и У1-S…У5-S.
- Значимость не требуется. X1 и W5-G остаются контрольными версиями в любом исходе. W8-G — экспериментальная.
- Если правило не выполнено: «не прошёл (М…/У…)» с числом.

В отчёте раздельно:
1. техническая корректность (гейты IMPL);
2. численное улучшение;
3. прохождение ограничений;
4. статистическая подтверждённость;
5. независимое подтверждение — только на данных после 10.11.2026 на замороженном коде, по процедуре Л5–Л6.

**Ответ «что улучшило прогноз»** (Ж-254 п. 16):
- A1 − A0 — структура памяти;
- A2 − A1 — внутридневное представление;
- A2 − A2p — привязка ко времени дня;
- A0 − X1 (М1-уровень) — переоценка корректора и HAR-части без новой структуры, то есть «только дополнительная гибкость»;
- плюс эффективное число параметров.

## 9. Вычислительный план (Мак, CPU, без платных ресурсов)
- **Данные:** ≈ 3124 сессии × 53 бара. S для всех k — свёртка по ≤ 66 лагам. Одна оценка функции потерь с градиентом (torch, float64, ≈ 2700 пар) — порядка 1–5 мс; замерить в I2.
- **На одну переоценку и вариант:** 3 λ (обучение без валидации) + 1 финальная подгонка = 4 подгонки × 5 seeds = 20 запусков L-BFGS-B по ≤ 500 итераций ⇒ ≈ 10–50 с.
- **Всего:** 107 переоценок × (A1, A2, A2p ≈ 3 × 30 с + A0 ≈ 5 с) ≈ 2,8 CPU-ч в худшем случае; при 2 процессах — ≈ 1,5 ч стенных.
- **Слои X1 и W5** — секунды на вариант (3 прохода α + боевой).
- **Оценка:** SPA / StepM / бутстрап B = 10 000 × 2198 × ≤ 9 рядов — минуты.
- **Итого:** ≤ 4 CPU-ч, ≤ 3 ч стенных при лимите 2 процессов. Перед счётом — `df -h` (правило диска Ж-147: ≥ 40 ГБ). Выходы < 50 МБ.
- **Стоп по замеру:** если I2 покажет > 20 мс на оценку, кодер докладывает до прохода. Варианты: сократить seeds до 3 (отступление с записью) или maxiter. Протокол и сетка не меняются.
