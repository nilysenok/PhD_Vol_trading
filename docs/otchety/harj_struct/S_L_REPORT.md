## 3. L3 — почему память не добавляет

Выигрыш на основной массе пар идёт от совместной настройки памяти с уровнем и корректором; доли не аддитивны.

## 4. Решение по таблице 7.2 (выводится кодом из `S_D_ELEMENTS.csv` и `S_L_DIAG.csv`)

| строка | условие | значения | выполняется | следствие |
|---|---|---|---|---|
| 1 | (i) необходим или «хуже без него» и L2: π не объясняется v₁, v₂ | (i) = worse_noise; L2 чтение О-5: v₁ → 1, v₂ → 1 (1 = не объясняется) | **да** | S-RL1 — сдвиг уровня C одним параметром, процедура R на уровне F |
| 2 | (i) необходим и L2: π ≈ режим v₁ (или v₂) | (i) = worse_noise; v₁ → 1, v₂ → 1 (2 = π ≈ режим) | **нет** | S-RLv |
| 3 | (i) не обнаружен | (i) = worse_noise | **нет** | S-RL1 с потерей уровня C |
| 4 | (iii) вредит | (iii) = not_found | **нет** | m := 1 в преемнике |
| 5 | L3: у памяти A2 нет выигрыша на 99 % пар в ≥ 80 % месяцев | старый S-A2, полное θ, уровень C (О-8): 0.689 | **нет** | линия обучаемой памяти закрывается |

**Как читать исход (i) = «worse_noise».** В разд. 5 четыре вердикта; «вклад элемента не обнаружен» — только при Δ ≤ 0. У (i) Δ = +0.1504 %, 90 % интервал [-0.0333; +0.3412], вердикт «без элемента хуже на +0.1504 %; вклад от шума не отделён».
- Строка 1 таблицы 7.2 явно включает «или «хуже без него»»; строка 3 требует «(i) не обнаружен».
- По тексту разд. 5 и 7 исход читается как «хуже без него» → строка 1. Строка 2 требует строгого «необходим» и не выполняется.
- В чтении (i) двусмысленности нет.
- Альтернатива для дирижёра, если он сочтёт (i) «не обнаруженным»: строка 3 — S-RL1 с потерей уровня C, связь с π не регистрируется. Текст спецификации эту альтернативу не поддерживает.

**Где спецификация двусмысленна.** P-f2: значение 1.0414 при пороге 0.8931, итог «нет» (`S_D_PRED.csv`). По разд. 2.4 тогда «выбор разд. 7 идёт по ветке «механизм не подтверждён»», но в таблице 7.2 такой строки нет. Два чтения, выбор не делаю:
- **(А)** Ветка не меняет строку: разд. 2.4 прямо говорит, что невыполненное предсказание вердикт не меняет. S-RL1 и есть прямая проверка механизма H-Lπ с контролями (а), (б) — регистрировать S-RL1 (`S_L_SPEC.md`).
- **(Б)** «Механизм не подтверждён» блокирует доработку, основанную на этом механизме. S-RL1 (H-Lπ) не регистрируется до решения дирижёра; следующий шаг — без регистрации.
- **Строка 4 не выполняется:** (iii) = «not_found», поэтому m в преемнике — как в S-RCK.
- **Строка 5 при объявленном чтении О-8 (полное θ старого S-A2, уровень C) не выполняется:** 0.689 < 0.80. Линия обучаемой памяти по критерию 7.2 не закрывается.
  - Если под «памятью A2» понимать только параметры памяти (ω, ψ, c) при фиксированном θ, доля = 1.000 ≥ 0.80, и линия закрывалась бы. Это разложение, не абляция, и до счёта оно критерием не объявлялось. Выбор чтения — за дирижёром.
