# S-B-DIAG — критерий решения, объявлен до счёта диагностики (11.11.2026, 18:02:19 по `date`; ни одной цифры диагностики ещё нет)

Вопрос (б): есть ли априорное основание ждать пользы модуля B (качество измерения перераспределяет лаговые веса, Σa = 1), если A1 (обучаемая память без состояния) дала −0,014 % к A0.

Только готовые ряды, без новых обучений гибрида: `data/regen/harj_struct/A/{a0,a1,a2}.parquet` (F, θ по месяцам), бары SBER (`Src`, как `a_feat`), признаки q1–q8 кодом `models_v2/s13/v6_2_q.py` без правок. Окно — D_M, t⁺ 2018-01-04…2026-11-10, n = 2198.

## Сигналы
- Мера качества z сессии s (больше — хуже): (1) ln q5 = ln Σr⁴/(Σr²)² (относительная сэмплинговая дисперсия RV ≈ (2/3)·q5, BPQ); (2) u = среднее z(q3), z(|q6|), z(q1), z(q2) V6; нормировка компонент — по сессиям до 29.12.2017 (раньше D_M, PIT для всех дат D_M).
- **Направление B (лаговое)** — производная ln S_k по силе η в a_kl(η) ∝ a_kl·exp(−η·z_{t−l}) в точке η = 0: D_k,d = −(Σ_l a_kl z_{d−l} RV_{d−l} / S_k,d − Σ_l a_kl z_{d−l}), k = s, m, l; a — веса A1 (A2) месяца переоценки строки d, восстановленные из θ строки; RV — обычная (без b). Это первый порядок эффекта B из точки вложения варианта без B.
- **Обычный корректор с теми же q (K)**, класс V6 C3 / HARQ: z_d, z_d·s1, z_d·s2, z_d·s3, s1..s3 = ln RV_d, ln RV_w, ln RV_m − ln F базы.
- Оракул: g = c + γ'X, F' = F·e^g, минимум средней QLIKE на всех 2198 датах (в выборке — **потолок**, только для решения «нет основания»). G(X) = 100·(QLIKE(F·e^{c*}) − QLIKE(F·e^{c+γ'X}))/QLIKE(F), %. G(B|K) = прирост от добавления D_s, D_m, D_l к c + K.
- Нуль: те же столбцы B, циклически сдвинутые по датам на случайный сдвиг 60…2138 строк (500 сдвигов, seed 0; K и F не сдвигаются). p = (1 + #{G_нуль ≥ G})/501. Избыток E = G(B|K) − медиана G_нуль.

## Решение
Основание есть, если хотя бы для одной из 4 гипотез {база A1, A2} × {z = ln q5, u} одновременно:
1. E ≥ 0,10 % QLIKE базы (мягкая планка: в выборке, до сжатия; реальный выигрыш B вне обучения меньше оракула);
2. p Холма (m = 4) < 0,05;
3. G(B|K) без t⁺ = 2022-02-24 (оракул переоценён на 2197 датах) − медиана нуля ≥ 0,10 %.

Иначе — «основания нет», B не расходуется (Ж-254 п. 7), записывается «не запускалось, основание не найдено», а не «проверено отрицательно». Основная база решения — A1 (поручение); A2 — вторая база той же семьи.
