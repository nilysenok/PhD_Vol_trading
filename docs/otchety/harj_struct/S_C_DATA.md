## 2. PIT-фактор
1 и 2 главные компоненты корреляционной матрицы доходностей 16 бумаг. Нагрузки, σ_i и корреляции — только по барам окна 120 прошлых сессий (s−120…s−1; сессия s не входит, `c_factor.LAG = 1`). Выбор 120: ~6300 баров, ошибка выборочной корреляции ~1/√n ≈ 0,013; 60 сессий дают вдвое больший шум в PC2. Не менее 60 прошлых сессий (иначе нагрузок нет). Бумага входит, если у неё ≥ 50 % баров окна; σ и корреляции — по парно присутствующим барам; фактор бара — МНК z_i ≈ Σ_j f_j W_ij по присутствующим бумагам (≥ 8) с проверкой обусловленности. Пропуски не заполняются. Знак/порядок PC между сессиями произвольны, значим только линейный подпространство сессии. Окно выбрано до счёта и не подбиралось по результату.

## 3. Разложение
На покрытых барах (есть фактор): r = P r + (I−P) r, P — МНК без свободного члена в этой сессии. rv_common = ‖P r‖², rv_specific = ‖(I−P) r‖², rv_uncovered = Σ r² баров без фактора (сессия с < 10 покрытых баров целиком в uncovered). Коэффициенты проекции сессии s известны только после её конца — это метка для t⁺, не признак.

Тождество rv_common + rv_specific + rv_uncovered = RV целевого определения: **макс. абсолютная невязка 1,364e-12 %² (k = 1, 2022-02-24, RV = 3519,6 %²), относительная ≤ 1,9e-15 на каждой сессии** (k = 2: абс. 4,5e-13). Абсолютный допуск 1e-12 на дне RV = 3520 %² превышен на 1,4e-12 — это машинная точность суммы больших чисел, относительная невязка 1e-15; тесты проверяют относительную < 1e-13. Перекрёстный член 2⟨Pr, r−Pr⟩ в сессии: |cross| ≤ 1,2e-12 %² (относительно RV ≤ 2e-15) — ортогональность подтверждена.

Вариант «PIT-нагрузки» (коэффициент проекции b оценён по тем же нагрузкам и фактору, но по SBER только прошлых 120 сессий, в сессии s не пересчитывается): перекрёстный член не исчезает.
- k = 2: Σ cross_pit / Σ RV = +0,029 (знаковая сумма; 55 % сессий — отрицательный), Σ|cross_pit| / Σ RV = 0,21, медиана |cross|/RV = 0,15, 90-й процентиль 0,57, максимум по сессии |cross| = 776 %². k = 1: +0,032, 0,22, 0,15, 0,56. Тождество с учётом cross_pit сходится (отн. ≤ 1,3e-15). Точное равенство common + specific = RV для этого варианта не утверждается и не выполняется.
- Доля common PIT (k = 2) 0,400 против 0,488 «внутрисессионной»: разница 0,088 включает механическую подгонку МНК по ~53 барам (ожидаемо k/n ≈ 3,8 %) и дрейф β. Внутрисессионная доля — верхняя оценка, PIT-доля — честная нижняя для информации «прошлого».

## 6. Решения по синхронизации (кратко)
1) Сетка — только канонические сессии и бары SBER, RV не сокращается до совпадающих баров (Ж-254 п. 8): непокрытые бары — `rv_uncovered`. 2) Бары бумаг приводятся к интервалам баров SBER; пропуск — NaN без заполнения. 3) Фактор — МНК по присутствующим бумагам (не среднее с ffill). 4) Нагрузки только по прошлому окну 120 сессий, LAG = 1; текущая сессия не входит. 5) IMOEX в фактор не входит (его бары — доп. покрытие, потенциальный вход листа S-C-MODEL).

## 7. Что проверено тестами (`tests/test_s18_c_*.py`)
Тождество на синтетике и 60 реальных сессиях (k = 1, 2); известный ответ для P (cross = 0); бар выброшен → тождество рушится (синтетика и реальная сессия); пустая лента и частично непокрытые бары; нагрузки не меняются при порче будущих баров (побитово); усечение реального ряда датой cut не меняет строку сессии (PIT на реальных данных); мутации: окно с текущей сессией (`LAG = 0`), SBER в факторе, бар следующей сессии в сессии s; записанные выходы — тождество на всех 3124 сессиях; `--check` не меняет хэш каталога, мутация «`--check` пишет файл» ловится.
