### 1.3 Память компонент (вход дня d)
Для X ∈ {c, p}:
- X_d, X_w (среднее уровней за 5 строк сегмента, включая d), X_m (за 22 строки) — тем же кодом, что у K1 и K7: `models_v2/s9/hv2_dec.wmean`, сегменты `daily.build_daily`. Окна через разрыв 2022 не склеиваются.
- Ряд компонент начинается с первой покрытой сессии 2014-08-27. Раньше — NaN, а не 0: в эти сессии вся RV лежит в u.
- **Ĥ_X,d** — HAR-J компоненты X: ln X_{t+1} = b0 + b_d·ln X_d + b_w·ln X_w + b_m·ln X_m + b_J·ln(1 + J_d), J — скачок SBER.
  - МНК по парам t + 1 ≤ d одного сегмента, ежедневная переоценка, ≥ 252 пар, σ̂² = exp(f + s²/2).
  - Код — `models_v2/s10/hp_ctrl.harj_at` над `H.make_panel`, без правок; так в K7 построен Ĥ(u).
- **Доли**: ŝ_X,d = X_m,d / RV_m,d для X ∈ {c, p, u}, RV_m = c_m + p_m + u_m. Параметров нет, сумма ≈ 1.

### 1.4 Встраивание в гибрид — канал C, слои X1 и W5-G сохраняются
Для всех вариантов:

  **C_V,d = cfg8_d · 𝓜_V,d**,  X1_V = `de_e1_state.run(rv, B_mix, C_V, s, d, t⁺)`,  F_V = `x1_w5_gap.walk(d, t⁺, rv, base = X1_V, gap^PIT)`.

- Канал доверия и поправка после перерыва пересчитываются тем же кодом, без правок, над новым C_V.
- Корректор cfg8 (якорь w⁸ на B_mix и MoE-часть m) не переобучается и не меняется. Поэтому это не повтор старого MoE и не residual boosting.
- Прогнозы X1_d и W5-G_d дня d — внешние слои этой цепочки. Отдельными признаками 𝓜 они не входят: это функции B_mix, cfg8, π и gap, которые цепочка уже использует.
- **Вложение.** Нулевые параметры ⇒ 𝓜 ≡ 1.0 ⇒ C_V ≡ cfg8 побитно. 𝓜 вычисляется в форме 1 + Σ ŝ·expm1(η), а expm1(0) = 0 точно. Тогда X1_V = X1, F_V = W5-G — побитно, если повторный проход слоёв по (B_mix, cfg8) воспроизводит сохранённые x1 и w5g побитно. Иначе — с объявленным допуском 10⁻¹² отн. и печатью максимума; выше допуска — стоп и разбор (гейт I3.G2).
- **Общий уровень меняется.** 𝓜 ≠ 1, как только η ≠ 0. Фиксированный cfg8 не распределяется по долям: сумма компонент равна cfg8 только в нулевой точке (Ж-254 п. 9). В отчёте обязательно распределение ln 𝓜 на D_M.
- Основная потеря — QLIKE суммы C_V против прежней RV SBER: ℓ(RV, F) = RV/F − ln(RV/F) − 1, цель RV_{t⁺} целевого определения.

### 1.5 Компонентный прогноз (C-K, C-KA, C-KL, C-7)
Для X ∈ {c, p}:
- **якорь** A_X,d = ŝ_X,d·cfg8_d;
- **η_X,d = γ_X·ln(Ĥ_X,d / A_X,d) + θ_X0 + θ_X1·ln(X_d / X_m)**;
- **F_X,d = A_X,d·exp(η_X,d)** ≥ 0; **F_u,d = ŝ_u,d·cfg8_d**;
- **𝓜_K = 1 + ŝ_c·expm1(η_c) + ŝ_p·expm1(η_p)**, C_K = cfg8·𝓜_K;
- тождество Σ F_X + F_u = C_K — гейт ≤ 10⁻¹³ отн.

Смысл параметров:
- γ_X ∈ [0, 1] — сколько компонента верит своей HAR-памяти, а сколько доле cfg8.
- θ_X1 — обучаемое под QLIKE суммы затухание недавнего шока компоненты.
- θ_X0 — уровень компоненты относительно её доли.

Точки вложения:
- γ = θ = 0 ⇒ cfg8 (W5-G после слоёв);
- γ = 1, θ = 0 ⇒ F = Ĥ_c + Ĥ_p + ŝ_u·cfg8 — K7-класс с фактором этапа (контроль S-C7).

**Чем это структурно отличается от прямой коррекции.** В первом порядке d ln 𝓜_K / dη_X = ŝ_X,d. Влияние памяти компоненты на прогноз пропорционально её текущей доле, а части складываются в уровнях, а не перемножаются. Именно эта гипотеза проверяется сравнением C-K против C-D.

- **Пары обучения** — строки D_M (у них есть cfg8, B_mix, e_d, gap). Пул месяца D: `x1_z_walk.closed_pool(t⁺, d, D)`, т. е. t⁺ ≤ D. Расширяющееся окно.

- **Валидация и λ.** На каждой D: последние 126 закрытых пар — валидация, остальные закрытые — обучение.
  - λ ∈ {10⁻⁴; 10⁻³; 10⁻²} — по QLIKE суммы на валидации (у C-KA — тоже по QLIKE суммы); при равенстве — больший λ.
  - Затем переобучение на всех закрытых парах.
  - Пока закрытых пар < 252 (на включении их 124; 252 набирается к началу 2019), валидации нет: λ = 10⁻², максимальное стягивание к cfg8.
  - Ни одна пара с t⁺ > D не входит ни в обучение, ни в валидацию, ни в выбор λ.
- **Функция потерь:** L = mean_{j∈P} ℓ(RV_j, C_V,j) [+ μ-член у C-KA] + λ·‖θ‖². Штрафуются все 6 параметров, к нулю, то есть к cfg8.
- **Оптимизатор:** scipy L-BFGS-B, градиенты — torch autograd float64, maxiter 500, ftol 10⁻¹⁰. Новых библиотек нет.
- **Перезапуски, seeds 0–4.** Seed 0 — точный ноль. Seeds 1–4 — ноль + N(0; 0,05²), γ и ρ обрезаются в [0, 1]. Итог — перезапуск с минимумом штрафованной L; при равенстве — меньший seed (Д-2).
- **Градиенты в нуле.** ∂L/∂γ_X ∝ Σ_j ŝ_X·ln(Ĥ_X/A_X)·(1 − RV/C) и ∂L/∂θ в общем случае ненулевые. γ = 0 — граница, а не насыщение: L-BFGS-B уходит внутрь при отрицательной производной. Ни один градиент не заблокирован (Ж-254 п. 6).
- **PIT входов.**
  - c, p, u сессий ≤ d — из `C_sessions.parquet` (sha сверяется).
  - Ĥ_X,d — МНК по парам t + 1 ≤ d.
  - cfg8, B_mix, e_d, gap^PIT строки d — сохранённые PIT-ряды (входы `S_A_SPEC.md` разд. 8).
  - Новый период (t⁺ 2026-03-02…2026-11-10) уже покрыт `C_sessions.parquet`; ряды моделей — `data/fwd/models/new/`.
- **Вычислительный план** (Мак, CPU, лимит 2 процесса):
  - Ĥ: 2 компоненты × (реальное + сдвинутое разложение) × ≈ 3100 МНК ≤ 3100 × 5 — около минуты.
  - Обучение: ≈ 100 переоценок × 4 обучаемых варианта × (3 λ + 1) × 5 перезапусков = 8000 запусков L-BFGS-B по 6 параметрам и ≤ 2200 парам. При ≤ 2 мс на оценку с градиентом — ≤ 30 CPU-мин.
  - Слои — секунды. Бутстрап B = 10 000 — минуты.
  - Итого ≤ 1 CPU-ч. Перед счётом — `df -h` (Ж-147, ≥ 40 ГБ). Выходы < 20 МБ.
  - Стоп по замеру: > 5 мс на оценку — доклад до прохода. Протокол и сетка не меняются.

## 4. Критерии — объявлены до счёта, после результатов не меняются

### 4.1 Основной критерий — D_M
QLIKE — среднее дневных потерь на D_M (t⁺ 2018-01-04…2026-11-10, n = 2198). Δ — в % QLIKE базы. Простое среднее QLIKE разных периодов не используется.
- **(М1)** Δ(X1_V против X1) < 0 — тот же слой доверия над C_V и над cfg8.
- **(М2)** Δ(F_V против W5-G) < 0.
- Справочно, без критерия: против W8-G (экспериментальная версия, не победитель), K1, K2, K3, B_mix, ZB.
- Исходные значения — `S_A_SPEC.md` разд. 6.1 (`W8_TABLE.csv`, без перезапуска моделей).

### 4.2 Ключевое сравнение — структура (на уровне F, n = 2198)
- **(К1)** QLIKE(F_CK) < QLIKE(F_CD) — компонентная форма против прямой на той же информации и том же числе параметров;
- **(К2)** QLIKE(F_CK) < QLIKE(F_C7) — обучение внутри гибрида против K7-класса с тем же фактором;
- **(К3)** QLIKE(F_CK) < QLIKE(F_CKL) — привязка разложения ко времени.
- Вывод **«компонентная структура дала численный эффект»** — только при К1 ∧ К2 ∧ К3 (`S_NOVELTY.md` 3.3, условия (а) и (б)). Без К1 выигрыш C-K над W5-G записывается как эффект рыночных признаков, а не структуры.
- Абляция C-KA против C-K — показ: ценность дополнительной компонентной задачи.

### 4.4 Статистика — показывается; «новой контрольной версией» не управляет (по `S_STAT_AUDIT.md`, как `S_A_SPEC.md` 6.3)
- **DM.** Ньюи–Уэст, односторонний, основной лаг NW-94: L = 8 при n = 2198, для подпериодов — по их n. Лаг 5 — справочно.
- **Бутстрап.** Стационарный (Politis–Romano), средний блок 20, B = 10 000, seed 0: 90 % интервал Δ и p.
- **Холм с N программы** (разд. 6): исправляются p этапа, остальные до N — единицы. Прежние опубликованные поправки не меняются. NaN-p не превращается в 1: сначала фильтр конечных (`S_STAT_AUDIT.md` разд. 4).
- **Семейства этапа:**
  - кандидаты {S-CK, S-CKA} × базы {X1, W5-G, K2, K3} = 8 гипотез, Холм m = 8; против X1 — X1_V, против остальных — F_V;
  - структура {К1, К2, К3} для S-CK, Холм m = 3.
  - S-CD против баз — сырые p и Холм N программы, справочно.
- **«Лучший из многих»:** studentized SPA (Hansen 2005) и StepM (Romano–Wolf 2005) над {F_CK, F_CKA, F_CD}, бенчмарк W5-G; для уровня X1 — X1_V с бенчмарком X1. Стационарный бутстрап, блок 20, B = 10 000, seed 0.
- **MCS 90 %** (T_max, с фильтром конечных и положительных) по {F_CK, F_CKA, F_CD, F_C7, F_CKL, W5-G, X1, W8-G, K2, K3, B_mix}.
- **«Подтверждено»** — только при p Холма (N программы) < 0,05 **и** p SPA < 0,05. Отсутствие значимости не называется отсутствием выигрыша.
- **Мощность** для (М1), (М2), (К1) по S-CK:
  - σ_LR (NW-8), наблюдаемый эффект;
  - n для мощности 0,5 и 0,8 при α = 0,05 одностороннем: n = ((z_α + z_β)·σ_LR/|Δ_абс|)²;
  - то же без 2022.
  - Недостаточная мощность не превращается в «улучшение невозможно».

### 4.6 Решение — выводится кодом из таблиц
- **NEWCTRL.** Кандидаты по порядку S-CK → S-CKA. Первый, выполнивший (М1), (М2), У1-S, У2-S, У3-S, У4-C, У5-S, — «новая контрольная версия». Иначе — «не прошёл (М…/У…)» с числом.
  - S-CD, S-C7, S-CKL кандидатами не являются.
  - X1 и W5-G остаются контрольными версиями при любом исходе. W8-G — экспериментальная.
  - Значимость не требуется.
  - Выбор по минимуму QLIKE запрещён.
- **STRUCT.** «эффект структуры» = К1 ∧ К2 ∧ К3; «подтверждён» = STRUCT ∧ p Холма N программы (К1) < 0,05 ∧ p SPA < 0,05.
- Если S-CD численно лучше W5-G, а STRUCT не выполнен, отчёт пишет: «прямая коррекция на рыночных признаках, справочно, не кандидат; структура отличия не доказала». Продвижение S-CD — только новой регистрацией.

В отчёте раздельно (Ж-254 п. 12): техническая корректность; численное улучшение; ограничения; статистическая подтверждённость; независимое подтверждение — только на данных после 10.11.2026 на замороженном коде.

**Ответ «что улучшило»** (Ж-254 п. 16):
- C-K − C-D — разложение риска как структура;
- C-K − C-KL — привязка разложения ко времени;
- C-K − C-7 — обучение внутри гибрида против раздельных HAR;
- C-KA − C-K — дополнительная задача;
- C-D − W5-G — рыночные признаки без структуры, то есть «дополнительная гибкость».
