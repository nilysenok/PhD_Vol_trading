## 1. Причина

**Причина в постановке, не в реализации.** Обучение 𝓜 на среднем QLIKE по расширяющемуся пулу почти целиком определяется горсткой крайних недопрогнозов cfg8. Главный из них — пара t⁺ 2022-02-24: RV/cfg8 = 42,5, QLIKE пары = 37,8 при среднем 0,22 на D_M.
- Медиана по 100 месяцам: 1 % лучших пар даёт **233 %** выигрыша S-CK внутри выборки. У S-CD — 200 %, у S-CKA — 298 %, у S-CKL — 269 %.
- После февраля 2022 одна пара 2022-02-24 даёт 154 % выигрыша (медиана по 56 месяцам).
- На остальных 99 % обучающих пар найденные θ **хуже cfg8 уже внутри выборки, в 100 месяцах из 100**, у всех четырёх обучаемых вариантов. Средний проигрыш — +0,0054 QLIKE абс. у S-CK.
- Вне выборки «отклик на крайний день» не повторяется. δ = ln 𝓜 становится шумом: corr(δ, ln(RV/cfg8)) = −0,024, κ* = −0,35 (S-CK, активные). Этот шум стоит C-каналу +2,24 %; сдвиг уровня добавляет ещё +0,34 %.
- Слой доверия реагирует правильно: среднее π падает с 0,462 до 0,392. Этим он гасит около половины вреда. Итог F: +1,12 % к W5-G.

Штраф λ этого не останавливает. Наибольший λ = 10⁻² выбран в 72 месяцах из 100 (S-CK) и в 97 из 100 (S-CKA). При этом штраф составляет лишь 9 % (медиана) выигрыша внутри выборки. Варианта θ = 0 (cfg8) в выборе нет.

## 5. Согласованная постановка — основание для следующей зарегистрированной попытки

Это не правка результата C. Каждая строка — новая регистрация с N + 1.
1. **Цель на уровне F.** Потеря обучения — QLIKE пары по F_j = B_mix_j^(1−π_j)·(cfg8_j·𝓜_j)^(π_j)·exp(β_j·gap_j). Здесь π_j, β_j — сохранённые PIT-значения X1/W5-G дня d_j, известные на d_j. Так обучение видит то же, что оценка, и затухание через π. Само по себе это не лечит причину: C_V хуже уже на уровне C. Поэтому обязательны и пп. 2–3.
2. **Ограниченное влияние одной пары — только в обучении.** Отношение RV/F в потере обрезается PIT-квантилем 99 % закрытых пар (или используется Хьюбер-QLIKE с тем же порогом). Оценка остаётся прежним QLIKE.
3. **Выбор с нулём.**
   - Сетка: {θ = 0 (cfg8); 10⁻¹; 1; 10}.
   - Валидация: три последовательных блока по 126 закрытых пар (rolling origin), а не один.
   - θ ≠ 0, только если выигрыш отрицателен в среднем по блокам **и** без 1 % лучших пар валидации. Ничья — θ = 0.
4. **Объявленная диагностика до счёта:** доля выигрыша внутри выборки от 1 % лучших пар (у S-C — 2,3) и знак выигрыша на остальных 99 % (у S-C — хуже cfg8 в 100 мес. из 100). Порог: доля ≤ 0,5 и знак «лучше».

Решение о новой регистрации — за дирижёром и владельцем; это новая гипотеза, если сомнение — класс A. Умолчание: новых регистраций нет.
