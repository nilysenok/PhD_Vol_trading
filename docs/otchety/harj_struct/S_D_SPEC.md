## 1. Что разделяют две абляции

| элемент R (толкование Ж-256) | уже разделено (`S_D_EXPLAIN.md` разд. 3) | абляция |
|---|---|---|
| (i) уровень потери F вместо C | нет | **S-RCKf** = R с потерей уровня C |
| (ii) обрезка RV/F | только вместе с (iii): R − Rb = −0,083 % | (ii) без (iii) = S-RCKm против S-RCKb; (ii) + (iii) против (ii) = S-RCK против S-RCKm |
| (iii) поправка уровня m | нет | **S-RCKm** = R при m := 1 |
| (iv) блоки | R − Rc = +0,0125 % | — |
| (iv) θ = 0 | общий у всех рядов R; дни θ = 0 ≈ 0 | — (Д-3) |

**Почему нужна S-RCKf, хотя S-C-WHY нашёл вред уже на уровне C.** S-C-WHY объяснил вред старого S-CK крайними парами — и это лечится обрезкой, θ = 0 и блоками, то есть без уровня F. Но выигрыш S-RCK над W5-G устроен иначе (`S_D_EXPLAIN.md` разд. 1.6, 2.3):
- сам C почти не лучше cfg8: −0,08 %;
- выигрыш есть при замороженном π: −0,18 %;
- 89 % Δ даёт сдвиг уровня C, который на уровне C вреден (+0,09 %);
- балл уровня в θ = 0 на уровне C тождественно 0, на уровне F положителен во всех 75 месяцах.

Значит, есть альтернативное объяснение выигрыша: связь «уровень C × π», доступная только при потере уровня F. S-RCKf его проверяет. Без неё вывод «R помогла» нельзя разнести между «лечением крайних пар» и «связью со слоем доверия».

**Почему нужна S-RCKm.** При m := 1 у обрезки нет компенсации уровня. Балл уровня в θ = 0 становится mean π_j·(1 − min(x⁰_j, c)): к ковариационной части добавляется π̄·(1 − m) ≈ 0,43 × 0,028 ≈ 0,012 (`H_level_score`). Без m обрезка сама тянет C вниз. Абляция показывает, сколько выигрыша даёт именно m и не держится ли «сдвиг уровня» S-RCK на самой обрезке.

## 2. Формулы (всё прочее — как S-RCK, `S_R_SPEC.md` разд. 2)

Общее у S-RCK, S-RCKm, S-RCKf:
- архитектура C-K: C = cfg8·𝓜(θ), 6 параметров, границы, штраф λ‖θ‖²;
- сетка Λ = {0; 10⁻¹; 10⁻²; 10⁻³};
- три блока по 126 пар, правило 2 из 3, ничья — больший λ;
- включение — 630 закрытых пар (2020-08-03, 75 активных месяцев), пул t⁺ ≤ D;
- 5 перезапусков, итог — минимум потери;
- слои X1 и W5 над C пересчитываются прежним кодом;
- **валидация G_{λ,b}** = mean_{V_b}[ℓ(RV, F^fr(θ̂)) − ℓ(RV, W5-G)], F^fr = B_mix^(1−π)·C^π·e^{βg} с сохранёнными π, β·g.

### 2.1 S-RCKm — R без поправки уровня
На обучающем множестве T (T_b блока или пул P):
- x⁰_j = RV_j / W5-G_j, c_T = Q₀,₉₉(x⁰_T) — как в R;
- **m_T := 1**, κ_T = c_T;
- u_j = ln(RV_j / F^fr_j(θ));
- L = (1/|T|)·Σ ρ_{c_T}(u_j) + λ‖θ‖², где ρ_κ(u) = eᵘ − u − 1 при u ≤ ln κ и (κ − 1 − ln κ) + (κ − 1)(u − ln κ) иначе.

Отличие от S-RCK — только m. Отличие от S-RCKb — только обрезка (у Rb c = ∞, m = 1).

### 2.2 S-RCKf — R с потерей на уровне C
На обучающем множестве T:
- x^C_j = RV_j / cfg8_j, c^C_T = Q₀,₉₉(x^C_T), m^C_T = mean min(x^C_T, c^C_T);
- u_j = ln(RV_j / (m^C_T·C_j(θ))): π := 1, ln B := 0, β·g := 0 **только в потере обучения**;
- L = (1/|T|)·Σ ρ_{κ^C_T}(u_j) + λ‖θ‖², κ^C_T = c^C_T / m^C_T.

Валидация, выбор λ*, сетка, блоки, слои — как у S-RCK, на уровне F. Свойство: балл уровня в θ = 0 тождественно 0 (проверено на пулах S-RCK, max 2·10⁻¹⁶, `H_level_score`).

### 2.3 Вложение
θ = 0 (λ* = 0 во всех месяцах) ⇒ C = cfg8 побитно ⇒ X1 и W5-G над ним = сохранённые x1 и w5g (≤ 10⁻¹², как W.G2 `S_R_SPEC.md`) — у обеих абляций. До 2020-08-03 C = cfg8 побитно.

### 2.4 Предсказания механизма — объявлены до счёта
δ = ln(C/cfg8) на днях C ≠ cfg8. У S-RCK среднее −0,0313 (`E_C / S-RCK`).
- **P-m:** среднее δ у S-RCKm < −0,0313. Без m обрезка дополнительно тянет уровень вниз.
- **P-f:** \|среднее δ\| у S-RCKf < 0,0157 (половина S-RCK). На уровне C у сдвига уровня нет балла в θ = 0.
- **P-f2:** в разложении при фиксированных θ доля «только уровень» в Δ(F против W5-G) у S-RCKf меньше, чем у S-RCK (0,89).

Невыполненное предсказание вердикт разд. 5 не меняет. Но оно означает, что механизм `S_D_EXPLAIN.md` разд. 2.3 неполон, и выбор разд. 7 идёт по ветке «механизм не подтверждён».

## 5. Критерий интерпретации — объявлен до счёта

**Основная оценка:** обычная QLIKE на всех 2198 датах D_M, без обрезки.
- Δ_x = 100·(QLIKE(F_x) − QLIKE(F_RCK))/QLIKE(F_RCK), x ∈ {RCKm, RCKf}. База процентов — S-RCK.
- 90 % интервал — стационарный бутстрап, средний блок 20, B = 10 000, seed 0 (`a_eval_stat.stat_idx`, `boot_ci`).
- p DM NW-8 — справочно.

Вклад элемента = насколько хуже без него:

| исход | вердикт (выводится кодом из таблицы) |
|---|---|
| Δ_x > 0 и нижняя граница 90 % > 0 | «элемент необходим для выигрыша S-RCK; без него хуже на Δ_x» |
| Δ_x > 0, интервал содержит 0 | «без элемента хуже на Δ_x; вклад от шума не отделён» |
| Δ_x ≤ 0, интервал содержит 0 | «вклад элемента не обнаружен» |
| Δ_x < 0 и верхняя граница < 0 | «элемент вредит: без него лучше». Ряд кандидатом не становится, только новой регистрацией |

Элементы: S-RCKm → (iii) поправка m; S-RCKf → (i) уровень потери F. Дополнительно, без вердикта:
- (ii) обрезка без m = S-RCKm против S-RCKb, тот же формат, база — S-RCKb;
- Δ к W5-G (F) и к X1 (слой X1 над C), база — W5-G и X1;
- разложение «замороженный π + реакция слоя»;
- разложение при фиксированных θ («только уровень / память / затухание», как `S_D_EXPLAIN.md` разд. 1.6);
- среднее δ и предсказания P-m, P-f, P-f2 («выполнено / нет»);
- месяцы θ = 0 и λ*;
- срезы «без t⁺ 2022-02-24» и «без 2022». Контроль — S-RCK, база — QLIKE S-RCK на оставшихся 2197 и 1991 датах. Это одни и те же исключённые даты во всех сравнениях листа;
- вклады лет (Σ = Δ, 10⁻¹²).

**Сводный вывод** — по таблице, механически:
- (i) необходим, (iii) необходим — «выигрыш S-RCK = обрезка с поправкой m + связь уровня C со слоем доверия через потерю уровня F»;
- (i) не обнаружен — «выигрыш достигается на уровне C; связь с π не нужна»;
- (iii) вредит — «m лишняя; обрезка без m лучше» (без смены кандидата).

## 7. Следующая адресная доработка — предложение и критерий выбора, без регистрации

Регистрация — только после `S_D_ABL.md`.

### 7.1 Что установлено (`S_D_EXPLAIN.md`)
- Выигрыш S-RCK над W5-G (−0,21 %) — почти целиком сдвиг уровня C вниз на ≈ 3 %: 89 % при фиксированных θ.
- Он полезен через вес π и вреден на уровне C.
- Память компонент γ не используется: γ_c = 0 во всех месяцах.
- Под R лаговые и внутридневные веса A2 ≈ 0. Выигрыш A2 внутри выборки опирается только на 1 % крайних пар: на остальных 99 % — 0 из 78 месяцев.
- Это ветка Ж-256 п. 5: «помогает коррекция уровня, обучаемая память не добавляет».

### 7.2 Причина различия — диагностика без обучения (лист S-L, сохранённые ряды, ~20 мин)
- **L1 — PIT-версия таблицы `S_D_EXPLAIN.md` разд. 2.3.**
  - Пороги π — по прошлым дням (расширяющиеся квантили по датам < d).
  - Среднее min(RV/F, Q₉₉) по квинтилям π для W5-G, X1, cfg8, B_mix.
  - То же по квинтилям PIT-переменных режима: v₁ = ln(RV_d/RV_m,d) (затухание после всплеска), v₂ = ln(B_mix/cfg8) (расхождение каналов), s_d (экстремальный бар), gap^PIT, год.
- **L2 — заменяет ли режим π.** Разброс среднего отношения по π внутри квинтилей v₁ (и наоборот), описательно. Потолок «оптимальный постоянный сдвиг по квинтилю» использует исход — пометка «потолок», не прогноз.
- **L3 — почему память не добавляет.**
  - Для старого S-A2 по сохранённым θ месяца (прямой проход `a_model.forward`, без подгонки): выигрыш внутри выборки на 99 % пар без 1 % лучших — по месяцам.
  - Сравнить с тем же для сдвига уровня S-RCK (0,441 месяцев θ ≠ 0).
  - Это отличает «у памяти нет сигнала на основной массе пар» от «сигнал есть, но R его стягивает» (λ* = 0,1 — край сетки в 75 из 87 месяцев).

**Критерий выбора следующей доработки** — объявлен сейчас, применяется после S-D-EVAL и S-L:

| исход абляций и S-L | следующая доработка (одна регистрация) |
|---|---|
| (i) необходим или «хуже без него» и L2: π не объясняется v₁, v₂ | **S-RL1 — сдвиг уровня C одним параметром** a ∈ [−0,5; 0,5]: C = cfg8·eᵃ, процедура R на уровне F. Проверяет, нужны ли остальные 5 параметров C-K. Контроли — разд. 7.3 |
| (i) необходим и L2: π ≈ режим v₁ (или v₂) | **S-RLv — поправка уровня F как функция PIT-переменной режима** (1–2 параметра) на месте слоя W5, тем же R. Контроль (б) — v, циклически сдвинутая на 252 строки; (в) — W5-G |
| (i) не обнаружен | выигрыш на уровне C: S-RL1 с потерей уровня C; связь с π не регистрируется |
| (iii) вредит | в любом преемнике m := 1 (отступление от R с записью) |
| L3: у памяти A2 нет выигрыша на 99 % пар в ≥ 80 % месяцев | линия обучаемой памяти для SBER h = 1 закрывается как отрицательный результат. Новых вариантов памяти нет (Ж-256 п. 5: «не увеличивай сложность памяти автоматически») |

### 7.3 Гипотеза взаимодействия, ещё не проверявшаяся — формулировка и контроль
- **H-Lπ.** Выигрыш S-RCK — взаимодействие сдвига уровня C со слоем доверия, а не свойство C.
  - Сдвиг уровня C, обученный на уровне F при PIT-π, снижает QLIKE итога, потому что прогнозы завышены именно в дни высокого π.
  - Тот же сдвиг без привязки к π выигрыша не даёт: при процедуре R равномерный сдвиг F имеет нулевой балл в θ = 0 по построению m.
- **Кандидат** — S-RL1 (разд. 7.2).
- **Контроли** (`otbor_statistika.md` п. 2):
  - (а) S-RL1 с π в потере обучения, заменённым константой π̄ пула. Ожидается a ≈ 0 ⇒ ≈ W5-G;
  - (б) S-RL1 с π, циклически сдвинутым на 252 строки, — только в потере обучения. Слои оценки — настоящие;
  - (в) W5-G (a = 0, вложение).
- **Взаимодействие подтверждено численно**, если QLIKE(S-RL1) < QLIKE(W5-G), QLIKE(S-RL1) < QLIKE(контроль (б)) и S-RCKf по разд. 5 не лучше S-RCK. Пороги этапа S — без изменений.
- **Не предлагаются** (основание — `S_D_EXPLAIN.md` разд. 2.1, 3):
  - **A2-память внутри S-RCK** — под R a и b ≈ 0. Сдвиг уровня у A2 реализуется сжатием по уровню (corr −0,875), которое вредит на уровне F (+0,10 %). Совмещать нечего;
  - **общая процедура R для A и C** — по той же причине. Довод появится, только если L3 покажет сигнал памяти на 99 % пар.
