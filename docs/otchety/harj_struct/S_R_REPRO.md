- DM (HAC, Ньюи–Уэст, лаг 8, Бартлетт, односторонний): статистика 1,7742, p 0,03801 (заявлено 1,77425 / 0,03801; расхождение < 1e-11). Лаг 5: p 0,04181 (совпало). X1_R к X1: 0,8400 / p 0,2004 (совпало).
- Стационарный бутстрап (Politis–Romano, средний блок 20, B = 10 000, seed 1, свой генератор): 90 % интервал Δ к W5-G [−0,3967; −0,0241] против заявленного [−0,3989; −0,0248]; p(бутстрап) 0,0307 против 0,0296 (seed 2: 0,0311). Расхождения — в пределах бутстрапной ошибки при другом seed (до 0,002 п.п. по границам, 0,001 по p). Вывод не меняется: интервал целиком ниже нуля, p DM 0,038, p бутстрапа ≈ 0,03.
- X1_R к X1: [−0,2820; 0,0845] против [−0,2821; 0,0818]; p 0,1847 против 0,1843 — совпало с учётом шума.
- «Подтверждено» автором не заявлено (p Холма N ≥ 0,05) — не проверялось, вне задания.

## 4. Концентрация (Δ к W5-G, %)
Совпало до 1e-12 по всем заявленным: без 24.02.2022 −0,2289; без крупнейшего дня 2025-06-06 −0,2576 (день действительно первый по |разности потерь|); без года 2018…2025 — все 8 значений совпали (2022: −0,3040 — максимальный сдвиг; 2024: −0,1719); без 2026 −0,1394 (= заявленный no_top_year).
