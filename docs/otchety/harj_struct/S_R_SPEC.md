## 1. Гипотеза

**H-R.** Процедура обучения, устойчивая к влиянию одной пары, позволяет тем же архитектурам A2 и C-K улучшить итоговый F на D_M без опоры на 2022-02-24.

Почему ожидается эффект (`S_C_WHY.md`, разд. 1):
- в S-CK 1 % лучших пар давал 233 % выигрыша внутри выборки (медиана по 100 месяцам);
- на остальных 99 % пар подобранные θ хуже нулевого старта в 100 месяцах из 100;
- в сетке не было θ = 0.

R устраняет каждую из трёх причин отдельным элементом:
- ограничение влияния — разд. 2.2;
- θ = 0 в сетке — разд. 2.4;
- блочное правило — разд. 2.4.

Абляции (разд. 3) разделяют вклад элементов.

Что R **не** утверждает:
- что архитектура несёт сигнал. Если R выберет θ = 0 во всех месяцах, F_R ≡ W5-G, и это результат «процедура свелась к контролю»;
- что структура C доказана. Контроли структуры S-CD, S-C7, S-CKL обучены старой процедурой и под R не пересчитываются. Вывод R-CK — о процедуре, а не о разложении.

## 2. Процедура R — одна, общая для A2 и C-K

### 2.1 Уровень потери — итог F с замороженными PIT π, β (Д-1)
Для обучающей пары j с датой прогноза d_j:

  ln F_j(θ) = (1 − π_j)·ln B_mix,j + π_j·ln C_j(θ) + β_j·g_j,

- C_j(θ) — компонента C архитектуры: C_A из `a_model.forward` (вариант A2) или cfg8·𝓜_K из `cm_model.forward` (CK, μ = 0);
- π_j = `x1.pi` дня d_j, β_j·g_j = `w5g.beta`·1[gap = 1, refit_date ≠ NaT] дня d_j. Оба известны на d_j: π считается онлайн по парам t⁺ ≤ d_j, β — помесячно по парам t⁺ ≤ начала месяца d_j;
- пары пула A без X1 (t⁺ 2017-01-03…2018-01-03, 253 пары = 2451 − 2198, cfg8 нет) — ln F_j = ln H_A,j. Это прежняя трактовка S-A («g = 0»; слоя доверия на этих датах нет).

**Вложение проверено** (`<sp>/s_r/calib.py`): B_mix^(1−π)·cfg8^π·exp(β·g) против `w5g.F` — max отн. **0,0** на 2198 датах. При θ = 0 потеря R видит ровно W5-G, а у пар A без X1 — K1.

**Почему уровень F, а не C.**
1. Ж-254 п. 5: «итог обучать под дневную QLIKE»; п. 9: «основная потеря — QLIKE суммарного прогноза». Оценка идёт по F (Ж-254 п. 11).
2. По S-C-WHY гипотеза 1 отброшена: вред создаётся уже на уровне C, а слой доверия его уменьшает. Поэтому уровень F сам причину **не лечит**: он лишь согласует цель обучения с оценкой. Причину лечат пп. 2.2 и 2.4.
3. Градиент по ln C_j на уровне F равен π_j·(1 − RV_j/F_j). Вес пары — её доля в итоге (π ≈ 0,39–0,46). Остаток считается против F, а не против C. Ошибка, которую B_mix уже закрыл, не тянет C.
4. Довод из A: C_A у S-A2 лучше cfg8 на −0,67 %, а F_A ≈ W5-G (−0,0004 %, `S_C_WHY.md` разд. 2, `S_A_REPORT.md`). Выигрыш на уровне C до итога не дошёл.

**Цена.** π заморожен по X1 над cfg8. В оценке слой доверия пересчитывается над новым C_R (`a_layers.layers`, `cm_layers.layers` — без правок) и реагирует на него. Обучение реакцию π не видит. По S-C-WHY реакция π у всех вариантов C уменьшала вред (−0,23 % у S-CK). Значит, заморозка — консервативное приближение первого порядка. В отчёте даётся разложение «эффект при замороженном π + реакция π» (разд. 4.6).

### 2.2 Ограничение влияния одной пары — QLIKE Хьюбера с обрезкой отношения по PIT-квантилю и поправкой уровня
Перед каждой подгонкой на обучающем множестве T (пул месяца или обучающая часть блока):
- **опорное отношение** x⁰_j = RV_j / F_j(0): W5-G_j для пар D_M, K1_j для пар A без X1;
- **порог** c_T = Q_q(x⁰_T), **q = 0,99**, `np.quantile(·, 0.99)` (метод `linear`), только по парам T;
- **поправка уровня** m_T = mean_{j∈T} min(x⁰_j, c_T);
- κ_T = c_T / m_T, u_j(θ) = ln(RV_j / (m_T·F_j(θ))).

**Вклад пары:**

  ρ_κ(u) = eᵘ − u − 1, при u ≤ ln κ;
  ρ_κ(u) = (κ − 1 − ln κ) + (κ − 1)·(u − ln κ), при u > ln κ.

**Функция потерь:** L_R(θ; T, λ) = (1/|T|)·Σ_{j∈T} ρ_κT(u_j(θ)) + pen_arch(θ; λ). Здесь pen_arch — штраф архитектуры без изменений:
- A2: λ(‖δ‖² + Σω² + Σ‖c‖² + δw² + δκ²) + 10⁻⁴‖ψ‖²;
- CK: λ‖θ‖².

**Свойства.**
- ρ_κ выпукла по u, а значит и по ln F_j. Она непрерывна вместе с первой производной в точке ln κ: значение κ − ln κ − 1, производная κ − 1.
- При u ≤ ln κ функция ρ_κ совпадает с QLIKE от RV/m.
- **Балл пары** ∂ρ/∂ln F_j = 1 − min(RV_j/F_j, c_T)/m_T. Отношение RV/F обрезается сверху ровно в условии первого порядка. Снизу балл ограничен единицей и так.
- **Влияние одной пары** на балл ограничено величиной max(κ − 1, 1)/|T|. Без обрезки оно равно (x − 1)/|T|.
  - Последний месяц 2026-11-02, пул C (n = 2192): у пары 2022-02-24 влияние **0,01416 → 0,00135**, в 10,5 раза меньше.
  - x⁰ (2022-02-24) = RV/W5-G = **32,04** (RV/cfg8 = 42,54). Пара 2018-04-09 даёт x⁰ = 32,01.
- **Поправка уровня.** При θ = 0 средний балл по T равен 1 − mean(min(x⁰, c))/m = **0 точно**. Обрезка не тянет уровень вниз от W5-G. Без поправки она занизила бы уровень на 1 − m (см. калибровку ниже). QLIKE штрафует занижение сильнее завышения.

**Состоятельность — приближённая; условия записаны.** Модель F*_j = F⁰_j·exp(θ*ᵀz_j) с мультипликативной ошибкой RV_j = F*_j·Z_j, E Z = 1, распределение Z не зависит от z_j. Условие первого порядка в популяции:

  E[z·(min(Z·e^{−a}, c) − m)] = 0.

1. **θ* = 0** (нулевой сигнал; по S-C-WHY это главный практический случай). Тогда x⁰ ≡ Z, m = E min(Z, c) и θ̂ → 0. Оценка **состоятельна точно**: под нулём R не находит ложного сдвига уровня.
2. **θ* ≠ 0, ошибка независима от z.**
   - Наклоны состоятельны: стандартный результат M-оценок Хьюбера в масштабной модели.
   - Смещён только уровень: a решает E min(Z·e^{−a}, c) = m. Здесь m посчитан по x⁰ = Z·e^{θ*ᵀz}, а не по Z. Поэтому a ≠ 0 порядка различия распределений x⁰ и Z, малого при малом θ*.
   - Направление уровня в обеих архитектурах есть: δ₀ у A2; θ_c0, θ_p0 у CK — в нуле ∂ln 𝓜/∂θ_X0 = ŝ_X, сумма ŝ_c + ŝ_p = 1 − ŝ_u = 1 на D_M.
3. **Хвост Z зависит от состояния** — гетероскедастичность в логарифмах; для RV вероятна. Тогда смещены и наклоны. В состоянии z прогноз занижен примерно на

   b(z) ≈ (E[(Z − c)⁺ | z] − E[(Z − c)⁺]) / m  (в долях уровня).

   - Это **смещение, которое вносит обрезка.** R не учит условную массу хвоста выше c. В состояниях с более тяжёлым верхним хвостом, чем в среднем по пулу, F занижен.
   - Среднее смещение (1 − m) снято поправкой уровня. Остаётся только зависящая от состояния часть.
   - Оценка по обычной QLIKE (разд. 2.3) эту цену учитывает полностью.

**Почему q = 0,99, а не робастная функция другого вида.**
- Квантиль задаёт порог в единицах самого отношения, PIT и без свободного масштаба. 1 % — та же доля, в которой S-C-WHY нашёл концентрацию.

### 2.4 Выбор — сетка с θ = 0 и блочное правило
- **Сетка:** θ = 0 (вложенный контроль: C = cfg8, F = W5-G) и λ ∈ Λ⁺ = {10⁻¹; 10⁻²; 10⁻³}.
- **Блоки.** P — закрытый пул месяца D: t⁺ ≤ D, `closed_rows` / `closed_pool` прежних проходов, по возрастанию t⁺.
  - V₃ = последние 126 пар P, V₂ — предыдущие 126, V₁ — ещё предыдущие 126.
  - Обучение блока b: T_b = все пары P раньше V_b (rolling origin, расширяющееся окно).
  - c, m считаются по T_b. Пары V_b и более поздних блоков в T_b не входят.
- **Выигрыш блока:** G_{λ,b} = mean_{j∈V_b}[ℓ(RV_j, F_j(θ̂_{λ,b})) − ℓ(RV_j, F_j(0))]. Здесь θ̂_{λ,b} = argmin L_R(θ; T_b, λ).
- **Правило (объявлено):**
  1. w_λ = #{b : G_{λ,b} < 0} (строго; точный ноль — не выигрыш).
  2. λ допускается, если w_λ ≥ **2 из 3**.
  3. Если ни один λ не допущен, месяц получает **θ = 0**.
  4. Иначе λ* = argmax w_λ; при равенстве — больший λ (сильнее стягивание).
  5. Финальная подгонка: argmin L_R(θ; P, λ*), c и m — по P.
- **Почему 2 из 3, а не «все три» и не среднее по блокам.**
  - Одна пара лежит ровно в одном блоке и может перевернуть знак только его. При правиле 2 из 3 допуск требует выигрыша хотя бы в одном блоке **без** этой пары. Одна пара не может в одиночку допустить θ ≠ 0.
  - Среднее по блокам вернуло бы влияние одной пары: 2022-02-24 в блоке из 126 пар даёт ℓ ≈ 27,6 против W5-G (37,8 против cfg8) при среднем 0,22.
  - «Все три» при 126 парах в блоке делает θ ≠ 0 почти недостижимым и при реальном сигнале.
- **Сиды** — правило каждой архитектуры без изменений:
  - A2: seeds 0–4, ln C — среднее по seeds (`a_walk.fit_month`);
  - CK: 5 перезапусков, итог — минимум L_R, при равенстве меньший seed (`cm_model.fit`).
- **Корректор A2** (δw, δκ) обучается, если в T не меньше 120 пар с cfg8 (`a_walk.MIN_CFG`), как в S-A.

### 4.5 Статистика (по `S_STAT_AUDIT.md`, как `S_A_SPEC.md` разд. 6.3) — показывается, «новой контрольной версией» не управляет

### 4.6 Диагностика — обязательна в отчёте, условием не является

## 7. Вычислительный план (Мак, CPU, лимит 2 процесса, без платных ресурсов)
- **Подгонок на активный месяц:**
  - R, Rb: 3 λ × 3 блока + 1 финальная = 10 наборов;
  - Rc: 3 + 1 = 4;
  - каждый набор — 5 seeds (A2) или 5 перезапусков (CK).
- **A2:** (10 + 10 + 4) × 5 × 87 = **10 440** подгонок L-BFGS-B. По S-A на 2120 подгонок A2 уходило порядка 5 мин (оценка кодера, не замер). Отсюда ≈ 25 мин; верхняя граница ×4 — ≤ 1,7 CPU-ч.
- **CK:** 24 × 5 × 75 = **9 000** подгонок по 6 параметрам. По S-C — секунды на 1910 подгонок, итого ≤ 5 CPU-мин.
- **Прочее:** слои X1, W5 — секунды на вариант (6 вариантов); оценка (B = 10 000, SPA, MCS по 14 рядам) — минуты.
- **Итого:** ≤ 2 CPU-ч, ≤ 1,5 ч стенных при 2 процессах. Выходы < 50 МБ. Перед счётом — `df -h` (Ж-147, ≥ 40 ГБ).
- **Стоп по замеру** (I-лист печатает время): > 1 с на подгонку A2 — доклад до прохода. Протокол, сетка и число блоков не меняются; допустимо только возобновление по месяцам (`_part/`).
