## 1. Точная формула S-RCK по коду

### 1.1 Входы дня d — сохранённые ряды, R их не обучает
- cfg8_d — канал C гибрида X1: cfg8 = K1·exp(w⁸·ℓ + m), ℓ = ln(B_mix/K1), m — MoE-часть (`S_C_SPEC.md` стр. 13; ряд `x1_w3_core.load()["C"]`). Внутри — **память HAR K1 и корректор X1 без изменений**.
- B_mix_d = √(K2·K3) (`x1_w3_core.load()["M"]`, проверка в `x1_w3_core.py` стр. 86–87).
- Компоненты c, p (фактор 16 бумаг без SBER и остаток), окна 5 и 22 строки сегмента (`cm_feat.py` стр. 69–79):
  - доли ŝ_X,d = X_m,d / (c_m + p_m + u_m) (стр. 76–78), на D_M ŝ_u = 0, ŝ_c + ŝ_p = 1;
  - память компоненты Ĥ_X,d — HAR-J по ряду X, МНК по парам t + 1 ≤ d, ежедневно (`cm_feat.harj_hat` стр. 59–66 → `s10/hp_ctrl.harj_at` стр. 116–124). Это вход, R его не переобучает;
  - x_X,d = ln(Ĥ_X,d / (ŝ_X,d·cfg8_d)) (`cm_model.py` стр. 52–53), z_X,d = ln(X_d / X_m,d) (стр. 64).

### 1.2 Канал C — шесть параметров месяца
`cm_model.forward` стр. 78–80, `r_loss.lnc_of` стр. 64–67:

  η_c = γ_c·x_c + θ_c0 + θ_c1·z_c,  η_p = γ_p·x_p + θ_p0 + θ_p1·z_p,
  𝓜 = 1 + ŝ_c·expm1(η_c) + ŝ_p·expm1(η_p),  **C_R = cfg8·𝓜**.

γ_X ∈ [0, 1], θ ∈ [−3, 3] (`cm_model.bounds` стр. 30–31). Параметры θ = (γ_c, γ_p, θ_c0, θ_p0, θ_c1, θ_p1) одни на месяц. Проверено на сохранённых θ: cfg8·𝓜(θ строки) = C файла, max отн. 2,2·10⁻¹⁶ (rck), 4,4·10⁻¹⁶ (rckb), 2,2·10⁻¹⁶ (rckc), 0 (старый ck) — `<sp>/s_d/recon.py`.

### 1.3 Слой доверия X1 над новым C — π, α, η пересчитываются, правило то же
`cm_layers.layers` стр. 31–36 → `s15/de_e1_state.run` стр. 79–103:
- X1_R = B_mix^(1−π)·C_R^π (`v4_ntp_state.combine`);
- π — fixed share по состоянию s_d: логит сдвигается на −η·(QLIKE(C_R) − QLIKE(B_mix)) по закрытым парам своего состояния (стр. 63–66). Потери считаются **по новому C_R на уровне C** (стр. 83);
- η = 1/медиана потерь C_R и B_mix в пуле (стр. 61); α₀, α₁ — помесячно из {0,01; 0,02; 0,05} по контрфактическим потерям над C_R (стр. 71–76, 92–99).
- Не меняются: сетка α, VAL = 126, состояние s_d, форма fixed share.
- Факт (`recon.py`): у S-RCK π ≠ π X1 в 1546 из 2198 дней; α₀ ≠ в 311 днях, α₁ — в 128. Слой над сохранённым C_R воспроизводит `X1_R` и `F` файла побитно (max отн. 0).

### 1.4 Слой W5 — β пересчитывается, правило то же
`s16/x1_w5_gap.walk` стр. 50–64: u = ln(RV/X1_R) (стр. 54); β месяца = clip((ū₁ − ū₀) + ½(s₁² − s₀²); 0; 0,5) по закрытым парам (стр. 33–38, 57–61); F = X1_R·e^β только в днях gap^PIT = 1 (стр. 62–63). У S-RCK β ≠ β W5-G в 74 месяцах из 100.

**Итог:** F_RCK = W5(X1(B_mix, cfg8·𝓜_R)); W5-G = W5(X1(B_mix, cfg8)) — тот же код (`x1_w5_gap.compute` стр. 75–76).

### 1.5 Что обучается и чем (`r_loss.py`, `r_walk.py`)
- **Обучается:** 6 параметров θ на каждый активный месяц.
  - Потеря на уровне F при замороженных сохранённых π и β·g: ln F = (1 − π)·ln B_mix + π·ln C_R(θ) + β·g (`r_loss.ln_f` стр. 60–61; π, β·g — `level_arrays` стр. 38–46).
  - Функция ρ_κ(u − ln m), u = ln(RV/F) (стр. 85–89, 107–116); c = Q₀,₉₉(RV/W5-G) по обучающему пулу, m = mean min(x⁰, c) (стр. 74–82). Плюс λ‖θ‖² (`cm_model.penalty` стр. 92–93).
  - L-BFGS-B из 5 стартов, итог — минимум потери (`fit_r` стр. 126–136).
- **Выбирается:** λ* ∈ {0; 10⁻¹; 10⁻²; 10⁻³} по трём блокам из 126 пар, допуск при выигрыше в ≥ 2 блоках из 3; иначе θ = 0 (`r_walk.blocks` стр. 46–48, `decide` 51–59, `choose` 66–77). Валидация — обычная QLIKE уровня F.
- **Включение** — пул ≥ 630 закрытых пар (2020-08-03, `fit_month` стр. 83); до него и при λ* = 0 C_R = cfg8 побитно (стр. 82, 89).
- **Не обучается:** K1, cfg8 (память HAR, w⁸, MoE-часть), B_mix, Ĥ_X, ŝ_X, правило доверия, правило W5. c и m вычисляются, а не подбираются.

## 2. Почему S-RA2 хуже S-A2 (+0,10 %), а S-RCK лучше W5-G и бустингов

### 2.1 S-RA2 против S-A2: +0,1020 % (`D_pair / S-RA2|S-A2`)

3. **Замороженный π и реакция слоя** (`B_decomp`, % QLIKE W5-G):
   - старый S-A2: F^fr +0,489, реакция −0,490, итог −0,0004. Паритет старого S-A2 с W5-G создан пересчётом π, а не новым C при прежнем π;
   - S-RA2: F^fr −0,006, реакция **+0,108**, итог +0,102.
4. **Уровень C против cfg8:** старый S-A2 −0,67 % (лучше), S-RA2 **+1,64 %** (хуже), S-RA2b +0,92, S-RA2c +0,15 (`A_level`).

   - Слой доверия судит C по QLIKE уровня C (разд. 1.3) и над худшим C реагирует во вред: +0,108.
   - π при этом вырос: 0,476 против 0,455 у X1 на тех же днях (`J_layer`). Почему рост π вредит — гипотеза: сжатый C получает больший вес в дни всплесков. Не проверено.
5. **Что R сделала с весами a и b у A2.** Медианы по месяцам θ ≠ 0 (`I_a2_params`; θ — среднее по seeds, форма a и b — по среднему θ, приближённо):

   - **R практически выключила лаговую и внутридневную структуру A2.** Обучаемая память в S-RA2 почти нулевая, так что результат S-RA2 ей приписать нельзя.
