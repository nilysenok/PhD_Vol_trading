  Остальные до N заполняются единицами (`stats_d.py:66-71`), поэтому p_adj = N·p_min. Это граница «лучший из N кандидатов». Она валидна при любой зависимости, но N — не число нулевых гипотез семейства: кандидаты сравниваются с 3–4 базами, а в N попали конфигурации других задач.
