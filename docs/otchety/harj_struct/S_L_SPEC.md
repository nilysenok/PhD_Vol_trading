## 2. Формулы

### 2.1 S-RL1
День d, месяц переоценки M(d); π_d, β·g_d — сохранённые (X1, W5-G); B_mix, cfg8 — сохранённые.
- **Канал:** C_d(a) = cfg8_d·e^{a_M}, один параметр a_M ∈ [−0,5; 0,5] на активный месяц.
- **Уровень обучения:** ln F^fr_d(a) = (1 − π_d)·ln B_mix,d + π_d·(ln cfg8_d + a) + β·g_d. При a = 0 F^fr = W5-G.
- **Потеря обучения** на множестве T (T_b блока или пул P):
  - x⁰_j = RV_j / W5-G_j, c_T = Q₀,₉₉(x⁰_T), m_T = mean min(x⁰_T, c_T), κ_T = c_T / m_T;
  - u_j(a) = ln(RV_j / F^fr_j(a)) = ln x⁰_j − π_j·a;
  - L(a) = (1/|T|)·Σ ρ_{κ_T}(u_j − ln m_T) + λa², ρ — `r_loss.rho` без изменений.
- **Балл в a = 0:** ∂L/∂a = −mean_T π_j·(min(x⁰_j, c_T)/m_T − 1) = −cov_T(π, min(x⁰, c)/m). У S-RCK этот балл > 0 во всех 75 активных месяцах (`S_D_EXPLAIN.md` разд. 2.3), поэтому ожидается a < 0.
- **Валидация, выбор, включение — как S-RCK** (`S_R_SPEC.md` разд. 2.4):
  - сетка Λ = {0; 10⁻¹; 10⁻²; 10⁻³}; три блока по 126 пар; правило 2 из 3; ничья — больший λ; нет допущенных — a = 0;
  - G_{λ,b} = mean_{V_b}[ℓ(RV, F^fr(â_{λ,b})) − ℓ(RV, W5-G)] — обычная QLIKE уровня F с настоящим π;
  - включение при пуле ≥ 630 закрытых пар (2020-08-03, 75 активных месяцев); пул t⁺ ≤ D (`r_loss.pool_of("CK")`); финальная подгонка на P с c, m по P.
- **Итог:** слои X1 и W5 над C(â) пересчитываются прежним кодом (`cm_layers.layers`): F = W5(X1(B_mix, C(â))), как у S-RCK.
- **Вложение:** λ* = 0 во всех месяцах ⇒ C = cfg8 побитно ⇒ F = W5-G, X1_R = X1 (≤ 10⁻¹²). До 2020-08-03 C = cfg8 побитно.

### 2.2 Контроль (а) S-RL1a — π без вариации
Только в потере обучения на T: π_j := π̄_T = mean_T π.
- ln F_train(a) = (1 − π̄_T)·ln B_mix + π̄_T·(ln cfg8 + a) + β·g;
- c, m — по x_train = RV / F_train(0) (В-3).
- Валидация, выбор и слои — как в 2.1, с настоящим π.
- Ожидание: â ≡ 0 ⇒ S-RL1a ≡ W5-G побитно (L2.G3).

### 2.3 Контроль (б) S-RL1b — π, циклически сдвинутый на 252 строки
Только в потере обучения: π_j := π^(б)_j (В-4); c, m — по RV / F_train^(б)(0). Валидация, выбор и слои — настоящие.

### 2.4 Контроль (в) — W5-G
Сохранённый ряд, a = 0. Не пересчитывается.

### 2.5 Предсказания — объявлены до счёта, на вердикт не влияют
- **P-L1:** â < 0 не менее чем в 90 % месяцев с λ* > 0.
- **P-L2:** медиана â по месяцам с λ* > 0 лежит в [−0,063; −0,015] — q05…q95 ln(C/cfg8) у S-RCK (`S_D_EXPLAIN.md` разд. 1.6).
- **P-L3:** S-RL1a ≡ W5-G побитно.
- **P-L4:** если механизм — π, вклад S-RL1 против W5-G в 2021, 2025 и 2026 (годы S_π > 0 по `S_L_DIAG.csv`) ≥ 0 п. п.
