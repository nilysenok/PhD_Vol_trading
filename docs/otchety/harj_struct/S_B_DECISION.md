## 2. (б) Есть ли основание ждать пользы B после A1

### 2.1 Критерий — объявлен до счёта
Файл `s_b/KRITERIJ.md`, sha256 `e2953ec7c1822823895acd99ca3c6dd3bdee39a34f56e1da0619fbc2afdf7844`. Записан 11.11.2026 в 18:02:19, mtime 18:02:44. `S_B_DIAG.csv` впервые записан позже, финальная версия — 18:08:40. Ниже — суть критерия.

- **Меры качества z** (больше — хуже):
  - ln q5, где q5 = Σr⁴/(Σr²)² — относительная сэмплинговая дисперсия RV ≈ (2/3)·q5 по BPQ;
  - u V6 — среднее z(q3), z(|q6|), z(q1), z(q2); нормировка компонент — по сессиям ≤ 29.12.2017, то есть PIT для всех дат D_M.
  - q1–q8 считаются кодом `models_v2/s13/v6_2_q.py` без правок. Сверка с сохранённым `Q_features.parquet` V6: max |Δ| = **0,0** на 2649 общих датах.
- **Направление B-lag** — первый порядок эффекта a_kl(η) ∝ a_kl·e^{−η·z_{t−l}} в η = 0:
  D_k,d = −(Σ_l a_kl z_{d−l} RV_{d−l} / S_k,d − Σ_l a_kl z_{d−l}), k = s, m, l.
  - a — веса A1 (A2) месяца строки d, восстановлены из θ строки.
  - Если такое направление не снижает потерю, обучение η из точки «вариант без B» не сдвинется.
- **Обычный корректор K** (класс V6 C3 / HARQ): z_d, z_d·s1, z_d·s2, z_d·s3, где s1…s3 = ln RV_d, ln RV_w, ln RV_m − ln F базы.
- **Оракул.** F' = F·exp(c + γ'X) — минимум средней QLIKE на всех 2198 датах. Подгонка в выборке, поэтому это **потолок**, пригодный только для вывода «нет основания».
  - G(B|K) — прирост от D_s, D_m, D_l сверх c + K.
  - Нуль — 500 циклических сдвигов столбцов B по датам (сдвиг 60…2138, seed 0).
- **Основание есть**, если хотя бы для одной из 4 гипотез {A1, A2} × {ln q5, u} выполнены все три условия:
  1. избыток над медианой нуля E ≥ 0,10 %;
  2. p Холма (m = 4) < 0,05;
  3. E без t⁺ 2022-02-24 ≥ 0,10 %.
