## 5. Трактовки и отступления

- Условие L3 читает p по χ²₄ (строже плановой смеси 0,5χ²₀ + 0,5χ²₁: при n = 0 параметры β, η, ρ не определены); обе p — в таблице `Z2_H0_LR.csv`. Неясность — в пользу строгого, отступление.
- L3.1 («≥ 100 событий в каждом окне») читает ВСЕ помесячные окна от 2018-07-02 до последней переоценки склада (включая 2025–2026): плановой оговорки об окнах нет, строгий вариант.
- HD: дни E с active = 1 (после включения ZB); терцили τ^last — по прошлым дням E (не менее 30, иначе день без группы); «поздний» — нижний терциль τ^last (событие у закрытия). Условие L2 истинно по (а); (б) решения не меняет.
- Границы η ≤ 2 и ρ ≤ 1 плана достигаются в части окон (число — в разделе 1): параметры на границе — наблюдение, не правка границ.
- Оговорка до Z2 (дирижёр, 10.11): 80 % выигрыша ZB дают февраль–июнь 2022, 63 % — февраль 2022; условие L1–L3 по этой причине не меняется.
- Строки H1, Hc, H2 в реестре: «зарегистрирована; условная» / «не считается без решения владельца». Если H1 не запускалась — прогнозов, ключей `Z2`, `Z2.eval`, `Z2.rules` и таблиц оценки нет, N Холма остаётся 749 (не 751).
- Ступень 1 — numba-ядро (`x1_z2_hawkes`), аналитический градиент сверен с численным и с медленным эталоном по формулам плана (тесты); без seed, старт детерминирован.
