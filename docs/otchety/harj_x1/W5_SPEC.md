### 0.5 Ответ

Слой доверия исчерпан (W3). Состояния доверия и расхождения C/M меняют знак между половинами. Механизм с априорным основанием, видимый в обеих половинах, — один.

**Обоснование.** За время, пока рынок закрыт, накапливается информация (French, Roll, 1986). Вариация сессии t⁺ после перерыва выше и менее предсказуема. QLIKE-оптимальный прогноз E[RV] = exp(E ln RV + ½ Var) после перерыва должен быть выше. Ни K1, ни K2, ни K3, ни X1 этого не учитывают.

**Ожидание — честно и малое:** −0,1…−0,4 % к X1 на окне M. Это оценка по блоку D, а не прогноз. Главный риск — правило концентрации из раздела 5: выигрыш может держаться на 2022-02-24.

## 1. Гипотеза, формула, отличие от испытанного

**Гипотеза одной фразой.** X1 занижает прогноз сессии после нерабочих дней: смещение есть в 9 из 9 лет. Поправка уровня X1 только в эти дни должна улучшить итоговый гибрид на всём окне M. Механизмы X1 при этом не трогаются: канал C, выигрыш 2018, слой доверия π.

**Формула.**
- Метка: gap_d = 1[Δ_d > 0], где Δ_d = (t⁺ − d) в календарных днях − 1 (`models_v2/s16/x1_ya_feat.delta_days`, без правок). t⁺ — следующий канонический день по календарю пар (`x1.parquet`, колонка t_plus).
- Поправка: F_d = X1_d · exp(gap_d · β_m(d)), где m(d) — месяц переоценки.
- Оценка: β_m = clip( (ū₁ − ū₀) + ½·(s²₁ − s²₀), 0, 0,5 ).
  - u_j = ln(RV_{t⁺_j} / X1_j);
  - ū_k и s²_k (ddof = 1) — по закрытым парам переоценки P_m = {j: t⁺_j ≤ D_m} с gap_j = k.
- Свойства:
  - в днях gap = 0 F = X1 побитно;
  - π, α и C — сохранённые ряды X1, не пересчитываются;
  - β ≥ 0 — априорный знак;
  - при β = 0 F = X1 побитно.
- **Почему такой оценщик (выбран после просмотра, Д-2).** Для лог-нормальной ошибки QLIKE-оптимальный относительный множитель равен разности ln E[RV/X1] по группам: Δμ + ½Δσ². Выброс входит в него как ln и ln², а не линейно, как в отношении средних. Так снижается известный риск V4 E1–E6: поправка «перескакивает» после шоков (W2 № 24). Граница 0,5 (×1,65) защищает от одного события. Внутриполовинные значения ex post — 0,085 (h1) и 0,178 (h2), граница их не режет.
- **Сетки нет.** Все константы фиксированы: 0; 0,5; ddof = 1; пороги включения. Кандидат один, N кандидата = 1.

**Отличие от испытанного** (строки реестра W2, раздел 1):

**Почему это не календарная склейка (Ж-250 п. 3).** Метка повторяется каждую неделю во всех годах. Это день недели и праздник цели t⁺, известные на закрытии d. Нет переключения моделей по периодам и нет порога «размер выборки». Одна процедура действует на всём окне; β оценивается по закрытым парам.

**Почему не поправка внутри слоя доверия.** Вариант (M·e^{gβ})^(1−π)·(C·e^{gβ})^π при общем β совпадает с W5-G. Отдельные β для M и C — это уже два параметра и пересчёт π. Он не нужен: смещение после перерыва одинаково у M и C (блок D).

**Почему калибровка по ZB − X1, а не по X1 − K2 (как в примере дирижёра).**

- Из двух измеренных разреженных поправок взята более шумная, ZB. Так порог не слишком строг к поправке, которая меняет больше дней.

**Диагностика концентрации — показывается всегда, условием не является (кроме У5):**
- доля выигрыша от лучшего и от двух лучших периодов;

- сумма вкладов ухудшающих периодов;
- число периодов с выигрышем.

Почему только показ:
- победа в каждом году не требуется (Ж-250 п. 3);
- ухудшения уже ограничены У1–У3;
- для этих величин нет априорного порога, а порог после просмотра был бы подгонкой.

Условием сделано одно — У5: ровно этот провал программа уже видела на ZB.

**Правило «новая контрольная точка» (W5-G заменяет X1):** основной критерий и все У1–У5. Значимость не требуется. «Контрольная точка» — решение разработки, а не «подтверждено». Если правило не выполнено, X1 остаётся контрольной точкой; W5-G записывается как «не прошёл условие У…» с числом.
