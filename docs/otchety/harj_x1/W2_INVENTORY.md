## 3. Устройство X1 и ZB; что можно переобучать

**X1** — `models_v2/s15/de_e1_state.py`, `de_e1_stage.py`; реестр `harj_deep/ALL_TRIALS.csv`.
- **Формула.** F = M^(1−π_t)·C^(π_t), где M = √(K2·K3), C = cfg8 V7, π_t = π^(s_t), s_t = e_d. Оператор геометрический: Йенсен в ln F выполнен на всех датах (`P0_REPORT.md` разд. 4).
- **Доверие π^(s).** Fixed share NTP2 (`v4_ntp_state.fixed_share`):
  - логит веса C сдвигается на −η·(QLIKE(C) − QLIKE(M)) по закрытой паре (t⁺ ≤ d) своего состояния;
  - затем подмешивание α/2;
  - η = 1/медиана QLIKE обеих моделей по всем закрытым парам;
  - старт π = ½.
- **Выбор α.** α^(s) ∈ {0,01; 0,02; 0,05} выбирается помесячно по последним 126 закрытым парам состояния (контрфактический π).
- **Что обучается.** Градиентного обучения нет: только онлайн-π и помесячный выбор α. Среднее α в состоянии E = 0,050, верх решётки, в 2019–2026 (`E1_REPORT.md` разд. 5). При π ≡ 0 F = M побитно; при общем π для двух состояний — NTP2.
