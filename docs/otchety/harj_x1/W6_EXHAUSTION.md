## 2. Почему поправки уровня вредят в спокойные годы: разложение

Обозначения:
- u = ln(RV/X1);
- поправка c_t = ln(F/X1) на области S. Для W5-G S — дни gap = 1 с включённым β. Для ZB S — дни E с active = 1;
- φ(x) = e^{−x} + x − 1.

Тождество: Δ периода = **потолок** + **смещение** + **шум**.
- **Потолок** — Σ_S[l(c*) − l(0)], где c* = ln mean_S e^u — постоянная ex post периода («β года ex post»).
- **Смещение** — n_S·φ(c̄ − c*): ошибка среднего применённого уровня β или b.
- **Шум** — Σ_S[l(c_t) − l(c̄)]: колебания PIT-оценки внутри периода.

Все величины — в % QLIKE(X1) периода. Невязка тождества ≤ 5·10⁻¹⁵ (блок A_decomp).

**Почему смещение есть всегда — премия за хвост** (блок B_param).
- QLIKE-оптимальный уровень на расширяющемся пуле — это ln mean e^u. Его определяют редкие дни: 2022-02-24, где RV/X1 = 34,7; 2018-04-09; 2020-03-10.
- Для дней gap пулированный уровень на окне M равен 0,141, без 2022 — 0,039.

- Для дней E: пул 0,113, μ = −0,035, p = 0,44.
- Значит, поправка, оптимальная для ожидаемого QLIKE с шоками, — это страховка. В каждом спокойном году она платит премию φ(c̄) на день области, а возвращает её в году шока. На окне M такой год один — 2022.

## 3. Можно ли поправку, которая по построению не вредит в спокойные годы: сжатие по PIT-неопределённости

Правило одно для всех структур: κ = max(0, 1 − p/W).
- W — статистика Вальда параметров поправки по закрытым парам пула.
- p — число параметров: 1 у W5-G, 2 у ZB, 3 у объединения.
