## 1. Гипотеза, формула, отличие от испытанного

**Гипотеза одной фразой.** В спокойные годы (2019, 2020) X1 проигрывает бустингам, потому что ML-сторона M не получает информации сверх K2/K3, а доверие к C перевзвешивает «направление HAR-J». Поправка над M на признаках, которых нет у K2/K3, должна улучшить ML-сторону. При этом канал C остаётся, а с ним и выигрыш 2018.

**Формула.**
- Ступень 1 (компонент): M⁺_d = M_d·exp(clip(ρ_m·ĝ_m(x_d), −1, 1)).
  - M = √(K2·K3);
  - ĝ_m — QLIKE-GBM на остатке e = ln RV_{t⁺} − ln M_d, обученный на переоценке месяца m;
  - ρ_m ∈ {0; 0,25; 0,5; 0,75; 1} — сжатие к 0;
  - при ρ = 0 M⁺ = M побитно.
- Ступень 2 (гибрид): F_d = (M⁺_d)^(1−π_d)·C_d^π_d.
  - C = cfg8 — тот же сохранённый ряд, что в X1;
  - π и α — слой доверия X1 без изменений (`de_e1_state.run`), пересчитанный PIT на потерях M⁺.

## 2. Ступень 1 — компонент M⁺

### 2.1 Обучатель (фиксирован, без перебора)

- **Тот же `models_v2/s13/v6_1_fit.fit_gbm`, что у A0g и A2.** LightGBM с собственной целью QLIKE по g (g₀ = 0):
  - градиент 1 − e^{e−g}, гессиан e^{e−g};
  - num_leaves 4, learning_rate 0,03, min_data_in_leaf 50, feature_fraction 0,8, без бэггинга, seed 0, num_threads 1, deterministic;
  - не больше 300 деревьев.
- **Число деревьев:** лучшая итерация на последних 252 закрытых парах при обучении на остальных. Затем переобучение на всех закрытых парах с этим числом (мутации № 99, 100).
- **Сжатие ρ (новое в W4).** На той же модели, обученной без последних 252 закрытых пар, ρ_m = argmin среднего QLIKE на этих 252 парах по ρ ∈ {0; 0,25; 0,5; 0,75; 1}. При ничьей (|Δ| ≤ 1e-12) берётся меньшее ρ. Финальная модель — со всеми закрытыми парами и выбранными ρ и числом деревьев.
- clip |ρ·ĝ| ≤ 1, как в V6.
- **Цель:** e = ln RV_{t⁺} − ln M_d. В движке `v6_1_wf.walk_forward` таблица получает колонку h := M. Сам движок не правится.
- Нормировки нет: деревья к ней нечувствительны, `norm_stats` не вызывается.

### 2.2 Наборы признаков (две конфигурации)

- **W4-S1:** S = s1…s9 (9 столбцов, `S_features.parquet`).
- **W4-S2:** S + Σ = s1…s9 + `v6_1b_sig.SIGMA_NAMES` (12: a_*, m5_a_*), 21 столбец — ровно набор A2.
- Σ³ (`sig3_*`) и флаги не входят.

### 2.3 Правило временного обучения

- **Переоценка:** первый торговый день каждого месяца, d₀ (`v6_1_wf.refit_positions`). Обучающие пары — только t⁺ ≤ d₀ (`v6_1_wf.closed_rows`), расширяющееся окно с первой пары M (t⁺ 2017-01-03).
- Внутренняя валидация — число деревьев и ρ — только по последним 252 из этих закрытых пар.
- Прогноз g дней месяца — по модели переоценки d₀. Признаки дня d — только из баров с begin ≤ d 18:40.
- **Старт:** прогнозы с t⁺ 2018-01-04, как X1. Пока закрытых пар меньше 312, g = 0 (Д-3).
- Календарной склейки нет: одна процедура на всём окне. Переключение между M и M⁺ — только через ρ_m, выбранное по закрытым парам.

### 2.5 Порог продолжения (объявлен до счёта)

Окно M: t⁺ 2018-01-04…2026-11-10, n = 2198. QLIKE — среднее дневных потерь. Набор k ∈ {S1, S2} проходит, если выполнены все условия:
1. QLIKE(M⁺_k) < QLIKE(M) на окне M (условие дирижёра);
2. QLIKE(M⁺_k)/QLIKE(M) − 1 ≤ +0,50 % на 2018–2021 и на 2022–2026, это 2018-01-04…2026-11-10 (условие дирижёра);
3. QLIKE(M⁺_k) < QLIKE(K_a) на окне M (Д-1).

Если не проходит ни один набор, ступень 2 не считается. Строки W4-X, W4-Xa, W4-Xb получают статус «не считается, условие ложно» и остаются в реестре и в N. Отчёт ступени 1 пишется в том же формате.

## 5. Основная историческая оценка и правило «новая контрольная точка» (объявлено до счёта)

- **Окно M:** t⁺ 2018-01-04…2026-11-10, n = 2198. Половины — 2018–2021 (n = 1010) и 2022–2026 (n = 1188). QLIKE — среднее дневных потерь l = RV/F − ln(RV/F) − 1 на общих датах. Δ — в % QLIKE названной базы.
- **Порядок сравнений:** главное — W4-X против X1; затем против K2, K3; справочно — против M, ZB, W4-Xa, W4-Xb.
- **Статистика:**
  - DM Ньюи–Уэст, лаг 5, односторонний «ряд лучше базы»;
  - 90 % интервал Δ: блочный бутстрап, блок 20, B 2000, seed 0;
  - Холм с **N = 770, N_wide = 3245** (раздел 7). «Подтверждено» — только при p Холма < 0,05;
  - MCS 90 % — реализация W1.

**Правило «новая контрольная точка» (W4-X заменяет X1), все условия:**
1. Δ(W4-X к X1) < 0 на окне M;
2. Δ(W4-X к X1) ≤ +0,50 % в каждой половине;
3. QLIKE(W4-X) < QLIKE(W4-Xa) и < QLIKE(W4-Xb) на окне M: выигрыш не от сдвига уровня и не от формы признаков без привязки ко времени;
4. Δ(W4-X к X1) без лучшего для W4-X года t⁺ ≤ 0 (2026 — две части, как в W1). Это не победа в каждом году, но выигрыш не должен держаться на одном годе: ZB — 99,3 % из 2022.

**Обоснование 0,50 %:**
- разрыв X1 до ex post потолка доверия — 1,39 % (W3), а эффект «ничего не знающего» π в днях N — 0,32 % (W3, после просмотра);
- ухудшение половины больше 0,5 % перекрыло бы весь ожидаемый масштаб улучшения;
- полпроцента — порядок разницы X1 и K2 на продолжении (+0,58 %).

Правило не требует значимости. «Контрольная точка» — решение разработки, не «подтверждено».
