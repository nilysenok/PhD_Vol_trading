## 2. Ряды по пунктам поручения

### 2.1. Bv2 h = 5, 22 (XGBoost, LightGBM) — `*_val`

**1. Что за прогноз.**
- Цель — `rv_target_mean_h{h}`, среднее RV за [d+1, d+h]. В логарифме цель берётся при обучении (`tune_Bv2.py:59`, `:73`). Это среднее, не сумма.
- Проверено на SBER 2017-06…2021: доля дней, где `rv_target_mean_h5` равна среднему RV строк d+1…d+5, — 1,0; для h = 22 — тоже 1,0 (`b8_rvbase.py`).
- `date` — день прогноза d. `rv_pred` — уровень RV в долях², дневной (`tune_Bv2.py:146`).
- RV-основа отличается от цели h = 1 гибрида (раздел 3).

**2. Правило обучения.**
- Обучение по годам (`tune_Bv2.py:66–67`): шаг s → тестовый год ty = 2016 + s, val-год vy = ty − 1, обучение — годы < vy.
- В файл `*_val` пишется прогноз **на val-год** vy, `year = vy` (`tune_Bv2.py:144–146`, `:184–186`).
- Ранняя остановка идёт по тому же val-году:
  - XGBoost — `evals=[(dva,'val')]` (`:108`);
  - LightGBM — `valid_sets=[dva]` (`:125`);
  - отсечение на итерации 100 — по QLIKE того же года (`:85`, `:122`).
- На шагах 1–6 точка ЛГК выбрана как argmin `qlike_val` по тому же году (`:132–134`, `:172`). Совпадение подтверждено (`b8_struct.py`):
  - точки по годам в `Bv2_*_val` совпадают с `Bv2_selected_h{5,22}.csv` построчно. Пример — LGBM h = 22: 47, 74, 15, 91, 91, 44 на 2016–2021;
  - в 2022–2024 стоит точка шага 6 (`:176`): гиперпараметры там выбраны до года, но ранняя остановка всё равно идёт по своему году.
- «Закрыто + 1» нарушено на всём году: число деревьев и точка выбраны по целям, которые закрываются после d.

**3. Покрытие.**
