## 2. Гипотеза W8-G и формула (ДО СЧЁТА; ни одного прогноза W8-G нет)

**Гипотеза.** После перерыва ошибка X1 зависит от того, насколько спокоен рынок в день d. В днях gap с низкой реализованной волатильностью IMOEX (T1) X1 занижен сильнее, в средних (T2) — не занижен. Один β W5-G переплачивает в T2 и недоплачивает в T1. Групповой β снимает премию W5-G в спокойные годы и не трогает механизмы X1.

**Формула.**
- F_d = X1_d · exp(gap^PIT_d · β_{m(d), G(d)}).
- G(d) ∈ {T1, T2, T3, na} — PIT-терциль z_d = ln RV^IMOEX_d по 1.0 (W8D8):
  - бары основной сессии IMOEX с началом 10:00…18:30 дня d: архив `data/iss_check/index_10m/IMOEX.parquet`, продолжение `data/fwd/mkt_m10/IMOEX_m10_fwd.parquet`;
  - r_бар — лог-разность закрытий, первый бар — ln(close/open);
  - пороги — по z всех дней окна строго до d, не меньше 60.
- Метка пары — её собственный G(d_j), посчитанный один раз на d_j. Пересчёта меток пула по поздним порогам нет.
- β_{m,G} = clip((ū_{1,G} − ū_0) + ½(s²_{1,G} − s²_0), 0, 0,5) по закрытому пулу P_m = {j: t⁺_j ≤ D_m}, как W5-G. ū_{1,G} — по парам gap = 1 группы G, ū_0 — по парам gap = 0.
- **Включение группы:** в P_m не меньше 30 пар gap = 1 группы G (= `x1_z_fit.MIN_EXT`, как W5-G) и β W5-G месяца включён. Иначе β_{m,G} = β_m^{W5-G} из сохранённого `w5g.parquet`; группа `na` — так же.
- **Свойства:**
  - gap = 0 ⇒ F = X1 побитно;
  - группа не включена ⇒ F = W5-G побитно;
  - X1 и W5-G не пересчитываются.
- **Сетки нет.** Константы: 0; 0,5; 30; 60; 18:30; ddof = 1. Кандидат один.

**Не календарная склейка.** Группа — свойство дня d, оно меняется каждую неделю во всех годах. Переключения по датам нет, правила «до 2022 / после» нет.

**Отличие от испытанного:**
- W5-G — частный случай: одна группа;
- W6D-GJS — сжатие по SE, без состояния;
- ZB / ZB0 — состояние e_d по бару SBER, в днях E, а не gap;
- W5D (24 состояния) — признака IMOEX там не было;
- B4 W6 («экстремальный бар IMOEX») — другое: там хвост бара в днях E, здесь уровень RV индекса в днях gap.
