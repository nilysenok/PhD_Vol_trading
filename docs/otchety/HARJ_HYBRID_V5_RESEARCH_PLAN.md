- Пропусков дат нет: 0 из 20 206 бумаго-дней M16.
- Ошибки реализации нет: формула воспроизводит `crit_panel` 51 ряда с расхождением 6·10⁻¹⁷.
- Критерий не меняется.

**Равновесная по годам оценка EqY** (диагностика, не подтверждение). Ранги по EqY и по `crit_panel` совпадают не полностью: Спирмен 0,86.

- По EqY лучше всех контролей только H2 и H3 V4.

**Цель RV.** RV = Σ r² по M10-барам с 10:00 до 18:40, ночной интервал не входит. Разложение Парсеваля точное на всех бумаго-днях: расхождение 8·10⁻¹⁶.

**Предварительная диагностика направлений** (задним числом, гиперпараметров не выбирает):
- **Score.** Прогнозируемость остаётся и у бустинга M: R² 0,40 % в 2017–2021 и 0,29 % в 2022–2025. Она в основном межбумажная: t на среднем score остальных бумаг 4,7 и 4,1, корреляция score между бумагами 0,48–0,57. Собственная автокорреляция мала. Оценка порядка: R² 0,4 % от дисперсии логарифмической ошибки — это возможный выигрыш около 0,3 % уровня QLIKE, если весь он извлекается вне выборки. Направление 1 имеет смысл.
- **Спектр.** Доли полос в среднем 0,32 / 0,35 / 0,33 — почти белый шум; персистентность ≤ 0,04. Сверх HAR-J и Intraday Shape есть малая информация в доле высоких частот: частная корреляция −0,02…−0,04, ΔR² ≤ 0,17 %. Направление 2 — после 1.
- **Скачки.** J > 0 по определению проекта — в 82 % дней, потерь не концентрирует. В 1 % дней с наибольшей RV — 18–28 % суммарного QLIKE. Гипотеза направления 5 («редкие дни сильных скачков») проверяется бесплатной диагностикой значимых скачков (п. 6.5) до любой конфигурации.

## 2. Общая конструкция и отличие от V3/V4

V4 искала, **кому доверять**: веса, гейты и режимы между готовыми прогнозами H и M. V5 строит прогноз как замороженную основу HAR-J плюс аддитивные поправки в логарифме. Каждая поправка — отдельный объявленный механизм:

  ln F(i,t) = ln H(i,t) + g₀(i,t) + u(i,t) + Σ_m g_m(i,t),

где:
- H — замороженный HAR-J (K1).
- g₀ = ½·ln(M/H) — ограниченный нелинейный ML-модуль (Ж-226 п. 0): поправка бустингов к HAR-J, сжатая вдвое, без оцениваемых параметров. При u = g_m = 0 получается F = K8, лучший контроль V4. При g₀ = 0 получается F = H. Оба тождества проверяются тестом побитно.
- u — скрытое состояние систематической ошибки, обновляемое QLIKE-score (направления 1, 6).
- g_m — новые механизмы: спектральная поправка (2), моментно-регуляризованный корректор (3), скрытые факторы (4).

Так каждое направление отвечает на один вопрос: даёт ли его механизм что-то **сверх K8**. Ответ «нет» — отрицательный результат направления. Вопрос «есть ли информация, которой нет в бустингах» проверяется напрямую (п. 4).

Математические отличия от проверенного (подробно — `MAP_DONE.md`):
- **Graph-Score против E1–E5 (V4).** В E поправка смещения — сглаженное среднее отношения RV/F₀ к фиксированной базе. В V5 score берётся к окончательному F, который сам содержит u (обратная связь, динамика score-driven / GAS). Межбумажная передача — через оценённую по прошлому матрицу W, а не одно панельное среднее.
- **Spectral против Ж-214 и Intraday Shape.** Там энергия делилась по времени (части дня, Херфиндаль, последний час). Здесь — по частоте в ортонормальном базисе DCT-II: low несёт дрейф и автокорреляцию внутри дня, high — отскок и микроструктурный шум.
- **Moments против B/E/RQC.** Градиент QLIKE по коэффициенту линейной поправки θᵀφ равен −mean(s·φ). Штраф λΣm_k² — это регуляризация условной калибровки по заранее объявленным состояниям; при полном базисе она совпадает с условиями первого порядка. Новизна — в объявленных φ_k и частичном объединении моментов между бумагами.
- **Latent Innovation против E3/E4, H1/H2, C10/H8.** Там факторы были признаками текущего дня или фиксированными сглаживаниями. Здесь — скрытые факторы, оценённые по прошлому, с регуляризованными нагрузками и динамикой состояния.

## 3. Направления и формулы

### 3.1. Graph-Score (5 конфигураций; объявлено до счёта — `GATES_V5.md`, лист 1)

Обозначения:
- F(i,t) = K8(i,t)·exp(u(i,t)).
- s(i,t) = RV(i,t)/F(i,t) − 1 — отрицательный градиент QLIKE по ln F. Он известен после закрытия дня t.
- s̃ — используемая форма score: сырая s или ограниченная min(s, 3).

Обновление состояния:

  u(i,t⁺) = ρ·u(i,t) + α·s̃(i,t) + β·T(i,t),   u в первый день ряда = 0.

Здесь t⁺ — следующий торговый день бумаги, T — межбумажная передача по варианту:

| id | вариант | T(i,t) | s̃ |
|---|---|---|---|
| GS1 | A: только свой score | 0 | s |
| GS2 | A, ограниченный score | 0 | min(s, 3) |
| GS3 | B: + общий рыночный score | среднее s̃(j,t) по j ≠ i | по правилу ниже |
| GS4 | C: разреженный граф | Σ_j W(i,j)·s̃(j,t): три соседа j ≠ i с наибольшей прошлой положительной корреляцией s̃, веса ∝ корреляции, сумма 1 | по правилу ниже |
| GS5 | D: низкий ранг | (λ̃_i/λ̄)·Σ_{j≠i} λ̃_j s̃(j,t) / Σ_{j≠i} λ̃_j; λ — первый собственный вектор прошлой корреляции s̃ (знак: среднее > 0), λ̃ = ½λ + ½λ̄ | по правилу ниже |

**Правило формы score для GS3–GS5** (объявлено до счёта). Берётся форма GS1 или GS2 — та, у которой меньше `crit_panel`. Конфигурации GS1 и GS2 считаются обе и входят в N.

**Оценка параметров.** Параметры θ = (ρ, α, β) общие для панели, с ограничениями ρ ∈ [0; 0,99], α ∈ [0; 0,3], β ∈ [0; 0,3]. Они переоцениваются в начале каждого месяца по закрытым парам 17 бумаг (цель t⁺ ≤ последний закрытый день), при LOTO — без исключённой бумаги.
- Целевая функция: средний QLIKE плюс штраф V4 «κ = 250 пар-эквивалентов» к априорным θ₀ = (0,9; 0; 0).
- Меньше 60 закрытых дней — берутся θ₀, и тогда F = K8.
- Путь u в месяце m считается фильтром от начала ряда с θ_m: u в день t — функция только прошлых score.
- W и λ переоцениваются ежемесячно по прошлым s̃. Если у пары меньше 120 общих дней — строка W из равных весов.
- LOTO: строка W исключённой бумаги — равные веса, λ_i = λ̄; её ошибки не входят ни в оценку θ, ни в W остальных.

**Проверки.**
- Аналитический градиент QLIKE по ln F (−s) и по θ (через рекурсию) сравнивается с численным.
- Цена ограничения score — QLIKE GS1 против GS2 на 1 % крайних дней и без них.
- При α = β = 0 получается F = K8 побитно, при дополнительном g₀ = 0 — F = H.

**Закрытие направления.** Если ни одна GS не даёт «go», направление 1 закрывается, а направление 6 (Structural Break) не считается: оно меняет скорость обновления u.

### 3.2. Spectral Energy (4; объявление — до счёта направления 2)

Энергии полос: E_b(i,d) = Σ_{k∈b} c_k², c = DCT-II·r (дневной вектор M10-доходностей длины n). Полосы: low при 3k < n, mid при n ≤ 3k < 2n, high при 3k ≥ 2n. Тождество Σ_b E_b = RV проверяется на каждом бумаго-дне.

Прогноз:

  F = K8 · Σ_b π_b(i,d)·exp(g_b(Z)),

где π_b — расширяющиеся средние доли полос бумаги по закрытым дням, Σπ_b = 1. При g_b = 0 получается F = K8.

Варианты:
- (A) g_b из HAR-регрессий энергий полос — фиксированное разделение;
- (B) общий регуляризованный модуль с выходами по полосам: линейный QLIKE-ридж по лагам ln E_b и долей, при необходимости — один ограниченный бустинг на все полосы;
- (C) (B) + общий межбумажный спектральный фактор (средние доли 16 других, LOTO);
- 1 конфигурация — абляция «спектр против Intraday Shape» на той же модели.

Число M10-интервалов меняется со сменами сессий MOEX. Доли зависят от k/n, поэтому сопоставимы между режимами; n входит в Z.

### 3.3. Conditional Moments (3; объявление после диагностики моментов, п. 6.3)

Прогноз F = K8·exp(g(Z)). Корректор g обучается на функции

  L = mean QLIKE + λ·Σ_k m_k² + μ·Ω(g),   m_k = mean(s·φ_k),

с φ₀ = 1 и шестью заранее объявленными φ_k (п. 6.3).

Варианты:
- (A) чистый QLIKE-корректор (λ = 0);
- (B) малое λ;
- (C) моменты, частично объединённые между бумагами: m_k по бумаге сжимаются к панельному.

Модель принимается, только если QLIKE не хуже, чем у (A).

### 3.4. Latent Innovation (3; по результатам 1)

Прогноз:

  ln(F/K8) = a_i·f_mkt(t) + b_i·f_sec(t) + v_i(t),

где:
- f — скрытые факторы, не больше двух, оценённые фильтром только по прошлым score;
- a_i, b_i — нагрузки с сильным ридж-сжатием к 1 и к 0;
- v_i — медленное индивидуальное состояние.

Секторный фактор вводится только для групп из 3 и более бумаг. Обязательное сравнение — с E3/E4 и H1/H2 V4. Конструкция принимается только при выигрыше от динамики состояния.

### 3.5. Jump Distribution (3; только если подтвердится п. 6.5)

Прогноз:

  F = (1 − p(Z))·F_n + p(Z)·F_j,

где событие — значимый скачок (п. 6.5), а не J > 0. F_n и F_j привязаны к K8 через мультипликативные уровни. Ожидаемый вклад скачка второй раз не добавляется: в K8 уже входит jump-компонента HAR-J.

### 3.6. Structural Break Innovation Filter (2; только после «go» 1)

Скорость обновления становится зависимой от сигнала: α_t = α·(1 + γ·1[CUSUM сработал за последние k дней]). CUSUM причинный, как в CLD V4. Сравнение — с постоянной скоростью и с CLD.

### 3.7. Сочетания (2; только из направлений с «go»)

- V5-A: Graph-Score + Moments.
- V5-B: Graph-Score + Spectral.

Остальные — только при «go» обеих частей.

## 4. Прямой ответ на вопрос «есть ли информация, которой нет в бустингах»

Для каждой лучшей конфигурации направления считаются три диагностики.

**(а) Охват.** QLIKE-оптимальный ex post вес w в M^(1−w)·F^w по окнам 2017–2021, 2022–2025 и всей истории. Доверительный интервал — блоковым бутстрапом по датам. Если w > 0 значимо в 2022–2025, есть информация сверх бустинга. Если w ≈ 0, модель воспроизводит то, что бустинг уже знает.

**(б) Охват относительно K8.** Тот же вес w, но в K8^(1−w)·F^w.

**(в) Корреляция ошибок.** Корреляция ln(RV/F) и ln(RV/M), а также доля дней, где F и M ошибаются в одну сторону.

## 6. Бесплатные диагностики (0 конфигураций), лист 1b

**6.3. Моменты.** φ_k стандартизуются по расширяющемуся прошлому:
- φ₁ — z(ln RV_d − среднее ln RV за прошлые 252 дня): высокий уровень;
- φ₂ — z(ln RV_d − ln среднего RV за 5 дней): резкий рост;
- φ₃ — z(EWMA с полураспадом 5 по J/RV): недавние скачки;
- φ₄ — z(среднего s(j,d) по j ≠ i к K8): межбумажный score;
- φ₅ — z(|ln(M/H)|): расхождение HAR-J и ML;
- φ₆ — z(ln стандартного отклонения ln(RV/K8) за прошлые 20 дней): неопределённость.

m_k для баз K8 и M считается по годам на закрытых парах, с t по Ньюи–Уэсту и совместным тестом Вальда.

Правило (объявлено): направление 3 считается, если p совместного теста < 0,01 на 2017–2021 для базы K8. Иначе оно закрывается: «новой информации нет».

**6.5. Значимые скачки.** Используется статистика отношения Барндорфф-Нильсена — Шепарда (BV проекта, TQ по тем же M10-барам), уровень 0,1 %.

Правило подтверждения гипотезы (объявлено) — одновременно:
- доля дней со значимым скачком ≤ 10 %;
- доля суммарного QLIKE K8 и M в эти дни ≥ 2 × доли дней;
- не меньше 30 событий на бумагу за 2017–2021.

Иначе направление 5 закрывается без конфигураций.
