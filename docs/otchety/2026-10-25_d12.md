# Второй круг Д12 (h=5, h=22)

**Итог.** Из рычагов Д12.1–Д12.5 прошёл один: Д12.5 (Huber) на h=5, с улучшением −4,0% при выполненных c1–c4. На h=22 не прошёл ни один рычаг. Итоговые комбинации на `features_pit_v3` после полного переподбора optuna-30:
- **h=22 — `D12_h22`:** V9 + LightGBM linear_tree λ=1. Метрика 0,2029, ворота 0,919, выбор по правилу seeds3/V0_XGB/B-smrob/L0 со всеми критериями.
- **h=5 — `D12_h5`:** V9 + Д8.12 + Д7 + Huber. Метрика 0,2066, ворота 0,902, выбор по правилу single/V0_XGB/B-sm/L0 со всеми критериями.

Ухудшение при переходе v2 → v3 (+5,2% на h=22, +6,8% на h=5) почти целиком объясняется тем, что точки подбирались на v2. После переподбора на v3 остаётся −0,1% на h=22 и +0,7% на h=5.

Тест и подтверждающий набор (val шагов 7–9) не открывались. Журнал — `docs/otchety/dev_log_d12.md`, 29 строк, ссылка из `dev_log_L2.md`.

## Ограничения
- Все рычаги оценены на одной точке без своего подбора. Д12.5 на h=5 после переподбора свой выигрыш не подтвердил — см. оговорку выше.
- Д12.1 на точках, подобранных для 17 тикеров. Переподбор на 28 не делался, потому что рычаг не прошёл ни на одной из двух точек.
- Д12.2 (α) не считался поверх Huber и на переподобранных точках: по порядку плана он шёл первым и был отброшен.
- В справочном V0 на h=5 XGB pseudohuber без смещения разошёлся (QLIKE порядка 3·10⁶), поэтому этот вариант в справку не идёт.
- Тесты «будущее не влияет» для v3 и v3_28 пройдены у агентов-сборщиков (features-v3, PR #36). Новые флаги (`train28`, `har28`, `drop_tk`) меняют только состав строк обучения и признаков не вводят.
