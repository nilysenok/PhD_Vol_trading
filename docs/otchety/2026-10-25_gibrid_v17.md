# Гибрид V1-V7: параметризованная сборка (проверка на П1)

Слепой тест: метрик на тестовых годах нет. **Защита от переобучения (решение 25.10):** разработочный набор = val-годы 2016-2021 (шаги 1-6), подтверждающий = 2022-2024 (шаги 7-9; val 2025 у бустинга нет). Все метрики ниже - только по 2016-2021; перебор и выбор дизайнов (схемы, рычаги, поправка, step/minimax, ансамбли, V0) - только по разработочному набору. Подтверждающий набор скрыт и открывается один раз флагом `--confirm --finalists <список>` для 3-5 финалистов. Внутришаговые процедуры (выбор схемы V1-V7 на шаге по его val-году, вес w) работают как в коде на всех шагах. **Оговорка:** метрики П1 по 2022-2024 были видны до введения правила, поэтому П1 не чистая проверка (основной вариант - B). Boost = П1 (LightGBM gbdt + ES) + XGBoost.

## 1. Процедура (файл:строка в `moex_volatility/scripts/`)
Шаги, пул, val = последний год обучающего окна - как `walk_forward_full.py:133-205`. На шаге и h схема выбирается по наименьшему val-QLIKE среди V1-V7 (`gibrid_designs.select`, режим step) либо по минимаксу (минимум худшего val-года среди лет, доступных к шагу).
- HAR-J: пересчёт `walk_forward_full.py:61-100,193-205` (`gibrid_har.py`).
- V1: `walk_forward_full.py:258-290` (w_HAR in [0;0,60], шаг 0,01, при w=0 inverse-QLIKE) + выбор лучшей ML по val-QLIKE (`walk_forward_adaptive.py:270-273`; в `walk_forward_full.py:118` ML фиксирована).
- V2-V5: `walk_forward_adaptive_v2.py` (не v3): сетка 3 компонент (`:53-67`, w_HAR<=0,6, шаг 0,02); V2 - среднее весов двух val-лет (`:126-158`); V3 - режим по отношению среднего RV val-года к среднему за годы до тестового (>1,3 / <0,7), HAR-вес x1,5 (<=0,6) или x0,7 (>=0,05) (`:204-261`); V4 - сжатие к 1/3, lambda=0,3 (`:293,337`); V5 - веса V2, затем режим, затем сжатие (`:394-457`).

- V0 (решение 25.10): одна компонента с поправкой (HAR-J / XGBoost / LightGBM) - самостоятельный кандидат на каждом h.
- Прогнозы прошлых периодов (без заглядывания вперёд): val-прогнозы шага k - модель шага k на val-годе; V2 берёт ещё val шага k-1; история для режима - val-годы шагов 1..k; V7 для val идёт по склеенному ряду val шагов 1..9 (строка использует только более ранние), для теста - по склеенному ряду test-прогнозов.

## 5. Поправка Б0.1: контроли
- s² - только из валидационных остатков ln(RV)-ln(прогноз), для всех трёх компонент включая HAR-J (тест не используется). F=exp(s²/2) применяется к HAR-J, XGB, LGB до сборки гибрида (поэтому эталон критериев - модели с поправкой).

Выбросы общие для всех 17 тикеров (вклад каждого 6-7%, т.е. поровну; PHOR/LKOH чуть выше), а не отдельных бумаг. Они сосредоточены в датах, чьи цели (RV на h дней вперёд) накрывают 24.02.2022: наибольшие остатки +6,1...+6,9 (RV в сотни раз выше прогноза) у всех тикеров на 16.02 (h=5) и 24.01 (h=22).
