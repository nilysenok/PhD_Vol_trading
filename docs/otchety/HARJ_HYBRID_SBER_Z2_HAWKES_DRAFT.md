## 2. События, интенсивность, значение на закрытии

### 2.1 События (PIT)

Порог дня d — тот же, что у e_d:

q_d = Q_{0,99}{ |r_{j,i}| : сессии j < d, present_{j,i} }.

- **Событие** — N_{d,k} = 1[present_{d,k} ∧ |r_{d,k}| > q_d]. Название — «экстремальный M10-бар (превышение порога |r|)», не «скачок»: порог не отделяет скачок от диффузии (п. 14 блока).
- **Метка** — m_{d,k} = ln(|r_{d,k}|/q_d) > 0.
- **Тождество:** e_d = 1[Σ_k N_{d,k} ≥ 1] — побитно, это тест. Отсюда Z2 вкладывается в область ZB: в дни e_d = 0 событий дня d нет.
- **Время** — торговые минуты от 10:00. Бар k занимает интервал (10k, 10k + 10], событие относится к концу бара τ_k = 10(k + 1). Закрытие дня — T = 530 (конец слота 52), δ = 10.

### 2.2 Ядро интенсивности внутри дня d (дискретная, интервально-цензурированная постановка)

Интенсивность постоянна внутри бара. Поэтому вероятность события в баре:

P(N_{d,k} = 1 | прошлое) = 1 − exp(−δ·λ_{d,k}), λ_{d,k} = μ·f_{D,k} + H_{d,k}.

Событие бара k не возбуждает свой бар: интенсивность бара k определяется только событиями баров < k.

Возбуждение H задаётся рекурсией (экспоненциальное ядро с меткой):
- H_{d,0} = ρ^{1+Δ_{d−1}}·H^{cl}_{d−1} — перенос через ночь, Δ — определение Y1;
- H_{d,k+1} = e^{−βδ}·H_{d,k} + α·N_{d,k}·e^{η·m_{d,k}}, k = 0…52;
- H^{cl}_d = H_{d,53} — возбуждение на закрытии d.

Для слота с present = 0: N = 0, вклада в правдоподобие нет, затухание идёт (по часам). Так смены расписания обрабатываются без особых случаев.

В явном виде:

H^{cl}_d = α·Σ_{(j,i): N_{j,i}=1, j ≤ d} e^{η m_{j,i}} · e^{−βδ·(52 − i)} · Π_{ночи между j и d} ρ^{1+Δ}.

Это форма `lambda_t = mu + sum_j alpha*exp(-beta*(t-t_j))` из п. 15 блока. Добавлены метка e^{ηm} и затухание ρ за ночь.

**Сезонная база f_{D,k}.** Нормированный профиль Y4: f_{D,k} = p̄_k / mean_k p̄_k, где p̄_k — средняя доля r²_k/RV по 250 сессиям < D с присутствующим слотом k. Профиль фиксирован и не обучается. Обучается только уровень μ.

**Ветвление** (внутридневное приближение): n = α·m̄_η·δ/(1 − e^{−βδ}), m̄_η — среднее e^{ηm} по событиям окна. Ограничение n ≤ 0,9.

### 2.3 Значение на закрытии и переход к t⁺

Ожидаемое число избыточных событий в сессии t⁺ от состояния на закрытии d, с каскадом 1/(1 − n), делится на ожидаемое число базовых событий:

ξ_d = ρ^{1+Δ_d}·H^{cl}_d·Σ_{k=0}^{52} e^{−βδk} / [(1 − n)·μ·Σ_k f_{D,k}], ξ_d ≥ 0.

Свойства:
- ξ_d зависит от времени каждого шока до закрытия (e^{−βδ(52−i)}), от размера (e^{ηm}), от числа шоков и от длины перерыва до t⁺ (ρ^{1+Δ_d});
- ξ_d = 0 ⇔ событий не было ни в d, ни раньше, если ρ = 0. При ρ > 0 после событий прошлых дней ξ_d > 0 и в день e_d = 0 — это затухающий хвост.

### 2.4 Поправка над X1

F = X1·exp(g), u = ln RV_{t⁺} − ln X1_d, потеря l = e^{u−g} − (u − g) − 1 — как в плане Z.

**H1:** g_d = a·ln(1 + ξ_d).

- g ≡ 0 ⇔ a = 0. Тогда F = X1 побитно — тест.
- Свободного уровня нет: на спокойных днях (ξ ≈ 0) g ≈ 0 по построению. В этом отличие от a_n Y2 и от b ZB/ZB0, см. причину 1 плана Z.

## 5. Временной протокол (как план Z, раздел 4)

- **Ступень 1.** Ежемесячно, в первый торговый день D с 2018-07-02. Окно — 500 сессий строго < D (≈ 2 года). Плюс 20 сессий прогрева рекурсии с H = 0, в правдоподобие они не входят. q_d, f_{D,k} — по сессиям < d и < D соответственно.

- **Ступень 2.** Пул — все пары X1 с t⁺ ≤ D (закрытые). Цель — mean l + λ·a².
  - λ ∈ {0; 0,001; 0,01; 0,1}: обучение без последних V закрытых пар, QLIKE на последних V; V = 126 при n ≥ 252, иначе ⌊n/2⌋; при равенстве — больший λ.

  - Обучение — на всех парах, не только e_d = 1: ξ определена везде, на спокойных днях вклад в градиент ≈ 0.
- **Включение.** Как ZB: ≥ 30 закрытых пар с e_d = 1 к дате включения. До неё F = X1 побитно, `active = 0`.
- **Запрещено** (план Z):

## 6. Условие запуска (от исходов Z) и критерии

Условие записано до результатов Z. После них оно не меняется.

**Hawkes обоснован — нужны все три пункта:**
- **L1.** ZB или ZC выполнила K1, K2 и K5 плана Z: специализированная поправка на днях после шока даёт выигрыш без вреда.
- **L2.** Величина зависит от времени или размера шока — хотя бы одно из двух:
  - (а) ZB < ZB0 за весь период и в состоянии E: сигнал близости к закрытию s_d добавляет к сдвигу уровня;
  - (б) диагностика HD — описание, без конфигураций и прогнозов, на сохранённых рядах ZB. В дни E средний D_ZB = l(ZB) − l(X1) по терцилям τ^last_d (время от последнего события дня до закрытия; пороги терцилей — по прошлым дням E, PIT) и по N_d ∈ {1; ≥ 2}. Условие: разность «поздний − ранний» или «≥ 2 − 1» < 0 за весь период с 90 % интервалом бутстрапа (блок 20, 2000, seed 0) ниже 0 и с тем же знаком на 2018–2021.
- **L3.** Предпроверка H0 — только бары, без цели RV:
  - в каждом окне ступени 1 с 2018-07 не меньше 100 событий;
  - отношение правдоподобия H1 ступени 1 против пуассоновской базы (α = 0) на 2015–2021 даёт p < 0,01 (смесь χ², граница);
  - доля дней E с N_d ≥ 2 и частота событий по годам и слотам — в таблицу;
  - устойчивость порога: числа событий при Q 0,98 / 0,995 — справочно, в конфигурацию не идут;
  - правило дубля раздела 4 не сработало.

**Hawkes не обоснован** — направление D записывается как «не запускалось, условие ложно», без закрытия:
- ни ZB, ни ZC не выполнили K1, K2, K5 — более сложная форма неработающего механизма;
- ZB ≥ ZB0 и HD плоская — бинарного e_d достаточно;
- n̂ ≈ 0 или LR p ≥ 0,01 — кластеризации нет, Hawkes ≡ счётная поправка;
- дубль по правилу раздела 4.

Если L1 выполнено только у ZC (затвор), а L2 ложно — Z2 не запускается. Вопрос «ξ_d как вход затвора ZC» — отдельная запись, не в этом черновике.

**Подтверждение — без изменений:** правило 6.2 против X1 на 2018–2021 (Δ < 0, DM p < 0,05, ≥ 3 из 4 лет) и p Холма (N = 751, с H2 — 752) < 0,05. Иначе — «не подтверждено».

**Продолжение — все пять условий, как в плане Z:**
- **K1** — весь период: Δ H1 к X1 < 0;
- **K2** — состояние N (e_d = 0), весь период: Δ к X1 ≤ +0,10 %. Здесь это настоящая проверка: при ρ > 0 g ≠ 0 и в дни N;
- **K3** — Δ к X1 ≤ 0 не менее чем в 5 из 8 лет 2018–2025;
- **K4** — H1 < Hc за весь период; рядом H1 против лучшей из ZB/ZC (информативно: Hawkes против бинарной области). H2 сравнивается с H1;
- **K5** — 2018–2021: Δ к X1 ≤ +0,10 %.

Невыполнение любого условия закрывает гипотезу с записью; направление D не закрывается. Оценка, окна, статистика (бутстрап 20 · 2000 · seed 0, DM, Холм, MCS 90 %, стресс без 2018 и без 1 % крайних) — как в плане Z, раздел 5. Δ — в % QLIKE X1.
