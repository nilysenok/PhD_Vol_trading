## Определения (выбраны до счёта, класс B)
- Ряд — дневной избыточный x (с платой: x − плата × база), все дни, как в таблицах листа а. Объекты: A_fix (якорь), A_strogaya (плата за заём 0,05 и 0), A (s9), TEST_C, D (плата за шорт 0 и 5 %); периоды: полные, 2022, 2023, 2024.
- ACF(k), k=1..5: Σ(x_t−m)(x_{t−k}−m)/Σ(x_t−m)² (одна формула, как в Льюнге–Боксе и statsmodels.acf; `pandas.autocorr` не используется — он считает иначе). `summa_acf14` = Σ ACF(1..4).
- VR(5) = Var(недельные суммы W-FRI, ddof=1) / (5 · Var(дневной, ddof=1)). **Неполные недели:** в основной VR входят все недели — ровно те же, что в Sharpe нед. (`nedelnye_summy`), чтобы связь «VR > 1 → недельный Шарп ниже» считалась на одной выборке. Контроль `vr5_polnye` — только недели из 5 торговых дней (`n_polnyh_nedel`). Неполных недель на реальных рядах много (743 дня за 154 недели ≈ 4,8 дня на неделю), поэтому их вклад в разрыв Шарпов надо читать по разнице vr5 и vr5_polnye.
- Q(5) Льюнга–Бокса и p (χ², формула; сверена с statsmodels в тесте).
- Серии: убыток = x < 0; `p_ub`, `p_ub_ub` = P(убыток d+1 | убыток d) по соседним торговым дням, `dlina` — средняя длина серии убыточных дней, `dlina_nezav` = 1/(1−p_ub). Дни с x = 0 (нет позиции) считаются не-убытком; у C/D доля таких дней может быть большой — смотреть `dni` и `ekspoziciya` в `a_cd_test1.csv`.
- В строке рядом: Sharpe дн., Sharpe нед. (·√52), их разность (`raznost`), VR(5).

## Что проверено
Синтетика с известным ответом (`tests/test_avtokorr.py`): AR(1) φ=0,3 → ACF(1)≈0,3, VR(5)≈1+2Σ(1−k/5)φ^k ≈ 1,613; белый шум → VR≈1; Q и p = statsmodels; серии на ручном примере и цепи Маркова; мутации «лаг сдвинут» и «VR без деления на 5» ловятся; перепутанный знак (φ<0 → VR<1).
Гейт сверки на реальных рядах (Sharpe дн./нед. = опубликованным ≤ 1e-12) встроен в скрипт и отказывает при расхождении; без прогона он **не закрыт**.

### Sharpe нед. ≈ Sharpe дн. / √VR(5): проверка по каждому объекту (полные периоды)
Определение VR(5) = Var(недельных сумм)/(5 · Var(дневных)), обе дисперсии с ddof = 1, недели — те же, что в Sharpe нед. (неполные входят). Тогда точно: Sharpe_нед = Sharpe_дн / √VR(5) · k, где k = (N / n_нед) · √(52 / (5 · 252)), N — число дней, n_нед — число недель (неполные недели: ≈ 4,8 дня на неделю вместо 5). Простая оценка без k совпадает с таблицей с отношением 0,980–0,981 на полных периодах (0,970–0,992 по всем 40 строкам); с k — совпадает до ошибки счёта: максимум |Sharpe_нед(таблица) − Sharpe_дн/√VR · k| = 8,9·10⁻¹⁶ по всем 40 строкам таблицы (сверено при написании скриптом вне репозитория).

### Что это значит для паузы после стопов и тормоза по просадке
Довод «дневные убытки идут сериями» полными периодами не подтверждён; по отрицательной ACF(1) убыточный день в среднем сменяется менее убыточным (условная средняя доходность после убытка не считалась). В 2024 есть слабый положительный намёк (не значим). Решение о паузе и тормозе на основании этой таблицы принимать нельзя; это справочный результат, класс A остаётся за владельцем.

### Оговорки
