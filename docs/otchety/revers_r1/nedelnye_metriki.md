# Недельные Sharpe, Sortino, mSR рядом с дневными (реверс р.1, лист а, test1 2022–2024)

Статус: справочно, без выбора, после аудита. Основание: Ж-124 п. 3 («mSR при эксцессе 95–169 не определён — Корниш–Фишер за пределами применимости…»). Определение — класс B, `docs/resheniya/tolkovaniya.md`.

**Определение.** Недельная избыточная доходность = сумма дневных избыточных доходностей торговых дней недели `W-FRI` (неполные края входят, пустых недель нет). `Sharpe_нед = mean/std(ddof=1)·√52`; `Sortino_нед` — формула дневного (`fastbt.metriki_e.sortino_e`) с шкалой 52; `mSR_нед` — Корниш–Фишер (`metriki_e.msr`, шкала 52), вне области (mVaR ≤ 0) — NaN, без подмены. Код — `fastbt/metriki_e.py` (`nedelnye_summy`, `metriki_ned`, `stroka_ned`), одна формула на дневной и недельный ряд (Д7).

**Новые колонки** в `a_dve_metriki_test1.csv`, `a_po_godam_test1.csv`, `a_cd_test1.csv` и в `_net/`: `sharpe_ned, sortino_ned, msr_ned, skew_ned, kurt_ned, n_nedel, msr_dn_opredelen` (в конце; старые колонки совпадают с прежними с точностью 0 — max|Δ| = 0). Прежние версии — `docs/tables/revers_r1/_do_nedelnyh/` (sha256 в шапке).

## Где «эксцесс ниже, формула работает» НЕ выполняется

- Строки «(б) без 10 худших дней» (якорь и A_strogaya, обе платы): недельный эксцесс 26,1–40,8, асимметрия +3,8…+4,8; **mSR_нед = NaN** (вне области). TEST_C без 10 худших: эксцесс 37,0, асимметрия +5,1, mSR_нед = NaN. Утверждение владельца верно для (а), (в), (г) и «по годам», но не для вычеркивания худших дней: там недельный эксцесс остаётся большим.
- Строки A/C/D «стоп 2σ» и «размер 1/σ» в `a_cd` — «неприменимо» (как и раньше), недельных колонок нет.
- По годам (`a_po_godam`): mSR_нед определён во всех 16 строках, недельный эксцесс 0,25–6,6.
- Дневной mSR не определён в 8 из 20 строк `a_dve_metriki`; недельный — в 4 (все — «без 10 худших дней»).

## Что использовать другим листам (б, в, е, ж)

`from fastbt import metriki_e as me`; для строки с рядом `x` (дневной избыточный) и датами `dates` (np.datetime64[D]):
`me.stroka_ned(x, dates, hvost, plata, baza)` → словарь из семи новых колонок (`hvost` — `None`/`'hud'`/`'luch'`, отбор дней как в `dve_metriki_a.stroka`); для ряда без платы/хвоста — `me.metriki_ned(x, dates)`. Ряды без дат (только массив) недельно считать нельзя — нужен календарь торговых дней.
