## 2. Проверки до обучения (P0 — числа, а не объявление)

**(а) Масштаб RV.**
- B(w ≡ 1) = RV_d побитно на 100 % дней 2018–2025.
- **Нормировка V7 масштаб не сохраняет.**
  - Сумма z-нормированного канала r² за день коррелирует с RV на 0,86–0,9998, но медиана Σz / RV — от −5,4 до −0,07.

  - **Вывод для плана:** агрегация М2 — в уровнях r² с весами среднего 1 (масштаб сохраняется), без z-нормировки.

**(б) Нулевая инициализация.**
- В MoE V7 cfg6 при нулевых экспертах градиент по маршрутизатору = 0 точно (автоградиент и численный совпадают до 2,7e-10). Градиент экспертов — до 0,084.

- Средние π ≈ 1/3 — результат усреднения по дням и seeds, а не застревания.
- **Дефекта нет.** Эксперты стали бы копиями только при обнулённом выходном слое маршрутизатора; в V7 он случайный.
- Для плана (синтетика):
  - М2 при θ = 0 и γ = 0 — мёртвая точка: B = RV, g ≡ 0, градиенты θ и γ равны 0;
  - М1 — κ оживает только после a;
  - М3 — все параметры живы сразу.

  Инициализации ниже выбраны с учётом этого.

**(в) Оператор смешивания.**
- В лог-пространстве нарушений неравенства Йенсена для QLIKE нет ни у одного оператора: X1, NTP2, K8, MoE V7, X2.
