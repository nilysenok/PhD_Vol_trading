## ↺ Толкования (записаны в yaml до счёта)

- **RLS с забыванием** — точная форма: на каждый торговый день t взвешенный МНК, вес λ^(возраст в торговых днях), строки с концом цели < t. Это то же, что рекурсия с диффузным стартом (selftest). λ < 1 только с `refit = yearly`.
- **Точки переоценки** — календарные 1-е числа: строки обучения — дата < c и конец цели < c (строго до дня прогноза, на день консервативнее «≤ t»).
- **QMLE** — гамма-потеря, совместимая с QLIKE; пуассон — только selftest. Без штрафа: `leg.enet` не действует, ряд один. Калибровки нет (calib.* = default, иначе не применим).
- **HARX** у R — эл. сеть по `leg.enet` (λ — сила, α — l1_ratio). Каждая точка сетки — свой ряд `R__l<λ>_a<α>`, выбор делает O.
- **Остаточный ученик** — свои фиксированные гиперпараметры (yaml `boost.params`):
  - 300 деревьев, warm_add 75, lr 0,03;
  - без ранней остановки: «год валидации — только для оценки»;
  - G0 = `feature_cols` features_pit_v3.
  - Точек B (D12/D22) модуль не берёт.
