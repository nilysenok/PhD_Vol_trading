## 2. Направления 1–6

**1. Graph-Score** `u_{t+1} = ρu_t + α s_t + β Σ_j W_ij s_j`, `s = RV/F − 1`, `F = H·exp(u + g_ML)`.
- Ближайшие: E1/E2 (b = ln ĉ, ĉ − 1 = взвешенное среднее score относительно **F0**), E3 (общий панельный score), E4 (панель × бумага), E5 (Калман по u = ln(RV/F0)), H1/H2 (сюрприз ln(RV_d/H_{d−1}): рыночная медиана и сектор), B (Global + Individual).
- Формульное совпадение: E1 — частный случай с W = 0, ρ = e^{−ln2/hl}, F0 вместо F; E3 — W = полный ранг 1 (равные веса); H2 — W = блок-диагональный сектор, но как признак, не как динамика состояния.
- Отличие V5: score берётся относительно **окончательного** F (обратная связь: F содержит u, u обновляется собственным QLIKE-градиентом — динамика типа GAS), а не относительно фиксированной базы F0; передача между бумагами — оцененная по прошлому W (разреженная A/B/C/D), а не одно общее среднее.
- Абляция: A (только свой score) → B (+ рыночный) → C (разреженная W) → D (низкий ранг). Отличие V5 от E-этапа проверяется парой «B против E3/E4» (общий фактор уже есть в V4) и «F-обратная связь против F0-обновления» при тех же ρ, α. Предварительно (G5): score M межбумажно коррелирован на 0,48 — это в основном общий фактор, значит выигрыш W над B должен быть малым.

**2. Spectral Energy** `F = H·Σ_b π_b·exp(g_b(Z))`, полосы энергии DCT-II.
- Ближайшие: Ж-214 (`hv2_m10`: части дня open/mid/close по часам, rs_pos/rs_neg, RQ), C-a Intraday Shape (lasth, herf), H3 (herf, lasth, firsth).
- Формула: V4/Ж-214 делит энергию **по времени** (локализованные окна дня), V5 — по **частоте** ортонормального DCT-II: low 3k < n, mid n ≤ 3k < 2n, high 3k ≥ 2n; Σc² = Σr² = RV/1e4 точно (G4).
- Отличие V5: базис не локализован во времени; low несёт дрейф/автокорреляцию, high — шум микроструктуры (отскок bid–ask); herf и lasth — функции распределения q = r² по времени, а не по частоте.
- Абляция: (1) доли полос против {rv_open/mid/close, herf, lasth} при контроле HAR-J (это G7: частная корреляция high −0,023…−0,041, t(НУ) −2,3…−5,4, ΔR² ≤ 0,17 %; mid ≈ 0); (2) вариант A (фиксированное разделение) против B (общая ML-регуляризация) против C (общий межбумажный спектральный фактор).

**3. Conditional Moments** `Loss = QLIKE + λΣ_k m_k² + μ·Penalty`, `m_k = mean((RV/F − 1)φ_k(Z))`.
- Ближайшие: E1–E5 (безусловное смещение b), K8-RQC (a = mean x — нулевой безусловный момент), B5/B2 (ридж ln(RV/f) на z(ln RV_d/RV_m): условное среднее по одной переменной), C-a/C-b и NTP (гейты состояния), V4 `z_perf` (ewqd, lerr).
- Формула: градиент QLIKE по коэффициенту линейной g = θᵀφ равен −mean((RV/F − 1)φ) = −m. Поэтому штраф λΣm² — это взвешенная по состояниям норма градиента QLIKE (дополнительная регуляризация, а не новый критерий), и при полном φ-базисе совпадает с первым порядком условий QLIKE-корректора.
- Отличие V5: заранее объявленные φ_k и частичное объединение моментных ошибок между бумагами; отчёт об условной калибровке по режимам.
- Абляция: A (чистый QLIKE-корректор) = B-этап V4 → B (малая моментная регуляризация) → C (частичное объединение). Если A уже калибрует m_k до шума (проверяется по m_k на закрытых парах), направление закрывается по п. 9 («новой информации нет»).

**4. Latent Innovation** `ln(F/H) = a_i f_mkt(t) + b_i f_sec(t) + g_ML(Z)`.
- Ближайшие: Ж-217 C (Market/Idiosyncratic: m = β²RV_IMOEX), Ж-214 E8 (рыночная общность), E3/E4 (панель × относительная бумага), H1/H2 (рыночный и секторный сюрприз), H8 и C10 (иерархия η_i, наклоны β_i = β + η_i), E5 (Калман по u).
- Формульное совпадение: E4 = a_i·f_mkt с f_mkt = ĉ_t и a_i ≡ 1 плюс бумажный уровень; H2 = f_sec как признак; C10/H8 = индивидуальные нагрузки со стягиванием.
- Отличие V5: f_mkt, f_sec — **скрытые** факторы, оцененные по прошлому (максимум 2), нагрузки a_i, b_i с сильным ridge; динамика задаётся состоянием, а не признаком текущего дня.
- Абляция: сравнение с E3/E4 + H1/H2 как с «простыми панельными факторами»; принимается только прирост от динамического скрытого состояния сверх добавления рыночных признаков.

**5. Jump Distribution** `F = (1 − p)·E[Y|normal,Z] + p·E[Y|jump,Z]`.
- Ближайшие: V4 I (логит события J > 0 + EWMA величины скачка, согласованный Ĉ + p̂·m̂), Ж-214 J1/J3/HARQ-J (AUC вероятности скачка 0,511; Dx_J значимо хуже XJ, p 0,029 сырой), H4 (jp_ewma, jshare).
- Формула: V4 I — уже смесь «событие × размер» с той же определением J = max(RV − BV, 0); V5 с событием и размером по Z совпадает, пока событие определено тем же J > 0.
- Препятствие, показанное листом 0 (G6): J > 0 в среднем в 81,8 % дней (по бумаге 77,8–85,4 %), на ~82 % строк-дней с J > 0 приходится 79,7–83,0 % суммарного QLIKE — события не редки и не концентрируют потери; концентрация есть в верхних 1 %/5 % дней по RV (17,6–28,0 % и 31,2–42,2 % суммарного QLIKE при 1 % и 5 % строк; недооценка RV > F в 86–98 % и 80–93 % этих дней соответственно). Это свойство хвоста RV, а не признака «скачок по определению проекта».
- Абляция: смесь с событием «верхний хвост» (не J > 0) против I; изменение определения J запрещено заданием, поэтому направление 5 — вероятный кандидат на закрытие по п. 9 («структура совпадает с проверенной / новой информации нет») без счёта конфигураций.

**6. Structural Break Innovation Filter** — скорость обновления α_t скрытого score-состояния меняется после причинного CUSUM.
- Ближайшие: CLD (`v4_cld_brk`: тот же CUSUM как **признак** brk для регрессии D), H6 (brk как признак поправки), E3/E4 (разные полураспады, фиксированные), E5 (q/r Калмана раз в год), K8-RQC2 (годовая пересчёт), CS (убывающие штрафы n-зависимой скорости), NTP (доверие по недавнему преимуществу).
- Формульное отличие V5: CUSUM управляет **шагом обновления** α_t состояния u (адаптивная скорость, возврат к базовой), а не входом гейта или весом смеси. Режимного переключателя весов H/ML нет.
- Условие: направление 6 опирается на 1 (нужно состояние u и score); без «go» направления 1 не считается.
- Абляция: постоянная скорость (E1/E3) → скорость после CUSUM; сравнение с CLD (тот же CUSUM как признак).
