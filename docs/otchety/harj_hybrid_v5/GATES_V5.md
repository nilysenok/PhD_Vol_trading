  2. `crit_panel` без целей 2017 ≤ min(K2, K3, D2, K8 по той же мере) − 0,0005;
  3. `crit_panel` без 1 % дат с наибольшей |разностью QLIKE| к лучшему из K2/K3 по дате ≤ min(K2, K3, D2, K8 по той же мере) − 0,0005.
  Числа порогов записываются в `CHECKPOINT.json` листом 0 до первой конфигурации. Подтверждающие окна 2022+ в выборе не участвуют.
