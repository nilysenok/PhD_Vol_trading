# R2, агент G: воздержание (16), усадка к эталону (18), знак × δ (20) — код и дым

Протокол v4 (`docs/zadaniya/2026-10-26_vtoroy_raund_gibrida.md`, § 6 и § 7, строка G). Ветка `r2-G-abstain`. Журнал — `docs/otchety/dev_log_r2_G.md`.

## Что сделано

- **Модуль** `scripts/analysis/r2_gate_abstain.py`, yaml `models/designs/r2/r2_G_abstain.yaml`.
- **Входы.** Нога L и гибриды-компоненты seed × lib (B, M, E) берутся через `r2_core.load_series` по хэшу дизайна-кандидата. Коррекция c_j = ln ŷ_j − ln ŷ_L, c̄ = ln mean ŷ_j − ln ŷ_L.
- **Кластер 16**, ŷ = нога · exp(g_t·c), g_t ∈ [0, 1]:
  - `conf_seed`: g = 1{SD_j(c_j) < τ·|c̄|}, τ ∈ {0,25; 0,5; 1; 2; 4};
  - `regime`: g = P(спокойно на горизонте h). Привратник кластера 13 собран из функций E (`_gate`, `prep`, `_z`). Обучение — годы < vy с эмбарго h, метка — ln y_h ниже медианы тикера;
  - `shock_fresh`: g = 0 в первые k ∈ {3, 5, 10} торговых дней после скачка RV рынка выше q-квантиля прошлых 250 дней, q ∈ {0,9; 0,95; 0,99}. RV рынка — среднее rv_d d0 по всем тикерам;
  - `halt`: g = 0 для окон цели через 28.02–23.03.2022. Умножается на g любых ворот. В отборе ничего не меняет, функция `halt_g` готова для сборки A;
  - `soft`: g — выход `r2_ens.uncert_shrink` агента E (импорт, без дублирования), τ — сетка E.
- **Кластер 18.** ln ŷ = ln HAR + λ·(ln ŷ_канд − ln HAR), λ ∈ {0,25; 0,5; 0,75; 1}. HAR — эталон В2 (har_corr).
- **Кластер 20.** ln ŷ = ln ноги + δ·s, δ ∈ {0,1; 0,2; 0,3}. Два варианта s:
  - `znak`: s = sign(c̄);
  - `dolya`: s = 2p − 1, где p — доля компонент с c_j > 0 (аналог Д19.3).
- **Выбор τ, k, q, λ, δ** — вложенно в складке Y по годам T \ {Y}:
  - критерий — максимум средней панельной t против эталона, при равенстве — средний QLIKE;
  - панельная t — `ftp_stats.dm_main`, заглушка до `r2_gates.panel_t` агента O, хук уже в коде;
  - справочно есть режим «по прошлым шагам».
- **Выход.** Ряды G16_* / G18_* / G20_* — ансамбль и каждый seed — пишутся `write_series` в каталог кэша кандидата, modul = G. Параметры по шагам — `<кэш>/params.csv`. Прогнозы — только val 2017–2021.
- **Обвязка:**
  - `shift_check` для каждого ряда;
  - детектор «будущее не влияет»: при фиксированных параметрах возмущаются ряды, эталон и матрица d0 после среза; подлог d+1;
  - граница года — эмбарго привратника.
