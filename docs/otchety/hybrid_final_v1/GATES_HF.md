## Правила, объявленные до счёта (HF1–HF12)
- **HF1 (компоненты, замороженные).** `data/regen/xgb_lgbm_full_v1/e/components.parquet`: HAR = HAR-J(б) (PIT, OOF по построению), XJ = XGB `x2_best_j`, LF = LGBM `C0_inh_F4`, seed 42–46 — контроль. Лучший самостоятельный бустинг S* = минимум `crit_wf` из {XJ, LF} (R2 Ж-210; `d_comp.crit_wf`: pen_Y = mean_{y<Y} ann_y + 0,25·(max−mean), среднее по Y = 2018…2026). Residual R1 — ряды `b_B1q_s42`, `b_B2q_s42` (Ж-210, переносятся без пересчёта; g = ln σ̂² − ln HAR; объектив QLIKE, offset ln HAR + c0; градиент/гессиан проверены тестами `test_v2_xl_e_bfit.py`). Ж-204/206/210 не повторяются.
- **HF2 (реестр и N).** `ALL_TRIALS.csv` = Ж-204 (106, `sber_h1_deep_v1/OPTUNA_TRIALS.csv`) + Ж-206/210 (182: xgboost 75, lightgbm 72, ensemble 35) + пилот Ж-200/202 (189 уникальных прогнозов семей p1/p2/p3/pb/fix_a/fix_c из `INVENTORY.csv`; верхняя оценка — включены и базовые ряды p1) = **N_prior = 477**; новые trials Ж-211 дописываются (`hf_ledger.register`). **N для всех поправок = N_prior + число новых trials Ж-211 на момент статистики (≤ 537); объявляется в `CHECKPOINT.json` до E-статистики.** Справочно: N = 288 + новые (как Ж-210/Ж-204 D) и N = 182 + новые. Холм: `stats_d.holm_n(p, N)` — недостающие до N p = 1; семейство первичных сравнений — тесты A/B/C всех финалистов по всей истории.
- **HF3 (бюджет ≤ 60; единица = одна уникальная конфигурация с зафиксированными параметрами, правило выбора по прошлому с объявленной сеткой = 1 trial; повтор того же cfg — не новый).** residual XGB ≤ 15, residual LGBM ≤ 15, ограниченная коррекция ≤ 10, динамические веса ≤ 10, режимы ≤ 10. Превышение — стоп (`register` бросает ошибку). Счётчики — `CHECKPOINT.json`. Не использованное не тратится.
- **HF4 (R2, ограниченная коррекция; 10 trials).** `σ̂² = HAR·exp(clip(g, −c, c))`, g из R1 (B1q — XGB, B2q — LGBM). Сетка c ∈ {0,10; 0,20; 0,35; 0,50} (c = ∞ — это R1, переносится) × 2 модели = 8 trials + правило `R2_wf` (по 1 на модель) = 10. Правило `R2_wf`: на дате d c = argmin среднего QLIKE закрытых прогнозов (target_date ≤ d, расширяющееся окно) по сетке {0 (=HAR-J), 0,10; 0,20; 0,35; 0,50; ∞}; пока закрытых < 252 — c = 0 (HAR-J). Ничья — меньший c. c по будущим ошибкам не выбирается.
- **HF5 (R3, shrinkage; λ ∈ [0,1]).** `σ̂² = HAR·exp(λ·g)`; λ = 0 ⇒ побитно HAR-J (тест), λ = 1 ⇒ R1 (перенос). Сетка λ ∈ {0,25; 0,50; 0,75} × 2 модели = 6 trials (в бюджете residual XGB/LGBM, по 3) + правило `R3_wf` (по 1 на модель; сетка {0; 0,25; 0,5; 0,75; 1}, закрытые прогнозы, расширяющееся окно, до 252 закрытых λ = 0, ничья — меньшее λ) + совместное правило `R23_wf` (по 1 на модель: c × λ на сетке {0,10; 0,20; 0,35; 0,50; ∞} × {0; 0,25; 0,5; 0,75; 1}, то же окно и умолчание) — 5 trials на модель.
- **HF6 (R4, признаки корректора; этап VI).** R4 не создаётся по компонентам заранее. Группы: F1 динамика RV, F2 скачки, F3 полувариации/доходности, F4 квартичность/vov/range, F5 рынок IMOEX, F6 режим/смещение HAR (`feats_b2`, PIT, доступны на d). Кандидатные наборы выбраны по EX1 Ж-210 (ridge годовой LOYO: полезны F3 −0,0060, F5 −0,0035, F4 −0,0014; вредны F1, F2, F6) — **потолок** (отбор групп видел историю): `S345`, `S34`, `S35`, `S3` (4 retrain на модель), затем обратная абляция лучшего набора по `crit_wf` (≤ 3 retrain на модель) и одно правило `R23_wf` на лучшем наборе (1 на модель). Retrain — `bfit.run` (те же HP годового выбора И2, offset ln HAR + c0, seed 42, ежедневное переобучение, расширяющееся окно, пары t+1 ≤ d). Итого residual XGB: 5 + ≤ 7 + 1 = ≤ 13 ≤ 15; LGBM то же. Шесть шагов п. 10 блока для каждого набора: (1) доступность на d — тест порчи будущего; (2) связь с будущей ошибкой HAR — ridge LOYO (`diag`); (3) добавленная информация — ΔQLIKE к R1 и к HAR; (4) QLIKE; (5) по годам; (6) обратная абляция.
- **HF7 (динамические веса; ≤ 10 trials).** Переиспользуются A1–A4 Ж-210 (постоянный fixed_loyo, inv_qlike_252, roll_126/252, shrink_252 — не повторяются). Новое: сглаживание и ограничение скорости. Цель веса — `roll_126` (пара HAR+XJ, H1) и `roll_252` (HAR+LF, H2; HAR+XJ+LF, H7) из `rules.weights`. (а) EMA веса с полупериодом h ∈ {21; 63} (α = 1 − 2^{−1/h}): H1 2, H2 2 = 4; (б) ограничение скорости |Δw_i| ≤ r за день, r ∈ {0,005; 0,02}, затем нормировка на симплекс: H1 2, H2 2 = 4; (в) H7: EMA h = 63 и ограничение r = 0,02 над `roll_252` = 2. Итого 10. Начальный вес — равный; вес на d использует только закрытые прогнозы. Выбор лучшего из каждой пары — min `crit_wf`; устойчивость — разность `crit_wf` соседних значений (h, r) ≤ 0,0005 = «плато».
- **HF8 (режимы; этап IV).** Режимная конструкция допускается только при подтверждённом взаимодействии «режим × относительная ошибка»: dq_t = QLIKE(HAR) − QLIKE(ML) на цели d+1, ML ∈ {XJ, LF}. Режимы на d (всё по прошлому): V1 терциль ln RV_w (RV_w = среднее 5 дн.), V2 терциль ln(RV_w/RV_m) (m = 22), V3 знак Δ ln RV_w(5), V4 скачок за 22 дня (`f2_jfreq22 > 0`), V5 терциль рыночной RV IMOEX в виде `f6_mkt_chg` = ln(RV_w/RV_m) IMOEX (уровень рыночной RV в сохранённых признаках отсутствует — ↺ заменено относительным уровнем; PIT-терцили), V6 знак прошлой разности суммарных потерь HAR − ML за 63 закрытых. Терциль — `pit.past_bucket(x,[1/3,2/3])` (пороги по 252 предыдущим, без текущего). Тест: OLS dq на индикаторы групп (константа + k−1), ковариация Ньюи–Уэст (лаг 5, Бартлетт), Вальд χ²(k−1); 6 × 2 = 12 тестов, Холм по 12. **Взаимодействие подтверждено** для (V, ML), если Холм-p < 0,10 на всём периоде и без 24.02.2022 и знак (среднее dq группы max − группы min) совпадает в 2017–2021 и 2022–2026. Нет ни одного — режимная конструкция отклоняется: `ABANDON HF-G8 причина`, 0 trials режимов. Есть — режимные гибриды (≤ 10 trials): веса по группе (`rules.w_group`, прошлые закрытые, `min_group = 60`) только по подтверждённым V; пороги и веса — по прошлому.
- **HF9 (сводка H1–H7, этап V).** H1 HAR+XGB, H2 HAR+LGBM, H3 residual XGB, H4 residual LGBM, H5/H6 conditional (режимный гибрид или, при ABANDON, лучший адаптивный C Ж-210 — C6/C5 — с пометкой), H7 HAR+XGB+LGBM. Каждый — против соответствующего самостоятельного бустинга. H7 допускается как отдельный вариант, только если A4/H7 лучше H1 при DM p < 0,10 (иначе — «второй бустинг не добавляет», корреляция потерь XJ/LF 0,998).
- **HF10 (период и срезы, этапы VII–VIII).** Периоды: P1 2017–2021, P2 2022, P3 2023–2025, P4 2026 (неполный), «ранний» 2017–2018, «поздний» 2019–2026, вся история, без 24.02.2022. Годы с выигрышем = число лет из 10, где QLIKE модели < QLIKE опоры. Диагностика: без лучшего года, без топ-5 вкладов дней, спокойный/стресс (Г4), терцили RV. Тесты A (к HAR-J), B (к XJ), C (к LF): DM (Ньюи–Уэст лаг 5, `evalrows.vs`; d = QLIKE(модель) − QLIKE(опора), минус — модель лучше), блочный бутстрап (блок 20, 5000, seed 42, `stats_d.boot_delta`), ДИ 95 %; p сырые и Холма с N по HF2. Постселекционная оговорка в каждой строке.
- **HF11 (критерии успеха; объявлены до счёта).** Модель M, опора H = HAR-J, S* = лучший бустинг по HF1.
  - **Уровень 1 (над HAR-J)** = все: (а) `QLIKE(M) < QLIKE(H)` на всей истории и `crit_wf(M) < crit_wf(H)`; (б) знак Δ(M−H) < 0 минимум в 2 из 3 периодов {P1, P2, P3} и Δ < 0 без 24.02.2022; (в) сырой DM-p теста A < 0,05 и 95 %-ДИ бутстрапа для Δ целиком < 0; (г) p Холма (N по HF2) теста A < 0,10. Выполнено (а)–(в), но не (г) — «L1 только сырой», уровень 1 не засчитывается.
  - **Уровень 2 (самостоятельная ценность)** = все: (а) уровень 1; (б) `crit_wf(M) < crit_wf(S*) − 0,0005` и Δ(M−S*) < 0 на всей истории; (в) сырой DM-p теста B < 0,05, ДИ бутстрапа Δ(M−S*) < 0, p Холма (N по HF2) < 0,10; (г) **не сосредоточено в 2017–2018:** Δ(M−S*) < 0 минимум в 2 из 3 периодов {2019–2021, 2022, 2023–2025}, Δ < 0 на «позднем» 2019–2026 и DM-p на «позднем» < 0,10; (д) тест C: Δ(M−другой бустинг) < 0 на всей истории. Выполнено только L1 — гибрид сохраняется как EXPERIMENTAL и не заменяет принятую самостоятельную модель (п. 14 блока). L2 не достигнут — SBER закрывается без нового цикла подбора.
  - Всё, что выше, — относительно потолка: выбор конфигураций и критериев видел те же данные; «подтверждено» = только при выполнении (г)/(в) с Холмом.
- **HF12 (учёт).** Процессов ≤ 6 (spawn-пул 4), стадии по одной через run_in_background; не коммитить; `test_locked/`, `*_test.*`, `.env` не читаются. Данные — только список задания. Знак в аналитике — QLIKE `models_v2/metrics.py`.
