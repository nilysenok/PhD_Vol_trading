## Определения и реализация (`scripts/analysis/d19_signal.py`)
- **hyb₁** — нога финалиста h=1 D12_h1_A_d812, XGB top5, до поправки; на шагах без топ-5 берётся single, как в `gibrid_io`. Val берётся из `D12_h1_A_d812_xgb_h1_top5_val`. На тесте — `xgb_raw` из `test_locked/final2/final_h1_test.parquet` (дизайн top5/V0_XGB/B-sm), только для сборки.
- **HAR₁, HAR_h** — HAR-J шага (`gibrid_har.har_forecasts`, матрица `features_pit_v3`, совпадает с `har_raw` final2 до 0).
- **r̂₁** = ln hyb₁ − ln HAR₁ — только OOS: val шага s — прогноз года 2015+s моделью шага s. Поправка s² по правилу (с шага t−1) делается в `gibrid_v17.py` для итогового прогноза кандидата. Поэтому обе ноги r̂₁ берутся без поправки, и на val, и на тесте.
- **Д19.1**: ln ŷ_h = ln HAR_h + ρ_h·r̂₁.
  - ρ_h — OLS без константы остатка ln RV_h − ln HAR_h на r̂₁ по val шагов 1..s−1 (OOS-прогнозы прошлых шагов); для шага 1 — свой val-год.
  - Тест шага s — ρ по val шагов 1..s.
- **Д19.2**: ρ_h — средний за дни 1..h отклик ln RV на шок +1 в день 1, рекурсия дневной HAR-J шага по коэффициентам b_d, b_w/5, b_m/22. Скачки не шокируются, подгоняемых параметров нет.
- **Д19.3**: LGBM binary на P(ln RV_h > ln HAR_h). Метка строится по in-sample HAR-J окна шага.
  - Гиперпараметры — `D12_h{h}_selected` (lgbm по шагам, деревьев = best_iteration).
  - Признаки — числовые столбцы `features_pit_v3` без целей. Это ↺: не точная матрица L2 у D12.
  - ln ŷ = ln HAR_h + δ(2p−1). δ ∈ {0,1; 0,2; 0,3} выбирается по QLIKE с оптимальным масштабом на val шага t−1 (для шага 1 — на своём).
- **Д19.4** (= Д18.1 × Д19.1, h=22), уровень RV: ŷ = (5·hyb₅ + 17·exp(ln HAR₆₋₂₂ + ρ·r̂₁))/22.
  - hyb₅ — нога D12_h5 (wrap2, XGB-слот, до поправки; тест — `xgb_raw` из `final2/final_h5_test`).
  - HAR₆₋₂₂ — HAR-J шага на цель (22·mean₂₂ − 5·mean₅)/17.
  - ρ — как в Д19.1, на дальнюю цель.
  - HAR₆₋₂₂ построен самостоятельно, затем сверен с `D18_har_sub_h22_6_22_val`: ln-отношение в среднем −0,002, max 0,048, корреляция 0,99986. Причина различия — эмбарго в Д18; у HAR-J финалов эмбарго нет.
- **Варианты с ногой Д16.5** (решение владельца 01:40, только h=22). Нога Д16.5 — XGB single, лучшая V0-нога Д16.5 в гибриде.
  - **D19_1x**: слоты гибрида — Д19.1 и Д16.5.
  - **D19_4y**: слоты — Д19.4 и Д16.5.
  - **D19_4x**: дальняя часть с сигналом Д16.5: ln far = ln HAR₆₋₂₂ + ρ·r̂₁ + κ·(ln Д16.5 − ln HAR₂₂), ρ и κ — OLS без константы по OOS-истории. Второй слот — Д16.5.
  - **D19_3x**: классификатор на матрице Д16.5 (`features_pit_v3_d165`, `build_features(cfg={})`, `step_data('Bv2b')`), гиперпараметры `D16_5_h22_selected`.
- **Оценка** — `gibrid_v17.py --legs single --blend rv --features features_pit_v3` (OOS, без `--confirm`). Сводка — функциями `final3.designs/summarize`: представитель — лучший дизайн по правилу третьего круга (число нарушений, затем 2017–2020), V0_HAR исключён.
  - Отдельно показана одиночная модель-кандидат (V0_XGB).
  - Отложенный 2021 сравнивается с текущим лучшим кругов 1–2 из `final3_dry/incumbent.csv`: h=5 — F2m_h5 0,1553; h=22 — D12_h22 0,1404.

## Утечки: детектор `python3 scripts/analysis/d19_signal.py --leak` (`data/regen/D19/leak_test.txt`)
- (а) r̂₁ на val — прогноз года 2015+s моделью шага s (`year == 2015+step` для всех строк): OK.
- (б) ρ₁ для val шагов 2–9 не меняется при порче r̂₁ и остатков шагов ≥ s: OK.
- (в) Коэффициенты HAR-J h=1 и ρ₂ шага s не меняются при порче всех данных начиная с val-года шага s: OK.
- (г) Ноги Д16.5 и D12_h5 на val: год шага прогнозируется моделью шага: OK.
- (д) ρ и κ для val шага s в Д19.1, 19.4 и 19.4x совпадают с оценкой по шагам ≤ s−1: OK.
- Оговорка. Как и у HAR-J финалов, в обучающем окне шага остаются цели последних дней года перед val-годом. Окно этих целей (t+1..t+h) заходит в val-год. Д18 убирает такие строки эмбарго; расхождение HAR₆₋₂₂ с Д18 — до 0,048 по ln, в среднем 0,002.
