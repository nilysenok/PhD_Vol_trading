## П. 2. Деньги по времени

Код — Л-3, п. 2; рынок — Л-4, п. 2.

- **Капитал, занятый позицией.** Считается по 5-минутным барам: с бара исполнения входа по бар выхода включительно. Строка t — интервал [close t; close следующего дня). Свободная доля — `1 − занятые бары / бары дня` (`exec_e.py:100-103`). Вход рынком по close d в занятость дня d не входит (Л-3, 2.1).
- **Ставка на свободное.** Ключевая/365 × календарные дни: со строки пятницы начисляются 3 дня (`s9.py:496-497, 612-616`). Выход по close — ставка «с вечера выхода». Выход внутри дня — ставка по доле свободных баров. Отдельного времени «15:00» в коде **нет**, отсечки 18:40 **нет**. Окно — 09:50–18:50, close Н6 — бар 18:40–18:50 (Л-3, 2.2).

Л-3, п. 6.
- **mSR** считается на дневном избыточном ряду: `excess = r + fdr − mg − rf·cal`, то есть со ставкой на свободное и за вычетом ставки на весь капитал. Шкала — Cornish–Fisher, ddof = 1, `nan` при mVaR ≤ 0. Целевая — min по годам (`etap1_eval.py:187-199`, `metriki_e.py:55-61`).
