# R2, агент R — кластер 15: адаптивное обновление и оценивание под критерий (26.10, по Маку)

1. **Где.**
   - Код — `scripts/analysis/r2_refit.py`, yaml — `models/designs/r2/r2_R_refit.yaml`, записан до счёта.
   - Ядро — `r2_core.py` агента S (schema_v2, режим R2). Слой калибровки — `r2_calib.py` агента L (PR #183).
   - Драйвер — `r2_driver.py` агента S (PR #184), модуль R вызывается по контракту `run` / `leak`.
   - Код первого раунда не правился; `harx` и `gibrid_har` только импортируются.
2. **Нога** — HARJ и HARX (S1–S5 = `harx.TERMS`).
   - Решение строится по взвешенной матрице Грама.
   - HAR-J без штрафа, слагаемые — эластичная сеть (Фриш–Во). Совпадает с `harx.fit_en` на всех 9 точках `leg.enet`.
   - Каждая точка сетки — свой ряд `R__l<λ>_a<α>`, выбор делает O.
3. **`leg.refit`** — переоценка на 1 янв. / начала кварталов / начала месяцев val-года.
   - Строки обучения — дата < c и конец окна цели < c (эмбарго h по концу цели).
   - В каждой точке стоит охрана assert, минимальный разрыв пишется в params (`R.guard.min_gap_days`).
4. **`leg.rls_lambda`** (0,995 / 0,99) — RLS с забыванием в точной форме.
   - Коэффициенты пересчитываются на каждый торговый день t: взвешенный МНК, вес λ^(возраст в торговых днях), строки с концом цели < t.
   - Selftest: это совпадает с рекурсией RLS < 1e-6. Работает для HAR и HAR-X.
5. **`leg.estimator = qmle_level`** — E[RV̄_h] = exp(x'β), гамма-потеря (по уровню она совместима с QLIKE).
   - Ньютон с тёплым стартом от прошлой точки переоценки.
   - Selftest: гамма и пуассон состоятельны, у ln-МНК константа смещена на E ln ε.
   - Калибровки и штрафа у QMLE нет.
   - Сравнение с `log_ols_calib` (нога + слой L) делает O по рядам.
6. **`boost.boost_refit`** — остаточный LightGBM (`role = residual`) на ноге дизайна.
   - Режимы: yearly; quarterly_warm (`init_model`, +75 деревьев, lr 0,03 фиксирован); monthly (заново с нуля).
   - `num_threads = 1`, deterministic, без ранней остановки: год валидации — только для оценки.
7. **`calib.update`** (step / daily) — слой L.
   - Свой слой — запасной, только для calib.* = default.
   - Контроль: свой слой = L, Δ = 0 в обоих режимах.
8. **Выход.** Ряды `R[__вариант]` (итог, для O s2 = bez) и `R_raw[__вариант]` (сырой) пишутся через `r2_core.run_phase` (DONE_R). Параметры по шагам — `R2/cache/<hash>/params.csv` (`design_sha, h, step, param, value` + `seed`, строки `R.*`).
