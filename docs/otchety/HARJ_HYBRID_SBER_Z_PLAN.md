## 3. Конфигурации этапа Z (5; N Холма 744 + 5 = 749, N_wide 3193 + 10 = 3203)

Обозначения:
- u_t = ln RV_{t⁺} − ln X1_d;
- потеря l = e^{u−g} − (u − g) − 1, то есть QLIKE прогноза F = X1·e^g;
- s_d — признак Y-A (`x1_ya_feat.features`);
- e_d — колонка s файла `x1.parquet`.

Везде g ≡ 0 ⇒ F = X1 побитно.

| № | Кандидат блока | Формула | Обучаемое | Совпадение с выполненным |
|---|---|---|---|---|
| **ZA** | А: общий корректор + уменьшение веса | g = ω·(b + a·s_d) | b, a — по всем закрытым парам с L2 λ; ω ∈ {0; 0,25; 0,5; 0,75; 1} | близко к Y2 при a_n = a_e. Отличия: свободный уровень b и явный вес ω, выбранный на валидации. В Y2 сжатие — только L2 |
| **ZB** | Б: специализированный корректор области e_d = 1 | g = e_d·(b + a·s_d) | b, a — только по закрытым парам с e_d = 1, L2 λ, валидация по экстремальным парам | подмодель Y2 с a_n ≡ 0, обучаемая только на области, плюс уровень b. В Y1/Y2 a_n свободен, функционал и валидация общие. X1 (E1) уже использует e_d для доверия π, но не для направленной поправки |
| ZB0 | контроль (а) к ZB: без сигнала | g = e_d·b | b | сдвиг уровня X1 на экстремальных днях; в X1 — только смешивание M и C |
| **ZC** | В: совместное обучение области и поправки | g = σ(γ0 + γᵀz̃_d)·(b + a·s_d), z_d = (e_d, x_d, s_d, v_d) | γ0, γ (4), b, a — совместно по QLIKE F; L2 λ на a, b, γ (не на γ0) | ближайшие: V7 MoE 4–8 (маршрутизатор + эксперты, совместно, но эксперты — полные остаточные модели без нулевого прогноза по умолчанию); V4 C-b (6 затворов между HAR и ML, не поправка над X1); V4 CLD (регрессия дифференциала потерь); NTP2 и X1 (доверие по прошлым потерям или состоянию). Затвор над специализированной поправкой с якорем «g = 0 вне области» на X1 не проверялся |
| ZCp | контроль (б) к ZC | как ZC, z_d → z_{d−252} циклическим сдвигом по всему ряду дат (поправка b + a·s_d — с настоящим s_d) | как ZC | — |

Признаки затвора (только бары дня d, известны на закрытии d):
- x_d = ln max_k r²_{d,k} − ln(RV_d / n_d) — концентрация в крупнейшем баре;
- v_d = ln RV_d − ln((1/20)·Σ_{j=1..20} RV_{d−j}) — неожиданность уровня;
- z̃ — стандартизация средним и σ по датам пула переоценки (≤ D).

Старт ZC: γ0 = −2, γ = 0, b = 0, a = 0. Градиент по b и a в старте ≠ 0, по γ = 0 до ухода b, a — тест.

## 4. Временной протокол (как Y-A, раздел 8 плана X1)

- **Переоценка.** Ежемесячно с 2018-07-02, пул — все пары X1 с t⁺ ≤ D. До включения F = X1 побитно, с пометкой.
- **Включение.** ZB и ZB0 дополнительно требуют ≥ 30 закрытых пар с e_d = 1 на дату включения. Если к 2018-07-02 их меньше — первая дата месяца, когда выполнено; до неё F = X1.
- **Штраф.** λ ∈ {0; 0,001; 0,01; 0,1}. Внутренняя валидация:
  - ZA, ZC, ZCp — последние V закрытых пар: V = 126 при n ≥ 252, иначе ⌊n/2⌋;
  - ZB, ZB0 — последние V_e закрытых пар с e_d = 1: V_e = 60 при n_e ≥ 120, иначе ⌊n_e/2⌋;
  - равенство — к большему λ; у ZA — затем к меньшему ω.
- **ZA.** (λ, ω) выбираются вместе: (b, a) обучаются на пуле без блока валидации, ω — по QLIKE блока; затем (b, a) переобучаются на всём пуле с выбранным λ.
- **Оптимизатор.** L-BFGS-B, |a|, |b| ≤ 5, |γ| ≤ 10. Без seed: детерминированный старт.
- **Запрещено:**
  - календарные правила;
  - выбор по ошибке будущего дня;
  - выбор по окну 2022+;
  - исключение лет или экстремальных дней из основной оценки.

## 6. Критерии (записаны до счёта; после просмотра не меняются)

**Подтверждение — без изменений:** правило 6.2 против X1 на 2018–2021 (Δ < 0, DM p < 0,05, ≥ 3 из 4 лет) и p Холма (N = 749) < 0,05. Иначе — «не подтверждено».

**Продолжение гипотезы** (решение разработки, не подтверждение; использует уже просмотренные 2022+). Нужны все пять условий:
- **K1** — весь период: Δ к X1 < 0;
- **K2** — нет вреда обычным дням: Δ к X1 в состоянии N за весь период ≤ +0,10 %;
- **K3** — устойчивость: Δ к X1 ≤ 0 не менее чем в 5 из 8 полных лет 2018–2025;
- **K4** — лучше своего контроля за весь период: ZB < ZB0; ZC < ZCp. ZA сравнивается с ZB;
- **K5** — нет вреда окну разработки: Δ к X1 на 2018–2021 ≤ +0,10 %.

Невыполнение любого условия — гипотеза закрывается с записью; направление не закрывается. При выполнении следующий шаг — уточнение механизма и протокол независимой проверки (раздел 8), а не «подтверждено».

## 7. Диагностика ZD (без конфигураций, без прогнозов)

**Вопрос:** предсказуема ли полезность поправки по информации до дня t⁺?
- D_t = l(Y2, t) − l(X1, t) по сохранённым прогнозам; то же для Y1 и Y3.
- **Описание.** Средние D по состояниям E/N × год.
- **Предсказуемость.** Помесячно с 2018-07-02 на закрытых парах (t⁺ ≤ D):
  - логистическая регрессия 1[D < 0] на z̃_d (L2, C = 1);
  - гребневая регрессия D на z̃_d;
  - база — только e_d;
  - контроль — z_{d−252}.
- **Метрики** по годам: AUC, ранговая корреляция прогноза с D, калибровка по децилям.
- **Только описание.** Выбора экспертов, прогноза и строки реестра нет.
