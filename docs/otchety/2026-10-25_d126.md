## 1. Квантильный остаточный ученик h=5
- Точка — L2_h5: V9 (цель ln RV_avg(t+1..t+5) − ln HAR-J) + Д8.12 (ln HAR-J как признак) + блок Д7; параметры LightGBM — `data/regen/L2_h5_selected_h5.csv` по шагам 1–9, **без поиска**. Единственное отличие — `objective=quantile, alpha=0,8`, ранняя остановка по pinball-потере val-года (patience 30, потолок 1000). Код: `scripts/analysis/d126_quantile.py`, рычаг `quantile` в `l2_lib.fit` (две строки).
- **Матрица: features_pit_v2 + d7_h5 (318 признаков + ln HAR-J), не v3.** На начало счёта `features_pit_v3.parquet` не было; она появилась в 20:39, когда счёт шёл. Блока Д7 на v3 нет (`d7_block.py` строит его от v2), поэтому точка L2_h5 на v3 — другой набор признаков (242), с параметрами, подобранными на другом. Справочный прогон на v3 без Д7 сделан (`sigma_pred_h5_q80_v3.parquet`, в главе 4 не использован). Пересчёт на v3 с Д7 — после появления d7 на v3.
- Сверка конвейера: тот же код с `objective=mse` воспроизводит val L2_h5 (LightGBM, шаги 2–4) с точностью 2·10⁻¹⁵ по ln-прогнозу (`--check`).
- Выход: `data/regen/sigma_pred_h5_q80.parquet` — `date, ticker, sigma_pred_h5`, 39 492 строки (те же даты и тикеры, что `sigma_pred_h1_v2`), 2017-01-03 … 2025-12-30, без пропусков; шаги — `sigma_pred_h5_q80_steps.csv`. σ = sqrt(HAR-J × exp(квантильный прогноз остатка)), дневные единицы, поправка Б0.1 не применяется (это квантиль, не среднее). HAR-J — тот же (МНК на ln, окно шага), что смещение V9 в L2_h5.
- Деревьев по шагам 1–9: 22, 285, 41, 33, 8, 154, 89, 1, 31 (на шаге 8 — одно дерево: прогноз = HAR-J со сдвигом квантиля).
- Сверка масштаба с `sigma_pred_h1_v2`: корреляция 0,89 (по логарифмам 0,91), медианное отношение 1,15 (p5 0,92; p95 1,42) — масштаб тот же (дневная σ), q80 выше среднего прогноза.
- Диагностика на val шагов 1–6 (разработочный набор; по нему же шла остановка): доля фактических RV ≤ прогноза q80 — 0,82; 0,80; 0,80; 0,87; 0,76; 0,80 (ориентир 0,80). Val шагов 7–9 не печатался.

## 3. Ограничения
- Один дизайн-пара, одна матрица (v2+Д7), 4 года dev, один seed: разница с h=1 (0,05–0,16 по периоду) — порядок шума бэктеста; вывод «улучшения нет», а не «хуже значимо». Годы 2022–2026 не открывались.
- Смена горизонта меняет сразу всё в дизайне: и уровень (q80 выше среднего), и информацию (h=5 вместо h=1), и сетки B/D. Эффект одного только квантиля при h=1 не разделён (квантильного ученика h=1 в круге нет).
- Пересчёт на v3 + Д7 (если блок будет построен) может изменить параметры точки; текущий файл помечен v2.
