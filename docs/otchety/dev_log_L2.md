# Журнал уровня 2 бустинга (dev_log_L2)

Каждая строка — один оценённый вариант (рычаг × h). Оценка на точке B (параметры `Bv2b_selected_h{h}.csv` по шагам; max_bin 255 — сообщение дирижёра 25.10 после проверки владельцем max_bin 63), XGB и LGBM переобучаются на шагах 1–6 (все строки окна, ранняя остановка по нативной метрике на val-годе шага, patience 30, потолок 1000), без подбора гиперпараметров. Метрика — средний val QLIKE на шагах 2–6 (val 2017–2021) лучшего из двух бустингов с поправкой Б0.1 ord, s² вне выборки (оценка по val-году шага t−1, как в гибриде `gibrid_bias.py`); для objective gamma (Д1) — без поправки. Справочно — лучший из четырёх оценок s² (ord/rob/sm/smrob). Правило: рычаг остаётся при улучшении метрики текущей комбинации ≥ 1% или при снятии нарушения ворот; иначе отбрасывается. Эталон ворот — HAR-J с поправкой ord (гибрид, шаги 2–6): h=22 — 0,2189 (порог ×1,05 = 0,2298), h=5 — 0,2275 (порог ×1,00). Тест и подтверждающий набор (val шагов 7–9) не считались. Код: `scripts/analysis/l2_lib.py`, `l2_run.py`; выходы `data/regen/L2/` (`levers_h{h}.csv` — все варианты с метриками по моделям и оценкам s²).
