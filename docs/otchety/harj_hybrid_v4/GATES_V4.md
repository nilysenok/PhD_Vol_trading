## Договорённости программы (объявлены до счёта, 08.11.2026)

- **Обучение и выбор**: только 17 бумаг `fastbt/data.py` TICKERS; критерий выбора — `crit_panel` = среднее по M16 (17 без SBER) QLIKE на целях 2017–2021, walk-forward. SBER — отдельная диагностика, выбор по нему не делается. E11 — только перенос зафиксированной модели (Ж-220).
- **Базовые прогнозы не переобучаются**: H = K1 (HAR-J PIT, `har_<T>.parquet` / `engine_panel_p17.parquet`), M ∈ {K2 XGB, K3 LGBM} (`k23_<T>.parquet`); контроль LGBM-D2 (`hyb_lgbm_p17.parquet`). Перед использованием — аудит соответствия цели RV, дат, источников и PIT (лист V4-0).
- **Мета-слой** обучается только на закрытых парах (цель t⁺ ≤ d) прошлых дней, параметры дня d определены до d+1. Oracle — только диагностика: код oracle не импортируется путями прогноза (тест).
- **Метрики**: QLIKE (основная, определение проекта как в `models_v2.s10`), RMSE, MAE, R²; панельный DM (НУ лаг 5); блоковый бутстрап по датам; MCS 90 %; окна 2017–2021 (выбор), 2022–2025, 2026 (неполный), вся история.
- **N Холма** = все ранее просмотренные конфигурации h = 1 по этим бумагам (по реестрам, лист V4-0) + 60 (бюджет программы); объявляется в `CHECKPOINT.json` до первого p.
- **Stop/go этапа** (Ж-222 п. 12; толкование п. 6): «go» — лучшая конфигурация этапа имеет `crit_panel` ≤ min(K1, K2, K3, LGBM-D2 по `crit_panel`) − 0,0005; иначе этап закрывается отрицательным результатом и в сочетания J не идёт. Подтверждающие окна 2022+ в выборе не участвуют.
- **Не повторять**: архитектуры A–D панели (Ж-217–Ж-220), завершённые исследования линии SBER (Ж-211 `hybrid_final_v1`, Ж-212 `hybrid_struct_v1`, Ж-214 `harj_hybrid_v2`) — реестр «что уже сделано» в V4-0; повтор допустим только как воспроизведение контроля, без расхода бюджета.
