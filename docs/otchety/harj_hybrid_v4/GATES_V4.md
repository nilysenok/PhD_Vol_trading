## Этап B — QLIKE-оптимальные операторы объединения (задание `docs/zadaniya/2026-11-08_harj_v4_B.md`), 6 конфигураций

Объявлено до счёта (08.11.2026): H = K1; M = √(K2·K3) (B1–B5); оценка параметров — в первый торговый день каждого месяца по всем закрытым парам (t⁺ ≤ d) 17 бумаг с 2017-01 (расширяющееся окно); иерархия θ_i = θ_panel + δ_i, штраф κ·Σδ_i² с κ = 250 пар-эквивалентов; приор w₀ = 0,5 (B6: a = b = c = 1/3) с силой 250 пар; до первых 60 закрытых пар — приор. Минимизируется средний QLIKE на парах + штрафы. Гиперпараметры (κ, сила приора, частота) фиксированы, не выбираются.
- B1 арифметическое `F = w·H + (1−w)·M`, w ∈ [0, 1].
- B2 геометрическое `F = H^w · M^(1−w)` (выпукло по w, Ньютон).
- B3 гармоническое `1/F = w/H + (1−w)/M`.
- B4 степенное среднее `F = (w·H^p + (1−w)·M^p)^(1/p)`, p ∈ [−2, 2] — общий для панели, w — иерархический.
- B5 ограниченная экстраполяция `F = H^w · M^(1−w) · exp(b)`, b ∈ [−0,15; 0,15] иерархический — **только если** правило: по OOF-прогнозам B2 на M16 × 2017–2021 c = mean(RV/F_B2) отличается от 1 (НУ-t по датам, |t| ≥ 1,96) и средние log(RV/H) и log(RV/M) того же знака; иначе B5 не считается, 1 конфигурация уходит в резерв.
- B6 три эксперта `F = H^a · K2^b · K3^c`, a + b + c = 1, a, b, c ≥ 0, иерархический.
