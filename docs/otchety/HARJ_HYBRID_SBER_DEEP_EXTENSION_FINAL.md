## 3. Математика X1–X4; вычеркнутые дубли

QLIKE(F) = RV/F − ln(RV/F) − 1; u = ln(RV/F) (u > 0 — недооценка); H — HAR-J (K1); M = √(K2·K3); C = cfg8 V7; Z — признаки режима V7 (9), S — признаки V6 (9); e_d — экстремальный M10-бар дня d (PIT-порог 99 % по барам сессий до d).

- **X1 (D1, основная).** F = M^(1−π_t)·C^(π_t), π_t = π^(s_t), s_t = e_d. π^(s) — экспоненциальные веса с долей α^(s) ∈ {1 %, 2 %, 5 %} (внутренняя валидация, последние 126 закрытых пар), обновляются только на закрытых парах своего состояния, старт π = ½. π ≡ 0 даёт F = M побитно; при общем π для двух состояний — NTP2.
- **X2 (D2).** F = H·[(1 − p_t)·c_n(Z) + p_t·c_s(Z)]; p_t — логистика на метке «RV(t⁺) выше PIT-перцентиля 90 закрытых пар»; c = exp(tanh(·)), линейные по Z; потеря QLIKE(F) + β·BCE(p), β ∈ {0,1; 1} — внутренняя валидация. c_n = c_s = 1 даёт F = H побитно.
- **X3 (B1).** F = H·exp(g_s + a_t·g_a); g_s — сохранённая A0g; g_a — QLIKE-гребень по Z на последних 250 закрытых парах; a_t ∈ [0; 1] — сигмоида от CUSUM разности прошлых QLIKE «с g_a» и «без». g_a = 0 даёт A0g побитно.
- **X4 (C1).** F = H·exp(α_t·ḡ); ḡ — среднее 5 QLIKE-GBM на окнах: расширяющееся и 750 / 1000 / 1250 / 1500 закрытых пар; α_t = exp(−κ·sd_r/s̄), κ ∈ {0,5; 1; 2}. α ≡ 1 — справочный ряд «ансамбль без затвора» (ENS, не конфигурация).

Вычеркнутые дубли (план, раздел 2):

- **A1** (прямой QLIKE-бустинг F = H·e^g(Z)) ≡ V6 A0g / A2 — та же потеря и форма, отличается только библиотека.
- **A2** (мультипликативная калибровка c(Z) = E[Y/H | Z]) ≡ A1. Доказательство: для F = H·c производная по c ожидаемой потери E[ln(H·c) + Y/(H·c) | Z] равна 1/c − E[Y/H | Z]/c², она обращается в нуль при c* = E[Y/H | Z]; QLIKE-оптимальная мультипликативная поправка — условное среднее Y/H, разница между A1 и A2 только в оценивателе.
- Hybrid-XGBoost против Hybrid-LightGBM ≡ Ж-211 H7 / V6: второй бустинг на тех же признаках — один источник информации.
- Адаптивная HAR-J ≡ V4 E1–E6, Калман, RQC1–3: скалярная калибровка уровня по прошлому.
- Bespoke RV — V7+ (Ж-237), не здесь; orthogonal / alternating «бустинг + энкодер» ≡ V4 H + V7 (признак z без сигнала).
