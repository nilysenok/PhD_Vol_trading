# Ансамблевая обёртка финального V9 (h=5, h=22)

Решение владельца 25.10, 19:40. Без поиска: к точке optuna-30 уровня 2 (`data/regen/L2_h{h}_selected_h{h}.csv`) применены четыре компонента обёртки. Подтверждающий набор (val шагов 7–9) и тест не открывались: тестовые прогнозы записаны в `data/regen/test_locked/wrap/` и не оценивались. Журнал — `docs/otchety/dev_log_wrap.md` (продолжение `dev_log_L2.md`).

## Протокол
- Точки: h=22 — V9 + LightGBM linear_tree λ=1 (`L2_h22`, без блоков); h=5 — V9 + Д8.12 (ln HAR-J как признак) + блок Д7 (`L2_h5`, матрица `features_pit_v2_d7_h5.parquet`). Обучение — `l2_lib.fit`: все строки окна, ранняя остановка на val-годе шага, patience 30; бины окна шага 1 для шагов ≥ 2.
- Сверка: переобучение лучшей точки с seed 42 воспроизводит прогнозы поиска (максимальное относительное расхождение ≤ 4e−15).
- Исходный V9 — лучший из двух бустингов по метрике уровня 2: на обоих h это LightGBM (h=22 — 0,2031, h=5 — 0,2044). Компоненты 1a, 1b, 3, 4 применяются к нему, компонент 2 добавляет XGBoost.
- Усреднение — по прогнозу RV. Внутри модели и шага берётся среднее членов: {лучшая точка} ∪ 1a ∪ 1b ∪ 4. Затем применяется 3, затем 2. Поправка Б0.1 ord ставится к итоговому прогнозу вне выборки: s² оценивается по остаткам val-года шага t−1, как в `l2_lib.evaluate` и `gibrid_bias.py`.
- Метрика — средний val QLIKE шагов 2–6. Правило: компонент берётся, если он не хуже исходного V9. Все взятые компоненты проверяются вместе; если вместе хуже, компоненты убираются по одному, начиная с худшего.
- Компоненты:
  - **1a** — среднее топ-10 испытаний поиска шага, отобранных по val QLIKE шага; seed 42, прогнозы из `L2_h{h}_allpts_*`.
  - **1b** — среднее пяти seed (42–46) лучшей точки.
  - **2** — среднее V9-LightGBM и V9-XGBoost. V9-XGB — лучшая точка XGB того же поиска.
  - **3** — среднее моделей шагов t и t−1. Модель шага t−1 — её лучшая точка с seed 42; она предсказывает те же даты, то есть свой тестовый год, совпадающий с val-годом шага t. На шаге 1 пары нет.
  - **4** — бэггинг по пяти подмножествам из 70% признаков (seed 42–46), среднее; признак har_ln (Д8.12) остаётся всегда.
- Код — `scripts/analysis/wrap_v9.py`. Обучено 196 моделей на каждый h: 76 с на h=22 и 167 с на h=5, 6 воркеров.

## Ограничения
- Проверка смещена в пользу исходного V9. Лучшая точка выбрана по тому же val QLIKE шага с seed 42, и её ранняя остановка идёт на том же val-году. Поэтому средние по точкам (1a), seed (1b) и признакам (4) сравниваются с победителем отбора на тех же данных. Их проигрыш (+1–4%) — отчасти плата за этот отбор, а не только свойство компонента.
- Компонент 3 проигрывает сильнее других (h=22: +9,5%). У модели шага t−1 окно короче на год, и её ранняя остановка шла на более старом val-году.
- На h=22 компонент 2 отличается от V9 на 0,02%, на уровне шума; по правилу «не хуже» он отброшен. Отметим, что правило выбора гибрида на h=22 предпочло V0_XGB с тремя seed (seeds3), то есть другую ногу.
- На h=5 выигрыш компонента 2 (−0,7%) мал и получен на одном наборе val-лет.
- Тестовые прогнозы шагов 7–9 строятся без 1a: для этих шагов в поиске нет топ-10 испытаний, они используют точку шага 6. Для итоговой обёртки h=5 (только компонент 2) это не важно.
