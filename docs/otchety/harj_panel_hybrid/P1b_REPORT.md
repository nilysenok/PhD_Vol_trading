## Контракт движка (что P2 должен знать)
- Вход — **уровень базы** `base` (> 0: K1 σ̂² или RV_m), а не ряд ln: offset = ln(base) (`base_margin` / `init_score`), итог σ̂² = base·exp(λ·(clip(g, ±c) [+ s²_g/2 при l2log])). Так λ = 0 даёт σ̂² ≡ base **побитно** (exp(ln x) ≠ x). Модель не обучена (нет g) — поправка 0.
- QLIKE: grad = 1 − RV/f, hess = RV/f (проверено численно); l2log — только для A2 (цель ln RV, s²_g — дисперсия остатка на блоке ранней остановки).
- Окно: расширяющееся, месячное переобучение в первый торговый день месяца панели; пары (j, s) всех бумаг с s⁺ ≤ d; ES — последние 126 дат окна (по s⁺), вне обучения, финальная модель — лучшая итерация без дообучения; `exclude` — LOTO.
- Глубина {2; 4} — два прохода; c ∈ {0,5; 1; 2}, λ ∈ {0; 0,25; 0,5; 0,75; 1} — при прогнозе (У-7); 2016 и года без закрытых прогнозов — умолчания R8 (глубина 2, c = 1, λ = 1; аргумент `default`).
- Выход на бумагу-дату: g, s2g, глубина, c, λ, σ̂², n_train, n_trees, fit_sec.
