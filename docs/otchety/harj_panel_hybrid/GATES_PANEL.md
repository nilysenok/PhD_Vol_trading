## Правила, объявленные до счёта

- **R1 (вселенная и группы).** 28 бумаг с M10 в `data/iss_check/bars_10m_full/` 2014–02.2026. Группы: **M16** — 17 основных (`fastbt/data.py` TICKERS) без SBER; **SBER** — отдельной строкой, «история просмотрена» (Ж-206…Ж-214); **E11** — GCHE MRKC MRKP MSNG MSRS PIKK RGSS SELG TGKA TRMK UTAR. Каждая бумага считается один раз (пересечение 17 ⊂ 28). Обучение панели — все 28; выбор (R9) — только M16 × 2017–2021. Сектор — справочник, заданный в P0 до счёта (только для отчёта и K-абляции, не признак основных конфигураций). `test_locked/`, `*_test.*` не читаются. Новых выгрузок нет.
- **R2 (RV и сетка).** RV, J, C, RS±, части дня, RQ, семиковариации с IMOEX — то же определение и тот же код, что у SBER в Ж-214 (`models_v2/s9/hv2_m10.build`, `models_v2/daily.py`); для SBER ряды обязаны совпасть с Ж-214 побитно. Пара (i, t): признаки — бары бумаги и индекса до отсечки дня t (как у SBER); цель — RV бумаги i в её **следующий собственный торговый день** t⁺. Пары с разрывом t → t⁺ > 5 календарных дней (в т. ч. закрытие биржи 25.02–23.03.2022) помечаются `gap`; входят в основной счёт, результаты без них — отдельной строкой. Оценочные даты бумаги — с 03.01.2017 (или с первой даты, где у неё есть HAR-J и ≥ 252 закрытых пар), до конца данных.
- **R3 (HAR-J каждой бумаги, K1).** A0 = HAR-J(б) Ж-214 V1 без изменений: ln RV_{t+1} = b0 + b_d ln RV_d + b_w ln RV_w + b_m ln RV_m + b_J ln(1+J_d), OLS на парах t⁺ ≤ d этой бумаги, ежедневная переоценка, σ̂² = exp(f + s²/2). PIT по построению (прогноз на t⁺ — модель по парам, закрытым к t), значит out-of-fold для обучения поправки (§2 Ж-217). Для SBER — побитно равно `components.har`.
- **R4 (межакционная синхронизация, §4 Ж-217).** Признак бумаги i на дату t может использовать данные бумаги j только за дни j, **закончившиеся не позже отсечки t**. Поперечные (панельные) величины дня t считаются по бумагам, у которых есть день t; бумага без дня t в поперечные величины дня t не входит (не ffill). Обучение поправки на дату d — только пары (j, s) всех бумаг с s⁺ ≤ d. Тесты: подмена дня t+1 любой другой бумаги не меняет признаки и прогноз на t (мутация «чужой день t+1» обязана падать); обрезка будущего всех бумаг после d не меняет прогноз на d.
- **R5 (признаки, безразмерные).** Нормировка — только по прошлому самой бумаги (расширяющиеся медиана/МАД или квантили, ≥ 252 дня). Группы (точные формулы — `P0_FEATURES.md`, фиксируются в P0 до счёта P2):
  - **X — индивидуальные:** состояние HAR (ln RV_d/RV_m, ln RV_w/RV_m, ln(1+J)/…, ln Ĥ − ln RV_m), закрытые лог-ошибки HAR (1/5/22), jump-доля, доли OPEN/MIDDLE/CLOSE и их отклонения, ln CLOSE/MIDDLE, RS⁻/RS⁺, ln rv_rel;
  - **M — рыночные:** состояние HAR IMOEX (ln RV_d/RV_m, ln RV_w/RV_m), панельная медиана ln RV_d/RV_m, поперечный разброс ln RV_d/RV_m, доля бумаг с RV_d > RV_w;
  - **C — межакционные и структурные:** реализованная корреляция с IMOEX (22), β² RV_m / RV_i, ln идиосинкратической части, асимметрия семиковариаций (cov⁺⁺ − cov⁻⁻)/(…), ранг ln RV_d/RV_m бумаги в панели дня t, отклонение от панельной медианы.
  - Идентичность бумаги (номер, сектор, ликвидность) — **не признак** конфигураций A, C, D; индивидуальность — только через B (R7).
- **R6 (поправка и функция потерь; §2 Ж-217).** f_{i,t⁺} = Ĥ_{i,t⁺} · exp(λ·g(X, M, C)), offset ln Ĥ (`base_margin` XGB / `init_score` LGBM). **Основная функция потерь — QLIKE** (L = ln f + RV/f; grad = 1 − RV/f, hess = RV/f; проверка численно), ограничение |g| ≤ c, c ∈ {0,5; 1; 2} по закрытым (R8). L2-лог (цель ln RV − ln Ĥ, σ̂² = Ĥ·exp(g + s²_g/2)) — только конфигурация A2. Переобучение g — раз в месяц (первый торговый день) на расширяющемся окне; HAR-J — ежедневно. λ = 0 ≡ HAR-J побитно на боевом пути (тест).
- **R7 (бюджет 24 = 10 XGB + 10 LGBM + 4 резерв; §7 Ж-217).** Один и тот же список для XGB (`X·`) и LGBM (`L·`), модули не смешиваются:
  - **A1** Global Panel Residual: одна g на 28 бумаг, признаки X+M+C, QLIKE-offset (основная);
  - **A2** = A1 с L2-лог (функция потерь);
  - **A3** = A1 только X (без M и C) — ценность рыночной и межакционной информации;
  - **A4** = A1 + признаки утверждённого XGB (Б-2 + F4, в безразмерной форме) — сверх самостоятельного бустинга;
  - **B1** Global + Individual: g = g_global(A1) + g_ind,i, g_ind,i = α_i — сдвиг бумаги, оцениваемый на закрытых остатках g_global с ридж-сжатием к 0 (κ по закрытым, R8);
  - **B2** = B1 с g_ind,i = α_i + γ_i·(ln RV_d/RV_m)_i — простая иерархия (сжатие α, γ к 0 тем же κ), без отдельного ML на бумагу;
  - **C1** Market / Idiosyncratic: RV_i = m_i + u_i, m_i = β²_{i,t}·RV_IMOEX (β по прошлым 252 дням, ≥ 0), u_i = max(RV_i − m_i, ε·RV_i); f = Ĥ^m·exp(g_m) + Ĥ^u·exp(g_u), Ĥ^m = β²·HAR-J(IMOEX), Ĥ^u = HAR-J(u_i); g_m, g_u — две панельные поправки (QLIKE на итоговой f, совместный вес по закрытым); положительность — по построению; λ = 0 ≡ компонентная HAR (контроль K7);
  - **C2** = C1 с g_m ≡ 0 (уточняется только собственная часть);
  - **D1** Confidence-Gated: λ_{i,t} = clip(a + b·Ḡ_{i,t}, 0, 1), Ḡ — средний по закрытым 63 дням выигрыш QLIKE поправки A1 на бумаге i (прошлые ошибки); a, b — по закрытым парам панели;
  - **D2** = D1, в индекс надёжности добавлены разброс прогнозов (стандартное отклонение g по 5 подвыборкам бэггинга), состояние рынка (M: ln RV_d/RV_m IMOEX), изменение RV (ln RV_d/RV_w) и устойчивость знака поправки (доля одного знака g за 22 дня): λ = σ(w·z), w — логистическая регрессия «поправка помогла» на закрытых, ридж.
  - **Резерв 4** (`R·1…R·4`): только по записи «У-n» с причиной до счёта; первая очередь — по одной снятой группе (X-intraday / C-semicov) к лучшей конфигурации, если A3 покажет вклад M+C.
  - Порядок: простейшие сначала — A1, B1, C1, D1 (XGB), затем A2–A4, B2, C2, D2; затем LGBM тем же порядком. Досрочной остановки внутри списка нет (список объявлен); бюджет автоматически не расширяется.
- **R8 (гиперпараметры, малая сетка, без перебора; §1 Ж-217).** Деревья: глубина {2; 4}, lr 0,03, ≤ 800 деревьев, ранняя остановка на последних 126 датах окна обучения (блок ранней остановки не входит в обучение, мутация № 99), min_child_weight / min_sum_hessian и min_data_in_leaf ≥ 500 пар, L2 = 10, subsample 0,8, colsample 0,8, seed 42. Выбор {глубина} × {c} (и κ, a, b, w у B, D) — раз в год на начало года Y по закрытым прогнозам панели за год Y−1, полученным моделями, обученными до Y−1 (внутренняя валидация на прошлом; критерий — средний по бумагам QLIKE); первый год без закрытой валидации — глубина 2, c = 1, λ = 1, κ — максимум сжатия. Самостоятельные модели заново не оптимизируются.
- **R9 (выбор финалистов и тройки).** Критерий `crit_panel` = среднее по M16 `crit_wf` (`d_comp.crit_wf`, Ж-214) на датах 2017–2021. Финалист модуля — минимум `crit_panel` среди 10 конфигураций модуля; тройка архитектур (§10 Ж-217) — по одной лучшей из A, B, C, D по `crit_panel` (лучшая из XGB/LGBM), с условием `crit_panel` < `crit_panel`(K1) − 0,0005, иначе позиция пуста. Подтверждение — M16 × 2022–02.2026 и E11 × вся история (не участвовали в выборе); SBER — отдельно.
- **R10 (контроли, вне бюджета; §6 Ж-217).** **K1** HAR-J (R3). **K2** самостоятельный XGB на каждой бумаге — замороженная спецификация `x2_best_j` (Б-2 + F4, цель ln RV − ln RV_m, та же годовая сетка; без новой оптимизации). **K3** самостоятельный LGBM — `C0_inh_F4`, так же. **K4 / K5** панельный XGB / LGBM **без HAR-J**: тот же g, те же X+M+C **без** величин, построенных из прогноза HAR (ln Ĥ − ln RV_m, ошибки HAR), offset ln RV_m вместо ln Ĥ — это и абляция базового прогноза (§2 Ж-217). **K6** HAR-J + E8 (замороженная спецификация Ж-214 E8, per ticker; не новое исследование). **K7** компонентная HAR (C1 при λ = 0). Если K2/K3 не переносятся на бумагу (нет входа признака) — запись в P0 до счёта, бумага в сравнение с K2/K3 не входит. Сравнения — на общих датах (пересечение дат всех сравниваемых рядов бумаги) и при одной RV.
- **R11 (межакционная переносимость, LOTO; §5Б Ж-217).** Для A1 и для каждой позиции тройки (обоих модулей): g обучается без бумаги i (все прочие правила те же), HAR-J бумаги i — её прошлое; прогноз на i. Это оценка, не новые конфигурации (в бюджет не входит; в семейство Холма — входит). Мутация: бумага i в обучении LOTO обязана быть поймана тестом.
- **R12 (метрики; §8 Ж-217).** QLIKE (основная, `models_v2/metrics.py`), RMSE, MAE, R² (на RV и на ln RV), QLIKE по годам; по бумаге, по группам M16 / SBER / E11 / все 28 (среднее и медиана по бумагам), по секторам, периоды 2017–2021, 2022, 2023–2025, 2026; без 24.02.2022, без 5 крупнейших по вкладу дней (для панели — дат), без `gap`-пар; доли бумаг, где гибрид лучше K1, K2, K3; время счёта (с, по стадиям).
- **R13 (статистика).** Панель: DM на среднем по бумагам дневном дифференциале потерь (общие даты, Ньюи–Уэст лаг 5); блочный бутстрап **дат** (блок 20, 5000, seed 42) с сохранением всех бумаг дня; MCS 90 % на среднем по панели. По бумаге: DM (НУ 5), бутстрап, MCS — описательно. Холм: **основное семейство** — полный реестр программы (585 + конфигурации и LOTO-оценки этой программы; N объявляется в `CHECKPOINT.json` до статистики, `stats_d.holm_n`); **вспомогательное** — по бумагам (28 × сравнения) — описательно. Раздельно: «снижение QLIKE (описательно)» и «подтверждённое преимущество».
- **R14 (уровни, панельная версия Ж-214 V14).** На M16 × 2022–02.2026 (подтверждение) и параллельно на всей истории: **1** — лучше K1: Δ среднего QLIKE < 0, знак Δ < 0 в ≥ 2 из 3 периодов {2022, 2023–2025, 2026}, панельный DM p < 0,05, ДИ бутстрапа Δ < 0, p Холма < 0,10 (иначе «L1 только сырой»); **2** — уровень 1 и то же к K2 **и** K3 **и** к своему K4/K5 (гибрид использует HAR-J); **3** — уровень 2 и Δ < 0 без 24.02.2022 и без 5 крупнейших дат, доля бумаг M16 с Δ < 0 к K1 ≥ 60 %; **4** — уровень 3 на E11 и в LOTO. Пометка «потолок» везде, где выбор видел оценочные годы; ACCEPTED не присваивается.
- **R15 (диагностика причин; §9 Ж-217, количественно).** `diagnostics/CAUSES.csv`: (а) охват — γ регрессии дифференциала потерь HAR-J vs K2 (Ж-212 этап A) по бумагам и на панели; (б) сходство с бустингом — корреляция ln f_A1 − ln f_K4 с ln f_K2 − ln Ĥ, корреляция ошибок гибрид/K2; (в) индивидуальные эффекты — доля дисперсии остатка поправки, объяснённая сдвигом бумаги (ICC), выигрыш B над A; (г) неоднородность — QLIKE LOTO минус QLIKE пула по бумагам; (д) предсказуемость ошибки HAR — OOS R² поправки по e = ln RV − ln Ĥ; (е) наблюдения — QLIKE по годам против размера окна обучения (без дополнительных обучений); (ж) регуляризация — распределение выбранных λ, c, κ, результат при λ = 1; (з) согласование рядов — доля `gap`-пар, результаты без них, расхождение календарей. Каждая причина — число и вывод «подтверждена / не подтверждена».
