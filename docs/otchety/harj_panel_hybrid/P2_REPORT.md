## Трактовки У-11 (не изменения формул; каждая — для подтверждения дирижёром)
1. **λ = 0 ≡ K1 в B**: у B нет собственного λ; побитное тождество проверено при нулевых поправках (κ → ∞, тест с κ = 1e30: α = γ = 0, exp(0) = 1,0) поверх A1 при λ = 0; у A, D1, D2 и C — через λ = 0 (C: ≡ K7, тест `k7_parts + forecast_c` против `hp_ctrl.k7_series`). Ни B1, ни B2 при выбранном λ_A1 < 1 не равны K1 — так задано «f = f_A1·exp(α)».
2. **B**: α̂ — по ≤ 252 закрытым парам бумаги (t⁺ ≤ d), n — число пар в окне; нет пар — α = 0; первый год — κ = максимум сетки (1000). В B2 z = `z_x_d_m`.
3. **C**: глубина общая для g_m и g_u; сетка выбора — глубина {2; 4} × c {0,5; 1; 2} × λ_m, λ_u ∈ {0; 0,25; 0,5; 0,75; 1} по QLIKE итоговой f за Y−1. **C2 использует тот же проход g_u, что C1** (g_m ≡ 0 — обучение g_u идентично по построению; в реестре — отдельная строка, обучения нет).
4. **D1**: нет Ḡ (нет закрытых пар) — Ḡ = 0; первый год — λ = 1 (a = 1, b = 0). Ḡ считается по A1 при λ = 1 и выбранных на год глубине и c.
5. **D2**: копия seed 42 = сам A1 (подвыборка 0,8, seed 42 — HP движка), новые копии — seed 43…46, только на тех глубинах, которые A1 выбирал хотя бы в одном году; разброс — std (ddof = 1) g по 5 копиям на глубине года. Признак «z ln RV_d/RV_w» = x_d_m − x_w_m (сырой; винзоризация и стандартизация — ниже). Доля одного знака — по 22 строкам бумаги с ≥ 5 значениями. Логистика: ридж C = 1, свободный член есть; признаки винзоризуются по 1/99 процентилям **обучающих строк года** (раз в год, а не «расширяющимся» по дням — w переобучается раз в год) и стандартизуются; нет значения в строке — 0; год без закрытых пар (2016) — λ = 1.
6. **A4**: 32 столбца дизайна K2 (Б-2 + F4) 28 бумаг (мир P1a), каждый — `hp_feat.zscore` по прошлому бумаги (≥ 252). Одна нефинитная ячейка (z_a4_4, RGSS, 26.01.2024: inf) заменена пропуском — в коде и в кэше `hyb_a4_feats.parquet` (≈ 11 % значений столбцов — пропуски: первые 252 строки каждой бумаги и пропуски самого дизайна K2). Обрезка будущего на реальных барах SBER проверена (`test_v2_hp_hyb_a4.py`).
7. **Контроли**: К2/К3 в таблицах P2 нет (24 бумаги — пробел P1/Ж-218); контроли — K1, K4 (XGB) / K5 (LGBM), K6, K7.
