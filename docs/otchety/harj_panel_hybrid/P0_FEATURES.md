# P0_FEATURES — признаки панели (R4, R5), Ж-215 / Ж-217, лист P0

Статус: DEVELOPMENT; формулы фиксируются до счёта P2. Все величины строки t известны к 18:50 t (канонический день бумаги: ≥ 30 баров основной сессии, `daily.build_daily`).
Единицы: RV, J, части дня — %² (×1e4). Код: `models_v2/s10/hp_feat.py` (индивидуальные X, M-часть IMOEX, C-часть бумаги, z), `hp_sync.py` (поперечные величины), `hp_panel.py` (сборка).
Обозначения: ln — натуральный логарифм, NaN при аргументе ≤ 0; RV_w, RV_m — средние УРОВНЕЙ RV за 5/22 дня сегмента, включая t (`daily.add_windows`); Ĥ_t — σ̂² K1 из дня t (на t⁺); ε_s = ln RV_s − ln Ĥ_{s⁻}, где Ĥ_{s⁻} — прогноз из предыдущего собственного дня на s.

## Нормировка z (R5)
`z_<имя> = (x_t − med_{<t}) / scale_{<t}`; med — расширяющаяся медиана, scale = (q75 − q25)/1,349 расширяющихся квантилей, по строкам собственного ряда бумаги **s < t** (сдвиг на 1 строку), ≥ 252 наблюдений, иначе NaN; scale ≤ 0 → NaN. Код: `hp_feat.past_stats`, `hp_feat.zscore`. В панели — сырые `x_/m_/c_` и нормированные `z_x_/z_m_/z_c_`.

## Оговорки (предложения У-n в `P0_REPORT.md`)
- R5 пишет «ln(1+J)/…» без знаменателя: принято ln(1 + J_t/RV_m,t) (безразмерно).
- «Доли OPEN/MIDDLE/CLOSE и их отклонения»: отклонение — от средней доли за 22 предыдущих собственных дня.
- «ln CLOSE/MIDDLE» — по частям RV дня (rv_close, rv_mid), а не по ценам.
- c_sys_share не ограничен сверху (редкие дни с малой RV_s,sync дают значения ≫ 1; z-версия имеет тяжёлый хвост) — не усечён: усечение — выбор признака, откладывается на P2.
- Идентичность бумаги (номер, сектор, ликвидность) — не признак (R5); сектор лежит в панели только как справочная колонка.
