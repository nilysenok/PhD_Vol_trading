## Д25.1 — определения
- **Пересчёт RVI.** `close_RVI` — индекс RVI в % годовых на горизонте 30 календарных дней (≈ 22 торговых).
  - Дневная дисперсия: v(t) = (RVI_t/100)²/252.
  - Для h=22 окно RVI и окно цели совпадают, поэтому v(t) — это ожидаемая средняя дневная дисперсия за 22 дня.
  - Пропуски RVI (1,8% строк) заполняются последним известным значением тикера.
- **k_i(t)** = медиана RV_i,h(τ)/v(τ) по 252 последним строкам тикера с τ ≤ t−h. Цель RV_i,h(τ) — среднее rv за [τ+1, τ+h]; она известна к закрытию τ+h ≤ t, это эмбарго по концу цели. Минимум 126 наблюдений. Пропусков k на val и тесте нет.
- **Масштаб h=5.** v(t) та же: предполагается плоская временная структура внутри месяца. k_i^(5) оценивается по 5-дневной цели с эмбарго 5. Разницу уровней (k₅ < k₂₂: 2017–2021 медиана 0,61–1,41 против 0,67–1,60) снимает k.
- **Варианты:**
  - (а) `D25_1a_h{22,5}` — ŷ = v·k в обоих слотах гибрида.
  - (б) `D25_1b_h{22,5}` — x10 = ln(v·k) в объединителе Д22 (`d22_full`, слои 1–4, группа x1, x2, x6, x7, x9, x10 с суммой весов 1). Опорный прогон без x10 воспроизводит Д22 (h=5, seed 42: 0,2269 = V0_XGB D22_h5). Замечание: HAR-X⁺ слоя 1 уже содержит RVI как слагаемое; x10 добавляет нормированную по тикеру «ногу RVI».
  - (в) `D25_1v_h{22,5}` — ln ŷ = ln(v·k) + ρ·r̂₁, r̂₁ = ln hyb₁ − ln HAR-J₁ (OOS, как Д19). ρ — OLS без константы по OOS-истории шагов < t: val шага s оценивается по шагам ≤ s−1, тест шага s — по шагам ≤ s. `D25_1vx_h22` — XGB-слот = (в), LGB-слот = Д16.5, как D19_1x.
  - (г) h=5 — те же (а), (б), (в).

## Д25.2 — факторная декомпозиция
Код — `scripts/analysis/d25_2.py` и `d25_2_gibrid.sh`; выполнял форк агента в том же worktree.
- **Единицы и выравнивание.** RV_m = rv_IMOEX²/252: rv_IMOEX — годовая волатильность. Корреляция ln RV_m(t+k) с ln кросс-среднего rv тикеров в день t при k = −1 / 0 / +1: 0,544 / **0,647** / 0,534, то есть ряды выровнены по дате.
- **β_i(t)** — OLS ln rv_i на ln RV_m по 504 торговым дням тикера, включая t (дневные значения известны к закрытию t). Минимум 60 наблюдений, иначе β = 1. β по шагам — 0,37–0,63.
  - Окно 504 — ночное умолчание: два года дают устойчивую β, и ни 2014, ни 2020 в окне не доминируют.
- **Рынок h=22** — HAR на ln RV_m: ln среднего RV_m за 1, 5 и 22 дня, плюс ln(RVI²/252) — привязка Д25.1.
  - Цель — среднее ln RV_m за [t+1, t+22]. Эмбарго — 22 рыночных дня перед val-годом.
  - «HAR без J» (↺): у IMOEX нет ряда скачков.
  - Контроль D25_2An (без RVI) показывает, что привязка RVI ничего не даёт: гибрид 0,2428 против 0,2430.
- **Собственная часть.** u_i(τ) = ln rv_i(τ) − β_i(t)·(ln RV_m(τ) − x̄_i(t)), где x̄_i(t) — среднее ln RV_m по тому же окну β (только прошлое).
  - Центрирование — ↺ форка. Без него u несёт уровень β·ln RV_m ≈ −4…−6, который меняется вместе с β.
  - Цель бустинга — среднее u за [t+1, t+22] при β(t). Прогноз: ln ŷ = β(t)·(ŷ_рынка − x̄) + û.
- **Бустинг** — XGB и LGBM на признаках и шагах D15_h22: `l2_lib`, `cfg={}`, Bv2b, исключения D15.
  - Гиперпараметры — `D15_h22_selected_h22.csv` по шагам, ES на val-годе, seed 42/43/44.
  - Новый перебор optuna-30 к 06:00 не успевался (↺): «протокол как у D15_h22» = его выбранные параметры.
- **(Б) наивный рынок:** ŷ_рынка = среднее ln RV_m за [t−21, t].
- **Без рычага** — D15_h22 через тот же gibrid. Seed-варианты D15 — производные копии в `D25/`, исходные файлы не менялись.
- **Итог Д25.2:** ни один вариант не проходит порог. Лучший — гибрид (А): +1,1% к D15_h22 по среднему, лучше только на seed 44. 2021 проходят только гибриды: 0,1385–0,1394 ≤ 0,1404.
- **Справка, на выбор не влияет.** Первый прогон без центрирования дал гибриды 0,2384 и 0,2352 без нарушений, но их 2021 > 0,1404. Файлы перезаписаны.
