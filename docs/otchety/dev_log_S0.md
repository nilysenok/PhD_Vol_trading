|---|---|---|---|---|---|---|
| hyb_h5 | 0,783 | 0,718 | 0,630 | 0,583 | −2 | блок («отстаёт») |

У HAR-J (б) контроли такие же: 0,737 / 0,627 / 0,581 / 0,548 и 0,866 / 0,808 / 0,737 / 0,627. На 2018–2021 те же argmax.

Профиль убывает по k у всех рядов, включая контроли: argmax везде −2. Причина в окне цели: при k < 0 оно включает дни, уже известные в день d. y_{d−1} содержит RV_d, y_{d−2} — RV_{d−1} и RV_d. Поэтому против h-дневной цели правило «максимум на k = 0» ряд без сдвига от ряда со сдвигом не отличает. Формально блок ставится всем: и рядам, и контролям.

Сдвиг здесь виден только как перенос профиля на один шаг k:
- у ряда со сдвигом −1 профиль совпадает с исходным, сдвинутым на шаг: его k = −2 равно k = −1 исходного;
- у ряда с утечкой +1 — наоборот: его k = −1 равно k = −2 исходного.

Против дневной RV (основная проверка выше) ряды h=5 дают argmax 0, контроли — −1 и +1. Решение о допуске σ h=5 — за дирижёром. Ряды в `ch4_dev` не менялись.

## Дополнение 22:54: ряд RVI (вход D6 / D6lag1), поручение дирижёра

**Как формируется RVI.**
- Источник. `fastbt.s9.build_sources` берёт `close_RVI` из `features_pit_v3`: dropna, первое значение на дату; RVI один на рынок.
- Момент снятия. `close_RVI` — закрытие индекса RVI по 10-минутным барам ISS с begin ≤ 18:50 дня d. Это срез основной сессии d, вечерняя сессия не входит. Правило 18:50 введено после того, как в v1 нашли утечку через вечернюю сессию до 23:50 (`docs/otchety/2026-10-25_vneshnie_dannye.md`, `m0_features_pit_v2.py`).
- Известен ли на закрытии d. Да: срез тот же, что у собственной RV тикера (ISS `rv_1850`) и у `close_IMOEX`. Оговорка того же отчёта: у RVI 241 день с обрезанными при выгрузке барами — тогда закрытие берётся с более раннего бара того же дня.
- Использование. В D6 RVI идёт без лага: ratio = σ·√252·100 / RVI_d, ранг W252. В D6lag1 — RVI_{d−1} (`e.rvi(1)`, сдвиг на бар).
- Пересборка из `features_pit_v3` кодом `build_sources` на ≤ 2021 совпала с файлом побитно.

**Сдвиг — то же правило, что для σ.** Спирмен ln RVI²_d с ln RV_{d+k} тикера, медиана по 17 тикерам, ε = 0,01, решает уровень. RVI — котировка, а не оконное среднее RV. Значения при k = −2 / −1 / 0 / +1:

| ряд | 2017–2021 | 2018–2021 | итог |
|---|---|---|---|
| RVI | 0,275 / 0,273 / **0,282** / 0,265 | 0,361 / 0,360 / **0,364** / 0,343 | argmax 0, **проходит** |
| контроль: сдвиг −1 | argmax −1, запас 0,019 | 0,025 | блок |
| контроль: утечка +1 | argmax +1, запас **0,0077** | **0,0056** | **не блок** («плоский профиль», запас ≤ ε) |

Почему не блокируется утечка: связь уровня RVI с RV отдельного тикера слабая (~0,3), профиль плоский, и симметричное ε = 0,01 гасит утечку +1.
