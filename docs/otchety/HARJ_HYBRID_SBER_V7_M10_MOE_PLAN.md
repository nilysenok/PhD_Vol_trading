## 0. Итог в трёх строках

1. **Новое информационное множество в V7 только одно.** Это обучаемый энкодер сырых последовательностей M10 (1 и 5 дней). Маршрутизатор и смесь экспертов сами по себе новой информации не добавляют: класс функций Residual MoE с фиксированными признаками вложен в класс GBM-корректора V6 (A0g/A2), а Forecast MoE — в смеси V4. Поэтому план начинается с проверки «есть ли в энкодере информация сверх признаков V6». Если её нет, MoE-конфигурации не считаются.
2. **Главная измеренная трудность — 2019–2021.** На этом окне гибриды V1–V6 уже не лучше бустингов: K3 0,1241, A2 0,1255, NTP2 0,1240. Преимущество A2 за 2018–2021 (−4,60 % уровня K1 к лучшему бустингу) почти целиком даёт 2018 год (раздел 1). Цель V7 — выигрыш, который не держится на одном году.
3. **Смета — 11 конфигураций и 1 резерв** (≤ 12 по Ж-232 п. 14). Вычеркнуто как эквивалентное:
   - Path Signature Encoder (≡ V6 A1/A3);
   - Fixed Statistical Encoder (≡ V6 A0/A0g);
   - Conditional Expert Reliability (≡ V4 CLD).

## 2. Отличие от V1–V6: что ново и что вычеркнуто

Обозначения:
- H = K1, ℓ = ln(M/H);
- S — дневные M10-признаки V6 (части дня, семивариации, RQ, форма);
- Σ — площади Леви (сигнатура порядка 2) окон 1 и 5 дней;
- z — выход энкодера V7.

Вывод: V7 проверяет две отдельные гипотезы.
- **(H1) Информация.** z_M10 несёт сведения о RV(t⁺) сверх H, S, Σ и прогнозов бустингов.
- **(H2) Организация.** При тех же признаках адаптивная маршрутизация с режимом только во входе маршрутизатора лучше плоского корректора сопоставимой сложности.

H2 без H1 к цели «лучше бустинга» не ведёт: на одних признаках MoE ≤ GBM по классу функций, и выиграть она может только устойчивостью.

## 3. Входы

**Последовательность X_d.**
- Бары основной сессии дней d−w+1 … d, w ∈ {1, 5}; окно 22 — только при подтверждённой необходимости и только из резерва.
- Каналы (11, паспорт листа 0): ln-доходность, High–Low, Open–Close, объём, нормированный объём (к медиане слота за прошлые сессии), r², r²·1[r<0], r²·1[r>0], положение close к дневной VWAP, накопленная RV дня, положение бара в сессии.
- Нормировка — по расширяющемуся прошлому; маска для неполных дней и смены расписания.
- Построитель и тесты готовы (лист 0, `models_v2/s14/`, 47 тестов).

**Маршрутизатор Z_gate** (только PIT, все стандартизуются по прошлому):
- ln H;
- ℓ = ln(M/H) и ln(K2/K3) (расхождение прогнозов);
- EWMA₂₀ прошлой разности QLIKE(H) − QLIKE(M) по закрытым парам;
- последняя закрытая лог-ошибка ln(RV/H) и ln(RV/M);
- перцентиль ln RV_d по прошлому;
- доля скачка J/RV дня d;
- CUSUM прошлых лог-ошибок H (определение V4 H6).

Всего 9 признаков. z_M10 во вход маршрутизатора основной MoE не подаётся: Ж-232 п. 7 перечисляет его, но тогда режим и M10 смешиваются, и H2 непроверяема. Вариант «z и в маршрутизатор» есть только в конфигурации 5 (Forecast MoE). Плоский корректор на (z, Z) — конфигурация 4.

**Эксперты.** g_k(z) = c·tanh((a_k + b_kᵀz)/c), c = 1 (ограничение поправки, как клип V6), d_z = 4; g₀ ≡ 0.

## 4. Энкодер и обучение

**Предобучение энкодера** (Stage A, frozen):
- Задача-предлог: прогноз ln(r²_{j+1} + ε) следующего бара по барам ≤ j той же или предыдущих сессий окна (причинная маска).
- Метки — бары дней ≤ d, известные к закрытию d, PIT. Примеров ≈ 52 на день, но они не независимы. Дневная QLIKE на них не учится: энкодер учит только представление.
- Переобучение раз в год: энкодер года Y учится на барах до 01.01.Y.
- z_d — среднее и последнее скрытое состояние по окну, сжатые до d_z = 4 главными компонентами, оценёнными по прошлым z.
- Размеры:
  - TCN — каналы 11 → 8, ядро 3, расширения 1, 2, 4, 8, ≈ 900 параметров;
  - CNN — 11 → 8 → 8, ядро 5, ≈ 800 параметров.

**Корректор и маршрутизатор** (обучаются по дневной QLIKE):
- L = mean(ln F + RV/F) + λ_g·mean(G²) + λ₂‖θ‖² + λ_LB·Σ_k(mean_t π_k − 1/(K+1))² + λ_s·mean‖π_t − π_{t−1}‖², где G = ln(F/H).
- λ_g стягивает к HAR-J (или к базе с якорем), λ_LB не даёт экспертам схлопнуться, λ_s сглаживает веса.
- Параметры: маршрутизатор — линейный softmax, (K+1)×(9+1); эксперты — K×(4+1). При K = 2 всего 40 параметров, при K = 3 — 60. На 2018-01 это 6,3 / 4,2 дня на параметр.
- Переоценка — помесячно, по закрытым парам t⁺ ≤ d.
- Ранняя остановка и выбор λ_g ∈ {0,1; 1}, λ_LB ∈ {0; 0,1} — по внутренней валидации на последних 126 закрытых парах. Решётка 4 точки на конфигурацию — в N_wide.
- Ансамбль 5 seeds (0–4), среднее ln F.
- g ≡ 0 ⇒ F = H побитно (тест); F > 0 по построению.

**Совместное обучение** (Stage B):
- Энкодер, эксперты и маршрутизатор учатся по дневной QLIKE.
- Энкодер стартует с весов предобучения, штраф λ_e‖φ − φ₀‖² стягивает к ним.
- Первая переоценка — 2019-01 (507 пар); до неё прогноз Stage A той же конфигурации, с пометкой.

## 6. Правила, объявленные до счёта

**6.1 «go» конфигурации V7.** Окно разработки 2018–2021, δ = 0,0005, крит = средняя QLIKE окна. Условия:
1. QLIKE 2018–2021 ≤ min(K2, K3, M, K8, NTP2, A2) − δ;
2. то же без 2018 (то есть 2019–2021);
3. то же без 1 % дат с наибольшей |разностью QLIKE| к лучшему из K2/K3 (в основной оценке эти даты остаются);
4. QLIKE лучше лучшего из K2/K3 не менее чем в 3 годах из 4;
5. ни один год не даёт больше 50 % суммарного выигрыша над лучшим из K2/K3;
6. подтверждение: Δ к лучшему из K2/K3 на 2022–2025 ≤ 0 по точке.

«go» — все шесть. Статус «подтверждено» — только при p Холма < 0,05. Иначе — «статистически неподтверждённое историческое улучшение».

**6.2 «Новая информация» X против Y.** На 2018–2021 одновременно:
- Δ < 0;
- DM односторонний (Ньюи–Уэст, лаг 5) p < 0,05;
- Δ < 0 не менее чем в 3 годах из 4.

**6.3 Специализация** (Ж-232 п. 9, только описательно; вывод «эксперт специализирован», если выполнены оба):
- доля дней с π_k > 0,3 — не меньше 10 %;
- средняя дневная разность QLIKE «с экспертом k» и «без него» на этих днях отличается от остальных дней (интервал не включает 0).

Также показываются частота переключений |Δπ| > 0,5, стабильность весов по годам и связь π с фактическим преимуществом (задним числом, помечено).

**6.4 Статистика:**

- по годам 2017…2026 и окнам;
