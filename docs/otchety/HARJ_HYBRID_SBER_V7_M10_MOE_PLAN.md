3. **Бюджет — 11 конфигураций (утверждён Ж-233) и 1 резерв** (только по отдельному разрешению). Вычеркнуто как эквивалентное:

- H = K1, ℓ = ln(M/H);

- Σ — площади Леви (сигнатура порядка 2) окон 1 и 5 дней;

Вывод: V7 проверяет две отдельные гипотезы.
- **(H1) Информация.** z_M10 несёт сведения о RV(t⁺) сверх H, S, Σ и прогнозов бустингов.
- **(H2) Организация.** При той же общей информации (z, Z) адаптивная маршрутизация лучше плоского корректора сопоставимой сложности: MoE-B против конфигурации 4.
- **(H3) Информация маршрутизатора** (Ж-233 п. 3). При одинаковых экспертах g_k(z) меняется только вход маршрутизатора: A — Z, B — (Z, z), C — z.

H2 без H1 к цели «лучше бустинга» не ведёт: на одних признаках MoE ≤ GBM по классу функций, и выиграть она может только устойчивостью.

**Последовательность X_d.**
- Бары основной сессии дней d−w+1 … d, w ∈ {1, 5}; окно 22 — только при подтверждённой необходимости и только из резерва.

- Нормировка — по расширяющемуся прошлому; маска для неполных дней и смены расписания.
- Построитель и тесты готовы (лист 0, `models_v2/s14/`, 47 тестов).

**Маршрутизатор Z_gate** (только PIT, все стандартизуются по прошлому):
- ln H;
- ℓ = ln(M/H) и ln(K2/K3) (расхождение прогнозов);
- EWMA₂₀ прошлой разности QLIKE(H) − QLIKE(M) по закрытым парам;
- последняя закрытая лог-ошибка ln(RV/H) и ln(RV/M);
- перцентиль ln RV_d по прошлому;
- доля скачка J/RV дня d;
- CUSUM прошлых лог-ошибок H (определение V4 H6).

Всего 9 признаков режима. Вход маршрутизатора по Ж-233 п. 3:
- **A** — Z (9);
- **B** — (Z, z), 13; **основная конструкция**;
- **C** — z (4).

Эксперты во всех трёх вариантах одинаковы и получают только z. Плоский корректор на (z, Z) без маршрутизатора — конфигурация 4.

**Эксперты.** g_k(z) = c·tanh((a_k + b_kᵀz)/c), c = 1 (ограничение поправки, как клип V6), d_z = 4; g₀ ≡ 0.

## 4. Энкодер и обучение

**Предобучение энкодера** (Stage A, frozen):
- Задача-предлог: прогноз ln(r²_{j+1} + ε) следующего бара по барам ≤ j той же или предыдущих сессий окна (причинная маска).
- Метки — бары дней ≤ d, известные к закрытию d, PIT. Примеров ≈ 52 на день, но они не независимы. Дневная QLIKE на них не учится: энкодер учит только представление.
- Переобучение раз в год: энкодер года Y учится на барах до 01.01.Y.
- z_d — среднее и последнее скрытое состояние по окну, сжатые до d_z = 4 главными компонентами, оценёнными по прошлым z.
- Размеры:
  - TCN — каналы 11 → 8, ядро 3, расширения 1, 2, 4, 8, ≈ 900 параметров;
  - CNN — 11 → 8 → 8, ядро 5, ≈ 800 параметров.

**Корректор и маршрутизатор** (обучаются по дневной QLIKE):
- L = mean(ln F + RV/F) + λ_g·mean(G²) + λ₂‖θ‖² + λ_LB·Σ_k(mean_t π_k − 1/(K+1))² + λ_s·mean‖π_t − π_{t−1}‖², где G = ln(F/H).
- λ_g стягивает к HAR-J (или к базе с якорем), λ_LB не даёт экспертам схлопнуться, λ_s сглаживает веса.
- Параметры: маршрутизатор — проекция входа в 4 + линейный softmax на K + 1 выходов (A 51, B 67, C 31 при K = 2); эксперты — K×(4+1).
  - MoE-B при K = 2 — 77 параметров, при K = 3 — 93;
  - плоский корректор 4 — tanh-сеть 13 → 5 → 1 (76).

  На 2018-01 (253 пары) это ≈ 3,3 дня на параметр, поэтому обязательны L2 и стягивание к HAR-J. С 2019-01 (507 пар) — ≈ 6,6.
- Переоценка — помесячно, по закрытым парам t⁺ ≤ d.
- Ранняя остановка и выбор λ_g ∈ {0,1; 1}, λ_LB ∈ {0; 0,1} — по внутренней валидации на последних 126 закрытых парах. Решётка 4 точки на конфигурацию — в N_wide.
- Ансамбль 5 seeds (0–4), среднее ln F.
- g ≡ 0 ⇒ F = H побитно (тест); F > 0 по построению.

**Совместное обучение** (Stage B):
- Энкодер, эксперты и маршрутизатор учатся по дневной QLIKE.
- Энкодер стартует с весов предобучения, штраф λ_e‖φ − φ₀‖² стягивает к ним.
- Первая переоценка — 2019-01 (507 пар); до неё прогноз Stage A той же конфигурации, с пометкой.
