## Договорённости программы (объявлены до счёта, 09.11.2026 01:15)

- **Тикер.** Оценка любых параметров V6 — только по рядам SBER (M10, 2014 — 02.2026). Другие бумаги, IMOEX и внешние ряды не входят ни в обучение, ни в признаки, ни в подбор. 2014–2016 — прогрев; последовательная оценка — с целей 2017; 2026 (неполный) — отдельно.
- **Замороженные входы.** Не переобучаются, побитно не меняются:
  - H = K1 (HAR-J PIT SBER);
  - K2 / K3 (XGB / LGBM SBER, `k23_SBER.parquet`);
  - M = √(K2·K3), K8 = √(H·M);
  - D2 (LGBM-D2, панельный — только контроль);
  - лучшие варианты V4 и V5 по SBER (GS4 и SP1 — только контроли);

  Источники и хэши — `docs/otchety/harj_hybrid_v5/CONTROLS.csv` и `CHECKPOINT.json` V5.
- **База и форма.** F = H·exp(g(Z)); при g ≡ 0 F = H побитно (уровень 1). Прогнозы бустингов в Z не входят. Ценность сверх бустингов показывают сравнение на общих датах и охват.
- **Цель.** RV дня t⁺ (следующий торговый день) по определению проекта (V5 G4: 1e4·Σr² по M10, 10:00–18:40). Не меняется, не обрезается. QLIKE — определение `models_v2.s10`.
- **PIT.**
  - Признаки дня d — только из баров сессий ≤ d.
  - Параметры, нормировки, аналоги и штрафы — только по закрытым парам (t⁺ ≤ d).
  - Диагностика задним числом не импортируется путём прогноза (тест AST, как в V4/V5).
