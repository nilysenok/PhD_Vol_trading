# SDF — правила для агента
Анализатор и скринер Hyperliquid: Rust-крейты в корне, скринер в `skriner/`. Правда — в `spec.md`, `_dir.md`, `<блок>/_ctx.md`, `arhiv.md`. Производные (`ROOT.md`, `handoff.md`, `dashboard.*`) не править.

## Главная сессия — дирижёр
Код и диффы не читает и не пишет. Раздаёт работу и сливает:
- задача → `kodir` (sonnet): один PR на 15–20 минут, больше — резать;
- ответы владельца → `pisar` (haiku): канон, коммит;
- PR → `proveryayushchiy` (деньги и критерий — sonnet, канон — haiku): вердикт в PR;
- факт из сети → `issledovatel` (sonnet): запись со ссылкой в `docs/`;
- контракты, симулятор, модель угроз → `arhitektor` — по поручению.

Других агентов не запускать. Сборочных сразу — не больше «Потолок» в `spec.md`; перед запуском — `uptime`, `df -h`. Задание — по `docs/zadaniya/_shablon.md`. Сливать только PR с вердиктом. После группы слияний на `main` — `scripts/check.sh --konets`, коммит производных, push. Итог — 5 строк: где · сделано · цифра · блокер · дальше; шестая — токены. Вопросы — `❓` с умолчанием и сроком в сутки в ОТКРЫТО блока и `OTKRYTO.md`; нет ответа — умолчание и `↺`.

## Токены
- Начало: `handoff.md` → `cargo xtask brief <блок>`; дальше `cargo xtask show …` и один файл `docs/kanon/` по номеру из замечания валидатора.
- Не читать: производные; `KANON_polnoe_opisanie.md`; отчёты целиком; вывод сервера — в файл, в чат `grep`-куски.
- Простая задача — простой модели; основная — дирижёр и архитектор.
- Отчёт агента — до 10 строк и расход; вывод команд — «OK» или ошибка.
- Бюджет в строке задачи (`~20м · ≤ 50т`). Вышел — стоп и «как разрезать». Два бюджета — не возобновлять. Продолжение — тому же агенту.
- Закрытый шаг: коммит, push, 5 строк в ТГ, `/clear`.

## По ходу
- Один агент — один блок, своя копия из `~/Developer/.sdf-kopii/`. Нужно от соседа — `❓ … (для <блок>)`.
- Записывать сразу: решение владельца — `Ъ` его словами и датой; отступление — `↺ — что · откат: как (ДД.ММ)`; цифра — `≡`; неизвестное — `❓`. Свою ошибку — первой строкой.
- Первая цифра — потолок. Подбор и счёт на одних данных — подгонка: честная половина. Одна пара — не статистика.
- Владельцу — проценты, не bps; деньги — $/ч и % капитала в неделю.
- Данные не покидают сервер; счёт — на `sdf` под `nice`; Мак — код. Фон на сервере — только `scripts/server.sh bg`; снимать — по pid. Время — по `date`.
- Править только инструментами правки. Имена ручек — `docs/sdf_torgovaya_mehanika.md`.

## Когда останавливаться
Только ради денег и размера; ключей и заявок бирж; необратимого; противоречия в каноне без умолчания. Остальное — `↺` и дальше.

## Безопасность
Уровень доступа 3. `.env` не читать. Секреты — не в чат, git, логи. Ключи и заявки бирж — вне агентов. В белую: стоять лимиткой — да; двигать цену ради чужой ликвидации — нет.

## Команды
`scripts/check.sh [--konets]` · `scripts/finish.sh "<PR>" <описание.md>` · `scripts/sliyanie.sh N…` · `cargo xtask check|build|brief|show|self-test` · `scripts/server.sh bg|bg-stop`
