## Общие умолчания (класс B, для всех итераций h=5)

- О1. dev 2017–2021; годовое переобучение 1 января 2016…2021 по строкам с концом цели h < cut, окно расширяется от самой ранней доступной строки. 2016 считается только как история для слоёв, которые смотрят в прошлые прогнозы; в метрики не входит.
- О2. Ранняя остановка и любой внутренний выбор: внутренняя валидация — последние 126 торговых дат окна; строки обучения с концом цели внутри валидации или в 5 датах до неё удаляются (purge + embargo 5, как `purged()` раундов 6/6б).
- О3. Метрики — как в 6б (`scripts/analysis/gl3_r6b_common.py`): QLIKE = r − ln r − 1; среднее пяти годовых средних по пулу 17 тикеров; годы; стресс март–июнь 2020 и верхний терциль RVI (как `_stress` раунда 6); RV/σ̂² в обеих стресс-строках; число тикеров (из 17) строго лучше эталона (QLIKE тикера — среднее пяти годовых) и одностороннее биномиальное p. Число тикеров — против каждого из трёх эталонов.
- О4. Эталоны: (1) честно переобученный финал FIN_PIT (`data/regen/gl3_r6b_h5/pit/experts/FIN_PIT.parquet`, из п. 2б Ж-188: замороженные параметры warmup 2016, ES по О2, годовой refit); (2) HAR-J(б) — сохранённый эталон (`har_corr`, PIT-чист по аудиту 2а); (3) HAR-J(б) потикерный HAR_i — строится в итерации 1 (Э3 ниже). Сохранённый финал D12_h5 показывается справочно.
- О5. LOYO: если у строки есть сетка, прогноз года Y — точка с наименьшим средним QLIKE по остальным четырём dev-годам; точки сетки показываются строками с eligible = False.
- О6. «Лучшая схема» итерации, которая идёт дальше, — строка с наименьшим средним QLIKE LOYO.
- О7. Обратное преобразование лог-прогноза бустинга: exp(s²/2), s² — дисперсия лог-ошибки (ddof 0) на внутренней валидации текущего обучения, один скаляр на панель (по тикеру — только там, где это задано схемой).
- О8. Признаки v3 — список признаков финала h=5 (`docs/tables/gl3_r5_r6/frozen_warmup_configuration.json`, `feature_names["5"]`, построен на `features_pit_v3`), без выходов моделей (`har_feature`), как в Г8.
- О9. В этапе 1 — только LightGBM (категории и `init_model` — его средства). Отступление от «как сейчас»: финал — среднее уровней XGB и LGB; здесь только LGB.
- О10. Каждый fit — в ledger (h, cutoff, max_target_end < cutoff < 2022-01-01); на каждый новый модуль — тест на синтетике и мутация, которую тест ловит. Модели не сохраняются, прогнозы — float32.

## Итерация 1 (h=5) — что меняем: схема обучения бустинга; эталон HAR_i

Записано 05.11.2026 до счёта.

- Б-а — панель 17 тикеров, параметры LGB финала (`fin5params.lgbm`, функция потерь финала — Хьюбер, текущий порог), цель ln RV(t+5), ES по О2.
- Б-б — отдельная модель на тикер: max_depth 4, num_leaves 15, min_data_in_leaf 50, lambda_l2 5, learning_rate 0,03, feature_fraction 0,8, bagging_fraction 0,8, до 1000 деревьев, остановка через 50; признаки — 40 лучших по gain панельной модели Б-а той же отсечки (прошлое окно); s² по тикеру.
- Б-в — Б-а + тикер и сектор категориальными признаками LightGBM (`categorical_feature`); сектор — статический ключ из данных проекта.
- Б-г — модель Б-а той же отсечки → продолжение по тикеру (`init_model`), learning_rate 0,01, до 200 деревьев, остановка через 20 по внутренней валидации тикера, не меньше 50 деревьев; s² по тикеру.
- Э3 (HAR_i) — потикерный OLS HAR-J(б) в логах на регрессорах эталона, с той же схемой эмбарго; β*_i = λ·β_i + (1−λ)·β_pool, s²*_i = λ·s²_i + (1−λ)·s²_pool, λ ∈ {0; 0,25; 0,5; 0,75; 1}, выбор λ — LOYO (О5). λ = 0 обязан совпасть с HAR-J(б) эталона (≤ 1e−8 отн.).
- Итог итерации — таблица: эталоны (FIN_PIT, HAR-J(б), HAR_i по λ и LOYO, справочно сохранённый финал), Б-а…Б-г; лучшая схема по О6.
