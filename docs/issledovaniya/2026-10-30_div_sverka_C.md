## Как читать `net_istochnika`

Статус `net_istochnika` означает, что не подтверждена дата объявления (announce_date). Для большинства таких строк дата реестра и сумма подтверждены агрегаторами, не dohod.ru (smart-lab.ru, investmint.ru, investfuture.ru, interfax.ru/quote), и записаны в `record_date_2`, `dps_rub_2` (в `primechanie` — «частично»). У агрегаторов даты объявления нет. Ограничение: smart-lab и investfuture, судя по совпадению цен и ряда, берут данные из одной базы, поэтому как два независимых источника не считаются. По Д8 строки `net_istochnika` остаются неподтверждёнными по announce_date; значения dohod.ru для них не опровергнуты. Две пустые/без источника строки: OGKB 2015-06-25 и 2016-06-20 — ни один открытый источник не даёт 2015–2016 (investfuture с 2016 года реестра, investmint для ОГК-2 вернул 404); не подтверждено документацией.

## Замечания по определениям

- announce_date в `yes`-строках второго источника (investfuture для IRAO, LSRG, RTKM, OGKB 2018; Прайм для RTKM 2017; Интерфакс для SBER, VTBR) — дата публикации новости о рекомендации СД (МСК). Для IRAO 2018 (04:33) и OGKB 2018 (05:35) заседание СД могло быть днём раньше; таблица dohod.ru использует дату публикации, поэтому совпадение засчитано.
- VTBR: суммы ~0,001 руб., допуск 0,01 руб. для них тривиален, поэтому сверка относительная. investmint даёт суммы после консолидации 1:5000 (5,85 руб. = 0,00117 руб.); Интерфакс (608778): «0,117 коп. три года подряд» (2014–2016), 0,345 коп. за 2017. Для 2020 и 2021 агрегатор округляет (0,5 % и 1,3 % от таблицы) — записано в примечании.
- IRAO 2021-06-07: smart-lab 0,18 против таблицы 0,1807 — разница 0,0007 руб. < 0,01, но точность агрегатора ниже; из-за отсутствия announce статус `net_istochnika`.
- SBER 2020-10-05: рекомендация СД марта 2020 была отозвана в мае и подтверждена 21.08.2020 (по поиску, страницы не открывались) — announce_date таблицы (2020-03-18) не подтверждена.
