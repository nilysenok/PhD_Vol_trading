# Состав IMOEX на каждую ребалансировку 2015–2021 (И-а1)

Статус: разработка, данные только < 2022. Дата проверки всех ссылок: 2026-10-28. Задание: `docs/zadaniya/2026-10-28_zadaniya_a_i_diag2.md`, раздел «И-а1». Таблица: `docs/issledovaniya/2026-10-28_sostav_imoex.csv`.

## Метод
- Состав по дням: ISS `statistics/engines/stock/markets/index/analytics/IMOEX.json?date=ДАТА`, все дни 2015-01-01…2021-12-31 (1765 торговых дней с данными). Дата смены набора тикеров = `date_eff`. Всего 34 даты: 1 начало окна, 28 плановых (по 4 в год; из них без смены набора 2015-06-16, 2016-03-16, 2018-09-21, 2020-06-19) и 5 внеплановых/переименований (2015-11-19, 2016-07-01, 2018-01-03, 2018-08-30, 2021-12-14).
- Сверка: состав в csv побайтно совпадает с ISS на все 34 даты (проверено сравнением строк, 34 из 34).
- `known_from`: 2015–2017 — дата публикации пресс-релиза Мосбиржи (1-е число месяца, для 2015-03 — 2-е), URL в csv. 2018–2021 — последний день диапазона публикации по https://www.moex.com/ru/factsheet/rebalance (та же консервативная конвенция, что в `data/calendar/imoex_rebal_official.csv`).
- Формат csv: отступление от задания — вместо строки на тикер одна строка на дату, поле `tickers` (через пробел) и `n`; причина: хук запрещает запись текста оболочкой, а Write на ~1400 строк неразумен. Длинный вид получается разбиением по пробелу. Добавлены поля `known_from_url` и `known_from_status`.

## Сверка с `data/calendar/imoex_rebal_official.csv` (2018–2021)
- 13 из 14 дат 2018–2021, где ISS меняет набор, совпадают с календарём (14-я — 2019-12-20, см. ниже); `known_from` в csv для них взят из календаря.
- Дат календаря 2018–2021 без смены набора тикеров: 2018-09-21, 2020-06-19 (включены строками, состав без изменений). Остальные даты календаря 2018–2021 — все 15 присутствуют в csv.
- В календаре нет 2019-12-20, а ISS на эту дату меняет состав (+TCSG; −SFIN, RNFT, MVID). Дата подтверждена страницей https://www.moex.com/ru/factsheet/rebalance (2–6 декабря → 20 декабря 2019). Пробел в `imoex_rebal_official.csv`.
- 2015–2017 в календаре нет (страница календаря начинается с марта 2018).

## Что подтверждено, что нет
Подтверждено страницей Мосбиржи (содержание открыто): 2015-03, 2015-09, 2015-12, 2016-03, 2016-06, 2016-12, 2017-03, 2017-06, 2017-09, 2017-12 (ссылки в csv); внеочередное исключение MFON 2018-08-30 (https://www.moex.com/n20723, публикация 29.08.2018 08:45).
Не подтверждено документацией:
- 2015-06-16: `known_from` 2015-06-01 — оценка по шаблону (страницу не нашёл).
- 2016-09-16: страницу Мосбиржи не нашёл; 01.09.2016 — по пересказу СМИ (ссылка Rambler).
- 2015-11-19 (PGIL): подтверждено только сообщение от 17.11.2015 об исключении из залогового списка и «исключении из индексов»; сообщения об индексах не найдено.
- 2016-07-01 (EONR→UPRO), 2018-01-03 (EPLN→SFIN), 2021-12-14 (MAIL→VKCO): документ не найден; вероятные смены тикера, не смены состава; `known_from` = `date_eff`.
- Расхождение: пересказ страницы n15251 (2017-03) называл VSMO включённой, ISS и `tickers`-список показывают исключение (VSMO последний день 2017-03-16). Принят ISS; страницу вручную не перечитывал.
- Начало окна 2015-01-05: объявление базы с декабря 2014 не проверялось (до 2015 — вне задания).
