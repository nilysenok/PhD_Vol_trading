# MOEX: открытые позиции по группам клиентов (MIX, Si), лист И5.0

Дата обращения: 2026-10-31 (по часам Мака). Данные ≥ 2022 не запрашивались. Примеры: `data/raw/moex_oi/`. Записано в рабочую копию агента: хук запретил запись в основную копию; дирижёр переносит.

## Факты
1. Архив есть, бесплатный, без ключа, GET. ISS: `https://iss.moex.com/iss/statistics/engines/futures/markets/forts/openpositions/<ASSET>.json?date=ГГГГ-ММ-ДД` (или `from=&till=`). Список активов: `.../openpositions.json?date=...` (MIX, Si, RTS: date_from 2012-10-01). Ответ 200 проверен: 2012-09-28 пусто; 2012-10-01, 2013-01-09, 2014-06-02, 2015-03-16, 2015-06-01, 2016-06-01, 2019-12-30 есть; 2015-03-15 (воскресенье) пусто.
2. Колонки ISS: tradedate, asset, is_fiz (0 = юрлица, 1 = физлица), persons_long, persons_short (число лиц), open_position_long, open_position_short, oichange_long, oichange_short.
3. Пример 2017-03-15, MIX: юр. 31/65 лиц, long 7303, short 8017; физ. 333/197 лиц, long 4262, short 3548. Si: юр. 596/196, long 1227585, short 1897160; физ. 15761/2051, 798212/128637. Совпадает с CSV moex.com.
4. CSV: `https://www.moex.com/ru/derivatives/open-positions-csv.aspx?d=ГГГГММДД&t=1` (t=1: разделитель «,», точка в числах; t=2: «;», запятая). Колонки: moment, isin, name, contract_type (F/C/P), iz_fiz (пусто = юр., 1 = физ.), clients_in_long, clients_in_short, long_position, short_position, change_prev_week_* (изменение за неделю; ISS даёт oichange — отличие определений не сверено). Включает опционы. 200 без регистрации (с браузерным User-Agent). Страница: https://www.moex.com/ru/derivatives/open-positions.aspx
5. Гранулярность: дневная. ISS `analyticalproducts/futoi` — 5-минутный внутридневной ряд (tradedate, tradetime, clgroup, pos_long/short, pos_long_num/short_num, systime), но `futoi.dates` начинается с 2020-01-03; за 2017-03-15 пусто, для 2015–2019 непригоден. MOEX 29.05.2020 (https://www.moex.com/n28607): intraday бесплатно, в деморежиме.
6. Лимиты запросов и условия использования/лицензия — не подтверждено документацией.
7. Время публикации дня d — НЕ ПОДТВЕРЖДЕНО документацией: в ответе нет поля времени, страница и поиск его не дали. Для Д3: d+1 (консервативно). Уточнять только по первичному источнику MOEX (поддержка).
8. Полнота по праздникам и торговым дням 2015–2021 не проверена.

## Выгрузка
Полный архив 2014-06-01…2019-12-31 не выгружался (лист — проверка и примеры). ISS отдаёт диапазон `from/till` одним запросом.
