## 4. Альтернатива без MIX: IMOEX и цена финансирования

Это модель, не факт биржи: расчёт по формуле стоимости носительства фьючерса F ≈ S·exp((r − q)·T), где r — безрисковая ставка рубля (ключевая ставка ЦБ, `docs/issledovaniya/2026-10-28_kluchevaya_stavka_2013_2017.csv`; 2018–2021 — `docs/otchety/2026-10-27_stavka_2018_2021.md`), q — дивидендная доходность индекса.
- Доход короткой позиции по индексу на день: −β·R_IMOEX(price) + β·(r − q)·Δt при фьючерсном хедже, т. е. фьючерс сам несёт ставку за вычетом дивидендов (премия растёт к экспирации и сходится к нулю: короткая позиция зарабатывает схождение).
- Без фьючерса: шорт индекса недоступен; синтетически вычитается β·R_IMOEX(price) и добавляется β·(r_fin − q)·Δt. Если вместо цены использовать полную доходность (MCFTR за 2015–2019 нужно выгрузить, локально только 2022+), то q берётся из разницы MCFTR − IMOEX; иначе q оценивается по дивидендному календарю (`docs/issledovaniya/2026-10-28_dividendy_2015_2016.csv`, `2026-10-27_dividendy_2017_2021.csv` — уточнить охват).
- Допущение: ставка финансирования = ключевая ставка (ступенчатый ряд). Реальная базисная ставка MIX (спрэд к ключевой) без данных MIX не наблюдается; MIX-данные снимают это допущение.
- Эквивалентная стоимость для проверки: если хедж идёт на всю бету портфеля в среднем 0,5 за год, а r − q ≈ 6 % (оценка порядка величины для ставки 8–10 % и дивидендов 4 %), то ошибка модели носительства порядка 0,5 × (отклонение базиса от r − q), т. е. десятые доли процента годовых. Число — порядок величины, не измерено.

Вывод: без фьючерса хедж можно смоделировать, но поправка на финансирование модельная; с дневной историей MIX из ISS её можно проверить на самих данных.

## 6. Влияние на N

Хедж с ежедневной бетой по окну 63, одним правилом (как в Ж-090 п. 2: без выбора) — **N не растёт**: это одна конфигурация, не перебор. N вырастает, если: (а) окно беты 63 заменить на сетку, (б) выбирать между ставкой комиссии на фьючерс, ролловым правилом или MIX / IMOEX-прокси по результату. Для этого параметры (окно 63, ставка комиссии, правило ролла) фиксируются до счёта; строка «A′ без хеджа» остаётся справочной рядом.
