# И-21. Состав отраслевых индексов Мосбиржи для 17 тикеров, 2017–2021

Дата обращения ко всем ссылкам: 2026-10-28. Источник: ISS MOEX (публичный, без ключей). Таблица: `2026-10-28_sostav_sektorov.csv` (340 строк = 17 тикеров × 20 дат; у каждой строки ссылка). Статус: справка, данные ≤ 2021.

## Метод
- Состав: `https://iss.moex.com/iss/statistics/engines/stock/markets/index/analytics/<ИНДЕКС>.json?date=<дата>` для 10 отраслевых индексов (MOEXOG, MOEXEU, MOEXFN, MOEXMM, MOEXCN, MOEXCH, MOEXTL, MOEXTN, MOEXRE, MOEXIT). Список индексов и даты начала: `https://iss.moex.com/iss/statistics/engines/stock/markets/index/analytics.json`.
- Даты: 20 дат — понедельник после третьей пятницы марта/июня/сентября/декабря, 2017-03-20 … 2021-12-20 (квартальная ребалансировка). ❓ Календарь ребалансировок отдельным документом Мосбиржи не сверялся — даты вычислены по правилу «третья пятница → следующий понедельник»; не подтверждено документацией. Состав между этими датами не опрашивался: внутриквартальные замены (корпсобытия) не исключены.
- Для каждой даты ISS вернул состав на эту дату (поле `tradedate` совпало с запрошенной; для MOEXTN 2017-03-20 — 5 бумаг, AFLT вес 72,07 %).

## Результат (G1)
Каждый из 17 тикеров на всех 20 датах входит ровно в один из опрошенных отраслевых индексов; смен индекса нет:
AFLT — MOEXTN; ALRS, MTLR — MOEXMM; HYDR, IRAO, OGKB — MOEXEU; LKOH, NVTK, TATN — MOEXOG; MGNT — MOEXCN; MOEX, SBER, VTBR — MOEXFN; MTSS, RTKM — MOEXTL; PHOR — MOEXCH.
Исключение — LSRG: ни в одном отраслевом индексе на 17 датах 2017-03-20 … 2021-03-22 (в csv индекс «нет»); в MOEXRE на 2021-06-21, 2021-09-20, 2021-12-20 (на 2021-04-02, первая дата состава MOEXRE, вес LSRG 21,47 %: `.../analytics/MOEXRE.json?date=2021-04-02`). Запрос MOEXRE на 2017-03-20 вернул пустой состав и дату начала 2021-04-02. Состав MOEXRE на 2021-03-22 пуст по той же причине. MOEXIT (с 2021-04-02) — ни один из 17 тикеров не вошёл на опрошенных датах.
Оговорка: «нет» для LSRG установлено поиском тикера по всем 10 индексам на опрошенные даты, не по полному перечню индексов ISS.

## MOEXTN и MOEXRE (G2)
- MOEXTN (транспорт) существует, AFLT в нём на всех 20 датах. ISS: индекс с 2013-11-11 (`.../index/analytics.json`); дневной ряд `https://iss.moex.com/iss/history/engines/stock/markets/index/securities/MOEXTN.json?from=2017-03-01&till=2021-12-31` (есть, 2017-03-01 close 2065,8; 2021-12-30 close 1393,72); границы свечей: 10-минутки с 2013-11-11 10:00 (`https://iss.moex.com/iss/engines/stock/markets/index/boards/SNDX/securities/MOEXTN/candleborders.json`), запрос 10-минуток на 2021-12-20 вернул данные (`.../MOEXTN/candles.json?interval=10&from=2021-12-20&till=2021-12-21`).
- MOEXRE (недвижимость) существует, но состав — только с 2021-04-02. Дневные значения: ISS отдаёт с 2020-03-20 (база 5000; `https://iss.moex.com/iss/history/engines/stock/markets/index/securities/MOEXRE/dates.json` → 2020-03-20 … 2026-10-27; значения до 2021-04-02 — вероятно, рассчитаны задним числом, это предположение, документацией не подтверждено). 10-минутки ≤ 2021: нет — запрос `.../MOEXRE/candles.json?interval=10&from=2020-01-01&till=2022-01-01` вернул пустой набор; `candleborders.json` для MOEXRE пуст; без дат ISS отдаёт первую свечу 2025-07-14.
- Следствие: у LSRG до 2021-06 нет отраслевого индекса; 10-минутного ряда MOEXRE на 2017–2021 нет; дневной — только 2020-03-20 … 2021-12-31.
