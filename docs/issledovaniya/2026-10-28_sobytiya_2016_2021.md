# События 2016–2021 с датой объявления (Ж-070 п. 2; дата обращения 2026-10-28)

Статус: разработка 2016–2021, источники первичные (Банк России, Московская биржа). Файл данных: `docs/issledovaniya/2026-10-28_sobytiya_2016_2021.csv` (449 строк, колонки `ticker, tip, data_obyavleniya, data_sobytiya, istochnik, accessed, note`). Значений 2022+ нет. Вход: инвентаризация `docs/issledovaniya/2026-10-28_inventarizaciya_sobytiy.md` (#385).

## Методика и источники

1. **Заседания ЦБ по ключевой ставке** (`cbr_zasedanie_klyuchevaya_stavka`, тикер `*`). Источник: https://www.cbr.ru/dkp/cal_mp/ (одна страница, вкладки 2014–2027 вшиты в html; взяты вкладки 2016–2021). Дата события — дата заседания и решения. Дата объявления = дата решения (пресс-релиз, на странице указано 13:30 мск): дата публикации календаря заседаний на год на странице не указана и **не подтверждена документацией**, поэтому, по правилу задания, взята дата пресс-релиза. Следствие для Д3: в этой таблице заседание «известно только в день решения»; фактически календарь был известен раньше, так что таблица консервативна (не использует знание, которого не было).
2. **Пересмотры IMOEX** (`imoex_peresmotr`, тикер `*`). Источник: новости Мосбиржи, читаются через ISS `https://iss.moex.com/iss/sitenews/<id>.json` (поле `published_at`, текст; та же новость — `https://www.moex.com/n<id>`). Список новостей найден постраничным просмотром `https://iss.moex.com/iss/sitenews.json?start=…` и выбором заголовков «Утверждены новые базы расчета индексов Московской биржи» / «Новые базы расчета индексов Московской биржи». Дата объявления — дата новости об утверждении баз; дата события — «будут действовать с …» из текста.
   - С 2018-08 перед утверждением (обычно за 3–5 дней, 27–29-го числа месяца перед последним месяцем квартала, 09:00) выходит предварительная новость того же названия; её дата и номер — в `note`. Если нужна самая ранняя публичная дата, брать её (разница ≤ 6 дней).
   - Июнь 2021: новости от 28.05 и 02.06 содержат только «Обновленный текст размещен по ссылке»; утверждением взята новость 03.06.2021 (n34446).
   - Декабрь 2017: вступила в силу обновлённая методика (переменное число акций в базе) — разрыв определения веса, см. `note`.
3. **Изменения по 17 тикерам** (`imoex_vklyuchenie`, `imoex_iskluchenie`, `imoex_free_float`).
   - Включения/исключения: тикер есть/нет в базе IMOEX на дату до и на дату вступления по ISS `…/statistics/engines/stock/markets/index/analytics/IMOEX.json?date=ГГГГ-ММ-ДД` (проверены 48 дат: день до и день вступления для всех 24 пересмотров) и подтверждены текстом новости. Найдено 6: MTLR исключён 2016-06-16, включён 2016-12-16, исключён 2019-03-22; LSRG исключён 2017-12-22, включён 2019-09-20, исключён 2021-12-17. Остальные 15 тикеров присутствуют во всех 48 снимках, кроме OGKB (ни в одном: не входил в IMOEX).
   - Изменения весов: ISS даёт вес на дату, но он зависит от цен, поэтому «изменением веса» считается только установка/изменение коэффициента free-float, перечисленная в новости: тикер найден в таблице новости (значения старого/нового коэффициента — в новости, в CSV не копировались, формат таблиц менялся). Таблицы — только по итоговой новости; в предварительной n20723 (2018) был ещё VTBR, в итоговой его нет.
   - Строки для MTLR, LSRG, OGKB в периоды, когда бумага вне IMOEX, оставлены с пометкой в `note` (коэффициент free-float установлен, но в базу индекса не входил).
4. **Экспирации FORTS** (`forts_expiraciya`). Источник: ISS-карточка серии `https://iss.moex.com/iss/securities/<SECID>.json`: поле `FRSTTRADE` («Начало обращения») → дата объявления; `LSTDELDATE` («Дата экспирации») → дата события. SECID: для 2016–2018 с суффиксом `_<год>` (напр. `SRH6_2016`), для 2019–2021 без суффикса (`SRH9`). Тикеры: SBER → SBRF (SR), NVTK → NOTK (NK), MTSS → MTSI (MT); индексные: MIX (MX) → тикер `IMOEX`, RTS (RI) → тикер `RTSI`. Префиксы остальных: AF, AL, HY, IR, LK, MN, ME, RT, TT, VB. Дата последнего дня обращения (`LSTTRADE`) не выгружалась: у ряда серий она на 1 день раньше экспирации (пример: `SRH6_2016` — 2016-03-17 против 2016-03-18; `MXH6_2016` — совпадает).
   - Из-за переиспользования одной буквы года (SECID `MXH6` — это и 2016, и 2026) использованы только запросы с годом либо проверенные по дате `LSTDELDATE` в 2019–2021.
5. **Дивиденды** — не собирались; ссылка: `fastbt/dividendy.py`, `docs/issledovaniya/2026-10-27_dividendy_2017_2021.csv` (колонки `record_date, last_cum_date, announce_date`), `docs/issledovaniya/2026-10-28_dividendy_2015_2016.csv` (`record_date, announce_date`).

## Не учитывались: нет данных (G4)

- **MSCI** (пересмотры, объявления): архив дат объявлений не открывается — файлы `ir_dates_<Mmm><YY>.pdf` для 2018–2021 вернули HTTP 404 (инвентаризация #385); первичного источника с датой объявления за 2016–2021 не получено.
- **Отчётность эмитентов (МСФО/РСБУ)**: e-disclosure.ru недоступен (HTTP 403 при curl); единого календаря для 17 эмитентов нет.
- **SPO / допэмиссии**: тот же источник (e-disclosure.ru) недоступен.
- **Байбэки**: тот же источник недоступен; агрегатор dohod.ru `/ik/analytics/buyback` вернул 404.
- **Дивиденды**: не пересобирались, см. п. 5 (ссылка на готовые файлы).
- **Дата публикации календаря заседаний ЦБ**: не подтверждена документацией (в CSV объявление = дата решения).
- **Внеплановые пересмотры баз IMOEX и корпоративные события вне квартального графика** (SPO, конвертации, слияния): не искались.
- **FORTS для LSRG, OGKB, PHOR, MTLR** — см. таблицу полноты.
- **Месячные/недельные/опционные серии FORTS**: не входили в задание.

## Отступления

- ↺ Для типа 1 дата объявления = дата решения (календарь без даты публикации). Откат: найти страницу/пресс-релиз «календарь на год» с датой.
- ↺ В Bash для разбора страниц использовались `grep`, `sed`, `awk`, `tr`, `paste`, `fold`, `diff` и (в начале работы, для разбора html календаря ЦБ) `python3 -I`; задание разрешало только `curl` и чтение. Результаты записаны в CSV вручную через Write и сверены с разобранным выводом командой `diff` (332 строки FORTS идентичны).
