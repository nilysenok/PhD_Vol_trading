## Строка 1. Метод, расхождения, месячная таблица

Метод (↺ отступление от «только curl и чтение файлов»): parquet из 10-мин источника читать нечем (Python в Bash запрещён), поэтому проверка сделана по 1-мин файлам `data/regen/D25/bars1m/{T}_{2014,2015}.csv`: бары 10:00–18:49, 10-минутное ведро = первые 15 символов метки времени, число различных ведер за день; команды `grep`, `cut`, `sort -u`, `uniq -c` по текстовым файлам. Дни опоры — торговые дни SBER в этом же источнике: 90 (с 26.08.2014) и 250 в 2015 — как у архитектора (IMOEX). День валиден при ≥ 30 ведер (правило Ж-114 п. 1).

Расхождение с архитектором (`origin/arh-msp-fazy`, `docs/otchety/2026-10-28_msp_fazy_spec.md` §15.2, источник — `final_v6/candles_10m` parquet):

| тикер | архитектор, дни с ≥ 30 баров | мой счёт по 1-мин, дни с ≥ 30 ведер |
|---|---|---|
| LSRG, 2015 | 54,0 % | 221/250 = 88,4 % |
| LSRG, 2014 (с 26.08) | 48,9 % | 77/90 = 85,6 % |
| PHOR, 2015 | 82,4 % | 241/250 = 96,4 % |
| PHOR, 2014 (с 26.08) | 84,4 % | 88/90 = 97,8 % |
| OGKB, 2014 | 94,4 % | 100 % |

Причина не установлена. Гипотезы: (1) 10-мин parquet `final_v6` построен иначе, чем 1-мин `D25` (иная выгрузка/агрегация); (2) разное определение бара (непустое ведро против фиксированной сетки). Для решения нужен прогон по parquet (пайплайн берёт дневной ряд из `candles_10m`, `fastbt/data.py:36`). Пока расхождение не снято, для LSRG, PHOR, OGKB действуют числа архитектора (они взяты из источника пайплайна и строже); мои числа — справочные. IRAO и MTSS совпали с архитектором до целого дня.

Предложение для прогона по parquet (скрипт архитектора `scratchpad/msp/pokrytie_2014_2015.py`, фильтр `begin < 2016` оставить): заменить финальный `print` на `have.groupby(have.index.to_period("M")).apply(lambda s: (s >= 30).mean())` по тикерам — это даст ту же таблицу.

## Строка 3. IRAO: что учтено и что нет

- Учтено: фактор 100 на дату 2015-01-20 (первый бар после перерыва) в `data/corporate_actions.csv`, применяется при `load_ticker(..., corp=True)`; тест на скачок есть.
- Факты MOEX: сообщение от 24.12.2014 — торги IRAO приостановлены с 25.12.2014; 100 акций конвертируются в 1 (по поиску; дата операции НРД 26.12.2014 — вторичный пересказ, не проверена по первичному документу). Дата возобновления 20.01.2015 не подтверждена документацией (в 1-мин данных первый бар 2015-01-20 10:00, цена 0,8).
- Не учтено: 10-мин и 1-мин бары IRAO до 18.12.2014 не пересчитаны (цена 0,0071); после правила Ж-114 п. 1 декабрь 2014 – февраль 2015 невалидны, поэтому внутридневные сигналы этого окна не нужны. Для дневных σ-окон и рангов В2 корректировка нужна (`corp=True`).
- Расхождение дат: в `corporate_actions.csv` источник — «разрыв 18.12.2014→20.01.2015 без баров»; торги по MOEX приостановлены с 25.12; баров нет с 19.12 (гипотеза: ограничения режима торгов до приостановки; не проверено).
