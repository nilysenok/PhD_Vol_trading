## 2. Архитектура (Eq. 2–6)
- База (Eq. 2): MLP с двумя скрытыми слоями, GELU, ширина H, dropout 0,1 после каждого скрытого слоя, линейный выход. Вход — 16 признаков акции x.
- Обычный MoE (Eq. 3, для сравнения): каждый эксперт — полный MLP на x и предсказывает всю волатильность; гейт softmax(g(u)), u = (x, z).
- RG-ResMoE (Eq. 4–6): база даёт ŷ_base из x; K = 4 корректирующих эксперта r_k(x) видят только x, последний слой каждого инициализирован нулём; мягкий гейт softmax(g(u)), u = (x, z), z — режимные переменные.
- Форма остатка — аддитивная: ŷ = ŷ_base + Σ_k π_k r_k(x).
- Режимные переменные z: рыночная волатильность за 20 дней (рынок с равными весами) и идиосинкратическая за 20 дней (β по 120 дням). Они идут только в гейт, не в вход прогноза.
- Обучение в два этапа: сначала база, затем она замораживается, эксперты и гейт обучаются совместно.
- Маршрутизация: мягкий softmax по всем экспертам; top-1 — только вариант «жёсткая маршрутизация» (Table 5), он хуже.

## 3. Потери и регуляризация (Eq. 7)
- L = MSE(ŷ, y) + α·mean[(Σ π_k r_k)²] + λ_LB·Σ_k (π̄_k − 1/K)².
- Член α — сжатие суммарной поправки к замороженной базе; член λ_LB — балансировка нагрузки по средним за батч весам гейта.
- Против схлопывания: нулевая инициализация остаточных слоёв, замороженная база, оба штрафа.
- Не указаны: значения α и λ_LB; энтропийной регуляризации и сглаживания меток в описании нет.
- Функция потерь обучения — MSE, не QLIKE. QLIKE используется только как метрика оценки.

## 4. Протокол
- Данные: 1027 обыкновенных акций США (Yahoo Finance); Sec. 2.1 — декабрь 2015 – ноябрь 2025; оценка 2018–2025. Японская проверка: 1552 акции TSE Prime (Table 9).
- Частота и цель (Eq. 1): дневные прогнозы годовой 5-дневной вперёдсмотрящей реализованной волатильности √252·Std(r_{t+1..t+5}) — по дневным доходностям, не по внутридневным барам. Горизонт 5 дней.
- Walk-forward: окно разработки 504 дня (85 % обучение, 15 % валидация), тест 63 дня, шаг 63; 30 непересекающихся окон (апрель 2018 – октябрь 2025), около 1,9 млн прогнозов вне выборки.
- Число параметров RG-ResMoE не приведено; ёмкостно сопоставимая база MLP-L имеет H = 44, MLP-S — H = 16.
- Seeds: 30 на конфигурацию; подбор гиперпараметров — 3 seeds.
- Обучение: Adam полной выборкой, ранняя остановка по валидации с восстановлением лучшей точки.
- Базы: персистентность 20 дней, HAR (Corsi 2009), GARCH(1,1) по бумаге, Ridge, MLP-S, MLP-L и варианты «+z».
- Метрики: IC, ICIR, RMSE, R², QLIKE, доля отклонений Купьеца для VaR, число «схлопнувшихся» seeds (средний тестовый QLIKE > 2,0). Значимость — тест типа Диболда–Мариано, Newey–West, 4 лага.
- Результаты (США, Table 3, RG-ResMoE против MLP-L): IC 0,5469 против 0,5421; RMSE 0,2304 против 0,2320; R² 0,292 против 0,282; ICIR 6,14 против 6,08; QLIKE 0,735 против 2,23; схлопывание 0/30 против 3/30; обычный MoE — 24/30.
- Table 4: подача z в гейт — ΔIC +0,0004 (0/30 схлопываний); добавление z во вход MLP-L ΔIC −0,0043 (30/30 схлопываний), MLP-S ΔIC −0,0011 (22/30).
- Table 5: жёсткая маршрутизация ΔIC от −0,0021 до −0,0034, p < 10⁻⁴.
- Table 6: K = 2: ΔIC −0,0004 (0/30); K = 6: −0,0002 (3/30); случайная инициализация: −0,0039 (13/30); обычный MoE: −0,0056 (24/30).
- Table 7: доля отклонений VaR 5 %: 26,7 % против 30,3 % у MLP-L.
- Table 8: ΔIC над MLP-L: +0,0048 на всей выборке, +0,0207 в верхнем дециле рыночной волатильности, +0,0322 в COVID.
- Table 9 (Япония): IC 0,4858 против 0,4815; QLIKE 0,80 против 11,6; схлопывание 1/30 против 6/30.
- Масштаб выигрыша: по IC +0,0004…+0,0048 к MLP-L; основной эффект статьи — устойчивость обучения (меньше схлопываний, QLIKE), а не точность.

## 7. ТОЛКОВАНИЕ применимости к SBER, h = 1, цель RV, QLIKE (не факт; мнение исследователя)
Переносится как есть:
- Идея «база + аддитивная поправка» с нулевой инициализацией последнего слоя: при нулевой поправке прогноз равен базе (аналог требования G10 «g ≡ 0 ⇒ F = H побитно»).
- Режимные переменные только в гейт, не во вход поправки; замороженная база; штраф на размер поправки.
- Мягкая маршрутизация вместо жёсткой.

Требует адаптации:
- Цель: у статьи 5-дневная RV по дневным доходностям, потеря обучения — MSE; у нас h = 1, RV по M10-барам, критерий QLIKE (обучение — по QLIKE или в логарифмах); поведение штрафа α при QLIKE нужно проверять отдельно.
- Малая выборка: у статьи окна по 504 дня на панели ~1000 бумаг; у нас одна бумага, ≈ 2300–3000 примеров. K = 4 экспертов с MLP — много параметров на такую выборку; потребуется K = 2 (в Table 6 K = 2 не хуже по ΔIC, но на панели) и малая ширина; число параметров ограничивается G5/G10.
- Внутри окна 85/15 для ранней остановки: на одной бумаге окно валидации мало; нужна вложенная временная валидация и закрытые пары «закрыто + 1».
- Режимные z: рыночная и идиосинкратическая 20-дневная волатильность; для SBER рынок — IMOEX (допустимо только данные ≤ d).
- Значения α, λ_LB, скорости обучения в статье нет — подбор на разработке, входит в N поправки.

Неприменимо или не доказано для нас:
- Поперечный эффект: IC и ICIR измеряют ранжирование по бумагам; для одной бумаги не определены. Заявленные преимущества опираются на панель 1027 бумаг и 30 seeds × 30 окон; на одной бумаге такой мощности нет.
- Главный выигрыш — устойчивость (число схлопнувшихся seeds, QLIKE 0,735 против 2,23); сравнение шло с MLP, а не с HAR-J-подобной базой; выигрыш над сильной линейной базой статьёй не показан (HAR в базах есть, но таблицы с ним в пересказе не приведены — не подтверждено).
- Основание для ожидания улучшения на SBER статья не даёт: ΔIC над MLP-L мал (+0,0004…+0,0048); сильнее эффект лишь в стрессе (верхний дециль, COVID).
