## 2. Фазы аукциона закрытия (одинаково в снимках 2016, 2018, 2019)

Источник: те же снимки s1173 (16.03.2018, 14.12.2019; в снимке 23.07.2016 текст фаз совпадает).

- Без дополнительной фазы: сбор заявок 18:40–18:45; **определение цены закрытия и исполнение заявок 18:45**; фаза заключения сделок по цене закрытия 18:45–18:50.
- При активации дополнительной фазы (запускается «при невыполнении условий определения цены аукциона закрытия»): основная фаза 18:40–18:45; дополнительная 18:45–18:49; **определение цены и исполнение 18:49**; сделки по цене закрытия 18:49–18:50.
- Фаза сделок по цене закрытия: переносятся неисполненные рыночные и лимитные заявки; можно вводить лимитные заявки с ценой аукциона закрытия; непрерывные сделки по цене закрытия при наличии встречных заявок. Это и есть «послеторговый» участок по цене закрытия у акций (отдельного послеторгового периода у акций нет: «Послеторговый период» в расписании 2016/2019 указан для паёв, ETF и облигаций Т0, не для акций).
- Случайное окончание: страница s1173 (2016–2019) называет «принцип случайного окончания аукциона закрытия» (исключает заявку в последний момент), но в расписании фаз момент определения цены записан фиксированным (18:45 / 18:49). Звёздочка «длительность определяется случайным образом в интервале 0–30 с» в тех же снимках относится к аукциону открытия (09:59:30–59), а не к закрытию. Точный механизм случайности по аукциону закрытия в документах 2016–2019 не раскрыт: **не подтверждено документацией** (технический документ «Технология аукциона закрытия» и Правила торгов 2016–2019 недоступны: fs.moex.com отдаёт ошибку сертификата).
- Если по бумаге нет исполнимых заявок, ценой закрытия становится последняя рассчитанная текущая цена (moex.com/n3845, 26.08.2013).
- Контроль цен: заявки с явно нерыночной ценой (±30–40 % от цены закрытия предыдущего дня) отклоняются (n3845, 2013). Современный диапазон ≈ ±(0,5 × ставка рыночного риска), не более ±40 % (s1173, редакция 2026; для 2016–2019 не подтверждено).

## 4. Типы заявок в аукционе закрытия

- Лимитные и рыночные заявки «в аукцион» («Лимитные в аукцион», «Рыночные в аукцион») подаются в течение торгового периода и активируются в основной фазе сбора; приоритет над обычными лимитными и рыночными. «Возможность подавать рыночные заявки. Данные заявки имеют наивысший приоритет исполнения по сравнению с лимитными заявками, поданными в ходе аукциона закрытия.» Лимитные заявки с ценой аукциона закрытия — в фазе сделок. (Снимки s1173 2016, 2018, 2019.)
- Противоречие: объявление биржи от 31.03.2014 (moex.com/n5257) сообщает, что подача рыночных заявок в аукцион закрытия (в течение торгового периода и в самом аукционе) не допускается, доступны только лимитные. Снимки 2016–2019 перечисляют рыночные заявки как доступные. Дата снятия ограничения **не найдена**; какое из двух верно для конкретного дня 2016–2019 — **не подтверждено документацией** (Правила торгов тех лет не получены).
- Можно ли подать заявку «по цене закрытия», не зная её: заявки по цене аукциона закрытия принимаются только в фазе сделок после определения цены (то есть цена уже известна); до этого вход возможен рыночной или лимитной заявкой «в аукцион», цена исполнения заранее неизвестна.
- Гарантия исполнения рыночной заявки в аукционе: в документах 2013–2019 **не найдено**. Известно лишь: рыночные имеют наивысший приоритет; цена определяется по пересечению спроса и предложения; при отсутствии исполнимых заявок цена закрытия — последняя расчётная (n3845). Остаток неисполненных заявок переходит в фазу сделок по цене закрытия (s1173). Правила снятия остатка рыночной заявки — не подтверждено документацией.

## 6. Ответ на вопрос Ж-084 (по найденному)

Цена close d (цена аукциона закрытия) определяется в 18:45 MSK (иногда в 18:49 при дополнительной фазе), то есть после окончания непрерывных торгов (18:39:59) и сбора заявок; до этого момента она неизвестна. Тот, кто считает сигнал по `CLOSE` из ISS (цена аукциона) и «входит по рынку по close d», использует число, которого не было в момент последних непрерывных сделок; реально исполнимы: (а) рыночная/лимитная заявка «в аукцион», поданная до 18:45 без знания цены (исполнение по цене аукциона, гарантия не подтверждена; сигнал при этом должен быть посчитан по данным до ~18:40), либо (б) заявка по цене закрытия после 18:45 (цена известна, исполнение при наличии встречных заявок, окно до 18:50). Сигнал, посчитанный на `CLOSE d`, не может быть известен до подачи заявки «в аукцион». Это вывод из документов; на данные не накладывался.
