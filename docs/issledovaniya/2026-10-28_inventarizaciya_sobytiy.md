# Инвентаризация источников событий, 2018–2026 (И-соб, Ж-070; дата обращения 2026-10-28)

Только метаданные источников. Значения событий (даты и величины) не выгружались и не сохранялись; для периода ≥ 2022 не собиралось ничего, кроме того, что страница вообще есть и с какого года охватывает. Полнота — оценка по виду страницы, не по сверке.

## Что не подтверждено документацией
- Открытие e-disclosure.ru (отчётность, SPO, байбэки): curl — HTTP 403; нужны браузер или иной способ, не проверялось. Это три из восьми типов.
- Даты объявлений MSCI и ребалансировок IMOEX за 2018–2021: источник-архив назван, содержимое не открывалось.
- Календарь экспираций FORTS: правило определения дня экспирации не подтверждено спецификацией.
- Единый для 17 эмитентов календарь отчётности — не найден.

## Для PR данных
Первый шаг: ЦБ (источник открыт, даты заседаний и пресс-релизы по годам 2014–2021 доступны), затем состав IMOEX по ISS и экспирации по ISS. Отчётность, SPO и байбэки требуют проверки e-disclosure.ru. Значения 2022+ в PR данных по канону (`dannye.md`) не собирать.
