# Сверка дивидендов ≤ 2021, круг 2, часть Y: дата объявления (TATN, ALRS, AFLT, HYDR, SBER)

Дата проверки: 30.10.2026 (все ссылки открыты в этой сессии; время публикации - по метке страницы, Москва). Данные: `2026-10-30_div_sverka2_Y.csv` (34 строки = все строки `net_istochnika` этих пяти тикеров в кругах 1 A/B/C). Статус: справка по раскрытию, разработка 2015-2021.

Правило даты: дата объявления = дата публичного раскрытия решения/рекомендации СД. Источник - датированная новость Интерфакса/Прайма/Коммерсанта/Ведомостей/РБК/пресс-релиз эмитента. Агрегаторы (smart-lab, investmint, investfuture, dohod) не использованы как подтверждение. e-disclosure.ru и tatneft.ru не открывались без JS; первичный текст сообщения о существенном факте не получен ни по одной строке, поэтому по Д8 все `yes`/`rashozhdenie` держатся на одном датированном СМИ - «одна независимая публикация», а не «два источника». Оговорка важна: публикация СМИ - верхняя граница даты раскрытия, более раннее раскрытие (вечер накануне) исключить без e-disclosure нельзя.
