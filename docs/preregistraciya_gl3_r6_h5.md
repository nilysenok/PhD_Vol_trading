## Дополнение владельца:1г и Г7

1г: D12 — pooled17, общие гиперпараметры на библиотеку×шаг, без явного ticker/sector ID. HAR(а)/(б) — pooled коэффициенты; (б) — общий скалярs², (а) — без множителя. Подтверждение и17строк —2026-11-04_gl3_r6_h5_TICKERS.md.

Г7 применяется отдельно к сохранённому финалу и LOYO-лучшему родителю из Г1–Г6 (набор родителей заморожен, Г7 не выбирается родителем другого Г7):
- а: замена retransformation на exp(s²_i/2); s²_i — ddof0 дисперсия log-ошибки raw-прогноза по прошлым3годам, end_h5<cut, годовое обновление. При отсутствии истории множитель1; недостающий тикер использует pooled значение.
- б: множитель к уже исправленному прогнозу родителя. k_i_hat=mean(RV/p)_i, k_pool=mean(RV/p) по прошлым3годам, end_h5<cut. k_i=w*k_i_hat+(1−w)*k_pool, w=.25/.5/.75. Каждый w показан как hyperparameter point; основная допущенная строка — LOYO-выборw без оцениваемого года. Глобальный фиксированныйw для возможного будущего протокола выбирается по всем5годам; нельзя обойти LOYO-допуск выбором самой привлекательной промежуточной точки.
- в: ticker как настоящая категория LGB/XGB, общая панель17, без потикерного Optuna. Для FIN используются общие frozen-параметры исходного warmup2016, годовой purged ES/refit; это честное переобучение, а не причинная оценка эффекта одногоID относительно старого in-sample финала. Для родителя Г1 сохраняются его общие выбранные параметры/число деревьев; для Г4 — его фиксированная конфигурация. Для метамодели Г2/Г3/Г5/Г6 ID добавляется в её бустинговые компоненты FIN/K9, затем метамодель переоценивается по прошлому окну. HAR/HAR-X⁺/HAR-CJ/итерационный путь остаются фиксированными источниками. Нормировка Г4: stock-variance регрессоры /scale252, квадратные корни дисперсий /sqrt(scale252), внешние уровни сохраняют единицы.

Код Г1 сначала проверялся на технических прототипах с не полностью воспроизведёнными numeric defaults. Затем уточнены исключения признаков и log-floor D12; отдельно исправлена QLIKE trial-score: исходныйRV, а не RV+1e−10 из log-метки. Все такие fit/прототипы остаются в ledger и полном N; к выбору допускаются только окончательные прогнозы numerical contract D12_clean_v3. Бины гистограмм строятся на очищенном прошлом текущего fit; утверждение изоляции чистого причинного эффекта purge не делается. Сохранённый финал не меняется.
