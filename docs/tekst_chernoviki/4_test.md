## Текст

**Абзац 1 (протокол теста).** Тест проводился один раз, на периоде 03.01.2022–03.02.2026 (1 089 торговых дат); отдельно показан период 2025–01.2026 (345 дат) [s9_T2_podperiody_final3_test.csv, `days`].
- Каждый подход на тест шёл одним дизайном, выбранным на разработке 2018–2021 по правилу С8: подход C — правило режима C1 с окном 504 дня и порогом ранга 0,70 на прогнозе h=5; подход D — затвор D6 (отношение прогноза к индексу RVI); подход B — лучшая по С8 точка cap1_band20, хотя С8 она не прошла.
- Эталон — подход A, те же сигналы без прогноза волатильности, с фильтром оборота.
- Окна калибровки всех правил заморожены на 2018–2021. На тесте выбора не было.
- Основной p для разности Шарпа — Ледуа–Вольф с блоком 5, двусторонний.

**Абзац 2 (основной результат по подходам).** За 2022–2026 ни один дизайн с прогнозом волатильности не превзошёл эталон.
- A: Шарп −0,42.
- C: −0,61, Δ −0,19, p ЛВ 0,27.
- D: −0,74, Δ −0,32, p 0,17.
- B: −0,71, Δ −0,29, p 0,41.

[s9_osnovnye_final3_test.csv, `sharpe`, `d_vs_A`, `p_vs_A`]

A без фильтра оборота дал −0,37 — на 0,05 лучше основного A, незначимо (p ЛВ 0,52) [там же].

Положительного Шарпа за период нет ни у одного дизайна. Из полных лет положителен только 2022: у A (0,29), A без фильтра (0,43) и B (0,38). 2026 представлен 27 днями и не показателен [s9_osnovnye_final3_test.csv, `2022`, `2026`; s9_T2_podperiody_final3_test.csv, `days`].

На 2025–01.2026 все дизайны глубоко отрицательны:
- A −1,53;
- C −1,09;
- D −1,71;
- B −1,67.

[s9_T2_podperiody_final3_test.csv, `sharpe`]

C здесь наименее плох, но p для этого окна не считался [только в отчёте: разность −1,09 − (−1,53) = +0,44].

**Абзац 3 (доля закрытых дней).**
- Затвор C на тесте держал позицию закрытой в 42,7% пар-дней. Это близко к калибровочным 43,2% на 2018–2021 [s9_C_osnovnaya_final3_test.csv, `closed_dev`, `calib_closed`].
- Затвор D6 закрывал позицию в 25,6% пар-дней [s9_D_zatvor_final3_test.csv, строка «D6 (выбор по валидации)», h1, `closed_dev`]; на разработке — 18,1% [docs/tables/strat_dev/s9_D_zatvor_final3.csv, `closed_dev`].

Правила работали так, как были откалиброваны. Отрицательный результат связан не с вырождением затвора, а с тем, какие именно дни он закрывал.

**Абзац 4 (сравнение с разработкой).** Преимущество подходов C и D, полученное на разработке, на тест не перенеслось.
- На 2018–2021 C был лучше A на 0,42 Шарпа (p IID 0,006; p ЛВ 0,043). С учётом выбора точки из 26 p равнялся 0,081 [FINAL_DESIGN_strategies.md, раздел 9, п. 13].
- На тесте C хуже A на 0,19 (p ЛВ 0,27) [s9_osnovnye_final3_test.csv, `d_vs_A`, `p_vs_A`].
- D: +0,13 на разработке → −0,32 на тесте [docs/tables/strat_dev/s9_D_zatvor_final3.csv, `d_vs_A`; s9_osnovnye_final3_test.csv, `d_vs_A`].

Порядок подходов перевернулся. На разработке C > D > A > B, на тесте A > C > B > D [те же таблицы, `sharpe`]. Этот исход согласуется с оговорками, сделанными до теста: точка C выбрана из сетки по тем же годам, а режим C неустойчив к реализации прогноза — при корреляции прогнозов 0,977 маска совпадает лишь в 31% пар-лет [FINAL_DESIGN_strategies.md, раздел 4].

**Абзац 5 (H2).** Гипотеза H2 — более точный прогноз волатильности даёт лучший результат стратегии — на тесте не подтвердилась. Проверка шла внутри подхода C: одна и та же стратегия на гибриде, на HAR-J и на наивной оценке √RV_w.

В правиле C основного прогона (u02, h=1):

| | Шарп | Разность с гибридом | p ЛВ |
|---|---|---|---|
| гибрид | −0,83 | — | — |
| HAR-J | −0,22 | −0,60 | 0,0075 |
| наивная оценка | −0,16 | −0,66 | 0,0041 |

[s9_C3_tochnost_v_rezultat_final3_test.csv, строка Cref, `sharpe_*`, `d_hyb−harj`, `p_lw_hyb−harj`, `d_hyb−naive`, `p_lw_hyb−naive`]

Значимость здесь в обратную сторону. В семьях правил C1 и C2 разница гибрида с HAR-J незначима: +0,08 (p 0,42) и −0,00 (p 0,96) [там же, строки «C1 семья», «C2 семья»]. На разработке та же разность для u02 была +0,19 (p ЛВ 0,385) [docs/tables/strat_dev/s9_C3_tochnost_v_rezultat_final3.csv, `d_hyb−harj`, `p_lw_hyb−harj`].

Выигрыш гибрида в точности прогноза (глава 3) в результат стратегий не транслируется.

**Абзац 6 (H3).** Гипотеза H3 — превосходство МСП над классическими портфелями — не подтвердилась.
- Шарп МСП-A за 2022–2026 равен −0,42.
- Бенчмарки:
  - MCFTR с той же экспозицией −0,01;
  - MCFTR 16% плюс ставка −0,43;
  - смеси MCFTR/RGBITR 20/80, 60/40, 80/20 — −0,70, −0,51, −0,46.
- Положительные разности (+0,02…+0,29) незначимы: p ЛВ 0,72–0,98.
- Против MCFTR с той же экспозицией разность отрицательна: −0,40.

[tabl_4_final_h3.csv, строки design = main, approach = A: `sharpe`, `d_sharpe_msp_minus`, `p_boot`]

На 2025–01.2026 все пять разностей отрицательны [там же]. У МСП-A без фильтра вывод тот же [tabl_4_9_h3.csv, `h3_accept`].

Преимущество МСП — в просадке: 2,2% против 6,6–54,2% у бенчмарков [tabl_4_final_h3.csv, `mdd_pct`]. Но это не превосходство по Шарпу, которое утверждает H3.

**Абзац 7 (сценарий с маржой, вне гипотез).** Срочный рынок смоделирован без данных фьючерсов: в позиции 20% номинала, остаток под ключевую ставку. В этом сценарии Шарп за 2022–2026:

Сценарий не входит в проверку гипотез. Он показывает, что отрицательный избыточный Шарп спот-портфеля во многом объясняется ставкой на занятый капитал при экспозиции около 10–14% [s9_osnovnye_final3_test.csv, `exposure_pct`].

**Абзац 8 (чувствительность сетки C).** Остальные точки сетки C показаны для оценки устойчивости, без выбора.

Из 30 строк на прогнозе гибрида значимо (p ЛВ < 0,05) от A отличаются две:
- правило u02 на h=5 — Шарп 0,01, Δ +0,43, p 0,032;
- C1 с окном 504 и порогом 0,90 на h=1 — Δ −0,22, p 0,048.

[s9_C_chuvstvitelnost_final3_test.csv, `sharpe`, `d_vs_A`, `p_vs_A`]

Это ещё одно проявление неустойчивости правил режима. При 30 коррелированных строках две значимые разности не дают оснований для вывода.
