## Данные и dev

Только2017–2021;2014–2015 — исходное обучение,2016 — OOS-история инициализации, не шестой оценочный год. Расширяющееся прошлое окно, годовые модели по умолчанию. Цельh1=RV_(d+1),h5/22=среднее RV следующихh торговых дат. Конец каждой обучающей цели строго раньше момента переобучения; конец2021 за пределами2021 не декодируется. Все читатели численных данных — с фильтром даты/годовым файлом≤2021; шаги7–10/будущие коэффициенты не читаются.

Модели обучаются заново, не на поправке к сохранённому финалу раунда4. Сохранённый финал используется только для диагностики/сравнения. HAR-J и HAR-X⁺ компоненты переоцениваются на прошлых данных. Архитектура FIN: h1=HAR-X⁺ как признак+top5 XGBoost на lnRV с train-only winsor1/99; h5=среднее уровней нового residual-LightGBM и XGBoost на HAR-J, h22=HAR-J(б). Для воспроизводимости численные параметры старых FIN-компонент замораживаются по исходной warmup-ступени2016, не по оцениваемому году; число деревьев выбирается ранней остановкой на последних126 завершённых датах внутри прошлого окна, затем новый fit на полном прошлом. Никакой ES на текущем оцениваемом году.

Признаки — признаковые семейства финала с RV/HAR-компонентами, рассчитанными кd; h1: v3,RRV,ночной гэп, свежий HAR-X⁺; h5: v3+некалендарные Д7+свежий HAR; h22: HAR-регрессоры. Неизвестные даты объявления прежних календарей не допускаются как новые известные признаки: без подстановки «1января». RQ берётся из проверенной10-мин квартильности до18:50; в К11 «lnHARQ(realized quarticity)» означает lnRQ, не логарифм прогноза отдельного HARQ. Модельные преобразования/PCA/масштабирование обучаются только на прошлом. Каждый новый признак и каждый режим переобучения имеет мутацию будущих входов и негативный контроль сдвига даты происхождения/обучения вперёд.

## Закрытый список раунда5

- К9a: MSE log-остатка к заново обученному HAR-J(б), отдельно LightGBM/XGBoost; возвратHAR-J(б)×exp(correction)×exp(s²/2).
- К9б: тот же log-остаток, монотонная поправка: + по lnRV_d/w/m, − по lnHAR-J(б); ограничения заданы по четырём именованным входам при фиксированных остальных признаках; глобальная монотонность вдоль всех коррелированных признаков не заявляется.
- К9в: LightGBM linear_tree=True, linear_lambda=1; XGBoost-линейные деревья не подставляются.
- К9г: c=.25/.5/.75 к поправке лучшего структурного К9 внутри библиотеки; структура и c выбираются LOYO без оцениваемого года. Сжатие MSE не требует новых обучений; все проверенные рецепты всё равно входят в N.
- К10: выбранная LOYO структура/сжатие К9, собственная QLIKE-цель LightGBM в log-level, init_score=lnHAR-J(б), grad=1−exp(y−f),hess=exp(y−f); при параметризации c*g применяется правило цепочки. Отдельной поправки смещения нет.
- К11: OLS-модель центрированного квадрата прошлого OOS log-остатка по lnRVI,lnRQ,lnRV_w; vhat обрезается снизу0. Вместо скалярного exp(s²/2) — exp(vhat/2). Две ноги: свежий FIN и лучший К9/К10, если разрешён диагностикой. Окно до3 прошлых лет с эмбарго. На пустой начальной OOS-истории2016 множитель1, не подстановка будущей оценки.
- К12: LOYO-лучший из FIN/К9/К10/К11 при quarterly,monthly,annual с полураспадом1/2года,rolling3years. Всё обучение с нуля на завершённых целях перед началом периода; старый бустинг не дообучается на будущих данных. HAR-J(б)-адапт рассчитывается в тех же5 режимах, его вариант соответствует выбранному режиму кандидата.
- К13: среднее10 RV по минутным барам и10-мин сеткам со сдвигом0…9минут, только основная сессия и цены доступные к18:50. Используется существующий минутный архив2014–2021, без чтения файлов2022+. Нет цен до первой наблюдаемой минуты/ночной доходности/интерполяции из будущего. Результат применяется к stock-RV признакам и целям обучения LOYO-лучшего К9–К12; оценка всегда на прежней RV и том же кадре. HAR-J(б) на этой же мере — отдельный эталон.
- К14:10seed42…51 выбранного LOYO К9–К13. Геометрическое среднее сырых прогнозов, затем переоценённая по прошлой OOS-истории поправка выбранного типа (скалярная либо условная). Старые корректирующие множители не применяются дважды; на детерминированном HAR тождество seed явно помечается.

## Резерв раунда6

Запускается автоматически **только если на всехh нет допущенного К9–К14**. Если хотя бы одинh прошёл, резерв не используется для остальныхh без нового поручения.

Р1: положительный ridge(alpha1,intercept свободен, сумма весов не ограничена) на логарифмах заново обученных OOS FIN,HAR-J(б),HAR-X⁺,HARQ,HAR-CJ,доступных К9-LGB/XGB,К10 и ансамбля MLP Р5; окно/переоценка — лучший К12. Веса обучаются только по прошлым завершённым OOS-целям. Дубликаты FIN/HAR наh22 обозначаются, отсутствующие по диагностике К9/10 не подменяются.

Р2: общая нормированная панель17 тикеров, масштаб — средняя RV предыдущих252 наблюдений, известная наd; цель и численные признаки нормированы на этот масштаб, сектор добавлен как категориальный признак. Прогноз масштабируется обратно. Одна библиотека LightGBM без сетки.

Р3: два residual-бустинга calm/stress, RVI относительно прошлой медианы. Логистический gate по lnRVI и lnRV_w, совместная оценка на прошлом через3 фиксированных EM-итерации; два эксперта и gate каждой итерации входят в фактический счёт обучений. Ни текущий оцениваемый год, ни будущие режимы не обучают gate.

Р4: две головы LightGBM: μ для lnRV и v для квадрата прошлой OOS-ошибки μ; v≥0, прогнозexp(μ+v/2). Отдельной дополнительной поправки нет. Выбор другой библиотеки/NGBoost после исходов не делается.

Р5: MLP(32,16),ReLU,Adam,5seed42…46,макс100эпох,patience10; ES только на прошлой временной внутренней части, затем полный fit на выбранном числе эпох. Только компонент Р1, отдельно не допускается.

Р6: мера К13 + LOYO-лучший изР1–Р4, всё обучение повторяется на новой мере. Оценка на прежней RV.

## Отбор, допуск, N

QLIKE=y/p−ln(y/p)−1. Основная dev-метрика — равновесное среднее5 годовых QLIKE. Внутри года/стрессовой строки — пул17. Один победитель наh из фактически проверенного объединённого списка: минимум среднего среди прошедших. Допуск: строго лучше FIN в≥3/5 лет и **не хуже** в обеих стрессовых строках (здесь применяется текущее уточнение владельца; равенство допускается). Численная толерантность1e−12; тождество FIN всё равно не выигрывает3 года. Р5 не самостоятельный кандидат. Все внутренние выборы библиотеки/структуры/родителя/режима делаются по остальным4 годам, полный5-летний выбор фиксирует рецепт для возможного контроля; годовые оценки сами построены по расширяющейся прошлой истории. Это не новое заявление независимости после прежнего отбора.

N включает все реально обученные рецепты, каждый seed, предварительный ES-fit/полный refit, компоненты и отрицательные результаты; также отдельно считаются проверенные безобучаемые преобразования и метаоценки. Кэш не выдаётся за новое обучение. Ранее выполненные раунды3/4 повторно не начисляются. По уточнению владельца сохраняются прогнозы parquet/float32 и dev-таблица, а также малые метаданные счёта/происхождения. Деревья не сохраняются, кроме возможных победителей; собственные временные файлы удаляются после использования. Перед каждым этапом df -h /, при свободных<20GiB остановка и сообщение владельцу.
