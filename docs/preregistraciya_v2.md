## 4. Процедура калибровки (одна на все окна) [Ж-136 п. 2]
Тройка — (стратегия Sk, подход A, тикер), 17 тикеров. Для каждого окна t:
0. **Моррис (только v6, до полного прохода)** [Ж-137 п. 2]. 5 000 точек на стратегию, данные ≤ 2021, правило заморозки — У-4.
1. **Фаза 1 (Соболь).** N₁ = 200 000 индексов на стратегию [Ж-137 п. 2], на каждый куб (v5, v6), один проход по всему периоду (§9.1). У v5 несовместимые точки выбрасываются, N₁ берётся до выброса (У-3). Ворота v4 на окне: Шарп > 0, MDD > −30 %, экспозиция > 5 %. Затем top-50 по Шарпу окна.
2. **Фаза 2 (плато).**
   - Соседи ±1 по осям с эффектом (размах ≥ `TOR_MIN = 0,05`); плато — среднее точки и посчитанных соседей.
   - Меньше `MIN_NB = 3` соседей — край, точка не берётся.
   - Затем top-20 по плато.
   - Новые соседи считаются одним проходом, батчем для 10 окон, и идут в ledger и в N.
3. **Фаза 3 (исполнение v4).** 108 сочетаний над top-20 → top-10 по Шарпу окна. Пока П2 не слит, фаза 3 — тождество. Если П2 сливается до коммита — записывается здесь, после коммита — новая версия.
4. **Голосование.** `ENS_K = 10`, `VOTE_FRAC = 0,5`, по позициям автомата членов (`kalibr_v5_golos.golos_v2`). Ансамбль торгует год t.

Баланс Соболя: N₁ = 200 000 — не степень двойки, баланс полный только в префиксе 2¹⁷. Это принято вместе с числом владельца.

**Контроли** (`kontroli_v5.py`), все на тех же 10 окнах и на основной сетке:
- к1 — безусловное среднее по выборке префикса Соболя (4 096 индексов);
- к2 — циклический сдвиг весов выбора: 199 сдвигов, лаг ∈ [21, n−21], seed 20261027, p = (1 + #)/(N + 1);
- к3 — только оси v4;
- второй seed — вся процедура заново, печатается расхождение по годам;
- одна точка на всё — одна точка на стратегию для всех тикеров, argmax плато на окне ≤ t−1, заново каждый год.

**N для DSR.** Основное N — число различных `klyuch` на стратегию по всем посчитанным точкам:
- Моррис;
- фазы 1–2 обоих seed;
- к3 и фаза 3;
- обе сетки (v5, v6) и все прежние проходы.

Справочно рядом — N только основной сетки.

**PBO.** CSCV на общей матрице «точки × блоки»:
- S = 10 блоков из целых кварталов 2015-Q1…2026-Q1, границы объявлены в коде до счёта;
- правило выбора внутри CSCV — правило процедуры (Ж-080, мутация № 42), без голосования (У-19).
