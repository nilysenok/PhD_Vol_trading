Признаки, инвариантные к масштабу (z, каналы, ATR/close), от этого не меняются, но побайтного равенства может не быть. Гейт до коммита — задача К-wf4 (§11).
2. **Суммы по кварталам всего периода** — 45 кварталов (Б8). Окно t — это кварталы с номером < 4·(t − 2015), считая от 2015-Q1; граница окна совпадает с 31.12(t−1).
3. **Окно оплачивает выход на конце.** Для этого есть поля F_L/F_X (Л7b `75205e89`), поэтому окно по суммам = усечённому прогону.
4. **Точки Соболя от данных не зависят.**

Значит, объём = **1 проход × 6 Sk × N₁ на 06.2014–02.2026**, а не 9–10 проходов. Раздельные прогоны окон стоили бы Σ(t − 2014,5) ≈ 70 лет баров против 11,75 года одного прохода, то есть ≈ ×6.
