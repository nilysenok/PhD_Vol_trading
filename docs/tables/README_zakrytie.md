# Таблицы теста главы 3: две версии по правилу «закрытие биржи»

Срез сделан по поручению владельца после единственного запуска теста. Правило сформулировано после первого прогона теста (поручение 26.10, 09:55; FINAL_DESIGN, разд. 13). Все таблицы посчитаны из сохранённых тестовых прогнозов скриптом `scripts/analysis/test_dop2.py`. Тест повторно не запускался.

Формат всех файлов: разделитель «;», десятичная запятая, UTF-8 с BOM.

## Правило

Точка отсчёта t тикера исключается для всех моделей и всех h, если окно цели [t+1, t+h] задевает дни остановки торгов MOEX 28.02–23.03.2022. Окно цели — это следующие h торговых строк тикера. У LSRG, MTLR и OGKB, которые открылись 28.03.2022, в закрытие входят ещё и 24–25.03.2022. Исключённые точки перечислены в `table_3_zakrytie_isklyucheno.csv`: h=1 — 17, h=5 — 85, h=22 — 374. На каждом h это последние h точек каждого тикера до 25.02.2022 включительно.

## Какие файлы к какой версии

Окончание имени задаёт версию:
- `_test_bez_zakrytiya.csv` — без правила, все точки;
- `_test_s_zakrytiem.csv` — с правилом, точки из `table_3_zakrytie_isklyucheno.csv` исключены.

Колонка «правило» внутри файла повторяет версию.

| префикс | период | что внутри |
|---|---|---|
| `table_3_vse_*` | весь тест 2017–2026 (заранее заданный в `final_test.py`) | `svodka` — основная строка: QLIKE финала, HAR-J (б) — с поправкой, эталон; HAR-J (а) — как в диссертации; лучшая одиночная бустинга; % к эталонам, основной DM, p_MCS, знаковый тест. `dm` — DM тремя способами против обоих эталонов. `mcs` — MCS, T_R и T_max. `tickers` — по тикерам и доли. `subperiods` — 2017–2019, 2020–2021, 2022, 2023–2026. `znak` — доля тикеров с выигрышем и биномиальный знаковый тест |
| `table_3_kontrol_*` | контрольный 2022–2026 (2022–2024 — подтверждающий, использовался для выбора из трёх финалистов) | то же; в `svodka` и `dm` — флаг H1 (основной DM против HAR-J (б), 5%); подпериоды — 2022, 2023–2024, 2025–2026 |
| `table_3_neotkr_*` | неоткрывавшийся 2025 – 01/02.2026 | то же; подпериоды — 2025 и 2026 (01–02). Правило здесь ничего не меняет: обе версии совпадают |

Знаковый тест (`*_znak_*`) — только иллюстрация: тикеры коррелированы, поэтому тест не независимый.

## Связь с прежними файлами

- Прежние `table_3_kontrol_{svodka,dm,mcs,tickers,subperiods}_test.csv` и `table_3_neotkr_{dm,mcs,tickers,subperiods}_test.csv` (PR #114, без суффикса) — это версия **без правила**. По числам они совпадают с `*_test_bez_zakrytiya.csv`; `test_dop2.py` это проверяет. В новых файлах добавлены колонка «правило», знаковый тест и пометка.
- Сохранённые таблицы единственного запуска `table_3_*_test.csv` (и `*_test_raw.csv`) — весь тест **без правила**. С ними совпадают `table_3_vse_dm_test_bez_zakrytiya.csv` (= `table_3_9`) и `table_3_vse_mcs_test_bez_zakrytiya.csv` (= `table_3_mcs`).
- Терцили (`table_3_dop_terciles_v3_test.csv`), MZ, охват, RMSE/MAE, раскладка есть только без правила; по правилу они не пересчитывались.

Для текста главы основная таблица даётся в двух версиях: `table_3_kontrol_svodka_test_s_zakrytiem.csv` и `table_3_kontrol_svodka_test_bez_zakrytiya.csv`.
