Копии лежат в `data/server_2021/<тот же путь>` (в `.gitignore`); на этом прогоне — в рабочей копии агента (хук запретил запись в основную копию; для переноса скопировать каталог целиком или повторить скрипт: `usech_2021.py --koren <основная> --vyhod <куда>/data/server_2021`). После усечения каждая копия независимо проверена `manifest_perenos` (max ≤ 2021-12-31).

**Правило point-in-time (Д3) по файлам** (строка входит, только если ВСЕ перечисленные даты ≤ 2021-12-31):

- `torgovye_dni_moex.csv` — `date` ≤; будущие дни календаря (≥ 2022) отброшены.
- `cbr.csv`, `fomc.csv`, `cpi_us.csv`, `expirations.csv`, `imoex_rebal.csv`, `imoex_rebal_official.csv` — `date` (событие) И `known_from` (объявлено) ≤; запланированные события 2022+, объявленные раньше, не входят (событие в будущем). Пустой `known_from` — строка отброшена (объявление не доказано). `retrieved_at` (дата скачивания) очищен.

Фильтр на чтении: parquet — пакетами по 65 536 строк (`iter_batches`, без `read_table`), csv — построчно; значения ≥ 2022 накапливаются не больше пакета, не печатаются и не пишутся. Ранняя остановка по отсортированности — опция (`ostanov`), в прогоне выключена: файл дочитывается весь, чтобы строки ≤ 2021 после «выбившейся» строки не терялись молча.
