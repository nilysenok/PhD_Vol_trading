Пересчёт крейтом `moex_iss` (не Python) из скачанных с ISS баров всех сессий `data/iss_check/bars_10m_full/` (в `bars_10m/` бары уже обрезаны по 18:40 для первой проверки). Формула та же, что у хранимых признаков (`moex_volatility/src/data/intraday_features.py:105-173`; реализация `moex_iss/src/rv.rs`): r = ln(close_t/close_{t-1}) по сквозному ряду баров (первый бар дня даёт ночную доходность), RV = Σr², BV = (π/2)Σ|r_i||r_{i-1}| (лаг внутри дня), J = max(RV−BV, 0), RSV± = Σr² при r>0 / r<0, масштаб дневной. Меняется только окно баров: **begin ∈ [09:50; 18:50)**, то есть бар предоткрытия 09:50 (он есть в старых признаках), основная сессия и бар аукциона закрытия 18:40–18:50; всё с begin ≥ 18:50 (вечер) и раньше 09:50 (утро) отброшено.

Файлы (parquet, в репозиторий не добавлены; `n_quar` — число баров дня из карантина пайплайна, `n_bars` — число доходностей, т.е. баров окна):

- `data/iss_check/rv_1850.parquet` — **основной**: date, ticker, rv, bv, j, rsv_pos, rsv_neg, n_bars, n_quar; 17 тикеров, все биржевые бары без чистки (51 328 тикер-дней, 2014-06-02 … 2026-02-27; в первом дне ряда нет ночной доходности).
- `data/iss_check/rv_1850_noquar.parquet` — то же, но без баров из карантина (так, как чистил пайплайн; сравнимо со старыми признаками).
- `data/iss_check/rv_1850_from1000.parquet` — строгое окно begin ∈ [10:00; 18:50) без бара 09:50.

Воспроизведение (из корня репозитория; хранимые данные основной копии читаются только на чтение):

```
cd moex_iss && cargo build --release && cd ..
RAYON_NUM_THREADS=3 moex_iss/target/release/moex_iss rv1850      # три parquet + data/iss_check/report/rv1850_*.json, bars_count_*.csv
moex_iss/target/release/moex_iss report1850                       # этот раздел
```
