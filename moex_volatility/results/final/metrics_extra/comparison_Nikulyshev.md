# Сопоставление с работой Д.А. Никулышева (Задача 5)

**Никулышев Д.А.** «Машинное обучение для прогнозирования волатильности и улучшения торговых стратегий на российском фондовом рынке» // Фундаментальная и прикладная математика. 2025. №4. Т. 25.

## Что общего

1. **Объект исследования**: российский фондовый рынок, применение моделей машинного обучения к прогнозированию реализованной волатильности.
2. **Базовая модель**: HAR-RV (Heterogeneous Autoregressive model of Realized Volatility, Corsi 2009) как эконометрический бенчмарк.
3. **ML-модели**: градиентный бустинг (XGBoost / LightGBM) для прогноза σ.
4. **Метрика качества**: QLIKE (Patton 2011) как основная функция потерь при оценке.
5. **Оценка на OOS**: walk-forward валидация на современных данных MOEX.
6. **Цель**: улучшение торговых стратегий через интеграцию прогнозов волатильности.

## В чём наша работа шире и глубже

| Аспект | Никулышев | Настоящая работа |
|---|---|---|
| **Число инструментов** | ~5 тикеров | **17 тикеров** MOEX |
| **Период OOS** | ~2 года | **9 лет** walk-forward (2017–2025) |
| **Горизонты прогноза** | h=1 | **h=1, h=5, h=22** (краткий, средний, длинный) |
| **Класс моделей** | отдельные ML | **гибридная модель** (HAR-J + лучший ML, адаптивный выбор per-horizon) |
| **Признаковое пространство** | базовые HAR + лаги | **234 признака**: индексы MOEX, глобальные активы (Brent, VIX, S&P500), макроэкономические (КС, ФРС, ИПЦ, M2), календарные, отраслевые |
| **Стратегии** | 1-2 направленные | **6 сигнальных систем × 4 подхода** = 24 комбинации |
| **Механизмы интеграции прогнозов** | адаптивный стоп | **4 подхода**: A (ATR), B (σ-стопы), C (режимный фильтр), D (vol-targeting) |
| **Портфельный уровень** | per-ticker | **3-уровневая агрегация**: per-ticker → per-strategy (17 тикеров EW + ФДР) → МСП (6 стратегий EW) |
| **Статистические тесты** | Diebold-Mariano для QLIKE | **DM для QLIKE/MSE/MAE**, **bootstrap** ΔSharpe (10 000 реплик), **MCS** (Model Confidence Set) |
| **Бенчмарк** | IMOEX B&H | IMOEX B&H + **ФДР-смешанный бенчмарк** (та же экспозиция что у МСП) |
| **Экономическая оценка** | нет | **CE (certainty equivalent)**, **K_min** (пороговый капитал), Calmar, Omega |
| **Корректировка FDR** | нет | учтена как post-hoc FDR bias correction для QLIKE h=5 |

## Ключевые результаты нашей работы

1. **Гибридная модель значимо превосходит HAR-J** по QLIKE на всех трёх горизонтах (DM-тест p<0.001). На h=1 ΔQLIKE = 0,148 (−28% относительно HAR-J).

2. **Подход D (vol-targeting)** даёт Sharpe МСП **2,54** против 1,32 у базового A (+92%), p<0.001.

3. **Экономическая ценность**: ΔCE(D>A) = **+1,79%/год** при γ=10, статистически значим (p=0.022). Пороговый капитал K_min ≈ 180 млн руб.

4. **Портфельный эффект**: МСП с экспозицией 7-16% значимо превосходит как голый IMOEX, так и honest-бенчмарк с той же экспозицией (ΔSharpe +1,7…+3,0, p<0.01).
