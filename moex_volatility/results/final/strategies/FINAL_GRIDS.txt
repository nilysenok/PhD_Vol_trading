======================================================================
3. PER-STRATEGY ПОРТФЕЛЬ (stage5b_perstrat_portfolio.py)
======================================================================

Схемы взвешивания:
  EW (Equal Weight): w_i = 1/N
  IV (Inverse Volatility): w_i = (1/σ_i) / Σ(1/σ_j)
     σ рассчитывается на обучающей выборке
  RP (Risk Parity): итерационный алгоритм (100 итераций)
     RC_i = w_i × (Σw)_i / σ_p = σ_p / N
     Bounds: w_i ∈ [0, 1], Σw = 1
  MS (Max Sharpe): scipy.optimize.minimize
     max (μ'w) / √(w'Σw)
     Bounds: w_i ∈ [0, 1], Σw = 1, long only

Ticker selection:
  ALL: все 17 тикеров
  POSITIVE: тикеры с trading Sharpe > 0 на обучающей выборке
  TOP12: top-12 по trading Sharpe на обучающей выборке
  Минимум: 5 тикеров (fallback на ALL)

Walk-forward:
  Веса пересчитываются ежегодно
  Train: все данные до начала test_year
  Test: test_year

6. H5 (ОБНОВЛЁННАЯ ФОРМУЛИРОВКА)
======================================================================

Старая H5: Таргетирование волатильности обеспечивает наибольшую
           экономическую ценность среди подходов интеграции прогнозов.
Статус: НЕ подтверждена (D не значимо лучше C после исправления FDR)

Новая H5: Подходы интеграции прогнозов волатильности, основанные на
          управлении размером позиции (режимная фильтрация и
          таргетирование волатильности), обеспечивают статистически
          значимую экономическую ценность.

Обоснование:
  CE C>A: +2,12%/yr при γ=10 (p = 0,007 ***)
  CE D>A: +1,85%/yr при γ=10 (p = 0,013 **)
  CE D−C: −0,30%/yr (p = 0,66) — разница незначима
  → C и D оба значимо превосходят A
  → Различие между C и D статистически незначимо
  → Общий класс «управление размером позиции на основе vpred»
    значимо улучшает экономические результаты
