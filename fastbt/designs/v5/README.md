# Сетка v5 (Ж-127 п. 2): состав и формат

Сетка v5 = оси «37 000» (линия Р, `moex_volatility/scripts/daily_upper_bound.py@6a7a4636` + `grid_scan_*`, `daily_full_opt_v5.py` того же коммита — только определения осей, без точек и результатов) + оси v4, которых нет в Р (`strategies_walkforward*.py@c22a4b36`) + расширения v2 (Ж-111, Ж-114 п. 5). Таблица «ось → откуда → значения → есть ли в движке» — `docs/otchety/2026-10-29_setka_v5.md` §1. Объём — `python3 -I fastbt/designs/v5/obem_v5.py` (§2 того же файла).

v5 — новая конструкция: защищённая калибровка (`fastbt/approach_a.py`) и сетка Р вместе не запускались, и печать предзащиты v5 не воспроизводит.

## Формат `kub_S{k}.yaml` (появится следующим PR, после слияния zh126)

```yaml
v: 3
format: progon-kub
setka: v5
sid: S1
period: train4               # первый проход — train4 (Ж-127 п. 5); В2 — отдельный период ledger
komissiya: 0.0004
fdr: t0                      # Ж-111 п. 12
sobol: {seed: <объявить до счёта>, scramble: true, N1: 32768}   # правило N1 — отчёт §2.3
istochniki: {zh126: <sha файлов zh126>, v4: c22a4b36, r: 6a7a4636}
signal:   {<ось>: {setka: [...], otkuda: "zh126_S1.yaml:<ключ>"}}
filtr:    {<ось>: {setka: [...], otkuda: ...}}
vhod:     {k_e: ..., T: ..., reentry: ...}
vyhod:    {stop_nach: [...], tejk: [...], trail: [...], bezubytok: [...], stop_v_plyus: [...], tau: [...],
           chast: [...], pir: [...], smena: [...], razmer_tip: [...], m_sily: [...], rang_tip: [...]}
faza3:    {consec: [1, 2], min_hold: [0, 5], cooldown: [0, 5, 10], min_sily: [0.0, 0.1, ..., 0.8]}
msp:      {uroven_razmera: [...], L: [...], sigma_cel: [...], okno: [21, 63]}
yakorya_progon: {sigma: rv22, proverka: bars5m, storona: obe, ...}
```

Порядок осей — это порядок размерностей Соболя, порядок значений — соседство для плато. Значение-составная ось (`stop_nach: atr:2.0`, `tejk: rr:1.5`) — одна ось Соболя; единица уровня — префикс значения. Сетка коммитится до счёта (`otbor_statistika.md` п. 1); расширение после просмотра — с датой и причиной, N обновляется. Новый `v: 3` — потому что разделы `faza3`, `msp` и составные значения меняют формат `progon-kub v: 2` (`fastbt/designs/progon/kub_S1.yaml`).

## Сверка с zh126

После слияния zh126 число уровней каждой оси в этом каталоге сверяется с `scripts/setki/obem_kuba.py`. Если в zh126 значений больше, чем в отчёте §1, действует zh126. Если меньше — это расхождение: оно записывается сюда строкой и возвращается кодеру выгрузки.
