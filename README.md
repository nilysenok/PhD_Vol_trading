# Прогнозирование волатильности и торговые стратегии на российском фондовом рынке

Репозиторий к кандидатской диссертации **Лысенок Никиты Ильича**, НИУ ВШЭ.

## Постановка задачи

Прогнозирование реализованной волатильности (RV) на горизонтах 1, 5 и 22 дня для 17 ликвидных российских акций (10-минутные данные MOEX, 2015–2026) и проверка того, насколько эти прогнозы повышают качество торговых стратегий по риск-доходности после реальных издержек.

## Глава 3. Прогнозирование волатильности

Семь семейств моделей, walk-forward валидация 2017–2025 (17 тикеров), основная метрика — QLIKE.

| Модель | h=1 | h=5 | h=22 |
|---|:---:|:---:|:---:|
| HAR-J | 0,524 | 0,796 | 0,961 |
| XGBoost | 0,403 | 0,956 | 1,127 |
| LightGBM | 0,382 | 0,821 | 0,870 |
| **Гибридная (XGB + LGBM + LSTM поверх HAR-J)** | **0,376** | **0,762** | **0,888** |

DM-тест Гибридная vs HAR-J: t = +13,55 / +3,41 / +7,03, p < 0,001 на всех горизонтах. На h=1 гибрид снижает QLIKE на 28% относительно HAR-J.

## Глава 4. Торговые стратегии и портфели

Шесть стратегий (S1 Mean Reversion, S2 Bollinger, S3 Donchian, S4 Supertrend, S5 Pivot Points, S6 VWAP) и четыре подхода к интеграции прогнозов:

- **A** — базовый (без прогнозов)
- **B** — адаптивные стопы (масштабирование по σ̂)
- **C** — режимная фильтрация (торговля только в подходящих режимах волатильности)
- **D** — таргетирование волатильности (размер позиции по σ̂)

Walk-forward 2022–2025, 17 тикеров, реальные комиссии MOEX (0,05%). Подход A работает с 2020 года, B/C/D — с 2022.

### MSP (Multi-Strategy Portfolio, ALL6 × EW, comm = 0,05%)

| Подход | Excess Sharpe | Trading Sharpe | Ann Return | Ann Vol | MDD | Exposure |
|---|:---:|:---:|:---:|:---:|:---:|:---:|
| A | 1,32 | 1,84 | 19,6% | 4,4% | −2,8% | 15,7% |
| B | 1,47 | 1,96 | 19,5% | 3,8% | −1,6% | 13,0% |
| C | 2,51 | 2,86 | 21,2% | 3,0% | −0,9% | 7,2% |
| D | 2,54 | 3,16 | 20,9% | 2,9% | −1,1% | 12,2% |
| IMOEX B&H | −0,69 | — | −7,1% | 30,8% | −70,3% | — |

Все МСП дают положительную доходность в каждом из 4 лет 2022–2025.

### Бутстрап (10 000 реплик)

| Тест | ΔSharpe | p-value |
|---|:---:|:---:|
| B > A | +0,15 | 0,009 *** |
| C > A | +1,19 | < 0,001 *** |
| D > A | +1,22 | < 0,001 *** |
| MSP-A > IMOEX | +2,05 | 0,001 *** |

### Экономическая ценность (CE, относительно A)

| γ | B − A | C − A | D − A |
|---|:---:|:---:|:---:|
| 3 | −0,09% | +1,77% ** | +1,46% * |
| 5 | −0,05% | +1,86% ** | +1,56% * |
| 10 | +0,04% | +2,07% *** | +1,79% ** |

Подходы C и D дают значимый прирост CE при γ ≥ 3, B — нет.

## Воспроизведение

```bash
pip install -r moex_volatility/requirements.txt
```

Pipeline главы 4 запускается стадиями:

```bash
cd moex_volatility/scripts
python stage3_walkforward.py      # walk-forward A на 2020–2025
python stage3c_bcd_30phases.py    # 30 фаз оптимизации B/C/D (B.01–D.10)
python stage4_hourly.py           # часовой walk-forward
python stage5_msp.py              # MSP по 4 схемам взвешивания × 3 наборам
python stage5b_perstrat_portfolio.py
python stage6_correlations.py
python stage7_bootstrap.py        # 10 000 реплик
python stage8_economic.py         # CE при γ ∈ {3, 5, 10}
python stage9_figures.py
python stage10_tables.py
```

`chapter4_master.py` в эту последовательность не входит и не запускает её. Это отдельный вспомогательный сканер: он пересчитывает подход A при комиссии 0,06% и прогоняет детерминированную сетку B/C/D. Сетка оптимизируется на тестовых годах (импортирует `bt_universal` из `daily_upper_bound.py`), поэтому её результаты — верхняя граница достижимого, а не валидный бэктест; в диссертацию они не входят и ни одним скриптом далее не читаются. Механизма автоповторов и сверки с целевыми значениями в проекте нет.
